# 分部与分卷审阅专属检查清单

## 一、先判上游分配是否全量落地

- 是否已列出本层应承接的上游内容
- 这些内容是否有明确落点、执行方式与可拆章程度
- 是否存在遗漏、缩水、悬空与只挂名不落实

## 二、分层检查口径

### 分部层

- 是否正确承接总纲层分配
- 是否能指导后续分卷落地

### 分卷层

- 是否把上一级分配内容落到卷概览、章清单、工件与章节规划
- 5/15 节奏是否标清
- 钩子类型是否有分布策略

### 单元案层

- 启动 → 砸实 → 对抗 → 翻案 → 余波 是否完整
- 是否既能阶段闭环，又能给主线供血

## 三、常见严重问题

- 没有 5/15 节奏布点
- 章中没有回报，章末只有硬钩
- 上游已分配内容大量缺失、悬空或被偷换成一句摘要
- 单元案闭环了，但没反哺主线

## 四、网文卷级留存专项核查

- 前 5 章是否形成连续追读链，而不是只靠第一章抓眼
- 卷中是否持续提供真实回报，而不是连续推进已知信息
- 钩子类型是否轮换，是否出现连续疲劳
- 单元案是否既能独立成立，又能给主线供血

## 五、卷末续购与跨卷交接核查

- 卷末是否留下更贵的新缺口，而不是漂亮收尾
- 下一卷第一屏要接的人、物、信息、关系、后果是否已经明确
- 单元案闭环后，主线拼图、人物代价或制度后果是否仍在推动后续

## 六、平台节拍与拆章适配核查

- 当前卷长、章长、钩子密度更偏哪类平台
- 若目标平台与当前卷节奏错配，是否已明确指出错配点
- 是否存在“结构能看，但一拆章就失温”的风险

## 七、章节微型剧本镜像核查

- 章清单是否继续下压到逐章微型剧本，而不是只停在标题 + 事件概述
- 每章是否写清唯一职责与不应包含
- 关键章节是否补出读者情感入口 / 出口、`1–4` 个 beat、承重 / 灵活标记
- 是否存在钩子链验证与基本就绪判定，而不是把成熟度判断交给下游临场猜

## 八、问题来源层与执行判定

- 问题是否区分为：卷层结构层 / 章清单层 / 微型剧本层
- 是否给出 Green / Yellow / Red 执行判定，而不是只有“能写 / 不能写”的空话
- 是否指出最先回炉的 `3` 章，以及每章最该补“钩子 / 回报 / 升级 / 关系位移”中的哪一项

## 九、商业节奏与失温拦截审阅（新增）

> 对应设计Skill新增的"单章节奏黄金公式与量化标准"和"防失温门禁"。分卷层的节奏缺陷必须在审阅环节拦截，否则下游正文将系统性偏慢偏闷。

### 9.1 单章节奏黄金公式对标

- 章清单中每章是否标注了"本章节奏模板"（起承转爽/过山车/信息揭露递进）？未标注的章，判为节奏设计未完成。
- 每章的节奏是否可对标3000字标准章节的黄金公式：0-300字钩子锁住 → 300-1500字推进蓄压 → 1500-2500字爽点释放 → 2500-3000字新钩子收束？
- 对于偏离黄金公式的特殊章节（如纯蓄力章或纯过渡章），是否有显式理由说明为什么该章可以例外？

### 9.2 对话占比硬约束

- 章清单中的每章是否标注了"预期对话占比"？未标注的章，判为对话设计未完成。
- 是否存在连续3章对话占比<40%（女频<45%）的情况？若存在，需检查该卷是否有对话密集型章节做调节。
- 前三章对话占比是否≥40%（女频≥50%）？若<30%，直接判为"开篇对话过稀"，不得放行。

### 9.3 防失温门禁

- 卷内是否存在连续4章以上"无新冲突/无回报/无人际关系变化"的纯推进段？若存在，判为P1设计缺陷。
- "纯推进段"定义复核：章内无新冲突升级、无人际关系翻面、无新线索暴露、无爽点/虐点触发。仅有情节推进属于纯推进。
- 每卷的回报章（兑现伏笔/给出"值回票价"感的章）占比是否≥20%？若<20%，判为回报稀薄。
- 章末钩子是否有确定性钩子（非总结/抒情/问号收尾）？钩子类型是否在章清单中标注？连续3章是否出现同类型钩子重复？
- 若连续3章章末钩子类型一致，判为钩子轮换疲劳。

### 9.4 章节功能位轮换

- 章清单每章是否有"功能位"标注（钩子/蓄力/爆发/回报/转承）？未标注的章清单不可放行。
- 五种功能位是否至少出现四种？若仅出现两种（如全是蓄力和转承），判为功能位单一。
- 同功能位连续出现是否超过上限——蓄力≤3章、转承≤2章、钩子≤3章、回报≤2章？超过上限须标记为"功能位超标"。
- 该卷是否完成至少2轮完整的"钩子→蓄力→爆发→回报"四拍循环（节奏短卷可降为1轮）？

### 9.5 情绪刺激点布点

- 章清单中每章是否标注了情绪刺激点类型（虐点/爽点/反转/信息释放/关系推进）和位置区间？
- 每章是否至少标注了1个情绪刺激点？若存在无标注的章，判为"无读感设计"。
- 连续5章内同类型情绪刺激是否重复超过3次？若是，判为情绪类型单调，需引入更多样化的刺激类型。
- 冲突升级链标记中是否同时包含了情绪刺激点信息（参见设计分卷大纲的升级链表格示例）？

### 9.6 平台节奏差异化适配

- 若目标平台为七猫：前三章是否高密度投放情绪刺激（每500字一个虐点/爽点）？章节功能位轮换周期是否≤3章完成一轮四拍？
- 若目标平台为番茄：前10章是否已将最强卖点全部打出（而非藏着掖着）？每章钩子强度是否≥"信息投放式"级别？
- 若目标平台为起点：蓄力期内是否有小刺激（信息碎片/关系细节）嵌入？中段是否有可讨论的情节点（本章说争议点/站队点）？
- 卷末是否留有更贵的新缺口（而非收平），以满足起点付费读者的跨卷续购驱动？

### 9.7 更新可复制性审阅

- 该卷的高强度情绪场景（易写的爽点/冲突/对话章）占比是否≥40%？若以环境渲染和心理描写为主要推进方式且占比过高，需标注"写作难度风险"。
- 是否存在可复用的章节节奏模板（起承转爽/过山车等），还是每章都是独创性结构？若全卷每章结构均无规律可循，判为"更新可持续性风险"。

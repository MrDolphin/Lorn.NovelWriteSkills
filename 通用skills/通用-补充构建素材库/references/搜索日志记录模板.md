# 搜索日志记录模板

> 每次网络搜索后必须立即记录到 `07_网络搜索汇总/` 下的日志文件中。
> 日志文件是素材库可持续性的命脉——不记录搜索日志等于没有搜过。

---

## 搜索日志追加格式

每次搜索追加一行到日志文件的搜索记录表中：

```markdown
| [序号] | [搜索关键词] | [搜索工具] | [有效结果数] | [备注] |
```

### 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 序号 | 是 | 同文件中递增的数字序号 |
| 搜索关键词 | 是 | 实际使用的搜索词 |
| 搜索工具 | 是 | Tavily / Bing / 智谱搜索 / 其他 |
| 有效结果数 | 是 | 清洗后实际入库的条目数 |
| 备注 | 推荐 | 搜索质量评估（如"跑偏" "高质量" "需再搜"） |

### 搜索记录示例

```markdown
| 1 | 总裁豪门言情小说 经典桥段 女主逆袭 追妻火葬场 名场面盘点 | Tavily | 8条 | 高质量，直接可用 |
| 2 | 网文 总裁文 写作素材 剧情桥段 打脸反杀 高能情节 | Tavily | 6条 | 中等质量，需二次加工 |
| 3 | 追妻火葬场 小说 名场面 虐男主经典桥段 盘点 | Bing | 0条 | 跑偏，搜索结果不相关 |
```

---

## 搜索结果摘要追加格式

当搜索结果有引用价值时，在搜索记录表下方追加摘要段落：

```markdown
### [方向名称]
**来源**：[来源描述]
**要点**：
- [关键发现 1]
- [关键发现 2]
- [关键发现 3]

---

```

### 示例

```markdown
### 追妻火葬场经典套路结构
**来源**：腾讯新闻/界面新闻深度分析
**要点**：
- 核心前提：男强女弱→男主虐女主→失去→追悔→追妻
- 组合套路的底层公式：先婚后爱 + 替身文学 + 带球跑 + 重生复仇 + 追妻火葬场
- 迭代趋势：2025-2026年的追妻火葬场正在经历"被重新审视"的转折点——单纯虐不再受欢迎，需要"女主成长"与"男主赎罪"双线并进
```

## 日志文件管理

### 追加到已有文件

搜索量 < 10 次时，追加到 `07_网络搜索汇总/` 下已有的日志文件末尾。

### 新建增量文件

搜索量 ≥ 10 次时，新建日志文件：

```text
07_网络搜索汇总/NN_增量搜索_YYYYMMDD.md
```

文件结构：

```markdown
# 增量搜索日志 YYYYMMDD

> **搜索日期**：YYYY-MM-DD
> **搜索方向**：[补充方向名称]
> **搜索轮次**：[N] 次

---

## 搜索记录

| # | 搜索关键词 | 工具 | 有效结果 | 备注 |
| - | ---------- | ---- | -------- | ---- |
| 1 | ... | ... | ... | ... |

---

## 搜索结果摘要

### [方向名称]
...
```

新建文件后须在 `00_素材库总索引.md` 中声明该文件的存在。

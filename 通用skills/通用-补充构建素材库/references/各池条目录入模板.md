# 各池条目录入模板

> 本文件提供各素材池的条目录入模板与填写示例。
> 每条入库前必须对照本模板检查字段完整性。

## 01_情节桥段池 条目模板

### 情节池模板

```markdown
### [编号] [标题]
- **字数**：[数字]字-[数字]字
- **情绪锚**：[核心情绪词]
- **梗概**：[1-3段话描述完整情节轮廓]
- **设计逻辑**：[该桥段为什么有效]（可选但推荐）
- **适配故事面**：[故事面编码]（可选但推荐）
```

### 情节池示例（摘自 A_职场商战桥段.md）

```markdown
### A01-03 价格谈判中的沉默战术
- **字数**：2000-4000字
- **情绪锚**：心理战
- **梗概**：对方报了一个超出底线的价格，苏棠不回话，端起杯子喝水。对方加了一个条件，她还是不说话。对方开始慌了——"您觉得哪里不合适？"她放下杯子："我在等您把真正能谈的价格说出来。"
- **设计逻辑**：沉默是最有力的谈判武器——让对方先沉不住气
```

## 03_人物设定池 条目模板

### 人物设定模板

```markdown
### [编号] [人物标签]
- **人设标签**：[一句话核心记忆点]
- **底层欲望**：[驱动这个人物的核心需求]
- **核心矛盾**：[与外部世界或自身的核心冲突]
- **反差细节**：[让人物立体的反差行为（1-3个）]
- **声口特征**：[标志性说话方式、用词习惯]
- **成长弧光**：[初始状态→转变→终态]
- **适配故事面**：[故事面编码]（可选）
```

### 人物设定示例

```markdown
### C01 隐忍型霸总
- **人设标签**："把所有人的事都扛在自己肩上，却从不解释的半路总裁"
- **底层欲望**：证明自己不需要靠家族也能撑起一切
- **核心矛盾**：极度渴望被理解，但习惯性把所有事烂在肚子里
- **反差细节**：① 开股东大会时气场全开，回到家对着猫说话；② 签几千万的合同手都不抖，但给她发消息要删三遍
- **声口特征**：公事公办时用短句命令；私底下说话会不自觉地放慢语速、压低音量
- **成长弧光**：从"我处理就好"的孤立者→"我需要你"的成长者
```

## 竞品拆解 条目模板

> 竞品拆解底稿**不是**直接素材条目。从拆解中提取的可复用桥段/手法/金句应清洗后归入对应的01-05素材池。
> 此处模板仅用于在竞品拆解目录中记录分析底稿。

### 模板

```markdown
### [编号] [作品名] [提取段落描述]
- **原文段落**：[精选的原文片段]
- **拆解分析**：[作者用了什么手法、这段为什么抓人、可以借鉴什么]
- **适用场景**：[本段落可复用到什么类型的情节/场景]
```

### 示例

```markdown
### J01 《封总S1》 开篇三章追读链
- **原文段落**：（精选的开篇三章内容）
- **拆解分析**：① 第一章前500字设置了三个悬念钩子（身份谜团+冲突+情感张力）；② 每章结尾都是情绪峰值，不留给读者喘息空间；③ 前五章每章都有一个小爽点
- **适用场景**：总裁文/追妻火葬场题材的开篇节奏设计
```

## 题材新增池 条目模板（06+ / 自定义编号）

> 当题材需要新建通用 01-05 体系之外的池时，使用以下模板。
> 池编号从 06 开始顺延，池名自定。

### 通用新增池模板

```markdown
### [编号] [标题]
- **字数**：[数字]字-[数字]字
- **情绪锚**：[核心情绪词]
- **梗概**：[1-3段话描述完整条目轮廓]
- **核心机制**：[该条目的关键设计原理/技术逻辑/空间结构]
- **写作抓手**：[作者写作时可具体使用的描述元素/动作链/感官细节]
```

### 各新增池类型的字段差异

| 新增池类型 | 建议编号 | 额外强制字段 | 说明 |
| --- | --- | --- | --- |
| 技术设定档案库 | 06 | **核心机制**、**边界与代价**、**可证据化方式** | 技术原理怎么写进叙事、有什么限制、如何用证据展示 |
| 空间场景库 | 06/07 | **感官清单**、**空间常态与微反常** | 空间的视觉/听觉/嗅觉细节，以及打破常态的那个"不对" |
| 诡计手法库 | 06/07 | **手法逻辑**、**必要条件**、**漏洞/破解方式** | 推理诡计的完整设计与可破解性 |
| 能力设定库 | 06 | **能力规则**、**代价/冷却**、**进化路径** | 异能/超能力的具体效果、限制与成长 |
| 义体改造库 | 06/07 | **改造部位**、**功能**、**后遗症/风险** | 赛博改造的技术参数与人性代价 |
| 人机关系模板库 | 07 | **关系模式**、**信任裂痕触发点**、**反转可能性** | AI-人类关系的典型剧本 |

### 新增池示例：技术设定档案库（06_技术设定档案库）

```markdown
### 06-01 跃迁引擎的"不可观测"限制
- **字数**：2000-3000字
- **情绪锚**：技术敬畏 + 悬疑
- **梗概**：跃迁引擎生效期间，舰船处于"不可观测"状态——任何传感器都无法追踪。但这意味着舰船每次跃迁都是一次信任跳跃：你不知道穿出点是否安全，因为你无法在穿越过程中感知外面的变化。
- **核心机制**：跃迁时舰船从当前时空完全脱离，到达预定坐标后才重新出现。期间无法接收或发送任何信号。
- **边界与代价**：① 每次跃迁消耗大量能量，连续跃迁不超过 3 次；② 跃迁坐标误差随距离增长（每百光年误差 0.1 秒差距）；③ 跃迁穿出时若坐标被占据，后果不可逆。
- **可证据化方式**：跃迁日志显示的能量曲线、舰桥上的"不可观测"指示灯、跃迁后的坐标校准报告。
- **写作抓手**：跃迁前倒数——舰桥沉默——所有人盯着空无一物的屏幕——穿出瞬间刺耳的碰撞警报（如果有东西在穿出点等着他们）。
```

### 新增池示例：空间场景库（07_星舰场景库）

```markdown
### 07-01 舰桥——权力与信息的交汇点
- **字数**：500-1500字
- **情绪锚**：压力 + 秩序感
- **梗概**：舰桥是全舰的中枢——舰长座位在最高层，下面是战术/导航/通讯三位操作员。弧面主屏实时显示星图与传感器数据。照明偏暗，只有屏光与按钮指示灯。空气里有淡淡的臭氧味（电子设备散热）。
- **感官清单**：① 视觉——暗光环境下冷蓝色屏光、不断刷新的数据流；② 听觉——低频设备嗡鸣、键盘点击声、通讯频道里压缩过的语音；③ 嗅觉——臭氧+空调风+偶尔的咖啡味；④ 触觉——操作台金属表面冰凉、座椅在加速度下的推背感。
- **空间常态**：有序的忙碌——每个人都知道自己的位置和职责。
- **微反常**：① 战术位突然静下来了（他看到了不该出现的东西）；② 臭氧味突然变浓（电路过载）；③ 舰长座位转向了不该转的方向。
```

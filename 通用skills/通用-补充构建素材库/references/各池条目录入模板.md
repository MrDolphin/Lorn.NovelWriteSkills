# 各池条目录入模板

> 本文件提供各素材池的条目录入模板与填写示例。
> 每条入库前必须对照本模板检查字段完整性。

---

## 01_情节桥段池 条目模板

### 情节池模板

```markdown
### [编号] [标题]
- **字数**：[数字]字-[数字]字
- **情绪锚**：[核心情绪词]
- **梗概**：[1-3段话描述完整情节轮廓]
- **设计逻辑**：[该桥段为什么有效]（可选但推荐）
- **适配故事面**：[故事面编码]（可选但推荐）
```

### 情节池示例（摘自 A_职场商战桥段.md）

```markdown
### A01-03 价格谈判中的沉默战术
- **字数**：2000-4000字
- **情绪锚**：心理战
- **梗概**：对方报了一个超出底线的价格，苏棠不回话，端起杯子喝水。对方加了一个条件，她还是不说话。对方开始慌了——"您觉得哪里不合适？"她放下杯子："我在等您把真正能谈的价格说出来。"
- **设计逻辑**：沉默是最有力的谈判武器——让对方先沉不住气
```

## 03_人物设定池 条目模板

### 人物设定模板

```markdown
### [编号] [人物标签]
- **人设标签**：[一句话核心记忆点]
- **底层欲望**：[驱动这个人物的核心需求]
- **核心矛盾**：[与外部世界或自身的核心冲突]
- **反差细节**：[让人物立体的反差行为（1-3个）]
- **声口特征**：[标志性说话方式、用词习惯]
- **成长弧光**：[初始状态→转变→终态]
- **适配故事面**：[故事面编码]（可选）
```

### 人物设定示例

```markdown
### C01 隐忍型霸总
- **人设标签**："把所有人的事都扛在自己肩上，却从不解释的半路总裁"
- **底层欲望**：证明自己不需要靠家族也能撑起一切
- **核心矛盾**：极度渴望被理解，但习惯性把所有事烂在肚子里
- **反差细节**：① 开股东大会时气场全开，回到家对着猫说话；② 签几千万的合同手都不抖，但给她发消息要删三遍
- **声口特征**：公事公办时用短句命令；私底下说话会不自觉地放慢语速、压低音量
- **成长弧光**：从"我处理就好"的孤立者→"我需要你"的成长者
```

## 04_轻悬疑反转池 条目模板

### 悬疑反转模板

```markdown
### [编号] [标题]
- **字数**：[数字]字-[数字]字
- **情绪锚**：[悬疑/发现/情感冲击等]
- **梗概**：[发现→推导→揭晓的完整逻辑链]
- **证据形态**：[实物/文件/照片/录音/行为异常等]
- **前提铺垫**：[反转成立需要提前埋下的条件]
```

### 悬疑反转示例（摘自 D_轻悬疑桥段池.md）

```markdown
### D01-01 藏在旧书里的合同复印件
- **字数**：3000-5000字
- **情绪锚**：发现
- **梗概**：苏棠在父亲书房整理遗物时，一本旧书里夹着一份合同复印件。不是原件——是复印件。边缘泛黄，但字迹清晰。合同的日期是她结婚前六个月。签字人：父亲。
- **证据形态**：实物（合同复印件）
- **前提铺垫**：前文需交代父亲生前有在书里夹东西的习惯，且婚前的家庭经济状况有疑点
```

## 06_竞品原文提取 条目模板

### 模板

```markdown
### [编号] [作品名] [提取段落描述]
- **原文段落**：[精选的原文片段]
- **拆解分析**：[作者用了什么手法、这段为什么抓人、可以借鉴什么]
- **适用场景**：[本段落可复用到什么类型的情节/场景]
```

### 示例

```markdown
### 06-01 《封总S1》 开篇三章追读链
- **原文段落**：（精选的开篇三章内容）
- **拆解分析**：① 第一章前500字设置了三个悬念钩子（身份谜团+冲突+情感张力）；② 每章结尾都是情绪峰值，不留给读者喘息空间；③ 前五章每章都有一个小爽点
- **适用场景**：总裁文/追妻火葬场题材的开篇节奏设计
```

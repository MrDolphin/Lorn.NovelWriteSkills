# 缺件诊断检查表

> 补充素材库前使用此表执行系统化的缺件诊断。
> 输出一份标准化的缺件报告给用户确认。

---

## 诊断步骤

### 步骤 A：读取总索引

从 `00_素材库总索引.md` 中提取以下信息：

- **当前各池条目数**与**各卷素材密度目标**对比
- **本轮已覆盖的搜索方向**
- **总索引上次更新日期**
- **总索引声明的各池编号与文件名**

### 步骤 B：各池实际盘点

| 检查项 | 检查方法 | 记录 |
| --- | --- | --- |
| 01A 职场商战桥段实际条目数 | 读取 A_职场商战桥段.md 末尾编号 | |
| 01B 家族内斗桥段实际条目数 | 读取 B_家族内斗桥段.md 末尾编号 | |
| 01C 关系推进桥段实际条目数 | 读取 C_关系推进桥段.md 末尾编号 | |
| 02 名场面实际条目数 | 读取 F_名场面高光池.md 末尾编号 | |
| 03 人物设定池是否为空 | 检查 03_人物设定池/ 下文件数量 | |
| 03 各人物子文件实际条目数 | 读取各子文件末尾编号 | |
| 04 轻悬疑反转实际条目数 | 读取 D_轻悬疑桥段池.md 末尾编号 | |
| 05 冷幽默毒舌实际条目数 | 读取 E_冷幽默毒舌池.md 末尾编号 | |
| 竞品拆解数量 | 检查 竞品拆解/ 下文件数量 | |
| 搜索日志轮次 | 读取 搜索日志/ 下文件 | |

### 步骤 C：搜索日志缺口分析

读取 `搜索日志/` 下所有文件，提取各行搜索关键词，统计已覆盖的方向。与总索引中声明的"本轮搜索覆盖"表交叉比对。

**常见缺口模式**：

- 某情绪锚类型完全未覆盖（如"催泪"类没有搜索记录）
- 某素材池方向搜索但有效结果数为 0（Bing 搜索跑偏情况）
- 某子类（如人物设定池）完全没有搜索记录

### 步骤 D：情绪锚索引完整性检查

总索引中维护了一张"情绪锚索引"表。检查：

- 该表是否为空或已过时（更新日期是否与总索引声明一致）
- 是否存在频次 ≥ 3 但未入索引的情绪锚（扫描各池文件的 `**情绪锚**：` 字段）
- 上次补充后是否忘记更新此表

### 步骤 E：文件分裂阈值检查

检查各池文件是否接近或超过分裂阈值：

| 检查项 | 阈值 | 当前状态 |
| ------ | ---- | -------- |
| 01A 职场商战桥段条目数 | >100 → 分裂 | |
| 01B 家族内斗桥段条目数 | >100 → 分裂 | |
| 01C 关系推进桥段条目数 | >100 → 分裂 | |
| 02 名场面高光池条目数 | >100 → 分裂 | |
| 05 冷幽默毒舌池条目数 | >100 → 分裂 | |
| 各文件内 `##` 子类数 | >5 → 拆分子文件 | |

### 步骤 F：题材子库注册表检查

- 总索引末尾"子素材库注册表"中是否登记了所有已存在的题材子库
- 各题材子库的 `_索引.md` 是否与 `00_素材库总索引.md` 结构一致

### 步骤 G：空池/空子文件检查

- `03_人物设定池/` 下是否已建立子文件？
- 各子文件是否有实际条目，还是只有标题？
- `竞品拆解/` 下各文件是否都有内容？

---

# 通用-补充构建素材库

> 本 Skill 负责在已有素材库中执行"缺件诊断→定向搜索→格式落盘→索引更新→写入搜索日志"的全流程闭环。
> 素材库的构建理念、分类体系与方法论详见 `通用skills/写作研究/写作技法_网文作者素材库构建完全指南.md`。

## 硬规则（强制）

### 素材库目录约定

本 Skill 默认素材库位于 `素材库/`（项目根目录下），结构约定如下：

```text
素材库/
├── 00_素材库总索引.md              # 总索引（必须维护）——含题材交叉索引与情绪锚索引
│
│   ┌─ 【素材池区】写作时直接翻 ──┐
│   │                              │
├── 01_情节桥段池/                  # ★ 可直接用于写作的素材
│   ├── A_职场商战桥段.md
│   ├── B_家族内斗桥段.md
│   ├── C_关系推进桥段.md
│   └── ...                         # 当某子类超 100 条 → 拆分为子目录
├── 02_名场面高光池/                # ★
│   └── F_名场面高光池.md
├── 03_人物设定池/                  # ★
│   └── (子文件参考"深化规则")
├── 04_轻悬疑反转池/                # ★
│   └── D_轻悬疑桥段池.md
├── 05_冷幽默毒舌池/                # ★
│   └── E_冷幽默毒舌池.md
│   │                              │
│   └─────── 扩展方向 ① ──────────┘
│
│   ┌─ 【底稿区】研究参考 ────┐
│   │                          │
├── 竞品拆解/                     # ⓘ 竞品分析底稿
│   ├── 封总S1_分析.md
│   └── ...
├── 搜索日志/                      # ⓘ 搜索溯源
│   ├── 01_初始搜索汇总.md
│   └── ...
│   │                          │
│   └──────────────────────────┘
│
├── [题材名]/                      # 扩展方向 ②：题材级子素材库
│   ├── 该题材_索引.md
│   ├── 01_情节桥段池/             #  13/16/17 子类去编号，用题材名做前缀
│   ├── 02_名场面高光池/
│   ├── 03_人物设定池/
│   ├── 04_轻悬疑反转池/
│   ├── 05_冷幽默毒舌池/
│   ├── 竞品拆解/
│   └── 搜索日志/
│
└── [另一题材名]/                  # 每个题材一个同级子素材库
    └── ...
```

**三轴设计理念**：
- **扩展轴（题材层）**：当一个题材积累的素材量超过通用01-05池的覆盖范围（参见"可扩展——题材层"规则），在同级创建 `题材名/` 作为子素材库
- **深化轴（文件分裂）**：单文件超 100 条时，按子类拆分为子目录+多个文件（参见"可深化——文件分裂"规则）
- **搜索轴（情绪锚索引）**：`00_素材库总索引.md` 末尾维护跨池的情绪锚汇总表，配合 `grep_search` 快速定位（参见"可搜索——情绪锚索引"规则）

### 可扩展——题材层

> **问题**：01-05 通用池服务于当前小说的情节供血。但当你开新题材（如从都市职场转悬疑推理），不同题材的情绪锚/节奏/人设差异巨大，混在同一个池里互相干扰。

**触发条件**：出现以下任一情况时，应在 `素材库/` 同级下新建 `题材名/` 子素材库：
- 当前项目切换到不同题材（如从"都市职场"切到"太空科幻"）
- 通用池中"与当前题材无关"的条目数超过 30%（说明池已被稀释）
- 同一题材的素材总量超过 200 条，且仍在快速增长

**题材子库结构**：

```text
素材库/
├── (通用 00_总索引 + 01-05 池）
│
├── 都市职场/                    # 题材级子素材库
│   ├── 都市职场_索引.md         # 必建，格式同 00_总索引
│   ├── 01_情节桥段池/           # 子类去编号前缀，直接用题材名
│   ├── 02_名场面高光池/
│   ├── 03_人物设定池/
│   ├── 04_轻悬疑反转池/
│   ├── 05_冷幽默毒舌池/
│   ├── 竞品拆解/
│   └── 搜索日志/
│
└── 太空科幻/
    └── ...
```

**题材子库规则**：
1. **入口文件**：每个题材子库必须有一个 `题材名_索引.md`，格式参照 `00_素材库总索引.md`
2. **编号去前缀**：题材子库的子文件不使用前缀字母（如 `A_职场商战桥段.md`）——直接以意义命名（如 `太空遭遇战.md`），避免与通用池的编号体系冲突
3. **优先查子库**：写作时先查当前题材的子库，再回退到通用池。题材子库中不存在的通用桥段，用通用池补位
4. **新建后注册**：题材子库建好后，必须在 `00_素材库总索引.md` 末尾"子素材库注册表"中登记（路径+创建日期+覆盖池）

### 可深化——文件分裂

> **问题**：单文件持续追加条目（如职场商战 80+ 条、冷幽默 100+ 条），迟早会因文件过长导致查找困难和编辑性能下降。

**分裂阈值**：

| 计量指标 | 触发分裂 | 建议动作 |
|----------|---------|---------|
| 单文件条目数 | 超过 **100 条** | 拆为子目录 |
| 单文件行数 | 超过 **500 行**（不含空行与分隔线） | 拆为子目录 |
| 文件内子类数 | 超过 **5 个 `##` 二级标题** | 每个二级标题拆为单独文件 |

**分裂操作规范**：

以当前 `A_职场商战桥段.md`（≈80+条，含 A01-A04 四个子类）为例：

```text
分裂前：                        分裂后：
01_情节桥段池/                  01_情节桥段池/
├── A_职场商战桥段.md   →       ├── A_价格博弈与竞标/
│                               │   ├── _index.md        # 本目录索引
│                               │   ├── 01_沉默战术.md
│                               │   └── ...
│                               ├── B_会议对决与职场博弈/
│                               │   ├── _index.md
│                               │   └── ...
│                               └── C_行业声誉与危机管理/
│                                   ├── _index.md
│                                   └── ...
```

**分裂硬规则**：
1. **保留入口文件**：原文件保留为入口，内容替换为本目录的文件列表索引（`_index.md` 格式），各子文件条目的编号前缀保持不变
2. **`_index.md` 格式**：

```markdown
# [池名]

> **原文件**：`原文件名.md`（已分裂为子目录，YYYY-MM-DD）
> **总条目**：[N] 条

| 子文件 | 内容 | 条目数 |
|--------|------|--------|
| 01_沉默战术.md | 价格博弈与竞标对决 | 20+ |
| 02_会议对决.md | 会议博弈与职场对决 | 15+ |
| ... | ... | ... |
```

3. **全局编号不变**：子文件内的条目编号（如 `A01-07`）继承原文件体系，不重新编号
4. **子目录名称**：用原二级标题的缩写，最多 8 个中文字符
5. **分裂后更新总索引**：在 `00_素材库总索引.md` 的"文件结构变更记录"表中登记分裂操作

### 可搜索——情绪锚索引

> **问题**：素材散在多个池的多个文件中，写某一章时需要"一个爽的打脸场面"——但不知道它在哪个池、哪个文件里。

**方案**：在 `00_素材库总索引.md` 末尾维护一张**跨池的情绪锚索引表**。

**情绪锚索引表格式**：

```markdown
## 情绪锚索引

| 情绪锚 | 条目示例（池/编号/标题） | 池 | 数量 |
|--------|-------------------------|----|------|
| 爽     | 01A｜A01-01 用对手漏洞反制 | 情节桥段池-职场商战 | 30+ |
| 爽     | 02｜F01 签字离婚           | 名场面高光池 | 20+ |
| 心理战 | 01A｜A01-03 沉默战术       | 情节桥段池-职场商战 | 15+ |
| 悬疑   | 04｜D01-01 旧书里的合同    | 轻悬疑反转池 | 50+ |
| 毒舌   | 05｜E01-01 女主→男主       | 冷幽默毒舌池 | 100+ |
| ...    | ...                       | ... | ... |
```

**构建与维护规则**：
1. **初始构建**：在每次大规模补充后，由助手扫描各池文件的 `**情绪锚**：` 字段，汇总去重后写入此表
2. **索引条目的条件**：情绪锚出现频次 ≥ 3 次的才入索引（低频锚不值得维护）
3. **维护时机**：每次补充落盘 + 总索引更新时，同时更新此表
4. **配合 grep 搜索**：写作时，在 VS Code 中按 `Ctrl+Shift+F`，用情绪锚关键词搜索即可跨池定位：

```text
# 示例：搜索所有"心理战"标签的素材
Ctrl+Shift+F → grep: "情绪锚.*心理战" → 路径: 素材库/
```

5. **路径级精准搜索**：如果需要限定池：

```text
# 只在悬疑池中搜"证据"
grep: "证据形态" → 路径: 素材库/04_轻悬疑反转池/
```

6. **索引不做实时同步**：素材条目持续增加，索引在每次补充操作时批量更新即可，不需要每次新增一条就同步一次

### 条目录入格式规范

所有素材池中的条目必须遵循以下字段结构。**缺字段的条目不得入库**。

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| **标题** | 是 | 精炼概括本条素材的名称 | "用对手的漏洞反制对手" |
| **字数** | 是 | 该素材展开成文的预计字数范围 | "3000-5000字" |
| **情绪锚** | 是 | 核心情绪标签（爽/虐/燃/悬疑/催泪/暗爽/心理战等） | "专业碾压" |
| **梗概** | 是 | 1-3段话描述情节/场景/冲突的完整轮廓 | "招标会上，对手用苏棠上一家客户的数据来攻击她…" |
| **设计逻辑** | 推荐 | 该素材为什么有效，核心设计意图 | "沉默是最有力的谈判武器——让对方先沉不住气" |
| **适配故事面** | 推荐 | 该素材对应哪个故事面/M0/X线 | "X01 事业线" |

名场面高光池的条目**额外强制**包含 **金句** 字段——"读者想截图发朋友圈"的核心台词或旁白。

### 补充前必须做缺件诊断

在任何补充动作之前，必须先读取 `00_素材库总索引.md`，检查缺件方向：

1. **素材密度对标**：对比各池当前条目数与总索引中声明的"各卷素材密度目标"，找出低于目标密度的池
2. **覆盖方向缺口**：总索引中"本轮大规模搜索覆盖"表记录了已覆盖的方向，未覆盖的方向即为搜索缺口
3. **搜索日志检查**：读取 `搜索日志/` 下的搜索记录，确认某方向是否已做过搜索、搜索质量如何
4. **空池检查**：检查各池文件是否为空或条目不足（如当前 `03_人物设定池/` 为空）

得到缺件清单后，再规划补充顺序和搜索策略。

### 网络搜索范式

补充素材时，搜索策略按素材池类型区分：

| 池类型 | 推荐搜索方向 | 关键词组合 |
|--------|-------------|-----------|
| 情节桥段（01） | 按场景/冲突类型搜 | "职场商战 经典谈判桥段 应对刁难 反转" |
| 名场面（02） | 按情绪锚搜 | "打脸名场面 爽文 高光时刻 女主逆袭 社交传播" |
| 人物设定（03） | 按人设/身份搜 | "霸总人设 经典性格 大佬细节描写 反派模板" |
| 悬疑反转（04） | 按手法类型搜 | "轻悬疑 反转手法 真相揭露 伏笔回收 合同谜团" |
| 冷幽默（05） | 按性别/身份搜 | "女主毒舌金句 怼人 冷幽默 女频嘴炮" |
| 竞品拆解 | 按平台+题材搜 | "起点 女频 总裁文 追妻火葬场 爆款 结构拆解" |

- 每次搜索需记录到 `搜索日志/`（格式见后）
- 每条搜索结果必须清洗成标准素材格式后才能入库
- 不得直接粘贴搜索结果原文作为素材条目（违反"条目录入格式规范"）

### 总索引必须同步更新

每次补充素材落盘后，必须更新 `00_素材库总索引.md`：

- 更新对应素材池的"素材条目"计数
- 在"本轮搜索覆盖"表中追加本次补充的搜索方向和产出条目数
- 更新"更新日期"为当天

### 搜索日志必须同步记录

每次执行网络搜索后，必须在 `搜索日志/` 下的对应文件中追加搜索记录行，格式如下：

```text
| [序号] | [搜索关键词] | [搜索工具] | [有效结果数] | [备注] |
```

若搜索量大，可在 `搜索日志/` 下新建 `03_搜索素材汇总.md` 等增量文件，但需在总索引中声明。

### 条目录入质量门禁

每条素材在落盘前必须通过以下自检：

- [ ] 字段完整（至少标题+字数+情绪锚+梗概填充）
- [ ] 梗概有画面感：不是一个抽象概念，而是读者能直接想象的场景
- [ ] 情绪锚明确：读者知道读了这段是什么情绪预期
- [ ] 有区分度：不是"不说也知道"的套路描述，而是有具体细节/反转/金句
- [ ] 不与同池已有条目雷同（检查同池文件）
- [ ] 情绪锚/字数估算合理（字数估算偏差不超过 30%）

## 执行流程

### 步骤 1：缺件诊断

用户明确指定补充目标时，跳到步骤2。

用户未指定时，执行缺件诊断：

1. 读取执行目录下的 `00_素材库总索引.md`
2. 读取各池文件，检查实际条目数与总索引声明的匹配度
3. 检查 `03_人物设定池/` 等池是否为空
4. 检查 `搜索日志/` 下已覆盖的方向与缺口
5. 输出缺件报告（格式参考 `references/缺件诊断检查表.md`），提交用户确认

### 步骤 2：用户确认补充方向

展示缺件报告后，与用户确认：

```
补充方向建议：
├── 优先补充：[池名] — [缺的具体方向]
├── 条目数量目标：[N] 条
├── 搜索关键词：[初步搜索关键词]
├── 情绪锚覆盖：[情绪类型列表]
└── 确认 / 调整？
```

### 步骤 3：定向搜索

1. 按确认的补充方向，执行网络搜索
2. 清洗搜索结果，提取可用条目
3. 每执行一次搜索，立即记录到搜索日志

### 步骤 4：条目格式化与落盘

1. 将清洗后的条目按标准格式写入对应的池文件
2. 引用同池已有条目的编号（如果存在继发关系，如 `A01-06 基于A01-01的变体`）
3. 新条目使用池内递增编号

### 步骤 5：总索引更新

1. 更新 `00_素材库总索引.md` 中的素材计数
2. 在"本轮搜索覆盖"表中追加本次补充的搜索方向与产出
3. 更新总索引的"情绪锚索引"表（去重汇总本次新条目的情绪锚，频次 ≥ 3 的入索引）
4. 更新总索引的"更新日期"

### 步骤 6：搜索日志归档

1. 如果本次搜索量 < 10 次：追加到 `搜索日志/` 下已有的日志文件中

## 各池类型差异

### 01_情节桥段池（A/B/C）

- 每条必须包含清晰的情绪锚——读者预期读完这段的情绪
- 梗概必须包含具体人物、场景、对手、冲突、转折
- 设计逻辑可选但推荐——解释该桥段为什么有效

### 02_名场面高光池（F）

- 额外强制字段：**金句**
- 名场面必须达到"读者想截图发朋友圈"的传播级效果
- 优先收集"打脸反杀""催泪情感""反转震撼"三类

### 03_人物设定池

- 当前为空池，初次填充使用以下子类别结构：

```text
03_人物设定池/
├── A_霸总人设.md
├── B_女主设定.md
├── C_反派模板.md
├── D_配角原型.md
└── E_人物关系动态模板.md
```

- 人物条目的格式（区别于情节条目）：

| 字段 | 说明 |
|------|------|
| **人设标签** | 核心记忆点（如"极度信奉道教戒律的道士"） |
| **底层欲望** | 驱动这个人物的核心需求 |
| **核心矛盾** | 他/她与外部世界或自身的核心冲突 |
| **反差细节** | 让人物立体的反差行为 |
| **声口特征** | 标志性说话方式、用词习惯 |
| **适配故事面** | 可服务于哪些故事面/X线 |

### 04_轻悬疑反转池（D）

- 每条必须包含清晰的"发现→推导→揭晓"逻辑链
- 细节必须包含具体证据形态（实物/文件/照片/录音/行为异常等）
- 反转不能依赖"巧合"，必须有合理前置铺垫

### 05_冷幽默毒舌池（E）

- 每条必须适配目标人物的身份关系场景（怼男主/怼白月光/怼恶配角等）
- 金句标准：聪明不刻薄、犀利不伤人、一本正经地荒诞
- 优先收集"可三连击"的对话组——不是孤立一句话，而是有来有回的对话组合

### 竞品拆解

> 竞品拆解目录存放的是面向整部作品的分析底稿，**不是**可直接取用的素材条目。
> 竞品拆解中提取出的可复用桥段、手法、金句，应清洗后归入对应的01-05素材池。
> 若需直接制作素材条目，使用"通用-分析竞对作品"Skill。

- 条目采用"原文段落+拆解分析"的双段结构
- 拆解分析必须包括：作者用了什么手法、这段为什么抓人、可以借鉴什么
- 并非全文照搬，而是精选"可复用的技巧片段"

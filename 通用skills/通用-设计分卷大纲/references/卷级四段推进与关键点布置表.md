# 卷级四段推进与关键点布置表

适用于把单卷从“很多章、很多事件”校准成“有卷内起承转合、又能继续给总纲供血”的可拆卷结构。

## 一、先明确：单卷不是缩小版总纲，但也不能没有结构骨架

一个卷纲不必把全书九部件完整重演一遍，但至少要具备卷级四段推进：

1. 卷内布局
2. 卷内反应
3. 卷内进攻
4. 卷内解决 / 卷尾缺口

## 一点五、卷级来源层速判（新增）

- `卷段职责层`：布局、反应、进攻、解决 / 卷尾缺口四段是否各司其职。
- `关键点布置层`：本卷扰动点、第一情节点、中间点、卷尾前最后关键信息是否明确。
- `卷尾交接层`：本卷如何阶段闭环、同时把主线和下一卷缺口交出去。

如果单卷只有“持续调查 / 持续升级 / 持续推进”，读起来往往会散。

## 二、卷级四段的默认职责

### 1. 卷内布局

任务：

- 建立本卷主问题
- 让本卷新资源 / 新人物 / 新局面入场
- 明确这一卷与上卷相比新增了什么压力

这一段最怕：

- 重复回顾上卷
- 迟迟不给本卷独立抓手

### 2. 卷内反应

任务：

- 主角对本卷新局面先试、先躲、先摸索
- 暴露本卷阶段短板
- 让局面看似可解，实则越走越窄

这一段最怕：

- 主角刚入卷就全面掌控
- 线索只增不变，没有误判和代价

### 3. 卷内进攻

任务：

- 主角开始主动布局
- 卷内主要攻防在此真正成型
- 卷级卖点从“看见”转为“兑现 / 转化”

这一段最怕：

- 和反应段只是同一件事做得更久
- 没有明显主动权变化

### 4. 卷内解决 / 卷尾缺口

任务：

- 本卷阶段性问题得到处理
- 主线拼图更新
- 留下逼下一卷接棒的行动性缺口

这一段最怕：

- 卷内问题没解决，硬拖到下卷
- 卷尾只有抽象悬念，没有新驱动

## 三、卷级关键点至少要看四个

### 1. 本卷扰动点

- 这一卷最先把读者拽进去的事件 / 异样 / 代价是什么？

### 2. 卷内第一情节点

- 什么时候本卷主问题真正成立？
- 主角从“接到新情况”变成“必须处理本卷核心麻烦”的点在哪里？

### 3. 卷内中间点

- 哪个新认知、新误差或新压力，把本卷从反应推向进攻？

### 4. 卷尾前最后关键信息

- 哪个信息让卷内解决成为可能，同时把主线推进到更深一层？

## 四、卷纲最小布置表

| 卷级位置 | 主角主要在做什么 | 本卷阻力 | 卷内回报 / 坏消息 | 与主线关系 | 卖点作用 |
| --- | --- | --- | --- | --- | --- |
| 卷内布局 | 进入新局面 | 新资源 / 新敌意 / 新压力 | 第一刺激 | 接上卷余波 | 重新显影 |
| 卷内第一情节点 | 本卷主问题成立 | 本卷核心麻烦浮现 | 被迫入局 | 主线再咬合 | 转成任务 |
| 卷内反应 | 试探、误判、摸索 | 外部阻力 + 卷内短板 | 连续受挫 / 小发现 | 为主线探路 | 带出代价 |
| 卷内中间点 | 新认知 / 新误差 | 压力改向 | 方向改变 | 主线拼图更新 | 二次升级 |
| 卷内进攻 | 主动布局与反击 | 阻力升级 | 扳回一城 / 更险 | 对主线施加主动影响 | 卖点兑现 |
| 卷尾前关键认知 | 最后一批卷内关键信息 | 真阻力显影 | 决战前置 | 主线缺口扩大 | 卖点冲顶 |
| 卷内解决 / 卷尾缺口 | 阶段性收束 | 终局阻力 | 卷内结果 + 下一卷缺口 | 把主线送进下卷 | 卖点留钩 |

## 五、章清单如何配合卷级四段

章清单至少要看出：

- 哪几章属于卷内布局
- 哪几章属于卷内反应
- 哪几章属于卷内进攻
- 哪几章负责卷内解决与卷尾缺口

如果章清单从头到尾都是同一强度、同一类型的推进，说明卷级结构还没站起来。

## 六、与卖点保真的关系

每卷必须写明自己属于哪一种：

- 强化卖点
- 兑现卖点
- 转化卖点
- 为下一次卖点爆发铺垫

并进一步说明：

- 本卷前段怎样让读者重新认出这本书
- 本卷中段怎样避免卖点断供
- 卷尾怎样把卖点送进下一卷

## 七、和总纲层的接口

- 总纲层负责全书九部件与长线推进。
- 分卷层负责把其中一段长线切成可读的卷级闭环。

所以卷纲必须回答：

- 本卷承接的是总纲哪一段压力？
- 本卷结束后，主线局势改变了什么？
- 下一卷接手的是哪一种新缺口？

## 八、卷级"挖坑-爬坑"模型（新增——吸收自知乎专栏「中国网络文学研究」#47）

除了"四段推进"的结构视角，分卷还可以用"挖坑-爬坑"模型来组织，特别适合**由独立案件/事件驱动的卷**（推理卷、单元案卷、副本卷、独立冒险卷）。

### 核心理念

所有好故事的共同结构 = **主角掉进坑里 + 挣扎爬出来的过程**。每个卷就是一个"坑"的完整生命周期。

### 四步卷结构与四段推进的映射

| 四段推进（原模型） | 挖坑-爬坑（新视角） | 读者体验 |
| --- | --- | --- |
| 卷内布局 | 挖坑：正常世界被打破 | 读者被拽进本卷问题 |
| 卷内反应 | 第一次挣扎：尝试→挫败 | 紧张——主角会怎么破局？ |
| 卷内进攻 | 螺旋爬坑：多次尝试→学到东西→升级尝试 | 揪心——每次以为成了又被踹下来 |
| 卷内解决/卷尾缺口 | 爬出坑 + 下一坑的阴影 | 满足+期待——站上来了但前面还有坑 |

### 三种坑在卷内的交织

高明的分卷不会只写一种坑，而是让三种坑在卷内并行推进：

1. **外部坑**（驱动作案事件）：敌人太强、资源太少、时间太紧、规则不公平
2. **内部坑**（驱动人物弧线）：主角的缺点、心魔、过去的创伤、错误的信念
3. **关系坑**（驱动关系线）：队友背叛、爱人误解、盟友反目、信任崩塌

**卷纲判断标准**：如果一份卷纲只有外部坑（追凶/打怪/升级），没有内部坑和关系坑，卷内冲突就会只有一条明线，读者容易在中段疲劳。

### 爬坑单元的标准循环

卷内每一段"事件"都可以分解为：

```text
尝试 → 挫败 → 学到一点东西（或拿到一点资源）→ 下一次尝试升级
```

这个单元循环 3-5 次，读者就会像嗑瓜子一样停不下来——人性里有个贱毛病：看别人倒霉想笑，看别人快成功想加油，看别人又失败了想"再试一次吧求你了"。

### 卷尾的坑设计

最好的卷尾结局不让主角回到最初状态。而是让他爬出来后站在坑边回头看，发现：自己变了 / 世界变了 / 新的坑已在等着。

### 与现有模型的关系

"挖坑-爬坑"不是替代四段推进，而是**四段推进的具象化渲染**。四段推进告诉卷纲"结构上该有什么"，挖坑-爬坑告诉卷纲"读者体验上该感受到什么"。两个视角配合使用：四段推进→章清单分布对齐；挖坑-爬坑→判断卷内情绪起伏是否足够。

> 来源：知乎专栏「中国网络文学研究」#47《别想复杂了，写小说就是你掉进坑里，然后拼命从坑里爬出来的过程》顾里木图的小酒馆
> 置信度：高 — 与现有卷级四段推进模型完全兼容互补，三种坑分类可直接用于卷纲多线并行判断

## 九、硬性警报

出现以下任两项，应判卷纲未达标：

- 卷内主问题说不成一句话
- 中段没有明确改向点
- 卷内反应段和进攻段不分
- 卷尾只留氛围，不留行动性缺口
- 本卷读完对主线局势几乎没改变
- 卖点在本卷只出现一次，后面长期失踪

## 九、一句话收口

**卷纲不是把总纲切小，而是把总纲的一段压力切成可读、可回报、可交接的阶段性故事。**

## 十、最小卷级工件（新增）

```markdown
【卷段职责层】布局 / 反应 / 进攻 / 解决-缺口
【关键点布置层】扰动点 / 第一情节点 / 中间点 / 卷尾前关键信息
【卷尾交接层】本卷闭环 / 下一卷缺口 / 主线局势变化
【当前判定】Green / Yellow / Red
```

## 十一、Green / Yellow / Red 卷级判定（新增）

- `Green`：四段清楚、关键点明确、卷尾交接可追，可支撑真正的卷级闭环。
- `Yellow`：卷段方向大致成立，但中间点、卷尾缺口或主动权变化仍偏虚。
- `Red`：只有“很多章很多事”，没有卷级结构、关键点或交接缺口，读起来像流程堆叠。

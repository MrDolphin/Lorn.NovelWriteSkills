# 通用-蒸馏作品蓝本

> 核心理念借鉴自 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)：不是复制情节，而是**提取一部作品的叙事架构 DNA**——让下游写/审 Skill 能参照这套已验证的叙事规律，而不是凭空决定节奏和钩子。

## 继续读取的 references

- `references/作品蓝本模板格式定义.md`（**必读** — 产出格式规格与模板完整结构。**特别注意 §十五 故事线台账 和 §十六 读者吸引与留存指纹——§十五首次将"理清作品有多少条故事线"纳入蒸馏产出，§十六是蒸馏的最高优先级内容**）

## 核心区别

| | 作者风格模板 | 作品蓝本模板 |
| --- | --- | --- |
| 蒸馏对象 | 一位作者的文笔特征（跨作品） | 一部作品的叙事架构特征 + 套路指纹（纵贯单作品） |
| 关注什么 | 句长、段落、感官、比喻、禁忌 | 章首切入方式、钩子轮换、回报间隔、节奏分布、信息释放节拍、套路配置 |
| 产出用途 | 文笔约束（怎么写） | 结构参照（写什么节奏）+ 套路参照（用什么公式） |
| 关键区分 | 捕捉 HOW the author writes | 捕捉 HOW the story is structured + WHAT formulaic patterns drive it |

> **形似 vs 神似**：统计章首类型、钩子轮换、回报间隔是**形似层**——它们告诉你这部作品"每隔几章放一个钩子"。但一部成功小说的节奏感不是靠间隔数字复制的，而是靠**一种内化的叙事直觉**——作者写完这一章，本能地知道下一章该给读者什么，不是因为数了间隔，而是因为读懂了读者此刻的期待压强。蒸馏的终极目标不是产出一张钩子轮换表，而是让下游**拥有和原作者同频的叙事节拍感**——当面对一个未出现过的情节位置，能自然做出和蓝本一样的节奏选择。套路指纹的加入不是稀释形似与神似的张力，而是在 WHAT layer 补上叙事架构 DNA 无法触及的那一半——**蓝本之所以被读者认出来，首先是因为它的套路配置让人一眼就知道"这是XX文"**。

## 故事线优先原则：蒸馏时先理清"作品有多少条故事线"

> 在进入任何结构统计之前，**必须先回答一个更底层的问题：这部作品有多少条故事线？**
>
> 故事线 ≠ 章节数量，故事线 ≠ 出场人物数量，故事线 = 由因果关系连接的、在多个章节中持续存在的叙事单元。蒸馏时若不先理清故事线，后续的章首统计、钩子分析、节奏分布都会失去"这条线在服务谁"的参照系。

自本节起，蒸馏流程在 Phase 1 完成后增加 **Phase 1.5 — 故事线识别**（详见下文"故事线识别阶段"），然后再进入 Phase 2 神似三问。

故事线识别的蒸馏方法详见 `写作研究/写作技法_蒸馏小说时识别与理清故事线的方法.md`，模板对应 **§十五 故事线台账**。建议蒸馏时优先完成故事线台账，再按原有优先级继续蒸馏。

## 吸引力优先原则：从"读者为什么点开"开始

> 蒸馏作品蓝本的**最高优先级**是回答两个问题：
> 1. **读者为什么点开这本书？** —— 书名、简介、开篇第一章的设计逻辑
> 2. **读者为什么继续追读？** —— 章标题、章首抓力、章末钩子、卖点保真链、黄金三章

> **本 Skill 现已强化商业化结构蒸馏**，确保蓝本的爆款规律不仅以"叙事结构"被记录，更以"为什么能追上读者期待、为什么能留住数据"的商业逻辑被理解。

这两个问题分别对应作品蓝本模板中的 **§十六 读者吸引与留存指纹**。蒸馏时若时间有限，**优先蒸馏本节**，再按优先级从高到低蒸馏 §一至§十四的结构指纹。

### 吸引层 vs 留存层 vs 商业层 vs 故事线层 vs 结构层：五层蒸馏优先级

| 优先级 | 层级 | 核心问题 | 对应模板节 | 蒸馏时机 |
| --- | --- | --- | --- | --- |
| **★★★ 最高** | **吸引层** | 读者为什么点开？ | §16.1 三关设计（书名/简介/开篇）+ §16.3 黄金三章 + §16.5 情绪刺激密度 | 优先完成 |
| **★★★ 最高** | **留存层** | 读者为什么继续追读？ | §16.2 章级工程（章标题/章首/钩子/卖点链）+ §16.4 卷级驱动链 + §16.6 对话占比 | 优先完成 |
| **★★★ 最高** | **商业层** | 这部作品为什么能跑出数据？ | §十九 情绪刺激密度与爽点虐点指纹 + §二十 对话占比与节奏速度指纹 + §二十一 平台适配与商业化结构DNA | 优先完成 |
| ★★ 高 | **故事线层** | 作品有多少条线？如何交织？ | §十五 故事线台账 | Phase 1.5 完成（通读统计后即做） |
| ★★ 高 | 结构层 | 节奏和钩子怎么分布？ | §一至§十四 | Phase 2 起完成 |
| ★ 中 | 仿写层 | 引擎如何迁移？ | §十七至§二十 | 需要仿写时完成 |

### 商业层蒸馏方法概览（新增）

> 商业层是吸引层和留存层的**数据维度补充**。吸引层回答"读者为什么点开"，留存层回答"读者为什么继续追读"，商业层回答"数据为什么跑得动"——即把这些设计翻译成平台算法和读者行为层面的商业竞争力。

#### 情绪刺激密度与爽点虐点指纹提取

从蓝本正文中提取以下数据（直接纳入 §十九）：

**爽点统计**
- 遍历蓝本各章，标记每章中出现的"爽点"（打脸/反击/升级/信息碾压/关系突破等）的数量与类型
- 计算：平均每章爽点数、爽点类型分布、爽点间隔（每N章一个中爽点）
- 记录蓝本中"大爽点"（卷级高潮）的章号与触发机制
- 标注爽:虐比例（按卷分段统计）

**虐点统计**（女频情感类强制）
- 遍历蓝本各章，标记"虐点"（被辜负/被误解/被伤害/被替代等）的数量与类型
- 计算：平均每N字一个虐点、虐点类型分布、虐点密集区（哪些章虐点最集中）
- 记录"虐中嵌爽"模式——每个虐点之后，蓝本用什么方式给读者一个小释放

**情绪刺激点间隔**
- 计算全篇平均情绪刺激点间隔（分析Top10%作品平均1.8章一次情绪高峰）
- 标注蓝本中是否存在"连续N章零刺激"的失温区域——若有，分析蓝本做了什么来补救

**刺激类型轮换**
- 标注连续章节的刺激类型是否轮换（避免打脸→打脸→打脸的同类型疲劳）
- 记录蓝本的典型轮换模式（如"虐→爽→解谜→感情→虐"的5章循环）

#### 对话占比与节奏速度指纹提取

从蓝本正文中提取以下数据（直接纳入 §二十）：

**对话占比统计**
- 逐章估算对话占比（对话行数/总行数），标注均值与波动范围
- 按场景类型统计对话占比差异：高潮章 vs 过渡章 vs 感情章 vs 解谜章
- 记录蓝本在对话占比上的核心规律：什么类型的章节蓝本最依赖对话加速，什么类型最依赖叙述

**章节节奏模板识别**
- 将蓝本的每章归类到节奏模板（起承转爽/过山车/信息揭露递进），统计各模板使用频率
- 识别蓝本的首选章节节奏模板是什么，特殊章节（如卷首/卷尾/高潮章）使用什么变体
- 记录是否为每章预设了固定的节奏模板（可批量性信号），还是每章结构都不同

**黄金三章量化拆解（强化）**
在现有§16.3黄金三章基础上，补采以下量化指标：
- 第1章前300字内冲突/异常/压力信号是否出现
- 第1章前1000字内金手指/核心能力是否亮出
- 前三章对话占比估算值
- 第1章章末钩子类型与强度
- 前三章"起承转爽"完整性评估

#### 平台适配指纹提取

**成功平台判断**
- 该蓝本在哪个平台取得最大成功（起点/番茄/七猫/晋江等）
- 其结构与节奏特征是否符合该平台的天然偏好？

| 观察项 | 起点偏好信号 | 七猫偏好信号 | 番茄偏好信号 |
| --- | --- | --- | --- |
| 章节字数 | 2000-3000字 | 2500-4000字 | 2000-3500字 |
| 对话占比均值 | ≥35% | ≥40% | ≥45% |
| 前三章情绪密度 | 允许2-3章蓄力 | 高密度，每500字有刺激 | 最强卖点全打出 |
| 卷首钩子类型 | 悬念/信息差 | 情绪炸弹/新危机 | 信息投放/反转 |
| 中段回报类型 | 能力升级+关系位移 | 身份反转+情绪爆发 | 打脸+信息释放 |

- 若蓝本的成功与特定平台策略高度绑定，标注为`[平台强绑定]`，提醒仿写者更换平台时需调整节奏

#### 失温风险点识别（新增）
- 遍历蓝本，标记"最容易流失读者"的章节区间（本章说/书评数量骤降的区域、连续无回报的章节群）
- 分析蓝本在这些失温风险点做了什么事来防止读者流失（插入小刺激/提前预告回报/关系翻面等）
- 记录这些"救火措施"的模式，供下游参考如何在失温风险点自救

#### 更新可复制性评估（新增）
- 判断蓝本的写作方式属于"易批量型"还是"难持续型"

| 信号 | 易批量型（日更6000+） | 难持续型（日更3000以下） |
| --- | --- | --- |
| 主要推进方式 | 对话+事件推进为主 | 环境+心理+文学渲染为主 |
| 高强度场景占比 | ≥40%章节是对话密集/冲突场景 | ≤20%章节是高强度场景 |
| 章节结构规律 | 有明显可复用的节奏模板 | 每章结构需重新构思 |
| 描写密度 | 平均每章不超过1-2段纯环境/心理描写 | 大量铺陈和抒情段落 |

#### 商业化结构DNA一句话总结
蒸馏完成后，为蓝本输出一段商业化结构DNA总结：

```markdown
【商业化结构DNA】

情绪刺激模式：
- 核心爽感：[一句话，如"智商碾压+打脸反转"]
- 爽:虐比例：[如"开篇3:7(高虐)/中段5:5/末期7:3"]
- 情绪高峰间隔：[平均每N章一次，是否达到1.8章/次行业Top10%水平]
- 对话占比策略：[如"均值45%，高潮章降至30%，过渡章升至55%"]

留存工程设计：
- 前3章追读链：[是否完成"冲突→碰壁→升级"三拍]
- 前1000字金手指窗口：[是否已在1000字内给出回报预期]
- 章末钩子类型：[如"新威胁型占40%，情绪炸弹型占30%"]

平台适配性：
- 主要成功平台：[平台名]
- 平台节奏归因：[该蓝本的成功在多大程度上依赖平台特性]
- 跨平台可迁移性：[高/中/低——更换平台需调整什么]

更新可复制性：
- 写作难度评估：[易/中/难]
- 日均可产字数预估：[X]字/日
- 核心节奏模板：[起承转爽/过山车/其他]


### 吸引层蒸馏方法概览

#### 书名策略提取
- 搜索该蓝本作品在各平台的发布名称（主书名 + 子标题 + 海外名）
- 对照其同赛道竞品书名，判断其书名策略的差异化点
- 用 `通用-设计标题` 的评估框架（字数/热词/首眼归类效率/信息差/跨平台差异）逐条记录

#### 内容简介提取
- 收集蓝本作品在各平台的简介原文（起点版/番茄版/其他）
- 对照 `通用-撰写内容简介` 的三句法/切片原则/交易本质标准，评估简介的抓力来源
- 记录简介与书名、开篇的承诺一致性

#### 开篇第一章提取
- 逐句拆解第一章前 300 字，对照"三句法"评估疑问/情绪/代入的达成度
- 记录第一个追问、第一个冲突位置、金手指登场位置、人物抓手
- 用 `通用-强化章节开头` 的七类切入标准判断章首模式

#### 逐章章标题提取
- 遍历蓝本各章的章标题，按六大策略类型分类统计
- 标注策略轮换规律和连续同策略区域
- 检测标题承诺与正文是否匹配

#### 章首/章末/卖点链
- 已有 §一、§二 的结构统计覆盖，但在蒸馏 §十六 时额外补充"读者视角"——为什么这个钩子有效、这个章首在哪类读者中引起最强反应

### 数据来源策略

吸引层和留存层的蒸馏不要求全量统计——以下方法均可接受，但须在模板中标注数据来源：

| 蒸馏对象 | 最佳数据来源 | 备选方案 |
| --- | --- | --- |
| 书名策略 | 网络搜索 + 平台榜单比对 | 手动搜索蓝本发布信息 |
| 内容简介 | 各平台截取简介原文 | 从作品页面提取 |
| 黄金三章 | 阅读/购买前三章完整正文 | 试读章节 + 本章说/读者评论交叉验证 |
| 逐章章标题 | 从目录页批量提取 | 从正文逐章摘录（劳动密集型） |
| 章首/章末模式 | 阅读完整章节 | 试读关键章 + 本章说验证 |
| **故事线台账** | **通读全篇后逐章标记"叙事问题"——记录每章结束时读者想知道什么** | 如有章纲/卷纲，比对纲中的故事线规划与实际执行情况；可配合 `写作技法_蒸馏小说时识别与理清故事线的方法.md` 的五步法执行 |

## 故事线识别阶段（Phase 1.5 — 新增，强制）

蒸馏流程在 **Phase 1（通读统计）** 完成后、**Phase 2（神似三问）** 启动前，必须插入一个"故事线识别"子阶段。这一阶段的目标是：在进入钩子分布、节奏统计等细微分析之前，先建立起蓝本的**故事线全局视图**。

### 执行步骤

```
Phase 1.5 — 故事线识别
│
├─ 1.5.1 逐章标注"叙事问题"（章末新增问题 / 章末回答问题）
│    └─ 输出：叙事问题追踪表
│
├─ 1.5.2 三问过滤 → 形成候选故事线列表
│    │    ① 它有独立的因果链吗？    ② 它在至少 3 章中持续出现？
│    │    ③ 删掉它，主线会受影响吗？
│    └─ 输出：候选故事线清单（含分类 L1-L5）
│
├─ 1.5.3 四色标记 → 逐章标注各线参与情况
│    │    🔴 主线 / 🔵 副线+人物弧 / 🟢 关系线 / 🟡 伏笔回收
│    └─ 输出：四色分布图（各线在各章的存在状态）
│
├─ 1.5.4 起始-终止映射 → 抽屉检测
│    │    · 未回收线：有起点无终点 → 标注
│    │    · 断线：中间消失再无下文 → 标注
│    │    · 弱连接线：出现密度 < 20% → 标注
│    └─ 输出：故事线台账（含回收完整性）
│
└─ 1.5.5 跨事件线复现验证 → 纳入现有三重验证框架
     └─ 输出：验证结论（通过/降级/丢弃）
```

### 产出物要求

- 必须填写模板 **§十五 故事线台账** 中的"故事线总览"表（每条线的编号、类型、起始章、终止章、出现密度、叙事问题）
- 必须填写"故事线评估"表（线数量合理性、回收完整性、交织密度、分布均匀性、副线对主线贡献）
- 建议填写"故事线交织模式"表（编织/交替/嵌套/从属）
- 建议填写"常见误判排除"表（至少排除 2 个易混淆的候选）

详细方法参见 `写作研究/写作技法_蒸馏小说时识别与理清故事线的方法.md`。

## 叙事引擎——从形似到神似（强制）

nuwa-skill 的提取框架指出：**"不是此人原话的拼凑，而是框架的运行"**。形似层（§一至§十二）记录了蓝本"做了什么"，神似层必须揭示蓝本"为什么这么做"——以及这个"为什么"如何在新故事中独立运行。

### 神似三问

蒸馏作品蓝本时，必须在 Phase 2 完成后、Phase 2.5 之前，对核心结构维度追问以下三问：

| 问 | 含义 | 从形到神的翻译 |
| --- | --- | --- |
| **这部作品的"叙事心跳"是什么？** | 不是"每 3 章一个钩子"——而是什么节奏感让读者读这部作品时有独特的心跳曲线？是前松后紧的蓄力爆发型？是章章高能的过山车型？还是暗流涌动的温水煮蛙型？ | 节拍数字 → 叙事心跳曲线 |
| **如果在这一章的位置，换成另一种情节，节奏会怎么变？** | 统计显示第 12 章用了"动作切入 + 新危机钩子"。如果第 12 章写的是"重逢"而非"战斗"，节奏选择会偏移吗？——能回答这个问题，才算理解了蓝本的叙事逻辑而非背诵了节拍表 | 固定排列 → 受情节类型调节的生成规则 |
| **这部作品有什么"结构羞耻"？** | 不是"回报章间隔≥1"这种技术禁忌——而是更深层的叙事伦理：绝不为了让读者哭而杀死配角、绝不在角色最脆弱时让叙述者冷眼旁观、绝不用巧合解决核心冲突 | 技术禁忌 → 叙事伦理边界 |

### 跨卷/跨事件线复现验证（强制）

作品蓝本中每个结构规律的认定，必须通过三重验证。其中"跨事件线"即指 §十五 故事线台账中识别的各条故事线——验证前应确保已完成 Phase 1.5 故事线识别。

| 验证 | 方法 | 通过标准 |
| --- | --- | --- |
| **跨卷复现** | 同一规律在前 30 章、中段、后 30 章至少两个区段可被观察到 | 若只在一个卷段成立 → 降级为"卷段局部特征" |
| **跨事件线复现** | 同一规律在 L1 主线事件和 L2-L4 各条故事线的事件中均成立（如主线高潮前的蓄力章数和副线高潮前的蓄力章数是否遵守同一规则） | 若只在主线成立 → 降级为"主线特化节奏" |
| **跨情感调性复现** | 同一规律在紧张章和松弛章中是否以不同方式体现（如"每次钩子轮换"在紧张章用新危机型、在松弛章用关系翻面型——规律本身没变，变的是落点） | 若规律随情感调性完全消失 → 降级为"仅高压场景规律" |

### 生成力测试——"遗失章节"测试（强制）

蒸馏叙事引擎的黄金标准：**能否生成一章在蓝本原作中"本应存在但不存在"的章节，让熟悉原作的读者无法判断它是不是真迹？**

Phase 4 质量验证中新增"遗失章节测试"：

1. 从蓝本原作中选一个**被略过的事件**——原作提到"三日后，他们抵达了都城"，但这三天发生了什么完全没写
2. 用本蓝本的叙事引擎（不使用任何形似层的精确数字），为这个略过事件生成一章控制卡：章首切入方式、中段回报类型、章末钩子类型、场景-续景节拍
3. 邀请熟悉原作的读者判断：这章控制卡"像不像原作者本人会设计的节奏"
4. 生成的控制卡再由 `通用-创建小说正文` 生成正文，做 A/B 盲测
5. 若正文被误判为原作真迹的概率 ≥ 50%，模板达到神似层

### 叙事矛盾弧记录（强制）

一部好小说的节奏规律从来不是机械的——它最动人的地方往往是"打破自身规律的时刻"：

- 前 30 章一直每 3 章一个钩子，但在第 31 章突然连续两章没有钩子——为什么是这里？发生了角色死亡？视角切换？还是作者有意让读者喘一口气？
- 一直用"动作切入"开章，但在唯一一次"环境切入"放在了一场大战之后——为什么？

蓝本模板新增 **§十四 叙事矛盾弧**：

| 矛盾弧 | 常态规律 | 打破时刻 | 打破位置 | 打破的叙事功能 |
| --- | --- | --- | --- | --- |
| 钩子密度 | 每 3 章一个钩子 | 连续 2 章只留白不收束 | 第 31-32 章 | 核心角色死亡后，给读者哀悼空间 |
| 章首切入 | 动作切入为主 | 唯一一处环境切入 | 第 78 章 | 大战后的废墟静默，环境本身在说话 |

### 从形到神的翻译模板——"叙事本能"

Phase 2 统计完成后，必须为蓝本输出一段"叙事本能"描述：

```
这部作品的叙事心跳：[一句话概括，如"七紧三松的过山车，但每次下坡都比上一次更陡"]

核心驱动问题链：
- 读者在第 1 卷追的问题是：[X]
- 进入第 2 卷后，问题演变为：[Y]
- 进入中段后，读者不再追问[X]而是追问[Z]——这个"问题漂移"是蓝本保持长线追读的核心叙事引擎

如果在全新故事中运行这个引擎：
- 不是复制钩子间隔，而是复制[问题驱动链]的结构
- 不是复制回报类型，而是复制[每一次回报都让读者更想追问什么]的调节逻辑
- 不是复制功能位的排列，而是复制[每个功能位都服务于读者当前期待压强]的决策直觉
```

## 仿写内核提取——从"叙事结构"到"可迁移引擎"（新增，强制）

蒸馏作品蓝本时，必须在 Phase 2 统计与神似层提炼完成后，追加一次跨维度的"仿写内核提取"——不是折叠已有维度的统计结果，而是回答几个纯结构统计无法触及的问题。

### 内核三问

| 问题 | 含义 | 提取方法 |
| --- | --- | --- |
| **这部作品的"核心爽感引擎"是什么？** | 读者读完每一章后最强烈的情绪回报是什么？是"智商碾压的快感""资源增长的满足感""关系翻面的意外感"还是"一步步逼近真相的紧张感"？ | 跨维度交叉推断：章末钩子类型分布 + 中段回报类型分布 + 情感弧分布 → 三者同时指向的"情绪回报" |
| **金手指/驱动力与主线的绑定模式是什么？** | 金/手指不是"有什么能力"，而是"这个能力如何每时每刻都在制造新冲突或新选择"？核心绑定模式是"吞噬→进化→需要更多"的滚雪球，还是"信息差→布局→反噬"的幕后黑手，还是"规则→试穿→规则升级"的递进？ | 从回报指纹 + 事件驱动方式 + 跨卷节拍迁移 → 提取驱动模式 |
| **跨卷问题链如何移位？** | 第一卷追"主角能不能活下去"；第二卷变成"他能不能报仇"；第三卷变成"他应不应该原谅"——这个"问题漂移"是长线追读的真正引擎 | 从叙事本能 + 核心驱动问题链 + 跨卷节拍迁移 → 提取问题链移位逻辑 |

### 可迁移性四维评估

对上述内核三问的答案，逐项做可迁移性评估：

| 维度 | 评估标准 | 标记 |
| --- | --- | --- |
| **题材绑定度** | 这个内核是否必须依赖特定题材设定才能运转？"幕后黑手甩锅"内核可以跨题材（西游→都市→科幻），"凡人修仙资源经营"内核高度绑定修仙题材 | `通用可迁移` / `题材半绑定` / `强绑定` |
| **文风依赖度** | 这个内核是否需要特定文笔风格才能生效？冷幽默型内核依赖吐槽式叙述者，正剧型内核依赖克制白描 | `文风自由` / `特定文风` |
| **作者存量依赖度** | 这个内核的成功是否依赖该作者的存量读者、历史口碑或特定平台的基础量？新人仿写时能否同样生效？ | `作者独立` / `部分依赖存量` / `高度依赖存量` |
| **发布时间窗口** | 这个内核的成功是否与发布时间窗口高度相关？是否利用了特定时期的题材红利、读者情绪或平台政策红利？当前窗口是否还在？ | `持续有效` / `窗口收窄` / `窗口关闭` |

### 仿写难度与替代方案

| 内核特征 | 仿写难度 | 推荐替代方向 |
| --- | --- | --- |
| 绑定独特设定系统 | 高 | 保留"驱动模式"，替换"设定外壳" |
| 依赖幽默文风 | 中 | 拉合作者/找文风相近者，或换为"正剧版"重新适配 |
| 纯结构驱动型（与设定/文风无关） | 低 | 直接复用内核，换题材换人物即可 |
| 依赖作者存量粉丝 | 极高 | 不仿写这本，转向同赛道新人更容易破局的蓝本 |

### 改写深度分层——"换/缝/乱"三级框架（新增）

根据《改写小说的系统方法论研究》的"换/缝/乱"三要素框架，仿写时对蓝本的借用可以在三个层次上进行。仿写内核卡必须显式标注每个可达层的具体内容：

| 层次 | 含义 | 在蓝本中的具体示例 | 仿写时的操作 |
| --- | --- | --- | --- |
| **表层改写（换）** | 替换人物名称、环境名称、情节细节等外在元素 | 蓝本的角色名/地名/道具名/时代背景 | 换掉名称，保留功能角色和事件骨架 |
| **中层改写（缝）** | 调整叙事结构、人物关系、情节逻辑，融合多源素材 | 蓝本的章首模式/钩子轮换/回报间隔/人物关系网络 | 保留结构规律和关系模型，换矛盾类型和世界设定；可融合 2-3 份其他蓝本的特色元素 |
| **深层改写（乱）** | 转换世界观架构、价值观念、核心主题，跨界融合 | 蓝本的核心爽感引擎/金手指-主线绑定模式/读者问题链移位逻辑 | 保留引擎驱动原理，但换掉整个世界观的"物理法则"和价值基础；可与不同文化/类型元素做跨界融合 |

**"功能对等"原则**（取自"换"手法的核心约束）：替换后的元素必须保持与原作元素相同的叙事功能——新角色在故事中承担的角色和作用应该与原作角色基本一致。如果换了名字但改变了角色的功能定位，需要重新验证引擎是否仍能运转。

**"内在合理性"构建要求**（取自"乱"手法的核心约束）：当进行跨界融合或高度创新的仿写时，必须确保：
1. **逻辑支点**：为看似不合理的组合找到合理的解释（如"科技修仙"的合理性建立在"科学也是认知世界的方式"这个支点上）
2. **渐进式引入**：不要一开始就展现所有离奇组合，通过逐步揭示让读者有接受过程
3. **情感逻辑支撑**：无论设定多离奇，情感逻辑必须真实——人类的情感（恐惧/希望/爱/恨）是跨设定共通的

### 从仿写到原创的演化路径（新增）

本 Skill 的终极目标不是让下游永远仿写，而是让仿写成为通往原创的跳板。《改写小说的系统方法论研究》指出，"从改写走向原创"是一个渐进过程。仿写内核卡中必须追加以下演化建议：

| 阶段 | 蓝本依赖度 | 创作行为 | 原创占比 |
| --- | --- | --- | --- |
| **阶段 1：表层仿写** | 高度依赖 | 保留蓝本的中层和深层引擎，只换表层元素（人物名/地名/时代） | ~20% |
| **阶段 2：结构重组** | 中度依赖 | 保留深层引擎，但用自己的中层结构重组——重新设计人物关系、调整叙事线索、缝合第二份蓝本的元素 | ~50% |
| **阶段 3：引擎迁移** | 轻度依赖 | 提取蓝本的引擎原理（而非引擎本身），在自己独创的世界观中重新实现这一原理 | ~80% |
| **阶段 4：独立原创** | 零依赖 | 不再参照任何蓝本，用积累的结构认知驱动完整原创 | 100% |

仿写内核卡在"综合仿写推荐度"下方新增一行 **"推荐演化终点"**，标注该蓝本最适合在哪个阶段停止参照。

### 原创性提升——从"仿得像"到"你写的"（新增 — 对标演化的进阶路径）

《改写小说的系统方法论研究》在 §6.3 中指出，超越仿写的关键在于三条具体的提升路径。当项目进入演化路径的阶段 3（引擎迁移）或阶段 4（独立原创）时，应主动启用以下指导：

#### 三条提升路径

| 路径 | 操作 | 从蓝本中提取什么 | 自己创造什么 |
| --- | --- | --- | --- |
| **核心创意提炼与升华** | 对蓝本的核心创意追问"这个创意的本质是什么"——不是复制创意的表面，而是提取其背后的原理，在自己的世界观中重新实现 | 蓝本的"问题意识"——它抓住了读者什么样的深层欲望？（安全感/好奇心/认同感/掌控感） | 属于自己题材的独特解决方案 |
| **独特视角建立** | 培养从蓝本作者不同的角度看世界的方式——不复制蓝本的"看世界方式"，而是建立自己的 | 蓝本的"叙事立场"——它是同情反派还是共情主角？它对世界是冷峻还是温情的？ | 自己独特的价值判断标准和表达风格 |
| **避免同质化三方法** | 在脱离蓝本参照后，用以下方法确保不会滑入新的同质化：**冷门题材挖掘**（关注未被充分开发的题材）、**角度创新**（从全新角度诠释常见题材）、**反套路设计**（打破传统人物设定和情节套路） | 蓝本所在赛道的"同质化陷阱"清单 | 自己的差异化标签——在同一个赛道里，读者为什么选你的书而不是别人的 |

#### 三条路径的启用时机

| 当前状态 | 推荐启用的路径 |
| --- | --- |
| 已经能稳定仿写，但感觉"写出来总觉得是别人的味道" | **独特视角建立** — 先不换题材，换自己的"看世界方式" |
| 仿写流畅但总觉得"深度不够，像表面模仿" | **核心创意提炼与升华** — 追问这个蓝本为什么会成功，它的核心抓住了什么 |
| 已经脱离仿写但在新赛道上发现别人也在做类似的事 | **避免同质化三方法** — 盘点赛道里的同质化陷阱，主动避开 |

### 仿写合规边界——明确你在做什么（新增）

《改写小说的系统方法论研究》在 §1.2 中区分了改写与原创、模仿、致敬的本质差异。仿写内核卡中必须追加一段 **"仿写合规边界"**，让下游清楚自己当前的操作落在哪个区间。这既是创作定位，也是版权风险预警。

| 创作行为 | 与蓝本的关系 | 对蓝本的处理 | 在仿写中应如何定位 |
| --- | --- | --- | --- |
| **原创（零参照）** | 无直接参照关系 | 无蓝本 | 阶段 4 独立原创的标志——不再需要本章仿写内核卡 |
| **改写/仿写（本 Skill 的目标）** | 以蓝本为起源文本，进行创造性转化 | 保留引擎和结构规律，换掉人物/场景/事件等具体表达 | **这是仿写内核卡的默认定位**——保持引擎运转，但确保读者不会觉得"这就是换皮" |
| **模仿（应警惕）** | 追求与原作的相似性 | 复制表层技巧和表达方式 | 这是"抄袭"的边缘地带——如果仿写内核卡的"不可迁移特质清单"中有超过 50% 的内容被忽略、直接照搬，就落入了模仿而非改写 |
| **致敬（应区分）** | 保留核心元素并明确标注来源 | 保留标志性元素，通常只用于特定场景 | 如果需要在作品中出现致敬元素（如客串、彩蛋），应在控制卡或正文中**显式标注"致敬"**而非混入仿写流程 |

**判断标准**：完成仿写后，用三问自检：
1. **一个读过蓝本的读者，能否在读完你的作品后说"这是另一部作品，不是 copy"？**（不能 → 落入模仿区，需要加大替换力度）
2. **一个没读过蓝本的读者，能完全无障碍地理解并享受你的作品吗？**（不能 → 过度依赖蓝本的知识，需要补独立叙事）
3. **你的作品的核心吸引力，是否来自你独创的某个设定/关系/视角，而非蓝本的剩余魅力？**（不能 → 仍处于表层仿写，需要推进演化路径）

### 叙事视角转换技法——从"讲什么故事"到"谁在讲故事"（新增）

《改写小说的系统方法论研究》指出：改变叙事视角是改写中最有效的"低成本高回报"手法——不改变情节框架，仅靠**改变"谁在看""从哪看""怎么看"**就能让同一个故事呈现完全不同的面貌，同时天然拉开抄袭嫌疑。仿写内核卡必须提取以下维度：

#### 蓝本的原始视角配置

| 维度 | 原始配置 | 在蓝本中的功能 |
| --- | --- | --- |
| 叙述者身份 | 第一人称 / 第三人称限制 / 第三人称全知 / 多 POV 轮换 | 这个视角如何服务于蓝本的爽感引擎？ |
| 默认镜头距离 | 贴身（强烈代入）/ 中景（平衡）/ 远景（冷静旁观） | 距离变化规律是什么？什么时候拉近、什么时候推远？ |

#### 可供选择的替代视角方案（仿写方向）

| 替换方案 | 效果变化 | 适用条件 | 风险提示 |
| --- | --- | --- | --- |
| **主角→配角视角** | 从旁观者的角度讲述蓝本故事，读者获得的不是"成为主角"的快感，而是"目睹传奇"的惊奇 | 蓝本配角群体丰富、存在未展开的叙事盲区 | 容易让读者失去爽感引擎的直接体验——需确保配角也有自己的目标链 |
| **反派→正派视角反转** | 把蓝本中的反派/对立面作为主视角，揭示蓝本中未被展示的另一面动机 | 蓝本反派有合理的动机空间，不是纯恶 | 不能美化过度导致读者三观不适 |
| **第一人称→第三人称** | 从"我就是主角"变为"我看着主角"，增加叙事层次，适合展现多线 | 蓝本群像丰富，单 POV 限制了信息量 | 代入感会下降，需用节奏补偿 |
| **第三人称→第一人称** | 强化代入感和内心冲突的冲击力 | 蓝本情感深度强但叙事距离偏冷 | 限制视角可能导致信息释放受限 |
| **宏观→微观** | 从整体俯瞰改为局部聚焦，让读者从"知道全貌"变为"一点一点发现" | 蓝本的世界观悬念感不足 | 可能拖慢节奏 |
| **线性→非线性重组** | 把蓝本的线性叙事改为倒叙/插叙/多线并进，创造全新的悬疑感和信息释放节奏 | 蓝本情节本身的因果链完整，适合打散重组 | 打散后必须确保每个碎片本身也有阅读价值，不能只靠悬念撑着 |

#### "视角转换检验"要求

在仿写内核卡中新增 **"推荐视角转换方案"** 字段，回答：
- 如果只换叙事视角、不换任何情节，蓝本故事是否能成为一个有独立阅读价值的新作品？
- 如果可以，推荐什么视角方案？
- 如果不可以，需要配合哪些中层改写（换人物关系/换结构）才能生效？

### 结构重组技法——六种可操作的结构改造手段（新增）

《改写小说的系统方法论研究》的 §3.3.2 枚举了六种具体的结构重组技术，均可用于对蓝本的结构做有目标的改造。仿写内核卡必须建议适用的改造方向：

| 技法 | 操作 | 典型适用场景 | 对蓝本改造的方向建议 |
| --- | --- | --- | --- |
| **顺序调整** | 改变关键事件的出场顺序，如把结局提前、把高潮后移 | 蓝本开篇节奏偏慢、或悬念感不足 | 是否可以将第 X 章的高潮拉到开篇？ |
| **线索合并** | 将蓝本中的多条人物线/事件线合并为一条主线 | 蓝本线索过多导致新人仿写难度高 | 哪些次要线索可合并到主线中？ |
| **线索拆分** | 将蓝本的一条主人物的成长路径拆成多人视角交替推进 | 蓝本世界观宏大、但视角单一导致信息浪费 | 如果把主角的某个阶段分离出来给配角视角会怎样？ |
| **结构嫁接** | 把蓝本的叙事结构（如悬疑递进/单元闭环/升级打怪）嫁接到另一个题材的设定上 | 蓝本的结构模式清晰、可脱离题材独立运行 | 这个结构能不能直接套用到目标题材上？ |
| **模块化设计** | 把蓝本视为由若干相对独立的叙事模块（如"身份确立模块""第一个案件模块""势力冲突模块"）组成的系统，重新排列组合 | 蓝本超过 50 万字、结构庞大 | 如何按照目标平台的节奏要求重新切分和排列这些模块？ |
| **主干修剪** | 提取蓝本最核心的叙事脉络，砍掉重复性循环（如《斗破苍穹》将"打怪-升级-再打怪"提炼为"三年之约"一条主线） | 蓝本有明显的公式化段落、重复性循环、填充章节 | 蓝本的核心叙事脉络可以精简到什么程度？哪些卷/章是"去掉也不影响主干"的填充？ |

**主干修剪法的使用原则**（取自《斗破苍穹》动画改编案例）：修剪的目标不是"砍字数"，而是**让读者最关心的那条情绪线始终不被稀释**。修剪后必须确保：
1. 核心爽感引擎的每次兑现之间不再隔着无关的填充
2. 被砍掉的填充章节中若包含世界设定/人物背景等必要信息，应通过对话或场景自然补入保留章节
3. 修剪后的章节序列不应该产生"情节跳跃"感——必要时用一句过渡交代"三个月后"

### 因果倒置——跨维度的情节逻辑反转（新增）

《改写小说的系统方法论研究》在"情节替换"节中提出了一个独立于上述六种结构重组技法的**逻辑层手法**：**因果倒置**。它不改动事件本身，而是把事件的因果箭头翻转，从而创造出全新的故事动力。

**操作定义**：将原作中原因和结果的关系颠倒。这不是"重组顺序"（结构层），而是"重组逻辑"（因果层）。

| 蓝本原逻辑 | 因果倒置后的新逻辑 | 故事动力变化 |
| --- | --- | --- |
| 因为努力修炼所以成为强者 | 因为是强者所以必须努力修炼以保持地位 | 从"进取驱动"变为"维持焦虑" |
| 因为发现真相所以陷入危险 | 因为身处危险所以被迫发现真相 | 从"主动探索"变为"被动揭露" |
| 因为相爱所以在一起 | 因为在一起所以必须相爱 | 从"情感驱动"变为"责任/身份驱动" |
| 因为主角弱所以被欺负 | 因为被欺负所以被认定为弱 | 从"实力→地位"变为"地位→实力"——社会标签先行 |

**适用条件**：
- 蓝本的故事动力建立在"线性因果"上（A→B），这类蓝本最容易做因果倒置
- 因果倒置后必须**重新验证核心爽感引擎是否能正常运转**——某些爽感引擎（如"升级打脸"）依赖"努力→变强"的正向因果，倒置后可能崩溃
- 若倒置后发现引擎熄火，改为仅对**支线情节**做因果倒置，主线保留原因果

### 高级时空技法——平行/循环/折叠（新增）

在基础的"顺序调整/线索合并/线索拆分"之上，《改写小说的系统方法论研究》还提出了三种更高维度的时空重组手段，可作为仿写差异化竞争的独特策略：

| 技法 | 操作 | 效果 | 适用蓝本特征 |
| --- | --- | --- | --- |
| **平行时空叙事** | 同时展现两个或多个平行时空的故事，通过对比和呼应深化主题 | 让读者双线追读，两条线互相解释对方 | 蓝本有"穿越""平行世界""前世今生"等设定基础 |
| **循环时间结构** | 设计时间循环，让人物在重复的时间段中寻找出路 | 创造强烈的宿命感和紧迫感 | 蓝本的冲突集中在限定时间和空间内 |
| **时空折叠** | 将不同时间和空间的元素折叠在同一个场景中 | 在梦境/幻觉/回忆中并置多时空画面，超现实效果 | 蓝本有丰富的回忆片段或有强烈的情感象征物可跨时空串联 |

**使用提醒**：这三种技法在网文场景中属于**高辨识度差异化武器**——不是每一本仿写都需要，但一旦使用得当，能让作品从同质化赛道中跳出来。仿写内核卡中新增 **"推荐高级时空技法"** 字段，标注该蓝本最适合使用哪一种（或是否适合使用）。

### 四大骨架模型——短篇/文学性作品的轻量结构蒸馏（新增）

> **文学蒸馏的核心：剥离情节、保留文法、提纯语感、复用骨架。** ——《文学作品仿写专用：文章蒸馏法》
>
> 四大骨架模型正是"复用骨架"原则的具体实现：骨架决定整篇文章的行进方向，微模板决定关键段落的情绪推进方式，词域决定具体用什么词来填充。

当蒸馏对象不是长篇小说，而是**短篇文学、散文、单章正文、或文学性较强的中短篇叙事文**时，标准的 13 维度蓝本蒸馏过于沉重。借用《文学作品仿写专用：文章蒸馏法》的四大骨架模型，可以在极短时间内完成"够用"的结构提取。

| 骨架模型 | 结构序列 | 适用文体 | 替代哪些标准维度 |
| --- | --- | --- | --- |
| **① 景入情式** | 眼前景物 → 触发回忆/思绪 → 轻轻感慨 → 收束留白 | 散文、氛围章、抒情章开头 | §四 场景节奏、§八 情感弧 |
| **② 小事悟理式** | 微小日常事件 → 细节放大 → 情绪转折 → 淡淡升华 | 记叙文、随笔、日常过渡章 | §三 中段回报、§八 情感弧 |
| **③ 时空对照式** | 当下平淡场景 → 插入过去片段 → 今昔对比 → 释然/怅然收尾 | 回忆章、人物背景章、跨卷交接章 | §十二 跨卷节拍迁移、§七 信息释放 |
| **④ 物我共生式** | 写外物状态 → 映射内心状态 → 不直白说情绪，借物抒情 | 文艺抒情章、情绪高潮前的蓄力章 | §一 章首模式、§八 情感弧 |

**使用规则**：

1. 当蒸馏对象为短篇或单章（字数 < 1 万字）时，允许以四大骨架模型替代完整的 13 维度统计——用户可选择"轻量"模式
2. 在轻量模式下，仍必须产出形似层信息（"本文套用的是哪类骨架"），但不需要统计精确的百分比数字
3. 若同一作品由多个短篇构成（如短篇集、单元剧），每个短篇独立做骨架识别，再汇总整体分布规律
4. 四大骨架模型不替代长篇蓝本蒸馏——当作品字数 > 3 万字或章节数 > 15 章时，回退标准 13 维度全量蒸馏

### 滤水预处理——提升蒸馏源质量的必要步骤（新增）

> **滤水原则**：删掉就没那味儿的，全部留下；删掉不影响气质的，全部去掉。——《文学作品仿写专用：文章蒸馏法》
>
> 本原则是整个蒸馏流程的"第一道闸门"：不去判断"这个句子好不好"，只判断"它对保留原作风味有没有贡献"。

无论采用全量蒸馏还是轻量模式，在正式执行 Phase 1（信息采集）前，对蒸馏源做一次"滤水"预处理可以显著提升蒸馏质量。本方法来自《文学作品仿写专用：文章蒸馏法》的"剥离情节、保留文法"原则。

| 步骤 | 操作 | 在蒸馏中的流向 |
| --- | --- | --- |
| **① 识别核心意象** | 扫描全文找出作者反复出现的景物、道具、象征物（雨、旧巷、灯火、晚风、旧物等） | → 汇入比喻指纹（比喻来源领域）和感官偏好 |
| **② 锁定情绪基调** | 用 2-3 个词概括全篇的情绪底色（清冷/温柔/怅然/治愈/苍凉/平静） | → 汇入情感弧分布（§八） |
| **③ 提取经典句式** | 选出最能代表作者语言风格的那 2-3 个句子——不是统计占比，而是"这就是他/她的句子" | → 汇入句长基线的定性判断 |

**滤水时机与正式蒸馏的关系**：

- **全量蒸馏时**：滤水作为 Phase 1（信息采集）的并行前置步骤——先滤出三原料，再带着这三条线索去进行逐维统计，提高维度采样的针对性
- **轻量蒸馏时**：滤水直接作为第一步，产出即为轻量模式的核心输入

### 微模板提取法——段落级模式蒸馏（新增）

四大骨架模型解决"整篇文章怎么写"，而微模板解决**"一个句子/段落怎么让它读起来像原作者的"**。《文学作品仿写专用：文章蒸馏法》的蒸馏示例展示了一种可复用的操作：从原句中抽象出段落级的模式公式，再在新作品中填入新意象。

#### 微模板 vs 骨架模型的层级关系

| 抽象层级 | 覆盖范围 | 示例 | 提取方法 |
| --- | --- | --- | --- |
| **骨架模型** | 整篇文章/整章 | "景入情式：景物 → 回忆 → 感慨 → 留白" | 全文扫描（四大模型之一） |
| **微模板** | 一个关键段落/句子集群 | "特定场景 + 触发回忆 + 遗憾情绪 + 借景物收纳心事" | 经典句子抽象 |
| **词域** | 词汇层面 | "词域 = 旧物/时光/温度" | 20+ 高频词归类 |

三者是**逐层细化的嵌套关系**：骨架决定大局方向 → 微模板决定关键段落的情绪推进方式 → 词域决定具体用什么词来填充。

#### 微模板的抽象方法

从蒸馏源中选出 3-5 个"最有味道"的句子或段落，执行以下操作：

| 步骤 | 操作 | 示例（从原文蒸馏示例来看） |
| --- | --- | --- |
| **① 拆解成分** | 把句子拆成若干功能部件（场景 / 动作 / 情绪 / 象征 / 转折） | "我总在傍晚的风里想起旧时光" → [特定时间] + [特定环境] + [触发回忆] |
| **② 抽象功能** | 把具体内容替换为功能标签，保留连接顺序 | 特定场景 + 触发回忆 + 遗憾情绪 + 借景物收纳心事 |
| **③ 填入新词** | 用目标题材的意象替换每个功能标签 | 深夜的月色 + 回望过往 + 仓促落幕的相遇 + 沉在星光里 |

#### 微模板的产出格式

每个微模板以"公式"形式记录，**推荐同时给出"蒸馏提纯→仿写重生"三行直观对照**（取自《文学作品仿写专用：文章蒸馏法》的蒸馏示例，能让读者一眼看懂变化）：

```markdown
【微模板：[名称]】
公式：[功能A] + [功能B] + [功能C] ...
原作示例：[原句/原段]

蒸馏提纯（模板抽象）：
[功能A] + [功能B] + [功能C] ...

仿写重生（填入新意象）：
[用目标题材的对应意象替换每个功能标签后的新句子]
```

**三行格式的价值**：它直观展示了"从具体→抽象→再具体"的完整路径——比单给一个公式更容易让下游理解怎么用。如果每个微模板都配上三行，后续仿写时下游的理解成本会大幅降低。

#### 微模板在不同蒸馏场景中的使用方法

| 场景 | 微模板的作用 | 提取数量建议 |
| --- | --- | --- |
| 长篇蓝本蒸馏 | 补充在 §十七 仿写内核卡的"差异化切入点建议"中——展示"关键段落的情绪推进方式" | 3-5 个 |
| 短篇/散文轻量蒸馏 | 作为四大骨架模型的下级补充——骨架决定整篇走向，微模板决定关键段落的句级节奏 | 5-8 个 |
| 纯文风蒸馏 | 不提取微模板（文风蒸馏关注的是统计规律，不是具体段落的模式） | 0 个 |

## 套路指纹——从"说什么故事"到"用了什么公式"（新增，强制）

现有 12 维蒸馏全部关注**叙事句法**（how the story is told），但任何爆款作品之所以被读者识别、被平台标签化、被同赛道模仿，首先是因为其**套路配置**（what formulaic patterns drive the story）。套路指纹与叙事架构 DNA 是**正交维度**——同一套路可以用不同节奏讲，同一节奏可以讲不同套路。

> **套路不是贬义词**。套路的本质是"被市场验证过的可复用故事公式"。蒸馏蓝本时不回避套路、不美化套路，而是诚实记录蓝本使用了哪些套路、如何组合、在哪变异——因为蓝本的真正价值往往不是"它独一无二"（那意味着无法仿写），而是"它在常见套路上做出了哪些独特的排列组合和差异化处理"。

### 套路的四级分类体系

为了标准化蒸馏时的套路识别与标注，使用以下四级分类体系。蒸馏者以该分类体系为参照框架，对蓝本进行逐卷/逐章的套路标注。

#### 第一级：核心设定类 — 故事的"初始配置"

| 套路 | 定义 | 读者预期 | 常见题材域 |
| --- | --- | --- | --- |
| 穿越 | 主角从现代/异界穿越到目标世界 | 信息差优势 + 现代知识降维打击 | 古言、历史、奇幻 |
| 重生 | 主角死后回到过去重活一次 | 预知未来 + 弥补遗憾 + 复仇 | 都市、言情、修仙 |
| 系统 | 主角获得游戏化辅助系统 | 数据化成长 + 任务驱动 | 全题材 |
| 穿书 | 主角穿越进一本小说中 | 预知剧情 + 改变命运 | 女频言情 |
| 日常/现实 | 无超自然设定，聚焦现实 | 真实感 + 代入感 | 都市、职场 |

#### 第二级：人物关系类 — 角色之间的配置张力

| 套路 | 核心关系张力 | 典型事件链 | 主要题材域 |
| --- | --- | --- | --- |

### 套路识别五信号法

每个套路在文本中会留下可识别的信号。蒸馏时从以下五个维度交叉判断：

| 信号维度 | 要提取什么 | 举例（追妻火葬场） |
| --- | --- | --- |
| **开局信号** | 前 3-5 章建立了什么初始关系配置 | 女主深爱男主 + 男主冷漠/有白月光 |
| **事件链信号** | 核心事件序列是否符合某套路模板 | 付出→忽视→伤害→临界事件→离开→追回 |
| **关系信号** | 关键人物之间的权力/情感关系 | 女方情感低位 → 男方高位 → 后逆转 |
| **情绪弧信号** | 读者在卷/章层面体验的情绪轨迹 | 先虐（心疼女主）→ 后爽（追妻打脸） |
| **标签自曝信号** | 平台分类/读者评论中如何被标签化 | 本章说高频出现"火葬场""渣男""求虐" |

**判断规则**：
- 一个套路的确立需要 **≥3 个信号** 同时指向该套路
- 仅 1-2 个信号指向 → 标注为"弱信号套路"（置信度低，在模板中标注 `[弱信号]`）
- 若多个套路在同一卷段同时被检测到，进入"套路组合分析"

### 套路纯度光谱

一部作品中的套路不是"有/没有"的二元判断，而是在一个光谱上：

```text
纯套路 ←——— 混合变异 ———→ 反套路
```

| 光谱位置 | 特征 | 读者感知 | 蒸馏标注 |
| --- | --- | --- | --- |
| **纯套路**（纯度 ≥ 80%） | 标准事件链 + 标准关系配置 | "这就是 XX 文的标准写法" | 标注为主套路 + 纯度百分比 |
| **混合变异**（纯度 40%-79%） | 主套路框架 + 其他套路的元素交叉 | "虽然是 XX 文但多了 YY 元素" | 标注为主套路 + 融合元素清单 |
| **反套路**（纯度 < 40%） | 先建读者预期后有意打破 | "这不是 XX 文…等等竟然是？" | 标注为反套路 + 对标对象 + 打破的位置 |

**纯度对下游消费的影响**：
- 纯套路 → 下游可直接复用该套路的标准事件链
- 混合变异 → 下游需要理解"主套路保持 + 变异元素是什么"的关系
- 反套路 → 下游需要知道"先建什么预期 → 在哪个位置打破 → 换成了什么替代方案"

### 套路-叙事节奏关联矩阵

某些套路对叙事节奏有天然倾向——不是绝对绑定，但跨作品统计上有显著相关性：

| 套路 | 倾向的章首模式 | 倾向的钩子密度 | 倾向的中段回报类型 |
| --- | --- | --- | --- |
| 追妻火葬场 | 内心独白切入（女主视角） | 高密度（每章有情绪钩子） | 关系推进/关系位移 |
| 升级打怪 | 动作切入 | 中密度（每 3-4 章一个大钩子） | 身份抬升/能力显示 |
| 解密探案 | 异常/悬念前置 | 中高密度（每 2 章一个新悬念） | 信息开口/线索显影 |
| 甜宠日常 | 对话切入或环境切入 | 低密度（钩子可有可无） | 关系推进 |
| 幕后黑手 | 内心独白或信息切入 | 低中密度（蓄力期长） | 局面反击/局面逆转 |
| 废材流/扮猪吃虎 | 动作切入或异常前置 | 中密度 | 身份抬升 + 打脸 |

**蒸馏时的工作**：在模板中记录"该蓝本中，套路 D 章的平均钩子密度 vs 非套路 D 章的平均钩子密度"，量化套路对节奏的实际影响。

### 套路指纹的三重验证

每个套路指纹的认定，必须通过以下三重验证：

| 验证 | 方法 | 通过标准 |
| --- | --- | --- |
| **跨卷复现** | 同一套路在至少两个卷段中均可被观测到（如"扮猪吃虎"在前 30 章和 70-100 章都存有信号） | 若只在一个卷段成立 → 降级为"卷段局部套路" |
| **事件链完整性** | 套路的核心事件链（至少 3 个节点）在蓝本中被完整执行 | 若只出现了开头（如只"装"了但没有"打脸"）→ 标注为"未完成套路" |
| **纯度自洽性** | 同一套路在不同卷段被标注的纯度差异不超过 25 个百分点 | 若纯度差异 > 25% → 检查是否是套路变异，在"套路变异节点"中记录 |

### 套路提取的执行步骤

在 Phase 2（统计与提炼）中，套路提取作为独立步骤执行：

**3.5 套路提取**（在跨卷复现验证之前）：基于 Phase 1 的采样数据，执行套路识别五信号法，标注蓝本的套路清单、时间线、纯度、组合模式，产出 §十八 套路指纹草案。套路提取后，将其结果作为跨卷复现验证的"对照数据"——节奏规律的复现验证需要排除套路切换导致的节奏偏移。

### 套路提取的虚假信号排除规则

识别套路时需警惕以下虚假信号，避免误判：

| 虚假信号类型 | 说明 | 排除方法 |
| --- | --- | --- |
| **单章偶发** | 某套路的事件链信号只在 1 章中出现后续消失 | 不认定为套路，标注为"单章致敬/彩蛋" |
| **标签污染** | 平台给作品贴了某标签但正文中该套路未被执行 | 以正文事件链信号为准，平台标签仅作暗示，不能作为主要判定依据 |
| **读者过度解读** | 本章说说某处"像 XX 文"但作者本意并非该套路 | 检查事件链完整性——若事件链节点 ≥3 才认定 |
| **开局误导** | 前 3 章建立了一个套路预期但第 5 章后完全转向 | 标注为"开局误导套路"——区分于真正的套路切换 |

## 仿写三原则：深层/表层区分、三重原型缝合与私有化叙事（新增——吸收自知乎精华）

> 以下三原则框架来自知乎回答"如何从头到尾仿写一本小说，又让人看不出来是抄袭"（作者我的世界），从叙事学与认知心理学角度给出了仿写的底层方法论。

### 原则一：深层结构 vs 表层结构——区分"全人类共有的"和"某个人独有的"

**核心理念**：故事的情绪模型和人物关系结构属于叙事学的"深层结构"，是跨文化、跨时代的通用原型（荣格原型理论），本质上不属于任何一部具体作品。而情节、设定、台词属于"表层结构"，是作者对母题的个性化实现——这才是作品的指纹。

**蒸馏时的区分规则**：

| 可以提取（深层结构） | 不可以抄袭（表层结构） |
| --- | --- |
| 读者读完每章的情绪回报类型——"压抑中的微光""智商碾压的快感"等 | 具体情节——"主角坠崖得宝""被退婚三年之约"等 |
| 人物关系动力泵——"善良精英在角斗场中被迫异化"的内核模型 | 具体的人物台词、互动方式、建立关系的事件序列 |
| 跨卷问题链的移位逻辑——"从生存→复仇→原谅"的问题升级轨道 | 具体设定细节——时间、地点、势力名称、道具功能 |
| 情绪刺激密度的分布规律——"每3章一个小高潮"的节奏模式 | 具体的排比句式、叙事口吻、修辞习惯 |
| 套路指纹的切换与变异模式 | 原作的特定桥段组合方式（如果该组合不是通用套路） |

**验收标准**：蒸馏出的蓝本模板中，如果存在任何需要在仿写时保留"具体事件名称""特定地名""特殊道具名"才能运行的描述，说明蒸馏尚未完成——这部分仍然是表层结构，还未剥离到深层。

**仿写时情绪模型移植案例**（来自知乎精华）：
> 《甄嬛传》的深层结构不是"后宫争宠"，而是"一个善良的精英在封闭的角斗场里，为了生存不得不异化成自己最讨厌的人，最终赢了天下输了自己"。这个骨骼可以套在任何背景下：现代顶级金融投行+寒门出身的金融天才女主+公司内部派系林立的高管们如同嫔妃争宠。全篇没有出现一个妃子、一个皇帝，但"甄嬛式"的压抑、挣扎和悲剧性宿命感严丝合缝。

### 原则二：人物三重原型缝合——"三体融合"代替"二元混合"

**核心理念**：认知心理学中的"特征融合阈值"表明——把两个原型缝合时，读者可以通过二元对比反向拆解出素材来源（A+B=混合体，基因来源太清晰）。引入第三个原型C后，特征之间发生化学反应，产生A、B、C都不具备的"涌现特质"，这个角色不再是任何原型的变体，而是一个全新的生命体。

**三个，是最小可行的"熔炼数"**。

**蒸馏时的提取规则**：
- 在 §十七 仿写内核卡的"推荐视角转换方案"之后，新增 **"人物三重原型提取"** 字段
- 对蓝本中每个核心（主角/重要反派/关键配角），提取3个不同的原型来源：
  1. 蓝本中该人物最让人记住的"行为原则"是什么？
  2. 这个行为原则+蓝本的另一部作品中哪个经典角色的"核心驱动力"可以融合？
  3. 加入第三个来源：一个现实人物/历史人物的"独特行为逻辑"
- 三重原型的来源必须跨作品/跨领域——三个都来自同类小说的同类型角色，不算真正的三重缝合
- 三重原型提取在仿写中作为"人物差异化起点"，而非直接套用

**仿写人物设计示例**（来自知乎精华）：
> 要写一个迷人的反派：① 取《蝙蝠侠》小丑的"混乱哲学"（不是为钱，是要证明人性本恶）；② 取《JOJO》DIO的"极致之恶与超凡魅力"（作恶时有王者姿态，让追随者甘愿献上一切）；③ 取现实某位争议性企业家的"扭曲说服力"（用逻辑自洽的歪理把智商按在地上摩擦）。捏在一起放进温文尔雅西装革履的大学教授身体里——读者看着眼熟，但无法指认任何具体来源。

### 原则三：私有化叙事——"只抄技法，不抄句子，用自己的生命体验反哺"

**核心理念**：文笔和叙事技巧是最容易被查重的地方，也是最容易洗脱嫌疑的地方。正确的做法是拆解句子的**技法内核**（如马尔克斯开头的"时间折叠技术"——用一个句子在未来-现在-过去三个时空中自由穿梭），然后用自己真实的生命体验去灌满这个技法。

**蒸馏时的提取规则**：
- 在 §十七 仿写内核卡的"推荐高级时空技法"之后，新增 **"标志性技法提取"** 字段
- 对蓝本中最有辨识度的3-5个叙事段落，提取其技法内核而非句式：
  - 句式是什么？→ 跳过
  - 技法是什么？→ 记录（如"时间折叠""感官并联""情绪落差对比""信息延迟释放"等）
  - 创作者自己的生命体验该如何填入？→ 提供问题引导："你是否有类似的经历/情感记忆/场景观察可以用来灌满这个技法？"

**仿写示例**（来自知乎精华）：

> ❌ 拙劣抄句式："多年以后，面对裁员通知，张三将会回想起老板带他去见识大保健的那个遥远的下午。"
> ✅ 抄技法（时间折叠）："当签字笔落下，将公司拱手让人时，他忽然闻到了三十年前，父亲工厂倒闭那天，院子里被砍掉的梧桐树散发出的、带着苦涩汁液的木屑味。"
> ——没有马尔克斯的句式，但完美复刻了时间跳跃带来的伤感。技法是你的，情感是我的。

## 多蓝本协同蒸馏策略（新增）

> 本 Skill 的 argument-hint 中已注明"支持多作品交叉蒸馏"。本节定义多蓝本蒸馏的协同策略——当蒸馏目标不是一部蓝本，而是 2–5 部同赛道或互补赛道的蓝本时，如何提取各部之长，合成一份可供下游消费的"综合蓝本"。

### 何时使用多蓝本模式

| 场景 | 说明 | 建议蓝本数量 |
| --- | --- | --- |
| **同赛道取长** | 在同一赛道中，A 蓝本章首抓力强、B 钩子轮换好、C 中段回报密——各取所长 | 2–4 |
| **跨赛道杂交** | 将不同赛道的成功结构移植到目标题材（如把悬疑的"信息释放节拍"嫁接到都市职场） | 2–3 |
| **结构覆盖补全** | 单部蓝本卷段不全（如只有前 30 章可读），用同作者的另一部作品补全中后段节拍 | 2 |
| **求最大公约数** | 对多部同赛道爆款做交集分析，提取"它们都做了什么"的共性规律 | 3–5 |

### 三种协同策略

#### 策略 A：主辅法（推荐首用）

选定一部蓝本作为"主蓝本"（结构骨架基座），其余 1–3 部作为"辅蓝本"（只在特定维度上覆盖或替换主蓝本的值）。

```text
主蓝本：[作品 A] — 提供完整的 13 维基线
辅蓝本：[作品 B] — 仅替换 §二 章末钩子指纹 + §三 中段回报指纹
辅蓝本：[作品 C] — 仅补充 §十八 套路指纹
```

**产出方式**：一份"综合蓝本模板"：
- 未替换的维度直接沿用主蓝本值
- 被替换的维度标注"取自 [作品 B/C]，原始值见对应蓝本"
- 附注替换理由（如"作品 B 的平均钩子间隔 1.8 章 vs 主蓝本 2.5 章，更符合目标平台要求"）

#### 策略 B：分域法（维度级分工）

不设主蓝本，按维度域将各部蓝本分别蒸馏，合并为一份综合蓝本。

```text
蓝本 [作品 A] → §一 章首模式 + §二 章末钩子 + §三 中段回报（节奏三件套）
蓝本 [作品 B] → §四 场景节奏 + §五 POV + §六 对话密度（场景与视角域）
蓝本 [作品 C] → §七 信息释放 + §九 功能位 + §十二 跨卷节拍（长线结构域）
蓝本 [作品 D] → §十八 套路指纹（套路域）
```

**产出方式**：一份"综合蓝本模板"，每节开头注明数据来源。

#### 策略 C：交集法（共性优先）

对多部蓝本的同一维度分别统计，提取"多数成立"的共性规律，将"仅一部成立"的降级为补充建议。

```text
示例（三部起点悬疑蓝本的 §一 章首模式交集）：
- 作品 A：对话切入 35%，动作切入 30%，悬念前置 20%
- 作品 B：动作切入 40%，对话切入 25%，悬念前置 20%
- 作品 C：悬念前置 35%，动作切入 30%，对话切入 25%

交集结论：前三章章首模式均为"悬念前置→动作切入→对话切入"递进
→ 综合蓝本采纳此递进为默认章首序列
→ 各蓝本的分布差异写入"补充思路"供参考
```

**产出方式**：每项规律标注"共性规律"或"某蓝本独有（降级参考）"。

### 多蓝本冲突仲裁

| 冲突类型 | 处理方法 |
| --- | --- |
| **数值冲突**（A 钩子间隔 2 章，B 钩子间隔 4 章） | 以更符合目标平台/节奏要求的值为准，注明采纳值、被否决值及理由 |
| **方向冲突**（A 以对话切入为主，B 以悬念前置为主） | 以与目标题材风格更接近的蓝本为准，写入备注 |
| **结构冲突**（A 用单 POV，B 用多 POV） | 不强行合并——标注为"分域建议"：建议目标项目在 XX 章节用单 POV、YY 章节用多 POV |
| **套路冲突**（A、B 使用互斥的套路组合） | 以主赛道套路组合为准，另一套路写入"可选替代方向" |

**冲突记录**：所有冲突及仲裁结果必须写入档案包 `synthesis/`，不得暗中取舍。

### 综合蓝本产出命名

综合蓝本模板写为：

```text
蒸馏产物/作品蓝本模板/[合成标识]-综合蓝本模板.md
```

命名规则：
- **主辅法**：`[主蓝本名]-[辅蓝本名]-综合`（辅蓝本多于 1 部时用 `-多源`）
- **分域法**：`[主赛道名]-[目标题材]-综合`（如 `起点悬疑-都市悬疑-综合`）
- **交集法**：`[赛道名]-共性综合`（如 `番茄甜宠-共性综合`）

### 在 Agents.md 中的注册

综合蓝本注册为一组关联条目，合成条目统领各源蓝本：

```markdown
### 作品蓝本模板（合成）
- 合成标识：[如 "起点悬疑-都市悬疑-综合"]
- 主模板路径：蒸馏产物/作品蓝本模板/[合成标识]-综合蓝本模板.md
- 合成策略：[主辅法 / 分域法 / 交集法]
- 合成日期：YYYY-MM-DD
- 适用平台：[平台名] 或 默认
- 源蓝本：
  1. [作品 A] — 路径：蒸馏产物/作品蓝本模板/[作品A]-作品蓝本模板.md — 贡献维度：§一 章首模式 / §二 章末钩子
  2. [作品 B] — 路径：... — 贡献维度：§四 场景节奏 / §九 功能位
  3. [作品 C] — 路径：... — 贡献维度：§十八 套路指纹
```

合成条目与单蓝本条目在 `Agents.md` 中并列存在，名称以 `（合成）` 后缀区分。下游 Skill 自动发现时，**合成条目优先级高于单蓝本条目**；若合成条目不存在，回退到单蓝本。

### 单蓝本蒸馏 → 合成蒸馏的流程关系

- **先有单再合成**（默认流程）：先分别蒸馏各蓝本，各自生成独立模板并注册到 Agents.md，再执行合成蒸馏生成综合蓝本。保证每部蓝本的完整档案可被回溯审计。
- **跳过单本直接合成**（可选项）：若用户明确要求"直接出综合蓝本"，且各部蓝本均有成熟的公开样本，允许跳过独立注册直接合成，但合成结果必须引用各蓝本的来源信息。

## 执行流程

### Phase 0: 需求澄清

收到蒸馏请求后，确认：

1. **作品名**：确保理解正确
2. **章节范围**（必填）：蒸馏哪段范围？默认前 100 章或全本（若章节数 < 100）；用户可指定精确范围
3. **聚焦维度**（可选）：全部 13 维 vs 只聚焦节奏/钩子/回报/套路等特定维度？
4. **平台标注**：该作品首发在哪个平台？（会影响节奏判断的基准线——番茄的"快节奏"和起点的"快节奏"不同）
5. **套路蒸馏**（可选）：是否包含套路指纹提取？默认为是；用户可跳过（纯结构蒸馏）

用户说"蒸馏 XX 的蓝本"无更多信息 → 默认全 13 维 + 前 100 章（或全本）+ 包含套路指纹提取 + 网络搜索获取。

### Phase 0.5: 创建自包含蒸馏档案包

正式统计前，必须先在目标小说项目根目录创建或确认本轮蒸馏档案包：

```text
蒸馏产物/作品蓝本模板/[作品名]-作品蓝本档案/
	sources/                         # 用户提供或可公开读取的一手章节/目录/样章
	references/research/              # 本轮维度化采样记录，必须落盘
		01-章首模式指纹.md
		02-章末钩子指纹.md
		03-中段回报与高潮分布.md
		04-场景节奏与卷级节拍.md
		05-POV与对话密度.md
		06-信息释放与情感弧.md
		07-章节功能位与场景续景节拍.md
		08-人物出场节拍与跨卷迁移.md
		09-套路指纹.md                   # 套路清单/纯度/时间线/组合模式
	synthesis/                        # 规律归纳、冲突处理、样本置信度
	validation/                       # 质量验证记录
```

硬要求：

- 最终主模板仍写入 `蒸馏产物/作品蓝本模板/[作品名]-作品蓝本模板.md`，便于 `Agents.md` 注册和下游读取。
- 所有章节抽样、类型判定、钩子归类、回报间隔计算和冲突处理必须落入档案包；没有档案的蓝本不得标高置信。
- 若仅有目录而无正文，只能产出"目录级低置信蓝本"，不得伪装成正文级结构统计。
- 蓝本只提取叙事架构 DNA，禁止复制情节、人物关系、专属设定、专属意象或谜底设计。

### Phase 1: 信息采集

#### 采集优先级

**第一优先级（必须采集，统计级）**：
- **章首模式指纹**：逐章检查前 150-300 字的切入方式，分类统计
- **章末钩子指纹**：逐章检查章末 150-300 字的钩子类型，分类统计
- **中段回报指纹**：逐章识别中段回报类型和位置

**第二优先级（尽量采集，分布级）**：
- **场景节奏分布**：抽样 20-30 章判断紧张/松弛/爆发比例
- **POV 切换规律**：检查 POV 配置和切换频率
- **对话密度分布**：抽样统计对话占比

**第三优先级（补充采集，规律级）**：
- **信息释放节拍**：跟踪主要悬念/伏笔的设-埋-揭示时间线
- **情感弧分布**：抽样判断每章的情感入口→出口方向
- **章节功能位密度**：将每章按"钩子/蓄力/爆发/回报/转承保温"分为 5 种功能位，统计占比、连续出现上限和轮换规律
- **场景-续景节拍**：抽样 20-30 个场景，按"场景（目标-冲突-灾难）→ 续景（反应-困境-决策）"框架逐场景标注
- **人物出场节拍**：追踪核心人物（≥3 个）在全篇的出场章节号，统计间隔均值、最大间隔、新人物引入速率
- **跨卷节拍迁移**：将全篇按节拍模式分为 2-4 个阶段（如"铺垫期→加速期→爆发期→收官期"），分别统计各阶段的关键维度值（章首抓力密度、钩子轮换期、回报间隔等），并标注节拍迁移发生的章节位置

#### 模式判断

| 模式 | 触发条件 | 策略 |
| --- | --- | --- |
| 网络搜索 | 用户未提供本地素材 | 通过在线阅读平台获取目录+正文片段+书评分析 |
| 本地语料优先 | 用户提供了全书 txt/电子书 | 先读本地，网络搜索补充外部分析 |
| 纯本地语料 | 用户明确说"只用我给的素材" | 只分析本地素材 |

#### 信息源

| 来源类型 | 揭示什么 | 优先级 |
| --- | --- | --- |
| 用户提供的全书文件 | 完整文本，最精准的统计基础 | 最高 |
| 作品目录/章节列表 | 确认总章数和结构 | 高 |
| 作品公开正文片段 | 可获取的章节样本 | 高 |
| 书评/拆解分析/读后感 | 外部对叙事节奏的定性判断 | 中 |
| 作者创作谈（如有） | 作者对结构的有意设计 | 中 |

信息源黑名单：知乎、微信公众号、百度百科。

#### 信息不足时的处理

| 情况 | 处理 |
| --- | --- |
| 只有目录无正文 | 只能基于目录做章节数量级估算，无法做内容级分析 |
| 只有少量章节样本 | 降低统计置信度，标注"样本量偏小" |
| 外部分析信息矛盾 | 以一手文本为准 |

#### 叙事结构分析四工具（新增 — Phase 1 深度分析前置）

《改写小说的系统方法论研究》在 §3.3.1 中提供了四种具体的结构分析方法，可在 Phase 1 信息采集阶段并行使用。这些工具不替代 13 维度的统计，而是为维度统计提供更精准的"靶点"——先找出结构的关键节点和问题区域，再做统计时效率更高。

| 工具 | 方法 | 产出 | 服务于哪些维度 |
| --- | --- | --- | --- |
| **图表法** | 画出故事的结构框架图，标注主要情节、次要情节、转折点、高潮、功能位 | 一张"结构鸟瞰图"，直观展示全书的节奏骨架 | 章节功能位密度、场景节奏分布、跨卷节拍迁移 |
| **时间轴法** | 绘制故事时间轴，标注重要事件的发生时间点，分析时间流逝速度和跳跃规律 | 一条"时间线"，暴露"哪里时间跳得太快/太慢" | 信息释放节拍、跨卷节拍迁移 |
| **人物关系图** | 绘制人物关系网络，分析关系变化如何驱动情节发展 | 一张"关系网"，揭示"谁驱动故事、谁被故事拖着走" | 人物出场节拍 |
| **情节功能分析法** | 分析每个情节在整体结构中的功能——是铺垫、发展、转折、高潮还是结局 | 一个"功能标签清单"，回答"这一块情节到底是干什么用的" | 章节功能位密度、场景-续景节拍 |

**使用规则**：
- 四工具**不是必选项**——只在用户有完整文本可读时使用；仅靠目录和公开片段时跳过
- 图表法和时间轴法优先于人物关系图和情节功能分析法——前者回答"故事的结构骨架是什么"（形似层），后者回答"为什么这样安排"（神似层）
- 四工具的产出应作为 Phase 1.5 采样 Review 检查点的补充材料

### Phase 1.5: 采样 Review 检查点

完成章节采样后，先暂停输出一页采样质量摘要，确认是否继续提炼：

| 维度 | 样本范围 | 样本量 | 关键发现 | 风险 |
| --- | --- | --- | --- | --- |
| 章首模式 | 第 X–Y 章 | [N] 章 | [最高频切入方式] | [样本少/章节偏前/无] |
| 章末钩子 | 第 X–Y 章 | [N] 章 | [最高频钩子类型] | [无] |
| 回报/高潮 | 第 X–Y 章 | [N] 章 | [回报间隔] | [无] |
| POV/对话 | 第 X–Y 章 | [N] 章 | [POV规律/对话占比] | [无] |
| 信息/情感 | 第 X–Y 章 | [N] 章 | [悬念揭示节拍/情感弧] | [无] |
| 功能位/场景续景 | 第 X–Y 章 | [N] 章 / [N] 场景 | [功能位分布/场景节拍规律] | [无] |
| 人物出场/跨卷 | 第 X–Y 章 | [N] 章 | [人物间隔/节拍迁移点] | [无] |
| **套路指纹** | **第 X–Y 章/卷** | **[N] 卷** | **[检测到的套路清单/纯度]** | **[信号弱/组合复杂/无]** |

用户确认采样质量 OK → 进入 Phase 2。若样本偏窄，先补样本或在后续模板中明确降级为低置信。

### Phase 2: 统计与提炼

按 `references/作品蓝本模板格式定义.md` 的所有 section 逐项填充：形似层 §一至§十二，读者层 §十五至§十六，**商业层 §十九情绪刺激密度 + §二十对话占比 + §二十三商业化结构DNA**，套路指纹 §二十二。填充完成后，追加神似层提炼和套路指纹提取：

1. **套路提取**：基于 Phase 1 的采样数据，执行套路识别五信号法，标注蓝本的套路清单、时间线、纯度、组合模式、套路-节奏关联矩阵，产出 §十八 套路指纹草案。套路提取应在跨卷复现验证**之前**完成，因为节奏规律的复现验证需要排除套路切换导致的节奏偏移。（若用户在 Phase 0 要求跳过套路蒸馏，则跳至第 2 步）
2. **跨卷/跨事件线复现验证**：将每个结构规律在至少两个卷段和两种事件线（主线/支线）中交叉验证。仅在一个卷段成立的降级为"卷段局部特征"。
3. **从形到神的翻译——"叙事本能"**：为蓝本写一段叙事本能描述——涵盖叙事心跳、核心驱动问题链、以及在全新故事中如何运行这个引擎。
4. **叙事矛盾弧记录**：识别"常态规律 vs 打破时刻"，写入 §十四 叙事矛盾弧。打破不是 Bug，是叙事深度的来源。
5. **叙事引擎提炼**：从跨域复现通过的规律中，提炼 3-7 条"叙事引擎规则"——即在全新故事情境中也能指导节奏选择的隐性直觉。

**统计原则**：
- 所有占比数据标注样本量（N=X）
- 钩子类型/回报类型的判别标准明确（如"信息曝光型钩子"的定义是：章末文字中出现了主角或读者之前不知道的关键信息）
- 轮换规律必须基于数据推导，不能凭感觉编
- "禁忌"类判断（该作品不做的事）需要明确标注依据

### Phase 2.5: 提炼确认检查点

提炼完成后，不立刻写最终模板，先输出结构摘要给用户确认：

- 蓝本核心结构指纹：3–5 条（必须是可执行节奏/钩子/回报/套路规律）
- 量化字段：列出有明确样本量支撑的字段数量
- 低置信字段：列出只有目录、少量片段或二手评论支撑的字段
- 反复制边界：明确哪些内容绝不能被下游复刻（人物关系、设定机制、谜底、名场面）
- 与写作研究模板可能冲突的维度：例如平台通用要求更快节奏，但蓝本前期慢热
- **套路指纹摘要**：检测到 [N] 个套路，主套路纯度 [X]%，关键套路组合 [组合名]
- **神似层摘要**：叙事心跳一句话、核心驱动问题链、已识别的叙事矛盾弧对数、跨卷复现通过的规律数

用户确认提炼方向 OK → 进入 Phase 3。若用户认为蓝本方向不对，回到 Phase 2 调整分类和归因。

### Phase 3: 产出与注册

1. 按模板格式生成完整的作品蓝本模板 `.md` 文件
2. 写入目标项目根目录下的 `蒸馏产物/作品蓝本模板/[作品名]-作品蓝本模板.md`
3. 在目标项目根目录的 `Agents.md` 中追加注册条目（若 `Agents.md` 不存在则创建）
4. 若本轮蒸馏时用户明确指定了适用平台（如"番茄""起点""知乎"），注册时必须加上"适用平台"字段；若用户未指定平台，标记为"默认"。
5. 单蓝本蒸馏的注册条目格式：

```markdown
### 作品蓝本模板
- 名称：[作品名]
- 路径：蒸馏产物/作品蓝本模板/[作品名]-作品蓝本模板.md
- 蒸馏日期：YYYY-MM-DD
- 蒸馏范围：[第 X 章-第 Y 章]
- 首发平台：[平台名]
- 适用平台：[番茄 / 起点 / 七猫 / ...] 或 默认
```

其中 `适用平台` 取值为：
- `默认`：未指定平台，所有平台通用
- 具体平台名（如 `番茄`、`起点`、`知乎`、`豆瓣` 等）：该模板专门为指定平台蒸馏

**平台注册逻辑**（强制执行）：

- 蒸馏时若不指定适用平台，写入 `- 适用平台：默认`
- 蒸馏时若指定适用平台，写入 `- 适用平台：[平台名]`
- 若目标项目 `Agents.md` 中已存在同平台同类型模板，询问用户是覆盖还是并存
- 若目标项目 `Agents.md` 中不存在 `主输出平台` 字段，但本轮写入的平台明确且是第一次注册，建议用户指定主输出平台（可选，不强制）

**多蓝本蒸馏注册**：若本轮为多蓝本合成蒸馏，则按"多蓝本协同蒸馏策略"节的合成条目格式注册，而非上述单蓝本格式。合成条目在 Agents.md 中以 `（合成）` 后缀与单蓝本条目区分。

6. 给用户提供蒸馏摘要：提取了哪些关键规律、8 个维度的置信度评估。

### Phase 4: 质量验证

最终模板写入前，必须做四项验证：

1. **留出章节回测**：选择未参与统计的章节，检查模板是否能解释其章首模式、章末钩子、回报类型和节奏位置。
2. **位置预测测试**：给出一个虚拟章位（如"第 12 章小高潮前一章"），用模板推导应采用的章首、回报和钩子配置，检查推导是否清晰可执行。
3. **反抄袭边界检查**：确认模板只描述结构规律，不复刻原作剧情、人物关系、设定系统、谜底或名场面排列。
4. **遗失章节测试**（神似层验证，新增）：从蓝本原作中选一个**被略过的事件**（如"三日后抵达都城"中未写的三天），仅凭叙事引擎层生成一章控制卡和对应正文，邀请熟悉原作的读者做 A/B 盲测。若正文被误判为原作真迹的概率 ≥ 50%，模板达到神似层。

通过标准：

| 检查项 | 通过标准 | 不通过信号 |
| --- | --- | --- |
| 回测解释力 | 留出章节主要结构现象能被模板解释 | 模板只写"节奏紧凑"这类空话 |
| 可生成性 | 能指导新项目的章首/回报/钩子选择 | 下游无法据此生成控制卡 |
| 反抄袭边界 | 没有原作情节链、专属设定、人物关系搬运 | 出现可识别原作结构复刻 |
| 诚实边界 | 标注样本范围、缺口和低置信字段 | 看似全能，无来源说明 |
| 生成力 | 盲测误判率 ≥ 50% | 生成的控制卡/正文读起来像"套了模板"而非"长出了叙事本能" |

验证结果必须写入档案包 `validation/`，并在最终模板中给出"置信度综合"。

### Phase 5: 双 Agent 精炼

验证通过后，默认启动两路独立精炼视角（可由主执行者模拟，也可由子 Agent 执行）：

- **Agent A：结构可执行性审阅**——检查蓝本字段能否直接服务 `设计分卷大纲 / 生成章节控制卡 / 强化章节开头 / 强化章末钩子`。
- **Agent B：原创边界审阅**——检查是否存在情节复刻、设定借壳、人物关系搬运、名场面复制风险。

主执行者综合两份意见，只接受能提升"可执行性 / 可审计性 / 原创边界"的改动；不为追求像原作而牺牲原创性。

### 跨卷节拍迁移追踪（新增）

对于长篇作品（100+ 章），不同卷段的节奏参数通常存在显著差异。蓝本必须显式追踪这种迁移：

1. **节拍阶段划分**：将全篇按节奏模式分为 2-4 个阶段（如"铺垫期→加速期→爆发期→收官期"）
2. **阶段边界标注**：精确到章节号，说明迁移的文本信号（如"从第 35 章开始，钩子强度从低→高"）
3. **逐阶段统计**：每个阶段独立统计章首模式、钩子轮换期、回报间隔、对话密度等关键维度
4. **迁移模式总结**：一句话概括该作品的节拍迁移方向（如"前松后紧：30 章后密度翻倍" / "七紧三松：每 10 章 7 章高压"）
5. **迁移边界检查**：节拍迁移处是否伴随卷级换段、世界观扩展、或主角身份质变？标注触发事件

### 与专业总纲五维框架的对齐（新增）

蒸馏蓝本时，应主动将 12 个维度映射到专业总纲的五维框架，确保蓝本能直接回答以下问题：

| 专业维度 | 蓝本中的对应证据 | 对齐问题 |
| --- | --- | --- |
| **开篇设计** | 前 3 章的章首模式+钩子+回报统计 | 该作品的开篇是告知型还是诱惑型？前 3 章是否形成"金手指→选择→小高潮"闭环？ |
| **节拍密度** | 章节功能位密度+中段回报指纹+钩子指纹 | 该作品的爆点密度在 1-10/11-30/31-50/51-70/71-100 章各区间的实际分布如何？ |
| **矛盾四层** | 跨卷分析中外部冲突/内部冲突/关系冲突/主题冲突的出场频率与交织模式 | 该作品是否四层并存？哪层是主导？层与层之间的触发关系是什么？ |
| **人物设计** | 人物出场节拍+情感弧分布 | 该作品的核心人物是否具备可辨识的成长弧光？人物回归频率是否形成了读者的期待节拍？ |
| **商业思维** | 章末钩子指纹+中段回报指纹+场景-续景节拍 | 该作品的钩子轮换和回报间隔是否明显服务于付费点/追读率等商业目标？ |

蓝本提炼确认时（Phase 2.5），必须额外输出一份"五维对齐摘要"，逐维写清该作品的表现等级（强/中/弱/不适用）与可迁移规律。

### 更新已有作品蓝本模板

当用户说"更新某作品蓝本"、"加入后续章节"、"这个蓝本不准"时：

1. 先读取现有蓝本模板和档案包，确认样本范围、调研日期、章节覆盖和置信度。
2. 只对新增章节、新增卷段或用户指出的不准维度做增量采样。
3. 对比新旧结论：
	- 新样本强化旧规律 → 补来源与样本量
	- 新样本推翻旧规律 → 标注"阶段性节奏变化"，按卷段拆分规律
	- 新样本只在特定卷段成立 → 写成"卷段局部规律"，不得覆盖全书蓝本
4. 更新模板中的蒸馏日期、样本范围、置信度和版本说明，不重写无关字段。

## 三模板冲突仲裁规则（新增）

当作品蓝本模板与作者风格模板、写作研究模板同时作用于同一字段时，按以下优先级裁决：

| 冲突场景 | 优先顺序 | 裁决逻辑 |
| --- | --- | --- |
| 蓝本与写作研究的结构约束冲突 | 蓝本优先 | 验证过的作品结构规律 > 通用研究建议 |
| 蓝本与作者风格的文笔约束冲突 | 作者风格优先 | 文笔字段（句长/段落/感官等）蓝本不涉及；蓝本只提供结构参照 |
| 平台硬门槛 vs 蓝本 | 平台硬门槛优先 | 若写作研究中的某条约束标注了"硬门禁"（如起点追读率底线），覆盖蓝本的同字段约束 |

## 结构DNA符合度审计（新增）

作品蓝本的终极检验标准是：**用这套蓝本模板指导创作的小说大纲和正文，其叙事架构是否与原作"同源"**——不是情节相同，而是节奏节拍、钩子密度、回报间隔、功能位分布等结构指纹高度一致，让熟悉原作的读者在结构层面感受不到差异。

### 审计对象

结构DNA审计同时适用于两类下游产物：

| 下游产物类型 | 审计内容 | 产出 Skill |
| --- | --- | --- |
| **大纲层**（总纲/分卷/章清单） | 节拍密度分布、功能位分布、高潮间隔、跨卷节奏迁移 | `通用-设计总大纲` / `通用-设计分卷大纲` |
| **正文层**（单章或多章正文） | 章首模式、章末钩子、中段回报、场景-续景节拍、人物出场间隔 | `通用-创建小说正文` / `通用-生成章节控制卡` |

两类审计使用不同的维度子集（见下文），但共用同一套符合度分级标准。

### 审计时机

当且仅当以下条件同时满足时，启动结构DNA审计：

1. 当前项目已存在一份通过 Phase 4 质量验证的**作品蓝本模板**
2. 下游 Skill 已产出一份**可供比对的成品**——至少满足其一：
   - 总大纲 + 至少 1 卷的分卷大纲/章清单（≥ 10 章的章级规划）
   - 连续 ≥ 5 章的正文
3. 用户明确要求"审计结构DNA""比对节奏""看看结构像不像"或类似表述

### 审计维度与计算方式

#### A. 大纲层审计维度

| 维度 | 数据来源（产出大纲） | 对比基线（蓝本模板） | 差异计算方式 |
| --- | --- | --- | --- |
| 功能位分布 | 统计章清单中各功能位（钩子/蓄力/爆发/回报/转承保温）的占比和连续出现上限 | 蓝本 §九 章节功能位密度 | JS 散度（0–1，越小越像）；连续出现上限是否 ≤ 蓝本标注值 |
| 高潮/爆点间隔 | 统计章清单中高潮章/爆点章的间隔均值和标准差 | 蓝本 §四 场景节奏分布的高潮分布 + §三 中段回报指纹的回报间隔 | 均值差异 ≤ ±1 章；标准差差异 ≤ ±30% |
| 跨卷节奏迁移 | 对比产出大纲的阶段划分、各阶段参数与蓝本的对应阶段参数 | 蓝本 §十二 跨卷节拍迁移 | 各阶段关键维度值差异 ≤ ±20%；阶段边界偏差 ≤ ±2 章 |
| 人物出场规划 | 统计大纲中核心人物的规划出场章号和间隔 | 蓝本 §十一 人物出场节拍 | 间隔均值差异 ≤ ±20%；最大间隔 ≤ 蓝本标注值 |
| 信息释放节拍 | 统计大纲中设悬念/部分揭示/完全揭示的标注间隔 | 蓝本 §七 信息释放节拍 | 均值差异 ≤ ±1 章 |

**大纲层权重**：功能位分布 25%、高潮间隔 25%、跨卷迁移 20%、人物出场 15%、信息释放 15%

#### B. 正文层审计维度

| 维度 | 数据来源（产出正文） | 对比基线（蓝本模板） | 差异计算方式 |
| --- | --- | --- | --- |
| 章首模式 | 逐章检查前 150–300 字的切入方式，统计各类型占比 | 蓝本 §一 章首模式指纹 | JS 散度 |
| 章末钩子 | 逐章检查章末 150–300 字的钩子类型，统计占比和轮换期 | 蓝本 §二 章末钩子指纹 | JS 散度 + 轮换期偏差 ≤ ±1 章 |
| 中段回报 | 逐章识别回报类型和位置，统计间隔和轮换规律 | 蓝本 §三 中段回报指纹 | 回报间隔差异 ≤ ±1 章 |
| 场景-续景节拍 | 抽样 5 个场景，按"目标-冲突-灾难→反应-困境-决策"标注 | 蓝本 §十 场景-续景节拍 | 冲突升级率差异 ≤ ±15%；决策驱动率差异 ≤ ±20% |
| 对话密度 | 统计每章对话占比均值和轮换规律 | 蓝本 §六 对话密度分布 | 均值差异 ≤ ±10%；连续高/低密度章数 ≤ 蓝本标注上限 |
| POV 切换 | 统计 POV 配置占比和切换触发条件 | 蓝本 §五 POV 切换规律 | JS 散度 + 章内切换次数 ≤ 蓝本标注上限 |
| 人物出场 | 追踪核心人物实际出场章号，统计间隔 | 蓝本 §十一 人物出场节拍 | 间隔均值差异 ≤ ±20%；无超出"蒸发预警阈值"的空窗 |

**正文层权重**：章首模式 15%、章末钩子 20%、中段回报 20%、场景续景 15%、对话密度 10%、POV 切换 10%、人物出场 10%

### 综合DNA符合度计算

```
综合符合度 = Σ(维度得分 × 维度权重) / Σ(维度权重)

维度得分：通过=100；未通过按偏差比例线性映射到 0–100
```

### 符合度分级

| 综合符合度 | 等级 | 含义 | 是否放行 |
| --- | --- | --- | --- |
| ≥ 90% | S 级 | 结构DNA高度一致，几乎可视为同一作品的节奏图谱 | ✅ 放行 |
| 80%–89% | A 级 | 核心结构指纹吻合，差异在可接受范围 | ✅ 放行 |
| 70%–79% | B 级 | 整体方向对，但部分维度结构偏差明显 | ⚠️ 附带整改清单放行 |
| 60%–69% | C 级 | 多个结构维度与原作显著偏离 | ❌ 回炉，回到对应设计 Skill |
| < 60% | D 级 | 结构DNA不匹配，蓝本参照失效 | ❌ 回到蓝本蒸馏阶段，检查模板是否失准 |

### 审计后的闭环动作

- **S/A 级**：归档审计报告。
- **B 级**：将审计报告中的偏差项转译为对应设计 Skill 的具体修改任务（大纲偏差→`通用-设计总大纲`/`通用-设计分卷大纲`，正文偏差→`通用-生成章节控制卡`/`通用-正文润色`），修改完成后**复跑审计**直至 A 级以上。
- **C/D 级**：C 级回炉到对应设计 Skill；D 级回到蓝本蒸馏阶段，说明蓝本模板本身可能失准或取样不足。

## 与其他 Skill 的边界

- 本 Skill 蒸馏**单部作品的叙事架构特征**。
- `通用-蒸馏作者文风` 蒸馏**作者层面的文笔特征**（横跨该作者的多部作品）。
- `通用-分析竞对作品` 做**竞争层面的市场分析**（市场数据、内容创作、运营策略、受众反馈四层），与本 Skill 的叙事架构蒸馏是互补关系。
- `通用-设计分卷大纲` 和 `通用-生成章节控制卡` 消费本 Skill 产出，作为节奏和结构的参照蓝本。

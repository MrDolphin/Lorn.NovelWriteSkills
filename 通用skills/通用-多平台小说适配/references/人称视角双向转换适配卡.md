# 人称视角双向转换适配卡

> 适用：平台分流前的视角策略决策，支持 `第一人称 ↔ 第三人称` 双向转换。
>
> **权威源声明**：各平台的人称锁定以工作区根目录 `平台POV基线表.md` 为唯一权威源。本适配卡负责"怎么切换"，不负责"该不该切换"——后者由 `平台POV基线表.md` 裁定。任何偏离基线表锁定值的人称切换，必须在 `适配策略/` 中记录偏离原因并逐条举证。

## 何时切换人称

- **先查 `平台POV基线表.md`**，确认目标平台的当前锁定人称。
- 若源稿人称与基线表锁定值一致 → 不切换，维持原人称。
- 若源稿人称与基线表锁定值不一致 → 按本适配卡执行转换，并在推演清单记录。
- **严禁在未查基线表的情况下自行裁定平台人称。**

## 双向转换总规则

- 必须可逆：`1→3` 与 `3→1` 都可执行。
- 必须保真：不丢信息、不改因果、不偷换立场。
- 必须控歧义：人物首次出现补关系锚，代词链可回指。

## 路径 A：第一人称 → 第三人称

1. 主语替换：`我` 改为角色名/他（按段位选择）。
2. 首现关系锚：首次出现“关系+姓名”同框。
3. 吐槽拆洗：括号吐槽改为动作/对话/体感反应。
4. 代词复检：多人同场时回补名字锚点，避免“他/她”混淆。

## 路径 B：第三人称 → 第一人称

1. 视角锚定：先确定唯一“我”是谁，本章中不漂移。
2. 信息裁剪：删除“我不可能知道”的全知信息。
3. 认知重写：将客观旁白改写为“我感到/我判断/我误判”。
4. 关系回补：把原三人称中的关系信息改成“我与他/她”的可感关系。

## 平台场景速查（供创建基线表条目时对照）

> 下表不是"答案"——各平台最终的人称锁定在 `平台POV基线表.md`。下表是帮助你**判断**的思维框架。详细场景分析见各 `通用-输出*版` Skill 的 `POV 选择指南` 节。

| 平台 | 第一人称的优势场景 | 第三人称的优势场景 | 核心权衡 |
| --- | --- | --- | --- |
| **番茄小说** | 主角有独特感知（异能力/特殊视角）；封闭空间猫鼠游戏 | 多角色快速切换、高外部事件密度；算法需要每屏有情绪回报 | 心理独白比例 vs 外部事件密度 |
| **七猫小说** | 普通人被卷入案件；感官联动式恐惧；"如果是我也会害怕" | 刑侦程序流、多线并行追踪；职业执法者视角 | 贴脸感 vs 信息宽度 |
| **知乎** | 亲历者自述体；可讨论的判断链；"我如何推理"的参与感 | 群像拼图、复杂时序回放；多角色信息拼接 | 讨论张力 vs 信息承载量 |
| **豆瓣** | 心理深度型（个人创伤/道德困境）；"和一个角色一起经历" | 社会观察型（群像处境/社会压迫）；"看多个角色在社会机器中挣扎" | 心理深度 vs 社会广度 |
| **出版社** | 法医秦明式职业亲述；专业身份锚定可信度 | 雷米式全景群像；多卷本长线结构；审读最友好 | 亲述说服力 vs 结构稳健度 |
| **微信订阅号** | 魔宙式"肩扛摄像机"跟拍普通人；周更陪伴关系 | 程序链/证据链需多角色承载；工程连载型悬疑 | 个人连接感 vs 证据连续性 |
| **百度百家号** | 调查记者/吹哨人亲历叙事；"我看到的"增加可信度 | 信息传播型多角色交汇；搜索友好；客观可信度感知 | 个人见证 vs 信息客观性 |
| **今日头条** | 主角认知偏差/心理误导做反转引擎；标题可借"我"抓点 | 多角色冲突+可讨论话题；信息流快速理解；深第三+推荐标题组合 | 代入强度 vs 讨论广度 |
| **小红书** | **几乎独占**：平台基因="我的体验"；藏线索机制；分享按钮为"我"而设 | 仅源稿有大量落盘无法切换时 | — |
| **新浪微博** | 即时情绪共振；短促抓点转发驱动；"我遭遇了"传播力最强 | 多角色拼图式叙事（不同角色掌握不同碎片） | 情绪密度 vs 拼图复杂度 |
| **B站** | 第一人称沉浸式体验（类FPS游戏视角）；单人恐怖实况感 | 弹幕评论多角色；视听化群像调度（类悬疑番剧导演视角） | 沉浸感 vs 讨论维度 |
| **纵横小说** | 单线调查自述驱动；证据链由"我"亲历；与主角同步推理 | 主角有"失去意识/无法感知"的场景需要补信息；需要偶尔展现主角背影/外部动作 | 推理沉浸度 vs 叙事灵活度 |
| **GoodNovel** | romance/thriller情感驱动；"I felt"跨文化通用 | 案件链+cliffhanger多视角并行；双主角关系张力 | 情绪通道 vs 多视角信息 |
| **My Fiction** | 关系向互动：读者与"我"一对一连接驱动订阅 | 信息密集型多线案件；结构清晰优先 | 关系黏性 vs 结构清晰度 |
| **WebNovel** | romance类型（情感人类共通）；已有成熟受众群 | **默认首选**：跨文化可读性最高；因果链全球通用；避免文化特定内心表达障碍 | 情绪普适性 vs 因果普适性 |

## 完成判定

- 人称切换后，读者不因指代混乱出戏。
- 关键事件、证据、关系与章末钩子保持一致。
- 遮住平台名后，文本仍能体现目标平台气质，而非“仅改了代词”。

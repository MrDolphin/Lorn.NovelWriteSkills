# 通用-设计题材定位框架

题材定位不是写一句“这本书是什么”，而是先把这本书为什么能成立、为什么能持续、为什么读者会继续追钉死。

## 一句话定全书：核心三要素（前置确认）

> **来源**：自知乎精华《如何写好一个优质的长篇小说？》（摘星，2026-06-17）。

在进入任何定位流程之前，必须先钉死以下三个问题——它们是整本书的“圆心”，后续所有决策（题材选择、平台校准、套路定位、代偿设计）都必须能回指到这三个要素。任何一个模糊，后续设计就会漂移：

| 要素 | 定义 | 验收标准 |
| --- | --- | --- |
| **主题（内核）** | 这本书最终想表达的内核——不是题材（“悬疑”），而是内核（“一个被冤枉的人如何找回自己的名字”） | 能否用一句话说清这本书“最终在讲什么”？如果只能说“悬疑+重生”，未达标 |
| **总冲突（驱动力）** | 外部恩怨/危机 + 主角内心缺陷/执念。两者必须同时存在，缺一不可 | 能否同时写出“外部危机是什么”和“主角内心过不去的那道坎是什么”？缺任何一个，冲突链就不完整 |
| **终极目标（终点）** | 主角从头到尾要完成的那件事——全程不跑偏的标尺 | 删除终极目标后，主角的行动链是否还能成立？若能，说明终极目标尚未钉死 |

### 三要素的互锁关系

- 三个要素必须**互相支撑**：主题决定终极目标的方向，总冲突为核心目标的推进提供持续的阻力，终极目标使总冲突不会沦为单纯的“打怪升级”。
- 其中任何一个要素被替换，另外两个也必须跟着调整——不能只改“终极目标”而保留原来的主题和冲突。
- 验收方法：如果三个要素写完后，随便替换其中一个（例如把“被冤枉的警察”换成“被背叛的特工”），故事仍然看起来成立——说明三要素还不够具体，需要继续收紧直到“只有这个主角、这个处境才能成立”。

## 灵感来源——先吸收，再创造（强制）

> **核心原则**：最赚钱的故事创意，从来不是凭空想出来的，而是从大量竞品、标杆、素材和研究里"长"出来的。题材定位的第一动作不是"想一个创意"，而是**先打开所有可吸收的灵感来源**。

在执行题材定位或概念工厂之前，必须先扫描并加载以下全部可用的灵感来源。**至少加载三种以上来源后才能进入概念生成环节**，否则判为"闭门造车"，输出的定位大概率没有竞争力。

### 来源一：网络搜索——捕获最新趋势（新增置顶）

> **核心原则**：网文趋势以月为单位变化。本地文件（竞对分析、写作研究等）的结论反映的是**截至数据采集时的市场状态**，无法覆盖最近几周的新风向、新爆款和新套路。**所有定位工作的第一步，必须是打开网络搜索捕捉最新信号。**

执行题材定位前，必须先用网络搜索捕获当前最新趋势，避免拿着过时数据和过气套路来做设计：

| 搜索方向 | 搜索目的 | 定位阶段如何使用 |
| --- | --- | --- |
| **赛道最新风向** | 搜索"{目标题材} + 网文 + {当前年份} + 趋势/爆款/新书" | 验证V1(题材)选择是否仍处于上升期，而非已过气的赛道；若搜索结果与本地研究结论不一致，以最新搜索结论为准 |
| **新晋爆款拆解** | 搜索"{目标题材} + 近期完本/连载 + 爆款/黑马/高收藏" | 补充本地竞对分析未能覆盖的最新竞品样本；重点关注最近 1-3 个月内崛起的新书 |
| **套路时效性验证** | 搜索"{套路名称} + 网文 + 饱和/过时/读者厌烦" | 验证计划使用的套路组合是否已被市场淘汰或读者疲劳；避免在2026年仍用2023年的热门套路 |
| **平台最新动向** | 搜索"{目标平台} + 新政策/征文/扶持计划 + {当前年份}" | 确认平台近期是否有题材扶持、征文活动或规则调整，校准V2(平台口径) |
| **读者情绪迁移** | 搜索"{目标题材} + 读者/书评 + 想看/审美/疲劳" | 捕捉读者偏好的微妙迁移——如"读者开始对XX套路审美疲劳，转向YY方向" |
| **跨行业信号** | 搜索"短剧/影视 + {目标题材} + 趋势 + {当前年份}" | IP衍生方向的先验信号，判断题材的跨媒介热度是否仍在上升 |

> **搜索来源**：可以使用环境中任意可用的搜索工具（如 Bing 搜索、智谱搜索、阿里百炼搜索等），根据可获得性和实时性选择合适的工具。搜索结论必须标注来源与搜索时间（精确到月），以便下游判断信息的时效性。不得将未经验证的搜索摘要作为决定性证据。

## 微创新维度（新增 — 概念工厂/PK筛选阶段）

> **来源**：七猫作家交流区精华帖 #34903《怎么写好微创新？在众多类型的小说中突出重围？》（编辑云杉，收藏14，阅读10888）。本文档提炼的微创新框架已沉淀为 `references/微创新框架与人设情节创新.md`。

题材定位的"创新组合"维度不能只靠直觉判断。引入微创新框架作为概念工厂阶段的评估工具：

### 微创新的核心约束

1. **不走"开创流派"路线**：受众群体有限的创新不是需要的微创新。在原有套路里创新才是最高效的。
2. **不追求每个剧情都与众不同**：成熟的套路是稳住后期质量的关键。微创新只针对**开篇切入部分**和**核心人设**。
3. **创新必须可被"一句话说清"**：如果不能用一句话说明"新在哪里"，说明微创新未落地。

### 人设微创新的两个方向

| 方向 | 类型 | 操作要点 |
| --- | --- | --- |
| **人物关系创新** | ①纯粹的男女主关系创新；②涉及配角的男女主关系创新；③重要配角关系创新 | 在标准人设上叠加一层非常规关系，关系必须对剧情推进有直接影响 |
| **身份职业创新** | ①该题材不常见身份；②特殊身份职业 | 选择该题材很少出现但有叙事价值的职业，能力必须推动主线 |

### 情节微创新的两个方向

| 方向 | 核心 | 适用题材 |
| --- | --- | --- |
| **生活化情节创新** | 日常细节中的细腻情绪调动 | 都市、婚恋、甜宠 |
| **夸张化情节创新** | 狗血戏剧性场景，涉及生死/极端抉择 | 古言、虐恋、玄幻 |

### 验收标准（概念生成与PK均适用）

1. 能否一句话说清"这书新在哪里"？
2. 这个创新是否让大部分目标读者有兴趣，而不是"好奇怪"？
3. 这个创新是否可叙事化——能在剧情中被反复使用，而不是一个标签？
4. 这个创新是否与核心卖点兼容？
5. 开篇 1-3 章内能否展示给读者这个创新？

详细框架见 `references/微创新框架与人设情节创新.md`。

### 来源加载优先级

**第一步：网络搜索捕获最新趋势（来源一）**——先确认当前网文市场的最新风向，避免拿着过时数据做设计。搜索结论必须标注来源与搜索时间。

**第二步：并行加载本地资产**——竞对分析报告（来源二）、作品蓝本（来源三）、写作研究（来源四）、素材库（来源五）、网络深度补证（来源六）、平台标签库（来源七）。本地下载与标签库加载可并行。

**第三步：来源七（平台标签库）仅在概念工厂启动或套路定位时加载**，纯定位诊断阶段可跳过。

> - **两步走 = 先选定方向（概念工厂），再砌墙（框架深化）。缺一步都不完整。**

## 商业思维五要素——从自嗨创作到精准打击（强制）

业余大纲思考的是"我想写什么""我觉得这个设定很酷"。专业大纲思考的是市场、读者、竞争、商业节点与数据预留。题材定位时，必须逐一回答以下五要素：

### 一、市场定位
- 这个题材在目标平台是否饱和？蓝海还是红海？
- 若为红海，差异化切入点是什么？若为蓝海，为什么此前没人做成？
- 示例："都市+异能+群像，避开纯修仙红海"——一句话说清赛道选择。

### 二、读者画像
- 核心读者是哪些人？年龄区间？阅读偏好？
- 第一目标读者群与第二目标读者群分别是什么？
- 示例："18–25 岁男性为主，喜欢快节奏、强对抗"——画像必须具体到可指导创作决策。

### 三、竞争差异化
- 同期爆款做对了什么？我方可以在哪些维度做出本质不同？
- 差异化不能只是"我写得更好"，必须是"我提供了一种竞品没有的阅读体验"。
- 示例："不写个人英雄主义，写'异能者团队协作'"——差异化必须在简介和前 3 章就能被读者感知。

### 四、商业节点
- 多少字可以安排第一个付费点/第一个强钩子？
- 何时适合开启 IP 衍生的支线或人物外传接口？
- 哪个角色最容易出圈，成为"梗"或"表情包"？
- 示例：
  - 第 30 章安排第一个小高潮，刺激首次付费
  - 第 80 章设计团队分裂危机，制造话题讨论
  - 第 150 章引入"国家异能机构"设定，为 IP 扩展预留空间

### 五、数据预留（名场面与传播点）
- 在哪个剧情点安排"名场面"刺激读者分享与截图传播？
- 如何设计"话题性情节"引发评论区讨论与本章说站队？
- 何时抛出悬念最适合增加追读率？
- 关键角色是否配置了标志性台词，易于传播？
- 重要战斗/场景是否考虑了视觉化呈现难度（为短剧/动漫改编预留）？
- 示例：
  - 每 15 章设计一个"团队高光时刻"，适合短视频剪辑
  - 关键角色配置标志性台词，易于传播
  - 重要战斗场景考虑视觉化呈现难度

### 商业思维验收规则

- 题材定位框架必须至少完整回答五要素中的四项；若只能回答"我想写什么"而无法回答"市场在哪、读者是谁、如何差异化"，判为商业思维缺失。
- 商业节点与数据预留可以标注为"待定"（尤其是早期项目），但不得完全空白；标注"待定"时需说明预计在哪个阶段（总纲/分卷/正文第 X 卷）补齐。

## 套路定位——确定作品使用的公式化叙事模板

> 题材定位不能只停留在"写什么题材"，还必须回答"用哪组套路来写"。"先婚后爱"不是题材（它属于现言/古言题材下的人物关系套路），"扮猪吃虎"不是题材（它属于玄幻/都市题材下的情节推进套路）。题材确定赛道，套路确定**读者预期**。
>
> **套路与叙事架构的正交性**：同一套路可以用不同节奏讲（追妻火葬场可以快节奏也可以慢热），同一节奏可以讲不同套路。套路定位决定"讲什么故事"，节奏设计决定"怎么讲"——两者独立决策、交叉消费。

### 套路四级分类体系（完整版）

基于对大量网文标签体系、读者讨论、推荐系统与竞品拆解的分析，网文套路可归纳为 **四个层级**，每选一层时**必须从表格中选择至少一个**：

#### 第一级：核心设定类——故事的"初始配置"

决定了"这个世界/主角凭什么不一样"。这是读者点开书后第一个接收到的信号。

| 套路 | 定义 | 读者预期 | 常见题材域 | 生命周期 |
| --- | --- | --- | --- | --- |
| **穿越** | 主角从现代/异界穿越到目标世界 | 信息差优势 + 现代知识降维打击 | 古言、历史、奇幻 | 贯穿全书，但知识优势在第2-3卷后递减 |
| **重生** | 主角死后回到过去重活一次 | 预知未来 + 弥补遗憾 + 复仇 + 先知先觉 | 都市、言情、修仙 | 贯穿全书，预知优势在第3卷后耗尽→需切换为"蝴蝶效应"驱动 |
| **系统** | 主角获得游戏化辅助系统 | 数据化成长 + 任务驱动 + 面板爽感 | 全题材（玄幻/都市/悬疑常见） | 贯穿全书，但需注意系统升级线不能与主线脱节 |
| **穿书** | 主角穿越进一本小说中 | 预知剧情 + 改变命运 + 与原著角力 | 女频言情 | 贯穿全书，预知优势在中段耗尽→需转为"被剧情反噬" |
| **异能觉醒** | 主角在现实世界中获得超常能力 | 日常中的非常规 + 隐藏身份 | 都市异能、悬疑 | 贯穿全书，能力成长线替代传统升级 |
| **日常/现实** | 无超自然设定，聚焦现实生活 | 真实感 + 代入感 + 生活质感 | 都市、职场、现实题材 | 贯穿全书，靠人物关系和社会压力驱动 |

**选择规则**：选且只选一种作为主角的初始配置。叠用（如"重生+系统"）需在概念工厂R1兼容性检查中说明两套配置的互动逻辑。

#### 第二级：人物关系类——角色之间的配置张力

决定了"读者为什么关心这些人之间的互动"。**男频可弱化此层（选"无核心关系驱动"），女频必须选。**

| 套路 | 核心关系张力 | 典型事件链 | 主要题材域 | 生命周期 |
| --- | --- | --- | --- | --- |
| **先婚后爱** | 婚约已存在但无感情 | 被迫成婚 → 磨合 → 产生真感情 | 女频古言/现言 | 贯穿全书，感情升温线自然支撑长线 |
| **追妻火葬场** | 一方辜负后追悔 | 付出 → 被辜负 → 离开 → 追回 | 女频言情 | 前30章虐→中30章独立成长→后30章追回 |
| **替身文学** | 一方被当作他人替身 | 被替代 → 发现真相 → 身份觉醒 | 女频言情 | 前20章替身期→中段觉醒→后段反转 |
| **白月光/朱砂痣** | 心中有个无法替代的人 | 比较 → 伤害 → 白月光塌房/释然 | 女频言情 | 前15章白色月光压制→中段塌房→后段释然 |
| **破镜重圆** | 分离后重逢 | 分手/离婚 → 各自成长 → 重逢 | 女频言情 | 前10章重逢冲突→中段重新认识→后段再选择 |
| **师徒恋** | 师生关系中的禁忌感 | 授业 → 依赖 → 越界 → 立场冲突 | 仙侠、玄幻 | 前30章师慈徒孝→中段越界→后段对抗外界 |
| **契约婚姻** | 假结婚各取所需 | 签契约 → 假夫妻 → 真感情 | 女频现言/古言 | 全程张力维持（契约解除倒计时驱动） |
| **对照组/打脸** | 被看不起 → 证明自己 | 被轻视 → 隐忍 → 爆发打脸 | 全题材 | 可贯穿全书，每卷一个打脸对象 |
| **雇佣关系** | 雇主与雇员间的地位差与逐渐平等 | 利益绑定 → 互相了解 → 地位翻转 | 都市、职场 | 前20章雇佣压制→中段反转→后段平等 |
| **无核心关系驱动** | 主线不依赖关系张力，关系仅作为辅料 | N/A | 玄幻升级流、硬核悬疑 | 关系套路可选跳过，但不得为零（至少留一条关系线） |

#### 第三级：情节推进类——驱动故事的事件模板

决定了"每一章/每一卷靠什么让读者想翻页"。**必须选1-2个，第一驱动和第二驱动。**

| 套路 | 定义 | 典型节奏 | 主要题材域 | 生命周期 |
| --- | --- | --- | --- | --- |
| **升级打怪** | 通过战斗/考核逐步变强 | 遇敌 → 战斗 → 升级 → 更强敌人 | 玄幻、奇幻、修仙 | 贯穿全书，但需注意"战力通胀"——每卷升级幅度需递减 |
| **解密探案/单元案** | 逐个解决案件/谜题，同时推主线 | 接案 → 调查 → 破案 → 牵出主线 | 悬疑、推理、都市 | 贯穿全书，单元案闭环+主线暗线的双线模式天然撑长篇 |
| **扮猪吃虎** | 主角故意隐藏实力后惊人爆发 | 低调 → 被挑衅 → 碾压对手 → 众人震惊 | 全题材 | 核心动力是"打脸→新身份→更大舞台"的循环，可全程维持 |
| **掉马甲** | 主角隐藏的身份被逐步揭露 | 隐藏身份 → 蛛丝马迹 → 身份曝光 → 震撼 | 全题材（常见于男频） | 前30章藏→中30章逐步漏→后段全曝光 |
| **退婚流** | 开局/早期被退婚由此开启主线 | 被退辱 → 立誓 → 逆袭打脸 | 玄幻、古言 | 通常只能支撑前30-50章，之后需切换到新驱动引擎 |
| **废材流** | 主角被认为是废物实则不凡 | 被轻视 → 隐藏实力 → 震惊全场 | 玄幻、修仙 | 前20章废物期→中段开始展露→后段王者归来 |
| **幕后黑手** | 主角在暗中操控局势 | 布局 → 棋子行动 → 收网 | 智斗、权谋、都市 | 贯穿全书，蓄力期长——前3章需有补偿性替代回报 |
| **种田/基建** | 从零建设势力/领地 | 白手 → 发展 → 扩张 → 遇威胁 | 历史、奇幻、科幻 | 贯穿全书，建设线+外敌线的双线推进 |
| **复仇流** | 主角以复仇为终极目标的推进模式 | 确认仇人 → 逐个击破 → 最终对决 | 都市、武侠、仙侠 | 贯穿全书，复仇对象按难度分层安排 |

#### 第四级：情绪回报类——读者的情感体验承诺

决定了"读者读完一章后，获得的核心情绪价值是什么"。**必须选且只选一种主承诺。**

| 套路 | 读者承诺 | 反面 | 适配代偿原型 | 核心技法 |
| --- | --- | --- | --- | --- |
| **爽文** | 持续的打脸/逆袭快感 | 憋屈（憋屈后爆发） | 底层崛起型、被低估复仇型 | 先压制后释放的循环，压制篇幅≤爆发篇幅 |
| **甜宠** | 关系中的温暖甜蜜 | 虐心、误会 | 大女主逆袭型（后期） | 关系推进稳定上升，冲突来自外部而非内部 |
| **虐文** | 让读者哭/心疼的情绪释放 | 轻松搞笑 | 大女主逆袭型（前期） | 被辜负情绪的真实刻画，哭完后必须给希望 |
| **悬疑** | 持续的未知感和解谜欲 | 剧透、过早揭露 | 所有原型（偏慢热） | 信息释放秉持"设悬念→逐步揭示→新悬念"的循环 |
| **治愈** | 读完感到温暖/释然 | 致郁、沉重 | 大女主逆袭型（结局期） | 创伤→理解→接纳的完整心理弧线 |

### 套路组合的兼容性矩阵

不是所有套路都能随便叠。以下矩阵标注了高频冲突对与黄金组合：

| 组合 | 兼容性 | 说明 |
| --- | --- | --- |
| 追妻火葬场 + 甜宠（同时） | 🔴 冲突 | 前者是"先虐后甜"，后者是"持续甜蜜"，同时存在会让读者困惑。解决策略：**分阶段**——前30章虐文+后期转为甜宠 |
| 爽文 + 悬疑 | 🟢 黄金组合 | 打脸后立刻抛新悬念，冲刺与留白交替，读者追读欲极强 |
| 重生 + 解密探案 | 🟢 黄金组合 | 重生者的预知优势与"知道凶手但没证据"的制造悬念天然咬合 |
| 系统 + 日常/现实 | 🟡 需补丁 | 系统面板出现在纯现实题材中需要合理隐藏/解释机制 |
| 退婚流 + 甜宠 | 🟡 需补丁 | 退婚后需要情感替代线，否则感情线空转 |
| 幕后黑手 + 爽文 | 🟢 黄金组合 | 蓄力期给出小胜（爽），收网期给出大胜（更爽） |
| 穿书 + 先婚后爱 | 🟢 黄金组合 | 穿书者知道原著的"相敬如冰"结局→努力改变→关系升温 |
| 种田基建 + 悬疑 | 🔴 冲突 | 种田的慢节奏积累与悬疑的高频信息释放存在根本节奏冲突 |
| 底层崛起 + 虐文 | 🟡 需补丁 | 底层已经够惨了，再加虐文会让读者感到绝望而非代偿——需确保每次虐后都有实质性的成长回报 |
| 升级打怪 + 解密探案 | 🟢 黄金组合 | 每解锁一个等级→接触更复杂的案件→环环相扣 |

> **黄金组合**表示两套路之间有天然的叙事咬合、不需要额外设计衔接。
> **需补丁**表示可以实现但需要额外的设计工作来弥合冲突。
> **冲突**表示不推荐直接叠用，除非有明确的阶段切换方案。

### 套路纯度光谱

完成套路选择后，需标注每条套路的**纯度定位**：

```text
纯套路 ←——— 混合变异 ———→ 反套路
```

| 位置 | 特征 | 读者感知 | 适用场景 |
| --- | --- | --- | --- |
| **纯套路** | 标准事件链 + 标准关系配置，读者一看就懂 | "这就是XX文的经典写法" | 新作者入门、平台跑量、读者忠诚度高的成熟赛道 |
| **混合变异** | 主套路框架 + 其他套路的元素 | "虽然是XX文但多了YY的新鲜感" | 大部分商业网文的最优选择——有辨识度又不至于太陌生 |
| **反套路** | 先建立读者对套路的预期、在关键时刻打破 | "等等，不应该是这样啊？" | 需要读者有"套路常识"才能欣赏反套路——不适合新手赛道 |

### 套路的跨题材迁移

相同的套路在不同题材中运转时表现形态不同。定位时需要注意迁移后的落地形式：

| 套路 | 玄幻版 | 都市版 | 女频版 | 悬疑版 |
| --- | --- | --- | --- | --- |
| 扮猪吃虎 | 废材隐藏修为→宗门大比碾压 | 大佬当保安→危急时刻出手 | 扮丑/扮蠢→关键时刻展露实力 | 菜鸟警员→在案发现场展现专业知识 |
| 先婚后爱 | 仙门联姻→共同抗敌中生情 | 家族联姻→意外同居→动心 | 古言赐婚→相敬如宾→共历患难 | 协议婚姻保护证人→假戏真做 |
| 幕后黑手 | 隐世大能操控宗门格局 | 幕后投资人操控商业战局 | 深宫棋手操控后宫权力 | 连环案的主谋在暗中操控调查方向 |

> 判定规则：若要做跨题材迁移，需要确保套路的**抽象关系结构**（关系的初始配置 + 核心事件链 + 情绪回报承诺）保持不变，变化的只是题材特定的表现形式。

### 套路-节奏绑定倾向

某些套路对叙事节奏有天然倾向——不是绝对绑定，但有统计上的高相关性：

| 套路 | 倾向的章首模式 | 倾向的钩子密度 | 倾向的中段回报类型 |
| --- | --- | --- | --- |
| 追妻火葬场 | 内心独白切入（女主视角） | 高密度（每章有情绪钩子） | 关系推进/关系位移 |
| 升级打怪 | 动作切入 | 中密度（每3-4章一个大钩子） | 身份抬升/能力显示 |
| 解密探案 | 异常/悬念前置 | 中高密度（每2章一个新悬念） | 信息开口/线索显影 |
| 甜宠日常 | 对话切入或环境切入 | 低密度（钩子可有可无） | 关系推进 |
| 幕后黑手 | 内心独白或信息切入 | 低中密度 | 局面反击/局面逆转 |

### 套路选择的四项决策

执行题材定位时，必须从上述四级分类中各选至少一项，显式完成以下决策：

| 决策 | 从哪里选 | 问题 | 示例 |
| --- | --- | --- | --- |
| **核心设定选择** | 第一级：核心设定类 | 穿越/重生/系统/穿书/日常/异能觉醒？选一个作为初始配置 | "重生+系统"双叠 |
| **人物关系配置** | 第二级：人物关系类 | 先婚后爱/追妻火葬场/破镜重圆/契约婚姻/对照组打脸/师徒？选一个作为关系驱动引擎 | "先婚后爱"作为核心关系配置 |
| **情节推进模板** | 第三级：情节推进类 | 扮猪吃虎/升级打怪/解密探案/种田基建/幕后黑手/退婚流/废材流？选1-2个作为事件推进方式 | "扮猪吃虎+掉马甲"双推 |
| **情绪回报承诺** | 第四级：情绪回报类 | 爽文/甜宠/虐文/悬疑/治愈？选一个作为读者情绪契约 | "爽文"主承诺 |

### 套路组合合理性检查

选定组合后，必须执行以下六项检查（比原有四项增加#5和#6）：

1. **兼容性**：所选套路之间是否存在冲突？对照 **兼容性矩阵** 检查。若命中"冲突"组合，必须有阶段切换方案或二选一。
2. **赛道饱和度**：检查所选套路组合在目标平台上是否已被大量使用。若为高饱和组合（如"穿越+宫斗+打脸"），需有明确的差异化方案；若为低饱和组合（如"重生+基建+现实向"），需有为什么此前没人做好的判断。
3. **卖点首露窗口**：套路组合中的关键元素是否能在前3章被读者感知？如果核心套路是"幕后黑手"（蓄力期长），必须有补偿设计在前3章给出替代回报。
4. **持续供血能力**：所选套路组合能否支撑100章以上的长线叙事？对照表格中的**生命周期**列检查——如果核心套路只能支撑30章（如退婚流），必须规划第30章后的切换引擎。
5. **节奏一致性**：所选套路的**天然节奏倾向**与V2(平台口径)的节奏要求是否一致？若不匹配，需要在"平台-定位-节奏三环校准"中给出调整方案。
6. **纯度可行性**：标注了"反套路"定位的，需要确认：① 目标读者是否熟悉被反的那个套路；② 反套路的设计能在第几章被读者识别为"反套路"（如果藏得太深，反套路策略无效）。

### 套路定位与题材定位的联动

| 场景 | 题材负责 | 套路负责 |
| --- | --- | --- |
| 起点都市重生文 | "都市"确定背景、"重生"确定初始能力 | "扮猪吃虎"确定事件推进方式、"爽文"确定情绪承诺 |
| 女频古言先婚后爱 | "古言"确定时代框架 | "先婚后爱"确定关系起点、"追妻火葬场"确定情绪轨迹 |
| 玄幻废材逆袭 | "玄幻"确定世界观 | "废材流"确定初始身份、"升级打怪"确定推进方式、"爽文"确定情绪承诺 |
| 都市悬疑解密 | "都市"确定空间、"悬疑"确定氛围 | "重生"+"解密探案"确定双线推进、"悬疑"确定情绪承诺 |

若已存在当前作品或同赛道蓝本的蒸馏产物（含 §十八 套路指纹），应直接读取其套路清单和跨题材迁移建议作为参照；若多部蓝本均使用同一套路组合且均获成功，可判定该组合为赛道"已验证有效组合"；若本赛道的竞对分析报告已覆盖套路维度，套路定位可以直接引用其结论避免重复。

## 读者代偿承诺设计——题材定位的核心发动机（新增）

> **核心发现**：网文读者追一本书，追的不是"情节"，而是"一种被压抑处境的想象性反转"。穷小子翻身比富二代天生更吸引人，不是因为"穷人设定更真实"，而是底层崛起天然提供了更大的**代偿空间**——读者在现实生活中处于被压制的低位，在阅读中体验"由低到高"的权力反转。这就是网文的底层驱动力。
>
> 《中国图书评论》2025年研究指出：标签系统之所以在网文中前所未有地庞大，不是因为平台分类需求，而是"爽"之文化逻辑的潜在驱动——标签所标识的，是以对爽点的标识为目的组建的关于如何言说压抑性生命经验的符号系统。

### 核心代偿原型清单（强制）

在确定题材定位前，必须先确定当前作品的**核心代偿原型**。代偿原型定义的不是"故事情节"，而是"读者读这本书时在代偿什么心理需求"。

**四大核心代偿原型：**

| 原型 | 读者在代偿什么 | 人物起始位置 | 权力结构 | 核心读感模式 | 典型题材 |
| --- | --- | --- | --- | --- | --- |
| **底层崛起型** | "你们都看错了，我才是对的"被低估→证明 | 地位/资源/能力全面低位；被排挤、被嘲笑、被轻视 | 上层压制下层；通过努力+金手指实现阶层逆转 | 蓄力→打脸→升级→再蓄力→更大打脸 | 玄幻废材流、都市穷小子逆袭、凡人流修仙 |
| **被低估复仇型** | "原来他是真大佬"隐忍→亮底牌→碾压 | 隐藏实力/身份；表面弱势，实际有底牌 | 表面的压制关系（强压弱）vs 真实的反转（弱实强） | 被轻视→忍而不发→关键时刻亮底牌→震惊全场 | 扮猪吃虎、掉马甲、隐藏身份回归、赘婿流 |
| **大女主逆袭型** | "你配不上我"被辜负→觉醒→反杀→让对方后悔 | 情感/关系/社会地位低位；付出不被看见、被辜负、被替代 | 情感权力真空（付出者被辜负）→觉醒后的权力反转 | 付出→被辜负→觉醒→独立成长→碾压让对方后悔 | 追妻火葬场、离婚后惊艳、重生复仇女、妈咪带球跑 |
| **无敌碾压型** | "我就是规则"轻松→碾压→快意恩仇 | 开局即巅峰（重生/系统/隐藏实力），或迅速达到巅峰 | 主角天然在权力顶层；世界规则服务于主角 | 轻松应对→游刃有余→碾压打脸→快意恩仇 | 重生文（知道未来）、系统爽文、神豪文、无敌流 |

**选择规则：**
- 每一部作品只能**选且只选一种核心代偿原型**。两种混合会让读者搞不清"这本书到底想让我爽在哪"。
- 允许在**长篇后期**切换代偿原型（如底层崛起到大后期切换为无敌碾压），但前50万字必须保持核心原型稳定。
- 代偿原型必须与题材选择一致：大女主逆袭型不能套在硬核科幻战争题材上；底层崛起型不适合慢热文艺题材。

### 代偿空间评估——凭什么你的设定比竞对更让读者"爽"

同题材内竞品众多，定位的核心差距不来自"题材不同"，而来自**代偿空间的大小**。

**代偿空间 = 人物的起始低位 × 最终的碾压高度**

| 人物设定 | 起始低位 | 最终高度 | 代偿空间 | 商业潜力（估） |
| --- | --- | --- | --- | --- |
| 本身就是富二代的公子哥 | 4/10（生来就在高位） | 9/10（维持高位） | 5分 | 低—读者无法产生"这不就是我吗"的代入 |
| 被家族嫌弃的私生子 | 2/10（生来就被压制） | 10/10（逆袭成为继承人） | 8分 | 高—大幅的代偿落差提供持续打脸燃料 |
| 重生回过去的普通人 | 1/10（处境悲惨） | 10/10（预知未来逆天改命） | 9分 | 极高—极致低位+极致碾压 |
| 被出轨离婚的全职太太 | 1/10（情感/经济/社会三重低位） | 9/10（事业成功+前夫后悔） | 8分 | 极高—代偿原型精准击中特定人群 |

**设计规则：**
- 定位框架中必须显式评估作品的代偿空间（1-10分），并说明代偿空间的来源（是起始低位足够低、还是碾压高度足够高、还是两者兼备）。
- 代偿空间≤5分的作品，若无其他压倒性的卖点（如IP改编潜力极强、题材稀缺性极高），默认判为商业潜力不足，不得直接进入总纲设计。
- 代偿空间的"起始低位"不能是抽象的（"她很惨"），必须具体到可以写进简介的处境（"离婚后带着孩子、无家可归、前夫娶了她的闺蜜"）。

### 代偿原型向下游Skill的传递规则

题材定位框架确定代偿原型后，必须将以下参数传递给下游所有设计Skill：

| 参数 | 下游Skill | 使用方式 |
| --- | --- | --- |
| 核心代偿原型 | 通用-设计总大纲 | 驱动M0/X/C体系的核心冲突类型设计 |
| 代偿空间评分 | 通用-设计总大纲、通用-平台签约评估框架 | 作为商业潜力评估的参照基线 |
| 代偿回报节奏预判 | 通用-设计分卷大纲 | 打脸/反杀循环的节拍设计 |
| **预期情绪密度等级** | 通用-设计总大纲、通用-设计分卷大纲 | 总纲的情绪刺激密度设计与分卷的黄金节奏公式基线 |
| **主力情绪回报类型** | 通用-设计总大纲、通用-设计分卷大纲、通用-设计故事面 | 各层面的情绪刺激点选择和卖点兑现方式 |
| **平台-定位-节奏三环校准结论** | 通用-设计总大纲、通用-平台签约评估框架 | 平台口径适配性判断与商业化节奏设计 |
| **黄金三章可执行性结论** | 通用-设计分卷大纲、通用-创建小说正文 | 前三章的结构设计硬约束 |
| 人物的起始低位设计 | 通用-设计人物传记 | 人物的起点状态、权力结构参数 |
| 代偿杠杆类型 | 通用-设计故事设定 | 能力/金手指的类型与成长路径 |
| 代偿协同需求 | 通用-设计故事面 | 支线的代偿类型选择 |

若在下游Skill设计过程中发现代偿原型与题材/人物/设定存在根本冲突，应回溯到题材定位框架层重新校准，不得在下游强行修补。

## 题材定位的节奏密度承诺（新增）

> **问题诊断**：多轮实践表明，作品在题材定位阶段选定了定位（如"现实主义文学向女频婚恋""都市悬疑慢热"），但在定位描述中从未标明"该定位对应的读者预期节奏密度是什么"。结果下游Skill按文学创作的本能写，读者按网文的节奏预期读——两者的错位导致了"太慢太闷、没爽点没虐点"的系统性负面反馈。
>
> **一句话原则**：**定位不仅定义"写什么"，还定义了"节奏必须多快、情绪多浓"**。选择定位A（追妻火葬场爽文）就等于承诺了"每500字一个情绪刺激、前三章冲突密集"，选择定位B（现实主义文学性）就不能把自己伪装成爽文——但代价是最初几周的留存数据可能不好看，且签约编辑可能因此拒稿。

### 代偿原型与情绪密度的映射

每种代偿原型天然倾向不同的情绪刺激密度。题材定位时必须在描述中写明所选原型对应的预期密度：

| 代偿原型 | 天然情绪密度 | 读者预期节奏 | 常见题材 | 开篇密度要求 |
| --- | --- | --- | --- | --- |
| **底层崛起型** | **中高密度**（每2-3章一个中爽点） | "看他怎么一步步打上来"的积累式快感 | 玄幻废材流、凡人流修仙、都市穷小子 | 前三章至少完成"被轻视→首次小胜→更大目标"的循环 |
| **被低估复仇型** | **高密度**（每1-2章一个反转/打脸） | "这次他又要亮什么底牌"的持续惊喜 | 扮猪吃虎、掉马甲、隐藏身份回归、赘婿流 | 前三章至少完成一次"被看不起→亮底牌→震惊"的完整打脸循环 |
| **大女主逆袭型** | **极高密度**（每章不少于1个情绪刺激点） | "疼完就该爽了"的虐爽交替 | 追妻火葬场、离婚后惊艳、重生复仇女 | **前三章每500-800字必须有一个虐点**，且每3个虐点嵌入1个小爽点（看清真相/拿到证据/有了新选择） |
| **无敌碾压型** | **中密度**（每3-4章一个高潮）但首章密度极高 | "看他这章要怎么装"的游刃有余感 | 神豪文、系统爽文、重生文 | 首章8-1200字内完成金手指展示+首次碾压 |

**设计规则**：
- 定位描述中必须显式标注本作品的"预期情绪密度等级"（极高/高/中高/中/低），并说明依据——这个依据来自代偿原型的选择。
- 若定位选择了"大女主逆袭型"但标注了"中密度"，说明定位与密度承诺自相矛盾，必须要么调整密度承诺、要么重新评估代偿原型选择。
- "低密度"不等于"没有密度"。低密度定位（如慢热现实主义、文学性悬疑）必须有两个补偿条件之一：① 定位明确声明为"非网文快节奏"、目标读者是特定小众群体；② 有稳定的读者存量或出版/IP渠道，不依赖平台推荐算法。

### 平台-定位-节奏三环校准

相同的题材定位在不同平台上，对节奏密度的要求差异巨大。定位框架必须同时完成平台口径校准，否则"定位对了但平台选错了=数据毒药"。

| 平台 | 对节奏密度的定价 | 对定位校准的影响 |
| --- | --- | --- |
| **起点中文网** | 付费逻辑驱动，老白读者容忍2-3章蓄力但要求逻辑自洽与铺垫后的反转有说服力 | 允许"中密度"定位（底层崛起型、无敌碾压型天然适配），但"大女主逆袭型"的极高密度在快节奏女频赛道同样受欢迎 |
| **七猫** | 免费+广告模式，留存率是核心KPI，开篇即可判断生死；签约编辑看前三章决定去留 | **强制极高/高密度**定位："大女主逆袭型"和"被低估复仇型"天然适配；"底层崛起型"需要在中密度基础上嵌入小刺激；"无敌碾压型"需首章即完成金手指展示 |
| **番茄小说** | 首秀定生死，新书期曝光量大但读者忠诚度低；前10章必须把最强卖点打出 | 强制高密度定位；"底层崛起型"的前三章蓄力周期在番茄上太长，需压缩为1章内完成"冲突起手→能力获得→首次小胜"；"大女主逆袭型"的前三章虐点密度需再翻倍 |
| **晋江文学城** | 情感共鸣驱动，慢热文可以靠口碑发酵；标签精准比节奏快更重要 | 允许中/中低密度定位，但需支付"慢热等待"的时间成本——读者可能在3万字后才判断是否追读 |

**设计规则**：
- 定位描述中必须包含"平台-定位-节奏三环校准结论"：目标平台是什么、该平台对定位的节奏要求是什么、当前定位的密度是否匹配该要求。
- 若三环校准发现冲突（如"七猫+底层崛起+中密度"=节奏偏慢不适合免费平台），必须给出调整方案：要么换平台、要么提高密度、要么证明已有存量。
- 若未配置主输出平台，默认按起点口径校准。

### 定位的黄金三章可执行性验证

题材定位最致命的陷阱是：**定位听起来很对，但前三章根本执行不了**。你可以在定位卡片上写"这是一本快节奏追妻火葬场爽文"，但如果前三章实际设计出来全是环境描写和心理铺陈，定位就是空头支票。

定位框架产出前，必须完成一项验证——**黄金三章定位可执行性检查**：

| 检查项 | 通过标准 |
| --- | --- |
| 前300字是否有与定位一致的冲突/异常/压力信号 | 快节奏定位的前300字必须有明确冲突起手；慢热定位不得藏到第3章才给冲突 |
| 前1000字是否完成了定位承诺的首个刺激点 | 大女主逆袭型应在第一段就出现"被辜负/被伤害"的虐点；底层崛起型应在800字内给读者看到"我比你以为的强"的信号 |
| 前三章的章末钩子是否与定位的叙事类型一致 | 大女主逆袭型应落"更虐/更爽"的情绪钩子；悬疑定位应落"更谜"的信息钩子；爽文定位应落"更打脸"的期待钩子 |
| 对话占比是否与定位的节奏密度对应 | 极高/高密度定位的前三章对话占比建议≥40%（女频≥50%）；中密度定位对话占比建议≥30% |
| 定位的核心差异点能否在前三张的至少2处被读者自然感知 | 如果"创新的A+B融合"只在简介里提了一嘴、正文前三章完全没体现→差异点是假的 |

**执行规则**：
- 定位框架产出时必须包含"黄金三章可执行性"验证结论（通过/有条件通过/不通过）。
- 若不通过，必须说明：最可能被哪类读者或编辑在阅读前几段时就判定定位不匹配。
- 定位与设计之间的脱节（"想写快节奏但实际写出来是慢的"）不能等到分卷或正文阶段才被发现——在题材定位层就应该通过可执行性验证提前暴露。

### 情绪回报类型声明（新增）

定位框架产出时，除了写清题材、套路、代偿原型，还必须写清**情绪回报类型**——这是读者看完一章后获得的核心情绪价值定位。

| 情绪回报类型 | 读者读完一章后的感觉 | 适配的代偿原型 | 适配题材 |
| --- | --- | --- | --- |
| **智商碾压型** | "这人太聪明了，我学到了" | 被低估复仇型、无敌碾压型 | 智斗、权谋、幕后黑手、解密 |
| **资源增长型** | "又变强了，资产又多了" | 底层崛起型 | 修仙升级、系统流、种田基建 |
| **关系拉扯型** | "他俩的感情终于动了/终于裂了" | 大女主逆袭型 | 追妻火葬场、破镜重圆、先婚后爱 |
| **身份震撼型** | "原来他/她才是真大佬" | 被低估复仇型 | 掉马甲、隐藏身份回归、替身文学 |
| **价值站队型** | "这个行为太解气了/太恶心了" | 所有原型 | 打脸、政治博弈、立场冲突 |
| **信息悬疑型** | "等等，这不对劲……" | 所有原型（偏慢热） | 悬疑解谜、阴谋论、规则怪谈 |

**设计规则**：
- 每个定位必须选取**1种主力情绪回报类型**+最多**1种辅助情绪回报类型**（如"智商碾压为主、身份震撼为辅"）。
- 主力情绪回报类型必须贯穿全书，不得在第一卷之后切换。辅助类型允许在中期轮换。
- 定位中必须写明"主力情绪回报类型在哪章首次兑现给读者"——如果无法回答，说明定位层还没有想清楚"读者读完到底爽在哪"。

### 题材大盘数据参照

- 起点用户画像：18–35 岁占比超 70%，男性 71%，月收入 5–10k 群体为主力付费人群；地域集中在东南沿海新一线及以上城市。
- 2025–2026 题材占比：都市 27.6%（含「华娱+年代+重生」霸榜组合）、历史 19.3%（「大明」遥遥领先）、仙侠 17.3%（「西游化」趋势明显）、轻小说 16.1%、玄幻 10.3%。
- 重点增量赛道：科幻品类作品数量增幅超 67%（《深海余烬》《异度旅社》均订破 10 万）；都市现实题材男频文 2025 下半年流量暴涨 270%；悬疑惊悚题材大爆发。

### 题材创新度三级评判

设计题材定位时，必须从以下三个维度给出现状判断与选择理由：

1. **市场饱和度**：「退婚流」「签到流」等传统套路已饱和，很难再成爆款；若主卖点依赖已被大量重复的套路，默认下调定位成熟度。
2. **融合创新能力**：如《大奉打更人》「仙侠探案」新品类，将科学探案与玄幻修仙碰撞融合。定位框架必须写出至少一组「A+B」融合公式，并说明融合后产生了什么此前同赛道没有的阅读体验。
3. **时代契合度**：2026 年火的不是传统升级打怪，而是反套路文（系统是反派、主角靠智慧反杀）、现实向小人物逆袭、接地气打败称霸世界。若定位仍停留在 「开挂碾压一切」而不给主角真实阻力，视为与当前读者口味脱节。

### 题材潜力快速筛查表

定位框架产出前，至少回答以下五问：

| 筛查项 | 通过标准 |
| --- | --- |
| 该题材在起点榜单 TOP50 占比是否≥30%，且更新活跃、新作不断 | 若低于 15% 或榜单老化，需证明为什么能逆势突围 |
| 题材是否自带强话题性（如职场内卷、原生家庭、性别平等），易引发社交讨论 | 若无话题钩子，需从融合创新或人物抓手补 |
| 是否避开了过气题材（无脑系统、傻白甜甜宠、重复度极高的古言宅斗） | 命中过气题材需有压倒性的创新证据才能放行 |
| 是否属于当前平台明确扶持的品类 | 起点悬疑灵异品类 2026.5.1–2027.12.31 有月票榜现金奖励+每月 1500 全勤补贴；科幻有「银河计划」专项扶持 |
| 是否能用一句话说清「这本书在什么题材里，做到了什么别人没做到的事」 | 若只能说「这是一本 XX 文」而说不出差异化，判为未完成 |

若五项中有两项或以上不通过，定位框架必须显式记录风险并给出弥补路径；若全部不通过，不得直接进入总纲设计。

### 目标读者与付费触发场景校准（新增）

- 起点口径下，定位文本必须显式写出“第一目标读者群”与“第二目标读者群”，并说明为何这两类读者会持续追更而非只看概念。
- 默认补答三问：
	1. 这本书打谁的哪种阅读冲动（智斗、逆袭、情绪代偿、关系站队、机制破解等）；
	2. 读者在第 `1` 卷与第 `2` 卷分别因为什么继续付费；
	3. 若不依赖强作者存量，作品本体靠什么稳住留存。
- 若定位只写“题材热度高”，却无法写清“目标读者是谁、为何买单、何处持续供血”，默认判为定位未完成。

## 概念工厂——多方案生成与PK筛选（默认入口）

> 本模块是 `通用-设计题材定位框架` 的**默认入口**。概念工厂的角色不是"可选的前置模块"——它是**这个 Skill 的大脑**。概念工厂决定"往哪个方向走"，后续的框架深化决定"这条路怎么铺好"。两者合在一起才是完整的定位流程。
>
> **工作流定位变化**：在之前的版本中，概念工厂是可选的、概念深化框架是默认的。从本轮修改开始，**概念工厂是默认的、概念深化框架是后置的**。作者拿到这个 Skill 后，第一件事就是跑概念工厂。

### 何时使用（默认场景）

- **开书前的标准动作**——先跑概念工厂PK，再深化
- 已有模糊想法但不确定"这个方向对不对"——把现有想法作为一个候选放入PK池，看它在与其他变体的PK中能排第几
- 团队/个人有多个题材/套路赛道选择，需要做优先级决策

### 可跳过概念工厂的例外情况

- **已经进入总纲/分卷设计阶段** → 跳过概念工厂，直接使用框架深化流程
- **纯个人表达/文学向创作** → PK法的商业化导向会扭曲创作意图，自行判断是否跳过
- **概念已基本确定、只需要做校准和钉死细节** → 跳过PK，直接使用框架深化流程
- **已有竞对/蓝本数据支撑的上一个概念工厂产出** → 直接复用上一次的决胜概念，进入框架深化即可

### 核心方法：要素排列组合 × 多轮PK

将题材定位涉及的关键要素拆解为 **8个独立变量**。选定前置约束（题材+平台）后，将剩余6个变量做排列组合，批量生成候选概念，再通过5轮递进式PK逐轮淘汰，最终锁定**一个决胜概念**。

#### 8个关键变量

| 变量 | 说明 | 典型选项示例 |
| --- | --- | --- |
| **V1 题材** | 故事发生的世界/时代（前置约束） | 都市/玄幻/悬疑/历史/科幻/职场 |
| **V2 平台口径** | 目标平台与节奏风格（前置约束） | 起点/七猫/番茄/晋江/知乎/多平台 |
| **V3 代偿原型** | 读者心理代偿方式 | 底层崛起/被低估复仇/大女主逆袭/无敌碾压 |
| **V4 核心设定** | 故事的初始配置 | 重生/穿越/系统/穿书/日常/异能觉醒 |
| **V5 人物关系** | 关系的初始张力 | 先婚后爱/契约婚姻/对照组打脸/师徒/雇佣 |
| **V6 情节推进** | 驱动故事的事件模板 | 扮猪吃虎/解密探案/升级打怪/种田基建/幕后黑手 |
| **V7 情绪回报** | 读者的情感契约 | 爽文/悬疑/甜宠/虐文/治愈 |
| **V8 职业切口** | 主角的具体职业抓手 | 法医/程序员/房产中介/外卖骑手/物业/保安 |

> V1(题材)和V2(平台)必须先选定——它们是后续排列组合的前置约束。其余6个变量每个至少给出 **3个选项**（建议4-6个），排列组合后产生 **不少于30个初始候选概念** 方可进入R1。少于30个时，必须从 **灵感来源** 中补充变量选项直到达标。上限不设限，但建议初始候选池控制在 **30-80个**，超出时随机/分层抽取出80个进入R1即可（80个已足够覆盖有效多样性，更多反而降低每轮PK的可比性）。

> **变量选项的来源**：上表中的"典型选项示例"只是启动时的默认预设。实际执行概念工厂时，变量的具体选项**必须**从 **灵感来源**（竞对分析报告中的套路清单、蓝本蒸馏产物的套路指纹、素材库中的桥段/反转/人物设定、写作研究报告中的题材趋势与平台数据、网络搜索发现的流行元素）中补充和丰富。例如：V4(核心设定)的选项可以从竞对拆解中找到"时光回溯""记忆嫁接"等变体；V8(职业切口)可以从素材库中挖掘"急救调度员""旧书店主""网约车司机"等新鲜选项。**变量选项库越丰富、越贴近实际市场数据，PK筛选出的概念就越有竞争力。**

#### PK总规则：火药味原则

> 概念工厂的PK不是"你好我好大家好"的温吞评审，而是**一场杀气腾腾的创意角斗**。每一轮都是一次"诛心拷问"——不是问"这个创意好不好"，而是问"这个创意凭什么能在前十章就把读者钉死在座位上、让编辑拍桌子加签"。
>
> **PK铁律**：
> - 对每一个候选概念，必须先找它的"死穴"再说它的优点——**负面优先，正面补证**
> - "还行""还不错""勉强可以"=**直接降级**。只有"这他妈绝了"和"这个方向很强"才配晋级
> - 每轮评委必须扮演三副面孔：**挑剔的编辑**（这能签吗）、**暴躁的读者**（这值得我花钱追吗）、**冷静的操盘手**（这能撑200章吗）
> - 如果一轮PK下来没有吵架、没有拍桌子、没有人说"我不同意"——说明火力不够，重来

#### 6轮递进式PK

##### 第零轮：脑洞核爆轮（R0·新增）

> **开场即核爆**。在所有候选概念进入兼容性检查之前，先做一轮极端的"脑洞压力测试"。这一轮不淘汰概念，但必须给每个概念标记一个"脑洞等级"和"致命弱点"。

**三记诛心拷问**：

1. **"这有什么了不起？"** —— 这个概念的"不可替代性"是什么？说的简单点就是：如果这个创意被另一个人拿去写，去掉书名和人物名，读者能靠故事本身认出来"这是那本独特的书"吗？如果不能——**你的创意还没有真正的身份**。
2. **"这凭什么不是一坨屎？"** —— 这是一个自我攻击式的拷问。不要护着你的创意，主动去想它最烂的可能性：它会不会变成"穿越+系统+打脸"的千篇一律模板文？它会不会在第三章就让读者觉得"哦，又是这套"？如果连自己都找不到它的致命弱点，说明你还没真正审视过它。
3. **"做完这个题材的人看到这个创意，会怎么骂你？"** —— 站在你已经读完的同题材爆款作品角度来审视：那本书的作者看到你的创意，是会觉得"有点意思"还是"又来一个蹭热度的"？这个问题的答案直接判定你的创意是在**开疆拓土还是拾人牙慧**。

**脑洞等级判定**：

| 等级 | 标签 | 判定标准 | R0动作 |
| --- | --- | --- | --- |
| **S级** | 卧槽这也行？ | 三记拷问全部通过，且至少有一记的回答让评委感到意外 | 标记⭐ + 直接保送R3（跳过R1-R2） |
| **A级** | 这个方向很强 | 三记拷问全部有合理回答，无明显致命弱点 | 正常进入R1 |
| **B级** | 方向对了但不够 | 有一记拷问的回答明显发虚 | 标记弱点后进入R1，R1-R2需优先修复该弱点 |
| **C级** | 太平了太平了 | 至少一记拷问完全回答不上来——"这有什么了不起？"答不上来、或者"凭什么不是一坨屎"找不出任何弱点 | **直接淘汰**。创意如果连"特别在哪"都说不出，后面的PK没有任何意义 |

**R0核心精神**：与其在后面几轮慢慢发现一个概念很平庸，不如在第一秒就用最狠的刀捅进去。**好的创意经得起最恶毒的自我攻击。经不起的，早死早超生。**

淘汰率约10-15%（直接毙掉C级概念）。但更重要的是——**每个幸存概念都被标记了致命弱点**，后续R1-R4必须直面这些弱点进行修复或辩护。

---

##### 第一轮：兼容性绞杀（R1）

> 上一轮的R1叫"兼容性过滤"。这一轮的R1叫"兼容性绞杀"。过滤只是筛选，绞杀是**用逻辑的刀把所有"看起来好像可以但实际站不住"的组合砍掉**。

**四刀致命**：

| 刀口 | 诛心拷问 | 一票否决场景 |
| --- | --- | --- |
| 代偿与情绪冲突 | "读者读完这章，到底是爽到了还是甜到了？如果两个都要，你的章节里怎么分配篇幅？" | "大女主逆袭"+"甜宠"没有明确的"虐爽交替"阶段划分方案→毙 |
| 人物关系与情绪冲突 | "被辜负者的故事里，前三章就让他俩甜蜜互动——读者想看的是这个吗？" | "追妻火葬场"+"甜宠"没有前置至少5章的"虐"阶段→毙 |
| 设定与题材自洽 | "系统面板出现在现实主义职场里——编辑翻到第三章发现主角在查属性面板，他会怎么想？" | "系统"+纯现实题材没有合理的"隐藏/解释"机制→毙 |
| 职业与情节撕裂 | "法医的基本工作是解剖和出报告，你让他去种田——这两件事能同时发生在同一章里不违和吗？" | 职业的方法论与情节推进方式之间没有任何交集→毙 |

**评委拍桌标准**：
- ✅ **果断可晋级**：四项全通过，且至少有一项在答辩中有让人"这个细节想得不错"的亮点
- ⚠️ **待定需补刀**：一项不通过但有明确的补丁方案（如"先婚后爱+甜宠"设计为"先结婚后恋爱，前5章写冷战处境，第6章开始关系松动"）→标记补丁方案后晋级
- ❌ **红牌罚下**：任何一项不通过且补丁方案也说不通→直接淘汰。**不许说"先留着再看看"**

淘汰率约30-40%。

---

##### 第二轮：创新浓度测试（R2·大幅强化）

> 上一版的R2叫"赛道饱和度检查"——太温了。这一版的R2叫"创新浓度测试"。不只看"这个套路有没有被做过"，更要看**"你的版本比已有的版本新在哪里、强在哪里、读者凭什么选你不选那三本"**。一个创意在市场上存在竞品不可怕，可怕的是**你说不出读者凭什么翻你的牌子而不翻竞品的牌子**。

**三道必答题**：

**① 竞品对标**："你说你这个创意有差异化——请列出在目标平台上、过去12个月内、与该概念核心套路组合≥70%重叠的3部作品，然后逐条告诉我，你的概念在哪几个维度上比它们更让读者想点开。"

> 如果找不到3部——说明你的赛道调研不足，降低该候选的"赛道判断置信度"，标注为"需补充调研"后待定晋级。
> 如果能找到3部却说不出至少2个维度的本质不同——**红牌罚下**。撞车不可怕，撞车了还没差异化才是最致命的。

**② 读者预期位移**："读者的阅读预期被你这个概念改变了多少？"

| 位移程度 | 说明 | 判定 |
| --- | --- | --- |
| 颠覆级 | 读者看了前三章会惊呼"网文还能这样写？" | ✅ 直接晋级、标注核弹级 |
| 迭代级 | 读者会说"这个组合有意思，以前没见过" | ✅ 正常晋级 |
| 微调级 | 读者会说"嗯，这个设定换了个皮" | ⚠️ 需补差异化证据 |
| 复刻级 | 读者会说"这不就是XXX换了个名字吗" | ❌ 红牌罚下 |

**③ 壁垒评估**："你的创意在执行层面有壁垒吗？"

- **正向壁垒**（加分项）：需要特定专业知识（如法医/刑侦/编程/金融）、需要特定写作技法（如多线叙事/时间线操控）、需要特定资源（如实地调研/专家访谈）——**壁垒=容易被模仿=长期竞争力**
- **负向壁垒**（减分项）："只要文笔不太差谁都能写"——**没有壁垒的概念在红海赛道活不过三章**
- **一票否决**：如果一篇创意在R3(代偿空间)和R4(商业评分)都及格、但"没有壁垒"+"复刻级创新"——编辑视角是："我签你不如签那本已经跑出来的" → **红牌罚下**

淘汰率约25-35%（比之前提高，因为加了读者预期位移和壁垒评估）。

---

##### 第三轮：代偿核弹评估（R3·升级）

> 上一版的代偿评估是个公式。这一版不仅保留公式量化，还要做一轮**情绪压力测试**——模拟读者在读完前三章后的真实反应。

**量化公式**（保留）：

```text
代偿空间 = 人物的起始低位(1-10) × 最终的碾压高度(1-10) × 读者共鸣系数(0.8-1.2)
```

**通过标准**（保留）：≥60分晋级，40-59分垫高后重评，<40分淘汰。

**新增：前三章情绪模拟测试**

评委各自扮演目标读者，回答以下问题：

1. **第1章前500字**："我读到第500字的时候，是被钩住了还是想划走了？具体哪个动作/哪句话让我想继续？如果找不到具体的一句话——说明开篇的抓力不够具体，不够具体=不够强。"
2. **第1章结尾**："我为什么要点开第2章？是"想知道后来怎么样了"还是"闲着也是闲着"？后者=淘汰信号。"
3. **第3章结尾**："这时候我已经知道主角要干什么了吗？如果还不知道——免费平台读者已经划走了。如果知道了但不期待——付费平台读者不会点下一章。"
4. **代偿可感知度**："这个概念承诺的'爽'，到底在第几章第几个场景里第一次兑现给读者？如果你说不出来——说明代偿承诺只是个口号，不是设计。"

**评委拍桌标准**：

- ✅ **情绪核弹**：前三章模拟全部通过，且至少一处让评委产生了"这个场景我想看"的冲动 → 晋级
- ⚠️ **有坑可填**：有一处不通过但没有结构性缺陷 → 标注问题后晋级
- ❌ **代偿空壳**：两处以上不通过，或者第4问完全回答不上来 → **红牌罚下**

淘汰率约20-30%。

---

##### 第四轮：商业沙盘推演（R4·替代）

> 上一版的R4叫"商业多维评分"——它是静态打分。这一版改成**"商业沙盘推演"**——模拟这本书从开书到100章的真实竞争环境和商业化路径。

**推演场景**（评委依次扮演以下角色）：

**场景一：编辑的30秒审稿（权重40%）**

> "我不看你的概念描述。我只看了你的书名和简介。30秒内我要做出判断：签，还是不签？"
>
> - 评委必须在30秒内给出"签/不签/再看看"的判断并说明理由
> - 30秒内说不清楚理由的→默认降级

**场景二：读者在榜单上的3秒决策（权重30%）**

> "你的书和一排竞品放在同一个分类榜单上。读者的眼睛扫过去——为什么你的书名+简介能让他停下来，而不是滑过去？"
>
> - 如果评委需要思考超过3秒才能回答"为什么点你的"→扣分
> - 如果评委说"如果我在榜单上看到这个书名，可能不会点"→**一票否决预警**

**场景三：第50章还撑得住吗（权重20%）**

> "你的概念在第1-10章是够用的。现在假设已经写到第50章了——你换了至少两个驱动引擎了吗？第一个引擎的燃料什么时候用完的？第二个引擎什么时候接上的？第三个引擎长什么样？"
>
> - 能清晰说出"引擎切换计划"→得分≥7
> - 只说得出"靠主线"或"靠人物成长"这种空话→得分≤5
> - 完全没想过这个问题→**一票否决预警**

**场景四：你的传播点在哪（权重10%）**

> "这本书有没有哪个场景/台词/关系设定，是适合做成短视频切片、截图传播、或者让读者在书评区吵起来的？如果完全没有——你的作品在2026年的社交媒体时代缺少自传播基因。"

**最终判定**：

- 推演总分 ≥ 7.5 → 进入终轮短名单
- 6.0-7.4 → 标注"可优化"后进入短名单
- < 6.0 → 淘汰
- 任一场景出现"一票否决预警"且评委组无法达成一致辩护→直接淘汰

淘汰率约30-40%。

---

##### 第五轮：一句话绝杀（R5·终轮）

> 前面四轮砍掉了至少70%的候选概念。现在短名单里剩下的2-5个，每一个单独看都是好创意。但**冠军只能有一个**。终轮的武器只有一件：**一句话**。

**绝杀测试**：

1. 将每个候选概念压缩成**一句话（≤50字）**——必须是"让人听了就想点开"的人话，不能是题材总结
2. 把这句话分别拿给三类人听：
   - **一个不了解该题材的人**（模拟路人读者）：如果对方追问"然后呢？"→+2分。如果"哦"→0分
   - **一个了解该题材的人**（模拟核心读者）：如果对方说"这个切入点有意思"→+2分。如果"这不就是XXX"→-1分
   - **一个编辑/资深作者**（模拟签约决策者）：如果对方说"这个可以"→+3分。如果"再看看"→0分。如果"不太行"→-3分
3. 累计得分最高者为**冠军概念**
4. 如果最高分出现同分→回到R4沙盘推演分更高的那个获胜

**冠军防后悔检查**：

- [ ] 如果"第一名"现在让你自己说"要不还是看看第二名吧"——说明第一名让你自己都没信心，**概念工厂没跑完，需要扩大变量选项重新生成候选池**
- [ ] 如果"第二名"比"第一名"在某个维度明显更强（如R4得分更高但R5一句话没写好）→**允许将第二名的概念卡与第一名的简介结合优化后作为冠军输出**

> **"哦"和"然后呢？"之间的距离，就是畅销书和扑街之间的距离。**

### 外部AI辅助PK（外脑盲评模式）

> **为什么需要外部PK？** 同一款AI生成的候选概念，再用同一款AI做评委，容易陷入"思维近亲繁殖"——评委对候选概念的偏好和生成时的逻辑偏好高度一致，缺乏外部视角的冲击力。引入外部AI做独立评审，相当于请了另一位编辑来拍桌子。
>
> **什么时候用外部PK？** ① 本AI内部的R0-R5已经跑完一轮，但仍然不确定冠军是否真的最强；② 想验证本AI的PK结论是否客观；③ 候选池中有2-3个概念在内部PK中得分接近，需要外部视角来打破僵局。
>
> **外部PK的核心原则**：外部AI只拿到候选概念列表和PK规则，**不知道**本AI内部的PK结果和倾向——保证盲评的独立性。

#### 外部PK的操作流程

1. 在本AI中先完成概念工厂的**候选池生成 + 第零轮脑洞核爆（R0）**（因为脑洞核爆是本Skill的独特方法论，外部AI不一定擅长）
2. 用户发出 **"生成外部PK提示词"** 或 **"导出候选池做外部PK"** 的指令
3. 本AI将候选概念列表 + 外部PK规则打包成一段**自包含的提示词**（一份可读的文本，不依赖本Skill的上下文）
4. 用户将该提示词拷贝到外部AI中运行
5. 外部AI执行R1-R5的PK流程，输出其评选出的冠军及理由
6. 用户带着外部AI的结果回到本对话，告知哪个胜出
7. 本AI将外部PK结果与内部PK结果做交叉对比，最终锁定冠军概念

#### 外部PK提示词的生成规范

当用户要求外部PK时，必须生成一份**自包含、可直接拷贝到其他AI中执行的提示词**。直接使用 `references/外部PK评估输出模板.md` 作为模板骨架填充。

填充规则：

- **评估任务**：直接套用模板中的「评估维度」和「输出格式要求」。外部AI只需做**6维快速评估**（题材判定/第一眼抓力/主角代入感/长线耐久度/最大风险点/改进建议），不需要重复本Skill的R0-R5全流程——那些是内部PK的方法论，外部AI没有相同的语境和前置数据，无法有效执行
- **候选概念**：按模板的表格格式列出每位候选（立意/一句话卖点/目标平台/第一眼新鲜点/主角抓手/情绪主轴/长线结构）
- **附加信息**：趋势参考、竞品参照、目标读者
- **不要**在外部PK提示词中混入内部PK的R0标签或取胜理由——外部AI需要的是**盲评独立性**

#### 外部PK结果的接回处理

当用户带着外部PK结果回来时：

1. **读取外部AI的PK报告**，特别关注其冠军选择与关键判定
2. **与本AI的内部PK结果做交叉对比**：
   - 内外冠军一致 → 双倍置信度，直接进入框架深化阶段
   - 内外冠军不一致 → 分析分歧原因（是R4权重偏好不同？还是R5一句话版本差异？）
   - 若分歧可调和（如外部冠军在内部是第二名，且理由充分）→ **以外部AI的评审为准重新指定冠军**
   - 若分歧无法调和（双方理由都站得住）→ 向用户展示两份冠军的理由，请用户做最终决定
3. 最终确定的冠军概念**按产出物落盘规则写回 `故事框架/`**
4. 如果外部PK产生了有价值的评审意见（如某个被淘汰概念有特殊亮点），同步记录到 `概念库/` 的归档文件中

### 概念工厂产出物格式

PK完成后，输出**三层概念卡**。

#### 产出物落盘规则（强制）

概念工厂的所有产出**不得仅停留在对话中**，必须写回文件。具体落盘规则如下：

| 产出物 | 落盘位置 | 文件命名规范 | 说明 |
| --- | --- | --- | --- |
| **决胜概念卡**（必选） | `{项目根}/故事框架/` | `{题材}_{一句话概念核心词}.md` | 含三层概念卡完整内容，**执行概念工厂后必须生成** |
| **PK全过程存档**（可选） | `{项目根}/故事框架/` | `{题材}_{概念核心词}_PK记录.md` | 含候选池完整列表、每轮淘汰情况与评分明细 |
| **概念库归档**（必选） | `{项目根}/概念库/` | `{题材}_{平台}_{日期}.md` | PK筛掉的候选概念归档到此目录，按题材×平台分类，供跨项目复用 |

> `故事框架/` 是项目根目录下的顶层目录（与 `素材库/`、`调研报告/`、`写作研究/` 同级）。若不存在则自动创建。决胜概念卡是**唯一必须写回**的产物；PK记录和概念库归档即使跳过也不得跳过决胜概念卡的落盘。

#### 决胜概念卡的文件格式

```text
# {一句话概念}

> {一段式简介}

## 取胜理由卡

- R0脑洞等级 {S/A/B} + 致命弱点 {一句话}
- R1兼容性绞杀 {四项结果} + 评委拍桌判定 {果断晋级/待定补刀/红牌}
- R2创新浓度 {竞品对标结果} + {读者预期位移等级} + {壁垒判定}
- R3代偿核弹 {量化得分} + {前三章情绪模拟结果}
- R4商业沙盘 {推演总分} + {四个场景中表现最强的那个}
- R5一句话绝杀 {三类人累计得分} + {对方的原话引用}
```

**输出示例**（写入 `故事框架/都市悬疑_重生法医查悬案.md`）：

> **一句话概念**（30字）：
> 重生法医回到命案发生前，发现每一具尸体都在逼他重查当年的那桩悬案。
>
> **一段式简介**（120字）：
> 重生回到毕业那年，顾深主动申请调去全市最冷门的县局法医科。同事们以为他想躺平，只有他知道——接下来三年，这座小城会发生七起看似毫无关联的命案，而每一起的尸检报告里，都藏着同一条线索：指向二十年前那桩被草草定性的案子。那时候他还是个孩子，现在他是法医。尸体不会说谎，但活着的人会。
>
> **取胜理由卡**：
>
> - R0脑洞等级 ⭐S级 致命弱点："法医题材需要扎实的专业知识壁垒，必须在设定层补入详实的法医工作流"
> - R1兼容性绞杀 ✅ 四项全通过，拍桌亮点："重生+职业切口+解密探案三个变量自然咬合，不像拼凑"
> - R2创新浓度 ⭐ 迭代级；竞品对标：起点过去12个月"重生法医"组合仅2本，其中1本偏感情线、1本偏刑侦群像，本概念聚焦"尸体线索驱动+单法医视角"是差异化空白；壁垒：法医专业知识为正向壁垒
> - R3代偿核弹 量化8.2分；前三章模拟：第1章500字"发现第一具尸体"钩子成立，第3章结尾"七起命案的线索图"已建立追读期待
> - R4商业沙盘 8.6分（编辑审稿30秒通过 9/10、榜单3秒决策 9/10、50章引擎切换计划清晰 8/10、传播点"每具尸体留下一个坐标"梗潜力 7/10）
> - R5一句话绝杀 累计+7分（路人"然后呢？"+2、核心读者"法医视角打开悬疑有意思"+2、编辑"这个切入点可以"+3）

### 概念工厂与现有框架的衔接

概念工厂的产出不是终点——它是**现有框架分析的入口**：

```text
概念工厂 → 产出决胜概念卡（一句话 + 一段简介 + 取胜理由）
    ↓ 提供"方向性"约束
【平台口径层】 → 已有框架详细校准（平台定位与追读承诺检查表）
【卖点抓手层】 → 已有框架详细设计（保真四问）
【现实代价层】 → 已有框架详细落盘（锚点矩阵）
【创新组合层】 → 已有框架详细展开（创新组合写法模板）
    ↓
总纲设计
```

即：**概念工厂决定"往哪个方向走"，现有框架决定"这条路怎么铺好"**。

### 概念库的跨项目复用

每次PK筛掉的候选概念不应被丢弃——每次PK产生的30-80个候选，经过筛选后仍有大量"过得去但没赢"的概念。

建议在项目根目录创建 `概念库/`，按题材×平台分类归档每次PK的候选概念与评价结果。当需要开新书时，先查概念库中同一题材×平台的历史候选，避免重复生成——也可以在旧概念基础上做"替换一个变量"的微调迭代。

## 执行顺序（两步走）

### 默认流程：概念工厂 → 框架深化

**第一步：概念工厂PK**

1. 加载灵感来源（至少三种）→ 丰富变量选项库
2. 选定V1(题材)+V2(平台)前置约束
3. 排列组合V3-V8生成候选池（≥30个）
4. 选择PK模式：
   - **内部PK**（默认）：在本AI中执行R0-R5全流程
   - **外部PK**（可选）：用户要求时，本AI完成候选池生成 + R0脑洞核爆后，导出外部PK提示词，由用户在外部AI中完成R1-R5
5. 产出决胜概念卡 **并写回 `故事框架/`**
6. PK筛掉的候选概念归档到 `概念库/`
7. 将决胜概念带入第二步

**第二步：框架深化**

1. 围绕决胜概念，先用保真规则中的"四问校准法"给出定位摘要
2. 再明确：主平台口径、主角抓手、母体来源、现实锚点、代价锚点、创新组合
3. 再用平台定位检查表、锚点矩阵、节奏密度承诺等模块逐层检查是否失真
4. 最后将深化后的定位结论**同步更新回 `故事框架/` 对应的概念卡文件中**

### 跳过概念工厂的捷径流程

当满足"可跳过概念工厂的例外情况"中的任一条件时：

1. 读取作品现有的简介、总纲、相关设定与人物入口文件。
2. 先用保真规则中的“四问校准法”给出定位摘要。
3. 再明确：主平台口径、主角抓手、母体来源、现实锚点、代价锚点、创新组合。
4. 再用平台定位检查表与锚点矩阵检查是否失真。
5. 输出结果时，优先给可直接回写到 `故事框架/` 概念卡文件的定位框架文本。
   - **定位结论必须写回 `故事框架/`**，文件名格式为 `{题材}_{主卖点核心词}.md`。
   - 若 `故事框架/` 下已存在同名概念卡——覆盖更新，保持与当前定位结论一致。

## 默认输出口径

- 默认输出一份可直接回写到 `故事框架/` 概念卡文件的定位框架文本。
- 默认同时给出主卖点、平台口径、现实锚点与代价锚点。
- **所有输出必须写回 `故事框架/` 目录下的对应文件中**，不得仅停留在对话中。

## 最低交付

- 能说清主卖点、主平台口径与主角抓手。
- 能指出现实锚点、代价锚点与创新组合。
- 能说明为什么这本书值得持续追读。
- **上述结论已写回 `故事框架/` 下的概念卡文件中**。

## 硬规则

- 禁止平台口径含糊，最后变成“每个平台都沾一点”。
- 禁止主角只有头衔，没有方法论抓手。
- 禁止机制 / 超常像万能工具，没有触发条件、代价和边界。
- 禁止现实议题只做主题词，不进入事件链、证据链与人物代价。
- 禁止卖点只停在概念层，不进入简介、开篇、总纲与后续正文。
- 定位起点或未标平台时，禁止不经过题材市场评估就直接下笔；至少必须回答：该题材当前在起点榜单 TOP50 的活跃度、是否有过气信号、是否有平台扶持窗口、是否避开了明显的过气题材。
- 创新融合公式（A+B）必须具体到阅读体验层，不得只写「玄幻+悬疑」「都市+科幻」这类空泛组合；要写出融合后产生了什么此前同赛道没有的读者感受。
- 若题材大盘数据显示该赛道已高度内卷（如传统退婚流、签到流、无脑系统），定位框架必须显式证明为什么本书能在内卷赛道中形成差异化；若证不出来，判为定位未完成。
- 禁止只给题材标签不给读者画像；禁止只给卖点口号不给付费触发场景。

## 与其他 Skill / Prompt 的边界

- 本 Skill 负责题材定位与平台口径钉死。
- 不直接代替总纲、分卷或正文创作。

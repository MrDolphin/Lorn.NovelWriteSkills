# 通用-设计题材定位框架

题材定位不是写一句“这本书是什么”，而是先把这本书为什么能成立、为什么能持续、为什么读者会继续追钉死。

## 保真迁移要求（强制）

命中题材定位任务时，除本文件外，**必须继续读取**：

- `references/题材定位保真规则.md`
- `references/平台定位与追读承诺检查表.md`
- `references/现实锚点与代价锚点矩阵.md`
- `references/创新组合写法模板.md`
- `references/立意升维与如果会怎样问题链.md`
- `references/腾讯专栏题材库与生活化增补.md`
- `references/腾讯专栏YY缺什么补什么增补.md`
- `references/腾讯专栏YY缺什么补什么增补.md`
- `references/腾讯专栏读者爽感与财色权武增补.md`
 - `references/腾讯专栏文风平台匹配增补.md`
	- `references/腾讯专栏题材背景三类坐标系增补.md`
	- `references/腾讯专栏题材金手指融合方法与核心点增补.md`

## 卖点保真要求（强制）

- 任何作品都必须先钉死一个**突出、鲜明、可快速被编辑和读者识别**的主卖点；副卖点只能服务主卖点，不得抢口径。
- 题材定位必须同时回答：卖点是什么、为何新、为何能持续供血、如何在简介与开篇阶段被迅速看见。
- 若定位摘要不能让陌生人用几句话说清“这本书最值得点开的地方”，视为定位未完成。

## 题材竞对分析接入要求（强制）

- 若当前任务服务某个题材，且该题材目录下的 `竞对分析/` 已存在与当前项目、当前平台或当前赛道相关的竞对分析报告，必须先读取并纳入定位校准。
- 不得把这些报告只当成背景资料；必须显式对比主卖点、平台口径、主角抓手、现实锚点、代价锚点与创新组合，说明我方准备在哪些维度追平、反超竞对。
- 定位框架的默认目标不是“做出同类感”，而是让当前作品在关键维度上**全方位超越竞争对手**；若看不出明确超越路径，应判为定位仍未完成。

## 常见触发词 / 用户说法速查

- 先做题材定位
- 这本书的平台口径不清
- 帮我钉死主卖点和主角抓手
- 看看现实锚点和代价链够不够
- 这本书到底该怎么归类

## 何时使用

- 开书前，先校准作品母体与主平台口径。
- 总纲已写出，但平台口径、现实锚点、代价链、读者承诺仍发虚。
- 需要把“职业切口 / 社会压力 / 机制母体 / 城市空间 / 规则系统”咬成一个统一卖点。

## 本 Skill 的核心任务

在正式设计总纲、卷纲、单元案之前，先回答并写实以下问题：

1. 这本书的**主卖点与第一眼新鲜点**是什么。
2. 主角为什么必须入局。
3. 主线谜团为什么足以撑长篇。
4. 中后段持续回报靠什么轮换升级，并继续兑现卖点。
5. 主平台口径、现实锚点、代价锚点与创新组合是否已经形成闭环。

## 起点平台题材市场评估（强制，当定位起点或未标平台时）

题材定位不能只从作者灵感出发，必须先看清当前市场水位。以下规则默认在起点口径或未标平台时启用。

### 题材大盘数据参照

- 起点用户画像：18–35 岁占比超 70%，男性 71%，月收入 5–10k 群体为主力付费人群；地域集中在东南沿海新一线及以上城市。
- 2025–2026 题材占比：都市 27.6%（含「华娱+年代+重生」霸榜组合）、历史 19.3%（「大明」遥遥领先）、仙侠 17.3%（「西游化」趋势明显）、轻小说 16.1%、玄幻 10.3%。
- 重点增量赛道：科幻品类作品数量增幅超 67%（《深海余烬》《异度旅社》均订破 10 万）；都市现实题材男频文 2025 下半年流量暴涨 270%；悬疑惊悚题材大爆发。

### 题材创新度三级评判

设计题材定位时，必须从以下三个维度给出现状判断与选择理由：

1. **市场饱和度**：「退婚流」「签到流」等传统套路已饱和，很难再成爆款；若主卖点依赖已被大量重复的套路，默认下调定位成熟度。
2. **融合创新能力**：如《大奉打更人》「仙侠探案」新品类，将科学探案与玄幻修仙碰撞融合。定位框架必须写出至少一组「A+B」融合公式，并说明融合后产生了什么此前同赛道没有的阅读体验。
3. **时代契合度**：2026 年火的不是传统升级打怪，而是反套路文（系统是反派、主角靠智慧反杀）、现实向小人物逆袭、接地气打败称霸世界。若定位仍停留在「开挂碾压一切」而不给主角真实阻力，视为与当前读者口味脱节。

### 题材潜力快速筛查表

定位框架产出前，至少回答以下五问：

| 筛查项 | 通过标准 |
| --- | --- |
| 该题材在起点榜单 TOP50 占比是否≥30%，且更新活跃、新作不断 | 若低于 15% 或榜单老化，需证明为什么能逆势突围 |
| 题材是否自带强话题性（如职场内卷、原生家庭、性别平等），易引发社交讨论 | 若无话题钩子，需从融合创新或人物抓手补 |
| 是否避开了过气题材（无脑系统、傻白甜甜宠、重复度极高的古言宅斗） | 命中过气题材需有压倒性的创新证据才能放行 |
| 是否属于当前平台明确扶持的品类 | 起点悬疑灵异品类 2026.5.1–2027.12.31 有月票榜现金奖励+每月 1500 全勤补贴；科幻有「银河计划」专项扶持 |
| 是否能用一句话说清「这本书在什么题材里，做到了什么别人没做到的事」 | 若只能说「这是一本 XX 文」而说不出差异化，判为未完成 |

若五项中有两项或以上不通过，定位框架必须显式记录风险并给出弥补路径；若全部不通过，不得直接进入总纲设计。

### 目标读者与付费触发场景校准（新增）

- 起点口径下，定位文本必须显式写出“第一目标读者群”与“第二目标读者群”，并说明为何这两类读者会持续追更而非只看概念。
- 默认补答三问：
	1. 这本书打谁的哪种阅读冲动（智斗、逆袭、情绪代偿、关系站队、机制破解等）；
	2. 读者在第 `1` 卷与第 `2` 卷分别因为什么继续付费；
	3. 若不依赖强作者存量，作品本体靠什么稳住留存。
- 若定位只写“题材热度高”，却无法写清“目标读者是谁、为何买单、何处持续供血”，默认判为定位未完成。

## 执行顺序

1. 读取作品现有的简介、总纲、相关设定与人物入口文件。
2. 先用保真规则中的“四问校准法”给出定位摘要。
3. 再明确：主平台口径、主角抓手、母体来源、现实锚点、代价锚点、创新组合。
4. 再用平台定位检查表与锚点矩阵检查是否失真。
5. 输出结果时，优先给可直接回写到简介、总纲总则或定位说明的文字。

## 默认输出口径

- 默认输出一份可直接回写到简介、总纲总则或定位说明的定位框架文本。
- 默认同时给出主卖点、平台口径、现实锚点与代价锚点。

## 最低交付

- 能说清主卖点、主平台口径与主角抓手。
- 能指出现实锚点、代价锚点与创新组合。
- 能说明为什么这本书值得持续追读。

## 硬规则

- 禁止平台口径含糊，最后变成“每个平台都沾一点”。
- 禁止主角只有头衔，没有方法论抓手。
- 禁止机制 / 超常像万能工具，没有触发条件、代价和边界。
- 禁止现实议题只做主题词，不进入事件链、证据链与人物代价。
- 禁止卖点只停在概念层，不进入简介、开篇、总纲与后续正文。
- 定位起点或未标平台时，禁止不经过题材市场评估就直接下笔；至少必须回答：该题材当前在起点榜单 TOP50 的活跃度、是否有过气信号、是否有平台扶持窗口、是否避开了明显的过气题材。
- 创新融合公式（A+B）必须具体到阅读体验层，不得只写「玄幻+悬疑」「都市+科幻」这类空泛组合；要写出融合后产生了什么此前同赛道没有的读者感受。
- 若题材大盘数据显示该赛道已高度内卷（如传统退婚流、签到流、无脑系统），定位框架必须显式证明为什么本书能在内卷赛道中形成差异化；若证不出来，判为定位未完成。
- 禁止只给题材标签不给读者画像；禁止只给卖点口号不给付费触发场景。

## 与其他 Skill / Prompt 的边界

- 本 Skill 负责题材定位与平台口径钉死。
- 不直接代替总纲、分卷或正文创作。

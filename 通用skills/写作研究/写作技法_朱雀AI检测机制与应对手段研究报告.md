## 核心发现

### 一、朱雀AI检测的技术原理

朱雀AI检测是腾讯混元安全团队朱雀实验室推出的AI生成内容检测工具，其底层机制如下：

**检测核心算法**：采用统计语言模型分析 + 多模型特征比对。

#### 检测维度深度解析

**① 困惑度（Perplexity, PPL）**

数学定义：$PPL = 2^{-\frac{1}{N}\sum_{i=1}^N \log_b p(x_i)}$，其中 $p(x_i)$ 是语言模型对第 $i$ 个token的预测概率。

- **AI文本特性**：LLM倾向于选择高概率token序列，整体PPL偏低。文本"过于可预测"。
- **人类文本特性**：人类作者会做出更多不可预测的词汇选择，PPL偏高。
- **关键趋势**：正如StyleShield论文（arXiv:2605.00924, 2026）指出：*"language models are trained on human-written corpora, the statistical boundary between AI and human writing will inevitably dissolve as models improve"*（语言模型训练自人类语料，AI与人类写作之间的统计边界将随模型改进而不可避免地消解）。这意味着单纯依靠PPL的检测方法长期不可靠。

**② 突发性（Burstiness）**——句子长度与风格的方差度量

- **定义**：衡量文本中句子长度和风格的波动幅度。GPTZero将其列为三大核心指标之一：*"How much variation is there in the sentence length and style?"*
- **AI文本特性**：句子长度分布窄、方差小。AI产出的句子长度趋近均匀（如每句12-18字），段落长度也趋于一致。
- **人类文本特性**：句子长度天然大幅波动——从极短句（"他死了。"2字）到长复合句（40+字）。段落长度随内容自然变化。
- **朱雀对该维度特别敏感**：网文场景中，均匀的句子分布是AI文稿最容易被标记的特征之一。

**③ 词汇熵（Vocabulary Entropy）**——词汇多样性度量

- 定义：文本中词汇选择的多样性。高熵 = 用词丰富、出人意料。
- AI特性：LLM倾向于使用"安全"词汇，避免低概率词，导致词汇熵偏低。但随temperature提高可人为增加熵值。
- 人类特性：用词选择更多样化，包含口语化词汇、方言、网络用语、行业黑话等AI语料中低频出现的词汇。

**④ 语义结构层面（句间关系与逻辑模式）**

- 朱雀不仅分析字词层面，还分析**句间关系模式、段落节奏和信息密度分布**。
- AI输出逻辑链条通常呈线性推进（A→B→C→D，每一步严丝合缝），缺乏人类叙述中常见的跳跃、留白、旁支与补充。
- **对称结构**：AI偏好"前半句信息量 ≈ 后半句信息量"的平衡句式。人类写作中这种对称性远低于AI。

#### 检测方法分类与准确性对比

基于arXiv:2509.00731（LoRA微调Qwen2.5检测器论文）：

| 检测方法 | 原理 | 中文准确率 | 局限性 |
|---------|------|-----------|--------|
| 统计特征法（PPL + Burstiness + Entropy） | GPTZero、Originality.ai采用 | ~76-83% | OOD条件下严重退化 |
| 编码器微调（BERT/RoBERTa） | 区分AI vs 人类嵌入分布 | ~79%（OOD时更低） | 跨模型泛化能力弱 |
| **LoRA解码器微调**（Qwen2.5-7B） | 指令微调大模型做二分类 | **95.94%** | 计算资源需求高 |
| 多模型特征逐一比对 | 朱雀采用的方法 | 未公开 | — |

**关键结论**：新一代基于解码器的检测器（如LoRA微调方法）准确率远超传统统计方法。朱雀作为腾讯混元生态的一部分，很可能使用了类似的**多模型逐一分析+深度特征提取**方案，而非单纯的PPL检测。

#### 朱雀检测的完整架构推断

基于腾讯云TMS（文本内容安全）产品功能描述与朱雀官方说明，推断其检测管线：

```
输入文本 → 多模型逐一分析（GPT/DeepSeek/Claude等独立打分）
         → 统计特征提取（PPL/Burstiness/Entropy）
         → 语义结构分析（句间关系/段落节奏/逻辑模式）
         → 模型指纹比对（特定模型的输出特征模式）
         → 融合判决 → [AI率% + 可疑段落标注]
```

**训练覆盖**：文本涵盖论文、小说、作文、新闻等多种载体。支持检测ChatGPT、GPT-4、Claude、DeepSeek、Gemini、豆包、Kimi、文心一言等主流模型。

**官方宣称指标**：行业宣传称准确率约95%，误判率3%-5%（需注意此为第三方宣传数据，腾讯官方未公布精确指标）。

### 二、朱雀检测的核心敏感特征（网文场景）

根据多来源实测与汇总分析，朱雀检测在网文场景中最敏感的文本特征：

| 敏感特征 | 触发条件 | 典型表现 |
|---------|---------|---------|
| **句长均匀度** | 全文句子长度方差过小 | 所有句子7-15字，缺乏长度起伏 |
| **段落节奏** | 段落长度过于整齐 | 每段3-5行，节奏无变化 |
| **连接词密度** | "然而""但是""因此""此外""值得注意的是"高频出现 | 每段2-3个转折连接词 |
| **对话标签单一** | 仅用"说""道""问"，缺乏动作/表情/心理伴随描写 | 通篇"XX说""XX道" |
| **情感分布平坦** | 叙述语气从头到尾一致，缺乏情绪高低起伏 | 无兴奋/愤怒/低落等情绪曲线变化 |
| **细节颗粒度均匀** | 每个场景的细节密度相同，不分主次 | 重要场景和过渡段落"分量一样" |
| **逻辑推进过于线性** | A→B→C→D，每一步都严丝合缝 | 缺乏人类叙述中的跳跃、留白、预设 |

**关键认知**：朱雀不是"看你的字是不是AI写的"，而是"看你的字像不像AI写的"——这是语义上的根本区别。

### 2.5 中文网文特有的AI触发模式详解

基于网文作者社区总结与多来源交叉验证，以下中文特有的写作模式会显著提高AI检测得分：

#### 高频触发词列表（建议全文搜索并替换）

| 触发词 | AI偏好原因 | 替换方案 |
|--------|-----------|---------|
| 然而 | 标准转折过渡，AI训练语料中高频 | → "可"、"但"或直接省略，用动作断句 |
| 此外/除此之外 | 论证推进的标准模板词 | → 直接删除，或"还有"、"再说" |
| 因此/因而 | 因果关系的显式标记，人类不常用 | → "所以"、"结果"或隐含因果 |
| 值得注意的是 | 正式文本高频套语 | → 直接删除或用具体描述替代 |
| 不可否认的是 | 转折让步的标准句式 | → "当然"、"说实话" |
| 总的来说/总而言之 | 总结段落的AI模板 | → 直接删除，让段落自然收束 |
| 换句话说/换言之 | 解释/重述的标准过渡 | → 用具体例子替代抽象解释 |
| 毫无疑问 | 强调语气模板，AI过度使用 | → "显然"或直接陈述 |
| 一定程度上 | 模糊限定词，AI安全策略 | → 删掉，或给出具体程度 |
| 不仅…而且… | AI偏好的平行结构 | → 拆成两句，或只用其中一个 |

#### DeepSeek模型特有指纹

据虎嗅网、爱范儿等多篇报道，以及社区长期观察：

1. **精密数字堆砌**：DS生成的章节开头常堆砌精确数字（"二十七层楼、三千六百秒、一百四十三人"）
2. **不必要的比喻**：DeepSeek-R1在强化学习过程中对"创造性"的偏好导致比喻过度使用。编辑称之为"DS味儿太浓了"——精妙比喻+淡淡的人机感
3. **意象堆砌**：在不需要描写的位置塞入大量意象（"暮色像打翻的砚台，楼道里的声控灯在咳嗽"）
4. **发散思维**：DS内容容易偏离主线，在细节处展开不必要的"联想"
5. **对称句结构**：DS偏好"前半句-逗号-后半句"长度相近的平衡句式

#### "均匀就是AI"原则（核心洞察）

综合多个来源的证据，**"均匀性"是AI检测最核心的敏感特征**：

- ✅ 每段3-5行 → **危险信号**
- ✅ 每句7-15字 → **危险信号**
- ✅ 每个场景细节密度相同 → **危险信号**
- ✅ 全文情感语气一致 → **危险信号**
- ✅ 每个段落质量无明显差异 → **危险信号**
- ✅ 逻辑推进每一步都在场 → **危险信号**

**反直觉的结论**：把每一段都打磨到一样好，反而增加AI嫌疑。人类写作天然有"好段落"和"凑合段落"的波动。

### 三、网文平台AI判定生态全景（深度版）

#### 各平台AI政策详细对比

|------|----------|---------|---------|----------------|
| **番茄小说**（字节跳动） | 边拥抱边整治。官方提供AI辅助写作工具（扩写/续写/润色），但同时打击AI低质内容 | 朱雀等检测工具 + 编辑人工鉴别 + 签约审核收紧 + 作者自证 | 验证期流量下降、签约门槛提高、批量低质文封号、追回稿费 | 非保底作者可用扩写和续写，保底作者限制使用 |

| **起点中文网**（阅文集团） | 开放但设限。作家助手已集成DeepSeek-R1，75%作家常态化使用AI工具 | 编辑人工鉴别为主，AI检测为辅，精品频道额外审核 | 精品频道淘汰、签约审核筛查 | 允许AI辅助大纲润色、资料查询、描写润色、卡文推演 |
| **知乎盐选** | 收紧中。短篇AI投稿量激增，2025年下半年开始收紧 | 自动化审核 + 编辑人工抽查 | 退稿率上升 | 模糊地带，无明确分级标准 |
| **豆瓣阅读** | 政策模糊，倾向原创，但无公开AI专项检测 | 编辑审稿为主 | 无公开处罚案例 | 未明确规定 |
| **LOFTER** | 已出台对AI稿件的判定或处罚事件 | 检测+人工 | 有公开处罚案例 | 有限制性开放 |

#### 平台判定三种路径（深度版）

1. **AI检测工具初筛**（朱雀/豆包/Chinaz AI/MitataAI等）
   - 自动标记疑似AI章节 → 提交编辑

2. **编辑人工鉴别**——核心检查项（按优先级排列）：
   - **主线逻辑一致性**（最高优先级）：AI经常在长篇幅中丢失线索，出现逻辑断层
   - **人设稳定性**：角色言行前后是否一致
   - **对话自然度**：对话是否符合角色身份和情绪状态
   - **过渡自然度**：场景切换是否生硬
   - **描写效率**：描写是否服务于情节推进，还是单纯堆砌
   - **文笔精细度**（最低优先级）："写得太好"反而不是AI的证据

3. **作者自证通道**——在被标记后可提供：
   - 码字视频（录屏）
   - 文档历史记录（Google Docs/Word的修订记录）
   - 之前过稿材料对比文风
   - 手写草稿照片

> 关键洞察：编辑最看重的是**"从初稿到终稿的修改痕迹"**——有修改痕迹 = 人在创作。纯AI输出的内容没有"改稿过程"这个人类写作的核心特征。

**平台判定三种路径**：
1. **AI检测工具**（朱雀/豆包/Chinaz AI/MitataAI等）——初步筛查
2. **编辑人工鉴别**——经验判断：文风一致性、人设连贯性、过渡自然度、细节真实感
3. **作者自证**——要求提供码字视频、文档历史记录、之前过稿材料对比文风

### 四、编辑人工鉴别AI稿的方法论

据虎嗅网采访多位网文编辑（番茄编辑花花、七猫编辑荔枝等），编辑判定AI稿的核心检查点：

1. **过渡生硬**：AI在场景切换、时间跳跃时缺乏润滑，直接"跳转"
2. **人设不稳定**：角色言行前后不一致，同一角色在不同章节行为逻辑断裂
3. **细节堆积不推动剧情**：描写精致但不服务于情节推进
4. **DeepSeek特有文风**：精妙比喻+淡淡的人机感+突如其来的转折+堆砌不必要的意象
5. **拼凑痕迹**：AI会混入未经消化的其他作品名句（如七猫编辑发现《地狱太冷，你来殉我》出自晋江经典）
6. **章节结尾机械**：AI倾向于在章节末尾强加心理描写，而非以行动或对话收尾

**编辑鉴别优先级**：主线逻辑一致性 > 人设稳定性 > 对话自然度 > 描写效率 > 文笔精细度。

### 五、Prompt工程降AI率方法

基于腾讯云开发者社区、即刻App作者社区、CSDN等多来源实测汇总，以下为经过验证的有效方法：

#### 方法A：语言风格转换Prompt（基础版）——实测AI率100%→31%

```
## Role
你是一位资深的语言风格转换与文本润色专家，需要帮助用户将AI生成的文章
改写成具有人性化和自然表达的内容。文章应避免机械感，确保在语言风格、
情感表达、逻辑结构等方面与人类写作保持一致。

## Profile
作为语言风格转换专家，你精通将AI生成的文本调整为自然的人类写作风格，
口语化表达。你对人类写作特征有深刻理解，能够识别并修改AI文本中的
典型特征，如重复用语、情感缺失、逻辑生硬等问题。

## Skills
1. 具备文本分析能力，能识别AI文本中的模板化语言与人类写作的差异
2. 掌握创造性写作技巧，通过词汇替换、句式调整、情感增强等手段优化文章
3. 具有细致的编辑能力，能优化文章结构和逻辑，确保整体流畅性

## Goals
- 调整AI文章至接近人类写作风格，文章内容口语化，降低AI特征，
  提升自然度和个性化
- 增加情感表达，提高内容吸引力和可读性

## Constraints
调整时保持原有信息准确性，避免改变文章基本意图和内容，
确保语言多样性和表现力。

## OutputFormat
提供调整后的文章，包含具体修改建议和优化说明。

## Workflow
1. 分析AI文本特征，识别重复词汇、刻板句式等问题
2. 调整词汇和句式，增加语言多样性
3. 加入情感色彩和个性化表达、口语化表达
4. 优化文章结构和逻辑连贯性
5. 校对润色，确保表达准确清晰
6. 进行总体评估，提供修改说明和效果分析
```

**关键要素**：
- 设定Role角色（语言风格转换专家）
- 明确Constraints（口语化、自然、避免重复用语、情感缺失、逻辑生硬）
- 要求Workflow（分析AI特征→调整词汇句式→增加情感色彩和个性化表达→优化节奏）
- **必须开启深度思考模式**

#### 方法B：即刻App社区验证的"去连接词+短句化"指令

来自即刻App作者社区（AI探索站圈子）的实操指令：

```
你是一位资深的语言风格转换专家，需要帮助用户将AI生成的文章改写成
具有人性化和自然表达的内容。文章应避免机械感，确保语言风格、情感表达、
逻辑结构等方面与人类写作保持一致。

请调整AI文至接近人类写作风格，文章内容口语化，降低AI特征，
提升自然度和个性化，增加情感表达，提高内容吸引力和可读性。

调整时保持原有信息准确性，避免改变文章基本意图和内容，
确保语言准确和表现力。

将所有的句子过渡词和连接词替换为最基础、最常用的词语。
尽量使用简单、直接的表达方式，避免使用复杂或生僻的词汇，
确保句子之间的逻辑关系清晰，删掉文末总结的部分。

写作风格介于书面学术写作和口语描述之间，
保证所有的句子都要有主语，不要用复杂的长难句，
尽量用短句输出，替换掉所有的非日常词汇。
```

> **用户评价**："实测朱雀检测从89%降到6%"——CSDN博客作者分享

#### 方法C：论文降重指令（可适配为小说场景的复杂结构化改写）

这类指令的核心思路不是"换词"，而是从**统计结构层面**消除AI特征：

- 句法结构重组（非连续结构占比≥40%、零形回指密度≥0.35）
- 韵律特征消解（打乱语言节奏模式）
- 认知负荷调控（信息熵阈值控制，确保文本复杂度超越LLM生成边界）

**应用在网文场景**：将上述学术指令中的"概念体系升级""句法结构重组"等描述替换为网文对应的"对话节奏打散""描写密度调整""情感曲线重建"。

#### 方法D：5步风格分析法（来自知乎专栏分享）

不同于直接改写，这个方法先建立"无AI率风格基线"：

1. **准备风格样本**：找一段自己手写的、确认无AI率的文本（300-500字）
2. **上传给AI做风格分析**：用豆包/DeepSeek等分析这段文本的风格特征（句长偏好、用词习惯、节奏模式）
3. **生成风格约束描述**：让AI输出"该文本的风格特征描述"
4. **将风格约束注入改写指令**：在改写指令中加入"保持以下风格特征：[风格描述]"
5. **迭代调整**：每改完一轮用朱雀检测，直到AI率达标

> **原理**：通过预先建立"个人风格指纹"，使改写结果更接近"这个人的写作特征"，而非"通用的去AI化文本"。

> **实测数据**汇总：腾讯云开发者社区的绕过试验中，方法A将AI痕迹从100%降至31%。但对于论文类文本，仅从100%降至61%——说明**文本类型越规范（如论文），朱雀检测越准确**；反之**文本类型越接近人类自然写作（如小说），降AI效果越好**。方法B在网文/新媒体场景下效果更佳。

### 七、对抗检测的技术前沿：StyleShield框架与学术进展

#### StyleShield：首个条件文本风格转移的Flow Matching框架

2026年论文（arXiv:2605.00924）提出的StyleShield是目前最接近"系统化规避AI检测"的学术方案：

- **核心机制**：在连续token嵌入空间中，通过DiT（Diffusion Transformer）骨干网络配合零初始化cross-attention适配器操作，实现文本风格转移
- **控制参数**：单一参数 $\gamma$ 提供对规避能力与语义保留之间平衡的平滑连续控制
- **核心结果**：
  - 针对训练过的检测器达到 **94.6%规避率**
  - 针对三个未见过的检测器达到 **≥99%规避率**
  - 同时保持 **0.928的语义相似度**
- **RateAudit调度算法**：证明检测分数可以被设置为任意值

**对网文作者的启示**：StyleShield证明了"从文本统计结构层面系统化消除AI特征"的可行性。虽然该工具尚未普及，但其技术路径验证了本报告推荐的**改写节奏+打散均匀性+注入个人特征**策略的底层合理性。

#### 检测技术的军备竞赛趋势

| 时间节点 | 检测方进展 | 对抗方进展 |
|---------|-----------|-----------|
| 2023-Q4 | GPTZero、Originality.ai上线 | 简单同义词替换 |
| 2024-Q2 | 朱雀AI检测上线（腾讯） | Prompt工程去AI化 |
| 2024-Q4 | 多模型逐一分析技术普及 | 风格迁移改写工具出现 |
| 2025-Q1 | 编码器微调（BERT）达83%+ | DeepSeek+专业Prompt降AI率至31% |
| 2025-Q2 | 朱雀5.18算法升级（据社区信息） | 5步风格分析法 |
| 2025-Q3 | LoRA解码器检测达95.94%（arXiv:2509.00731） | StyleShield论文发表（94.6%规避率） |
| 2026-Q1 | C-ReD中文检测基准发布（ACL 2026） | 社区积累系统化去AI方法论 |
| **趋势** | 检测从单维→多维融合，从通用→模型特定 | 对抗从换词→统计结构改写→风格迁移 |

**关键技术拐点判断**：随着LoRA微调解码器检测达到95.94%准确率，单纯基于文本表面的对抗方法（换词、调整句式）将逐渐失效。未来有效的对抗必须从**语义结构和叙事模式**层面入手。

### 八、检测与对抗的长期博弈框架

#### 成功规避检测的数学直觉

综合StyleShield论文原理与社区经验，规避概率可近似表达为：

$$
P_{\text{规避}} \approx f\left(\frac{\text{突发性差异}}{\text{困惑度一致性}}\right)
$$

即：**增加句子长度和结构的多样性（提高突发性），同时保持局部文本的合理困惑度（不要通过过度随机化使文本显得怪异）**，是最有效的检测规避路径。

#### 长期有效的三大原则

1. **不均匀性原则**：在所有维度上制造可控的不均匀性（句长、段长、情感密度、细节密度）
2. **个人指纹原则**：注入来自个人经验而非AI语料的细节与表达方式
3. **修改痕迹原则**：确保文本呈现"从草稿到终稿的修改过程"特征——而不是一次性完美输出

#### "猫鼠游戏"的终局判断

基于多方来源的趋势分析：

- **短期（1-2年）**：检测技术将持续升级，简单对抗方法会快速失效。降AI工具和Prompt方法需要持续迭代。
- **中期（3-5年）**：如StyleShield论文所预言，AI与人类写作的统计边界将"不可避免地消解"。检测将越来越困难。
- **长期**：平台的判定标准可能从"是否AI写"转向"是否有创作价值"——这是语义层面的终极标准，技术检测只能作为辅助。

### 九、写作流程层面的应对策略

基于上述检测原理与平台生态，以下策略按**有效性从高到低**排列：

#### 策略A：人机协作混合写作（推荐）

不依赖AI生成全文，而是将AI用于写作流程中**人做不好的部分**：

- AI做：资料搜集、大纲脑暴、段落扩写草稿、卡文时的多路线推演
- 人做主笔：关键情节落笔、对话设计、情感节奏控制、人物声音塑造
- 处理过的AI段落必须经过：**改写节奏 + 注入个人风格 + 添加具体细节**三步

**原理**：纯AI文在跨源复现验证（三重验证第一重）中极易被一次识破。人机混合文的统计特征接近人类写作，朱雀的统计模型难以区分。

#### 策略B：自我检测闭环

1. 写前/改写前用朱雀跑一遍检测，建立"当前AI率基线"
2. 针对被标红的段落逐段调整
3. 每改完一轮再次检测，观察AI率变化方向
4. 直到AI率降至可接受范围（网文领域无官方阈值，但建议控制在20%以下）

> **注意**：朱雀的检测结果本身不稳定。同一作品不同章节可能出现0%、44%、87%的差异。删减内容后反而可能从44%跳到100%。自我检测的目的是发现文本特征偏差，而不是追求绝对分数。

#### 策略C：去AI味核心手法

**节奏打散**：
- 不要每段3-5行均匀分布。穿插1行短段（制造节奏变化）和8-10行长段（展开细节）
- 句子长度从全部7-15字变成"短句2-5字 + 中句10-20字 + 长句25-40字"混合

**句式多样化**：
- 减少"然而/但是/因此/此外"等逻辑连接词的频率
- 用动作（他推开门）、环境（窗外的雨声）、对话直接衔接段落
- 把AI喜欢用的"毫无疑问/值得注意的是/不可否认的是"等模板化短语全部删掉

**细节控制**：
- 分清主次：关键场景多细节，过渡段落少细节——而不是均匀分配
- 加入"只有作者才知道"的个性化细节（对某类人群的观察、特定地域的体验）
- 不用AI生成的"标准细节"（阳光透过窗户洒进来、空气中弥漫着咖啡香）

**情感注入**：
- 加入角色的主观感受和即时反应，而不是客观叙述
- 对白中加入情绪标签（动作/表情/内心独白伴随）
- 节奏配合情绪：紧张时短句加速，舒缓时长句展开

#### 策略D：利用朱雀的已知短板

朱雀在以下场景**更容易误判**：
- **字数过少**（测试显示删减至1/3后AI率从44%跳到100%）——不要单章检测
- **翻译软件转写的文本**——纯手写但使用翻译工具的文本也容易被标为AI
- **规范化写作**——越规范的文本越"像AI"，不够规范的"糙"文本反而更安全
- **均匀精修**——每一段都打磨到同样水平反而触发"均匀性"检测

**启示**：不要追求完美文本。留一些"只有人才会犯的瑕疵"——偶尔的啰嗦、某一处的随意、段落间质量的轻微波动。

### 八、朱雀检测的已知短板与局限

| 短板 | 详情 | 证据来源 |
|------|------|---------|
| **检测结果不稳定** | 同一作品不同章节AI率波动极大（0%-44%-87%），删减后反而升高 | 爱范儿报道，荷桃粥实测 |
| **对短文本不敏感** | 字数越少越不稳定，可能越高 | 多家测试交叉验证 |
| **对DeepSeek文风的过敏感** | DS文风（比喻+数字堆砌）极容易被标为AI | 虎嗅/爱范儿多方报道 |
| **算法持续更新** | 2025年5月一次更新后，旧降AI方法效果下降 | 搜狐专栏报道提及"5.18算法升级" |
| **无法区分AI辅助与AI生成** | 无法判断"用了多少AI"，输出是概率值而非确定性结论 | 腾讯官方说明 |
| **误判人工写作** | 晋江站长冰心的原创诗歌被判定为AI | 晋江论坛/爱范儿报道 |
| **统计模型天然局限** | 样本特征重合即产生误判，非确定性检测 | AI检测业界共识 |

### 核心结论

朱雀AI检测的本质是基于统计特征的**概率判定**，而非确定性鉴定。它检测的是"文本像不像AI写的"，而非"是不是AI写的"。

**有效的应对策略应基于"改变统计特征"而非"隐藏AI使用"**。具体而言：
1. **节奏打散**（句长分布从均匀变为波动）—— 针对困惑度与突发性检测
2. **句式多样化**（减少AI模板化连接词）—— 针对词汇熵检测
3. **情感与细节注入**（加入只有人知道的个性化信息）—— 针对内容深度检测
4. **人机协作而非AI独写**（关键情节人落笔）—— 从根本上消除语义结构层面的AI特征

**三个不现实的做法**：
- ❌ 追求"一键绕过所有检测"——不存在
- ❌ 追求朱雀检测结果为绝对0%——检测本身不稳定
- ❌ 纯AI生成后仅换词不做结构改写——检测不仅看词汇

## 创作可用的结论与抓手

### 写作层面可直接执行的操作清单

1. **段长设计**：写完后全局扫一眼，确保3行以下的短段与5行以上的长段交错出现，避免中段（3-5行）比例超60%
2. **句长控制**：每500字检查一次，确保有3-5字短句和25字以上长句穿插，不要全是中句
3. **连接词替换**：全文搜索"然而/但是/因此/此外/值得注意的是/不可否认的是"等，删掉至少一半，用动作/对话/场景直接过渡
4. **对话标签多样化**：通篇"XX说"的段落，加入30%的动作伴随标签（"他放下杯子""她盯着对方"）
5. **章节结尾检查**：AI倾向于在章节末尾加心理描写或总结，改成行动或对话收尾
6. **均匀性检查**：找出写得最好的段落和最弱的段落，确认它们有明显的质量差异——太均匀本身就是红牌
7. **真实细节植入**：每章加入1-2个只有你（或特定人群）才知道的细节——地域特色、职业习惯、生活中的小观察
8. **修改后对比**：修改后用朱雀跑一次，观察AI率趋势而非绝对值——趋势下降说明方向正确

### 给项目根目录 Agents.md 的集成建议

在 Agents.md 中加入如下约束：

```
## AI检测规避约束
- 句长分布需有显著方差：短句≤5字占≥10%，长句≥25字占≥15%
- 连接词"然而/但是/因此/此外"在全文中出现频率每千字不超过2次
- 对话标签中"XX说"占比不超过70%，其余用动作/表情/心理伴随代替
- 每1000字应有≥1个只有特定群体才知道的真实细节
- 章节末尾不以心理描写收尾
- 段落长度变异系数≥0.3（即段落间有显著长短差异）
```

  - "降AI工具"的效果数据主要基于厂商自述和单次测试 [待验证]
- **置信度总评**：中高。核心检测原理（统计特征分析）可信度高，但具体算法细节和平台数据存在缺口。
- **反常识声明**：AI检测不是越写得好越安全，而是越写得"不均匀"越安全。刻意追求完美文本反而增加被判定为AI的风险。

# 通用-输出起点中文网版｜跨题材共性与迁移来源

## 迁移来源说明

本 Skill 的起点中文网平台共性规则来源于：

1. 从 `通用-创建小说正文` 等核心 Skill 中提取的起点专属硬编码规则（Phase 2 迁移）
2. `通用skills/通用-多平台小说适配/references/平台差异矩阵.md` 中起点中文网条目
3. 各题材 `写作研究/` 中起点平台的研究报告

## 跨题材共性

以下规则适用于所有在起点中文网发布的题材：

- 长线追读、章级回报工程
- 前 300/1000/3000 字分层抓力体系
- 章末强钩子 + 钩子类型轮换
- 黄金三章：开篇不铺垫
- 摄像头视角铁律（禁止上帝视角）
- 读者向作者有话说（非复盘腔）

## 后续迭代方向

- 各题材 `题材名-输出起点中文网版` 的 `references/执行细则与题材补丁.md` 负责题材专项规则
- 平台通用规则统一在本 Skill 维护
- 新增题材时直接复用本 Skill，无需重复定义起点共性

# 通用-设计人物传记

人物传记应写成作者可长期调用的裁判源，而不是漂亮但难落地的人设简介。

## 常见触发词 / 用户说法速查

- 帮我做人物传记
- 重写这个角色档案
- 这个人物还不够立
- 给角色补动机和代价
- 帮我把人物关系网整理出来

## 何时使用

- 新建某个角色的人物传记
- 把旧传记重写为可写、可审、可对齐大纲的版本
- 给人物补充写作抓手、关系网、心理弧线与索引映射

## 不适用情形

- 只做人物传记审阅，不改稿：优先使用 `通用-审阅人物传记`。
- 只写正文中的单场人物对话或人物表现，不建人物裁判源。

## 人物小传八问——专业与业余的人物设计代差（强制）

业余大纲的人物设定通常止步于姓名、年龄、外貌和简单性格标签。专业大纲的人物小传必须回答以下八个问题，缺一不可：

### 八问清单

1. **核心欲望**：ta 最想要什么？注意，表面欲望与深层欲望可能不同。
   - ❌ 业余："想变强"
   - ✅ 专业："想在 30 岁前买房给父母" / "想证明自己不是废物" / "想查明母亲死因，同时验证这个陌生世界是否值得守护"

2. **核心恐惧**：ta 最害怕什么？恐惧必须具体到可被正文事件直接触发。
   - ❌ "害怕失败"
   - ✅ "害怕成为权力的傀儡" / "害怕重蹈父亲覆辙" / "害怕被所爱之人当成怪物"

3. **道德边界**：ta 在什么情况下会突破底线？边界必须有明确的触发条件与后果。
   - 什么能让一个守法者杀人？什么能让一个忠诚者背叛？什么能让一个利己者牺牲？

4. **成长弧光**：故事开始和结束时，ta 在认知、能力、情感上如何变化？
   - 不只是"数值变大"，而是判断方式、关系处理、自我认知发生不可逆变化。
   - 示例：范闲——从"精致的利己主义者"到"责任的承担者"。

5. **人物关系网**：与每个重要角色的关系动态图，含起始关系、变化节点、最终关系。
   - 不能只写"他是 A 的朋友"；必须写出关系如何因事件而改变，以及改变发生在哪一卷/哪一章。

6. **标志性细节**：一个动作、一句口头禅、一个物件——让读者瞬间想起 ta。
   - 这个细节必须能直接回贴正文，而不是只在传记里好看。

7. **秘密与谎言**：ta 隐藏着什么秘密？对谁撒谎？为什么？
   - 秘密必须在正文中有暴露窗口；谎言必须有被揭穿或维持的代价。

8. **致命缺陷**：这个缺陷将如何推动关键剧情？
   - 缺陷不是"脾气不好"这类装饰；它必须直接导致某个关键转折点的发生。
   - 示例：范闲的致命缺陷是过度的现代思维与古代世界的冲突——这个缺陷贯穿全书，每次重大选择都与之相关。

### 八问验收规则

- 核心/重要人物必须完整回答全部八问；次要人物至少回答 1、2、5、6 四问。
- 若人物传记无法回答其中五项以上，或回答停留在抽象标签层（"他很聪明""她很善良"），判为人物未成立。
- 传记中的"写作抓手交付"区块必须能从八问中的至少三项直接导出可贴回正文的具体抓手（口头禅、习惯动作、压力反应等）。

## 题材竞对分析接入要求（强制）

- 若当前任务服务某个题材，且该题材目录下的 `竞对分析/` 已存在与当前项目、当前平台或当前赛道相关的竞对分析报告，设计人物传记前必须先读取并纳入本轮判断。
- 若目标平台为起点中文网，或未注明平台时默认按起点中文网标准处理，且当前题材目录下尚无可用竞对主报告，开始人物传记设计前应优先调用 `通用-分析竞对作品`，至少补齐 **Top10 候选池、`3–5` 本主样本与四层深拆速览**；若任务限制导致本轮无法补齐，必须显眼记录盲区，并降低本轮人物传记成熟度判断。
- 不得把这些报告只当成背景资料；人物传记必须显式说明本轮准备在哪些维度追平、反超竞对，以及哪些主样本暴露出的旧坑必须避开。
- 人物传记的默认目标不是“资料更全更细”而已，而是让当前作品至少在**主角抓手、人物付费价值、关系拉扯、成长弧线、记忆点**这 `5` 个默认关键维度里形成可举证的追平路径，并尽量在其中 `2–3` 项建立明确领先方案。

## 起点化竞对吸收口径（新增）

当人物传记服务起点中文网，或未标平台而默认按起点基线处理时，默认把竞对吸收拆成以下四层，并翻译成人物级设计约束：

- **市场数据层**：用榜单位次、均订 / 首订 / 收订比代理信号、推荐资源位等，反推这名角色是否真的支撑题材归类、持续付费价值与长线商业竞争位，而不是只在作者视角里“人设很完整”。
- **内容创作层**：重点吸收主样本在人物抓手、欲望与代价、关系拉扯、身份反差、能力边界、语言指纹、成长弧线与反派动机包装上的做法，把它翻成当前传记的裁判源字段与写作抓手交付。
- **运营策略层**：重点吸收主样本如何通过角色制造追读工程、本章说讨论点、站队点、关系张力与持续回报，把它翻成传记里的触发器、底线 / 开关、留痕偏好与可复盘细节库。
- **受众反馈层**：重点吸收本章说 / 书友圈 / 书评区里高频被夸的人物魅力点、被骂的脸谱化病灶、老白读者对降智 / 空心 / 无代价主角的敏感点，提前写进本轮传记的避坑与加码清单。

起点语境下，默认尽量使用以下术语，而不是写成空泛的“这个人物更立了”：`均订`、`高订`、`首订`、`追订`、`收订比`、`分类月票榜`、`畅销榜`、`新书榜`、`三江`、`本章说 / 段评`、`书友圈`、`老白读者`。拿不到精确值时必须写成代理信号，不得伪造具体数字。

## 默认执行顺序

0. 先判定平台口径：明确为起点中文网，按起点口径执行；未注明平台时，默认按起点中文网标准处理；明确为非起点平台时，按目标平台口径执行。
1. 若按起点口径执行且当前题材目录下缺少可用竞对主报告，先调用 `通用-分析竞对作品`，补齐 `Top10 候选池 → 3–5 本主样本 → 四层深拆` 的最小结论集。
2. 先确认目标人物文件与写入策略。
3. 若按起点口径执行，先吸收竞对主样本四层结论，并写清本轮人物要追平 / 反超的关键项。
4. 判断人物层级：核心 / 重要 / 次要。
5. 核心 / 重要人物优先采用“抬头元信息 → 写作抓手交付 → 基本信息 → 详细内容 → 完整心理弧线 → 索引 / 修订 / 自检”的整包结构，不要把关键模块零散埋在长段叙述里。
6. 先按模板确认四大基础栏位——背景、性格、外貌、其它——都已落位；再在此基础上搭建外层识别、成长时间线、动机、价值观、边界、关系、抓手、秘密、弧线、索引。
7. 再补公众形象 vs 自我认知、外部目标 vs 内部需求、压力反应与锚点物。
8. 最后走质量控制与验证流程。

## 人物硬要求（新增）

人物硬要求固定按三层优先级执行：先保可写性底盘（短板 / 动机 / 拉扯），再保结构化可调用字段，最后补增强模块与长期维护项。

- 无论人物层级如何，人物传记模板在原有细分结构基础上都必须显式覆盖 **背景、性格、外貌、其它** 四大基础栏位；允许继续沿用现有章节名，但不得缺栏，也不得把任一类压缩成无法快速检索的零散句子。
- 其中“其它”默认指除背景、性格、外貌外，直接决定人物可写性与可调用性的作者侧关键项，如能力边界、关系网、写作抓手、偏好厌恶、秘密爆点、心理弧线与索引映射。
- 人物至少要同时具备：**真实短板**、**务实动机**、**一个会反复拉扯他的关系或执念**。
- 传记里默认要写清角色想要什么、为什么现在必须要、为了得到它愿意失去什么。**欲望越具体，人物就越立得住，故事就越有驱动力。** 不要写「一个想升职的职场人」，要写「一个被裁员的北漂，想在30岁前攒够首付，给爸妈一个安稳的晚年」。
- 主角与重要角色都应有成长弧光：不是“会不会变强”这么空，而是价值判断、关系处理、行动方式或自我认知会发生什么可写变化。
- 角色魅力不能只靠标签、设定或外形；必须落到口头禅、动作习惯、压力反应、做错事后的补救方式等可直接回贴正文的抓手。
- “强”不是完美无缺；越是承担长线供血的角色，越要避免无短板、无代价、无反噬的万能写法。
- 核心 / 重要人物默认应在标题下显式标注：**人物类型、心理弧线步数、传记版本、最后更新**。
- 写作抓手默认集中放在 **写作抓手交付（正文可直接调用）** 区块，至少细分为：**口头禅 / 句式习惯、习惯动作与微反应、触发器、底线 / 开关、留痕偏好、反制动作模板**。
- 核心 / 重要人物的“基本信息”不止是身份摘要，还应尽量补足：**职业 / 身份轨迹、家族关系 / 原生关系、一句话卖点 / 差异化、题材或时代压力锚点、可复盘细节库、历史地位 / 结构功能**。
- 核心 / 重要人物默认还要写清：**关键经历时间线**、**公众形象 vs 自我认知**、**当前外部目标 vs 内部需求**、**价值观 / 误信**。
- 核心人物默认还应补出：**身份认同危机、内在冲突体系、情感变化链条、价值观演进、本轮修订 / 自检** 中的关键模块，避免只有“大而全设定”而没有“持续可维护结构”。
- 重要人物最好至少有一个**象征物 / 记忆锚点 / 空间锚点**，方便在正文里做回指、反差与情绪唤起。

## Nuwa 深度人物心智模型注入（新增）

> 核心理念源自 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)：好的人物不是漂亮人设的堆砌，而是一套**可运行的认知操作系统**。详细方法论见 `references/nuwa-深度人物心智模型注入.md`。

人物传记设计时，在完成四大基础栏位与八问后，默认追加以下 Nuwa 级深度层。这不是"锦上添花"，而是把人物从"设定完整"提升到"可预测、可碰撞、读者能感受到其思维重量"的关键工序。

### 心智模型：人物看世界的镜片（强制，核心/重要人物）

心智模型 = 人物看待世界的核心镜片，决定他如何理解事件、判断他人、做出选择。它不是"标签"（如"他很聪明"），而是"认知规则"（如"信任是需要挣的，不是给的"）。

**设计规则**：
- 核心人物提炼 3–5 个心智模型，至少 1 个是"误解型"（最终会在弧线中被修正的误信）
- 重要人物 2–3 个心智模型
- 每个心智模型必须通过虚构三重验证：跨场景复现（≥2 个不同场景类型）、有生成力（能推断新情境反应）、有排他性（不是所有人物都这样想）
- 每个心智模型必须写清"适用边界"：这个镜片在什么情况下会失效或让他犯错
- 不同人物的心智模型之间必须有差异性，能产生碰撞

**传记落位**：心智模型写入传记的"价值观 / 误信"区域，格式见 reference 文件 §2.4。

### 决策启发式：人物的快速判断规则（强制，核心/重要人物）

决策启发式 = 人物在压力下快速做判断的"如果X，则Y"式规则。它们比心智模型更具体、更行动导向。

**设计规则**：
- 核心人物 5–10 条，重要人物 3–5 条
- 至少 1 条是"错误规则"——会在关键时刻导致人物做出错误判断
- 每条必须有具体情节节点支撑
- 从心智模型自然推导——一个心智模型通常生成 2–4 条决策启发式

**传记落位**：决策启发式写入传记的"底线 / 开关"与"反制动作模板"区域。

### 表达DNA：人物的语言身份证（强制，核心/重要人物）

Nuwa 级表达DNA 不只是"说话很冷"或"爱怼人"，而是从以下可测量维度建立人物的语言身份证：平均句长、疑问句比例、类比密度、确定性语气、转折频率、引用习惯、禁忌词与口癖。

**设计规则**：
- 核心/重要人物必须补出完整的"语言指纹"区块
- 必须包含：声口分众表（对上位者/同级/下属/亲密对象/敌对对象的不同说话方式）
- 必须包含：情绪变体（愤怒/恐惧/伪装/亲密时的句式与用词变化）
- 必须包含：禁忌词——这个人物绝不说的话
- 目标：遮住名字读 100 字对话/独白，能认出是谁

**传记落位**：表达DNA 写入传记的"写作抓手交付"区块内的"口头禅 / 句式习惯"，格式见 reference 文件 §4.5。

### 矛盾深度框架（强制，核心/重要人物）

Nuwa 核心原则：**矛盾是人物的核心特征，不是需要修复的 Bug**。一个人物没有内在矛盾 = 纸板人。

**三种矛盾类型**：
1. **时间性矛盾**（人物弧线的引擎）：人物观点/行为随故事推进发生变化——这就是心理弧线的本质。变化必须有触发事件。
2. **领域性矛盾**（人物复杂度的来源）：人物在不同领域/关系中表现出不同行为准则（如工作冷酷、对家人温柔）。这不叫"人设崩了"。
3. **本质性张力**（人物最有魅力的部分）：内在价值观冲突，两种力量在心里持续打架。至少 1 对本质性张力要写入心理弧线的关键步骤。

**传记落位**：矛盾写入传记的"内在冲突体系"与"心理弧线"区域，格式见 reference 文件 §5.5。

### 诚实边界：人物的认知盲区（强制，核心人物）

诚实边界 = 人物看不到什么、理解不了什么、做不到什么。一个人物没有盲区 = 不可信。

**设计规则**：
- 核心人物至少 3 条诚实边界，其中至少 1 条与主线情节直接相关
- 边界类型可选：经验盲区、价值观盲区、能力盲区、信息盲区、性格盲区
- 每条诚实边界必须有正文触发计划：在哪一章/哪卷会被触发，触发后果是什么
- 诚实边界不是装饰，而是**情节的发动机**：人物的盲区 = 他会在哪里跌倒

**传记落位**：诚实边界写入传记的"能力边界"区域，格式见 reference 文件 §6.4。

### 智识谱系：人物的思想血缘（可选，核心人物）

人物的思维框架来源与传承：受谁影响（导师/经历/创伤），正在影响谁（徒弟/追随者/被保护者），在故事思想地图上的位置（与其他人物的立场对比关系）。

**传记落位**：智识谱系写入传记的"关系网"或单独"思想谱系"区域，格式见 reference 文件 §7.2。

### Nuwa 注入的最低交付标准

核心/重要人物设计完成后，默认用以下自检确认是否已达 Nuwa 级深度：
- 心智模型 ≥2 个，每个有 ≥2 个跨场景证据，且不同人物的模型能产生碰撞
- 决策启发式 ≥5 条（核心），其中至少 1 条是"错误规则"
- 表达DNA 完整：有句长/语气/禁忌词/声口分众/情绪变体
- 至少 1 对本质性张力，且已写入心理弧线
- 至少 1 处领域性矛盾
- 核心人物至少 3 条诚实边界，其中 1 条与主线直接相关

## 正文可调用素材清单（强制，核心/重要人物）

> 详细模板见 `references/正文可调用素材清单.md`。此清单解决"传记写得很满、正文里人物还是没立住"的核心问题——它不是另一份"设定"，而是把传记中的抽象特质翻译成**正文可直接插入的具体片段**。

人物传记设计完成后，核心/重要人物默认必须在传记末尾追加以下四种正文可调用素材。缺失任一类，传记不得判为"可就绪开写"。

### 压力反应微镜头（≥5 个 / 核心人物）

人物在特定压力类型下的 80–150 字微型叙事片段，格式为"外部动作 → 身体反应 → 内心一闪"。每个微镜头必须直接体现至少 1 个心智模型和 1 条决策启发式。压力类型至少覆盖：被质疑、被隐瞒、两难选择、被迫求助、独处破防。

**传记落位**：`## 正文可调用素材 > ### 压力反应微镜头`

### 声口即时贴（≥10 句 / 核心人物）

按情境分类的标志性台词（10–40 字 / 句），覆盖挑衅/求助/夸奖/失望/亲密破防等情境。必须从表达DNA可追溯（句长、语气、禁忌词），含 ≥2 句"没说出口但身体语言在说"的沉默/动作替代。

**传记落位**：`## 正文可调用素材 > ### 声口即时贴`

### 误判预设场景（≥3 个 / 核心人物）

人物因心智模型或诚实边界必然做出错误判断的微型场景描述。每个误判必须：来自诚实边界中的一条 → 写清"人物为什么这样判断" + "实际上发生了什么" → 有明确的卷/章定位建议。

**传记落位**：`## 正文可调用素材 > ### 误判预设场景`

### 关系拉扯动作库（≥8 组 / 核心人物）

与每个关键关系对象的标志性互动模式。每组含 ≥2 个具体可写的场景动作、底层动力（心智模型的碰撞点）、翻面条件。

**传记落位**：`## 正文可调用素材 > ### 关系拉扯动作库`

### 正文调用清单与下游 Skill 的联动（强制）

此清单是传记与正文之间的**执行层桥接**，下游 Skill 必须按以下规则消费：

- **生成章节控制卡时**：从出场人物的正文调用清单中提取本章要用的具体素材，写入场景单元和对话链
- **写正文时**：人物出场先查压力反应微镜头找默认反应基线，人物说话先查声口即时贴确认语气/禁忌词
- **审阅正文时**：对比正文中的声口/反应/误判与传记中的清单是否一致

若传记缺少正文可调用素材清单，下游 Skill 默认降低该人物的执行优先级——因为施工者没有可直接使用的素材，只能凭标签即兴发挥。

## 起点爆款主角人设与配角体系（新增）

### 主角人设四要素（起点口径）

起点爆款作品的主角人设普遍具备四个共同特征，人物传记设计时必须逐项核验：

1. **低起点**：开篇可以弱小或有明显缺陷，但不能是"设定上很弱但实际无敌"。低起点让读者产生"这个位置我也坐过"的代入感。
2. **强动机**：不是"想变强"这么空，而是"想在 30 岁前买房给父母""想证明自己不是废物""想找到杀父仇人"这类具体、可验证的欲望。欲望越具体，人物越立得住，故事越有驱动力。
3. **反套路**：在同类题材的人物模板上至少做一处本质偏离。示例：穿越者不是要争霸天下，而是只想躺平却被卷入；刑警不是热血正义，而是内心厌倦体制但被案件缠住。
4. **立体弧光**：开篇可以弱小或有缺陷，但需通过剧情推进实现可感知的蜕变——不是数值变大，而是判断方式、关系处理、自我认知发生不可逆变化。

### 八类主流主角人设速查

设计主角时，优先从以下起点验证过的人设类型中选择最贴合的一个作为主轴；可混搭但必须有主心骨：

| 类型 | 核心特征 | 适合题材 |
| --- | --- | --- |
| 冷静理智型 | 韩立式，计算得失、不轻易信任 | 仙侠、玄幻、科幻 |
| 热血冲动型 | 行动先于思考，凭直觉做正确的事 | 都市、热血竞技 |
| 腹黑算计型 | 表面无害、暗中布局、智商压制 | 权谋、商战、谍战 |
| 杀伐果断型 | 不圣母、不拖泥带水、该出手时绝对出手 | 末世、玄幻、都市高武 |
| 沙雕搞笑型 | 自带喜剧节奏，靠反差制造记忆点 | 轻小说、都市日常 |
| 低调扮猪型 | 实力远超表现，在不该低调时收、该亮时亮 | 都市、玄幻 |
| 霸道狂傲型 | 绝对自信、碾压式推进，但要给真实阻力 | 玄幻、都市异能 |
| 成熟稳重型 | 有阅历、有包袱、做事有分寸有代价 | 历史、都市现实 |

传记设计时，主角只能选定一个主轴类型；若想同时具备多种特征而写成了"完美主角"（冷静又热血、杀伐又善良、霸道又低调），判为人物未成立。

### 配角的功能性与独立性平衡

起点爆款作品的配角塑造遵循"工具性 + 独立性"双轨原则：

- **功能性**：每个配角必须有明确的剧情功能——导师传授能力、反派制造冲突、智囊分析局势、搞笑担当调节节奏。若一个配角删掉后剧情不受影响，说明这个角色只是人头而不是人物。
- **独立性**：配角不能只是"帮主角的人"或"挡主角路的人"；必须有自己的过往恩怨、隐藏身份、独立诉求。示例：搭档表面忠诚但暗中在和另一股势力接触——这种"有自己的算盘"让配角立体。
- **成长型配角**：从敌对到追随、从怀疑到信任，见证主角强大的过程也是配角自己改变的过程。这种配角最容易产生读者站队和本章说讨论。

传记设计时，每个重要配角必须同时写出"他的剧情功能是什么"和"他自己想要什么"，两句话缺一不可。

### 读者共情度建立规则

共情不是靠"主角很惨"堆出来的，而是靠以下三件事：

1. **让读者在主角身上看到自己的影子**：职场受欺负、情感受伤害、被误解、被低估——这些情绪触点比"身世凄惨"更能引发共情。
2. **让读者在主角身上看到理想中的自己**：通过努力改变命运、在关键时候做出正确选择、拥有读者想要但现实中很难拥有的品质或能力。
3. **主角的价值观要符合主流认知**：正义、善良、勇敢、智慧——但这不意味着主角必须完美；主角可以犯错、可以犹豫、可以自私，但最终的选择应该让读者觉得"换我也会这样"。

传记设计时，必须至少写出一个读者能立刻产生共情的具体情境——不是"他从小命苦"这种抽象背景，而是"他被裁员那天，在出租屋里对着手机通讯录翻了半小时，最后谁也没打"这种具体瞬间。

## 完整模板、动态状态与行为记录补强（新增）

- 主角 / 反派 / 核心重要人物默认按“完整模板”建档：基本信息、性格核心、语言指纹、背景、角色弧线、当前状态、章节行为记录。
- 普通配角可先用精简模板，但只要卷级职责上升、出场频率增多或开始承担独立冲突，默认升级为完整模板。
- “当前状态”属于每章都可能变的动态字段，至少关注位置、情绪状态、已知信息、持有物、身体状态、最后更新章节；“章节行为记录”采用逐章追加，不回改旧记录。
- 传记里的语言指纹不能只写平时怎么说，最好补出情绪变化时的语言变化，以及对上位者 / 同级 / 亲密对象 / 敌对对象的声口差。
- 关系总览只在关系发生实质变化时刷新；人物传记正文中若出现关系字段，应能与关系总览互相回指。
- 默认把“稳定字段”和“动态字段”分开维护：单章情绪波动、临时失态、短期伪装，不等于人物底色改写。

## 最低交付

- 至少能把人物信息清楚归并到背景、性格、外貌、其它四大基础栏位中，且四类都可被直接定位。
- 能写清外层识别、动机、边界、关系、抓手、弧线与索引中的核心字段。
- 核心 / 重要人物至少要补出成长时间线、公众形象 vs 自我认知、外部目标 vs 内部需求、价值观 / 误信中的关键字段。
- 核心 / 重要人物至少应补出“写作抓手交付”“可复盘细节库”“完整心理弧线（含总步数）”三类可直接调用模块。
- 能说明角色为什么值得继续写、继续审、继续回指。
- 能作为正文与大纲的可调用裁判源使用。

## 硬规则

- 传记不是宣传文案，禁止只写抽象褒贬。
- 若按起点口径执行，动手前必须先写清：本轮人物传记准备追平 / 反超哪类主样本的哪项主角抓手、关系拉扯或付费价值。
- 人物必须有动机，也必须有代价。
- 能力不能万能，关系不能只是“认识谁”。
- 写作抓手必须可直接贴回正文使用。
- 核心 / 重要人物的关键抓手不要只写成一行概括，优先列表化，方便在正文里逐项调用和回指。
- 禁止把成长时间线写成流水履历；必须写清哪些事件真的塑造了人物现在的判断、伤口与偏见。
- 禁止只写“别人眼中的他 / 她”或只写“自我独白”；公众形象与自我认知的差值要能制造戏剧。
- 心理弧线不要只写四个阶段标题；关键步骤默认应能回指到具体事件、物件、称呼、地点或编号。
- 除非用户明确要求只脑暴，不得只在聊天里给传记长文而不写入对应文件。
- 主角至少要写清执念、缺陷、秘密三者中的两项；反派必须写清可落地动机来源。

## 先有人设，再有对话（新增）

改对话的第一步不是改那几句话，是先把这个人立住。对话尬的根本原因是人物在替作者说话——那些话不是从人物嘴里说出来的，是从作者脑子里直接倒出来的。

### 网文常见主角性格速查

从以下选项中选两到三个，确定下来之后再让人物说话：

杀伐果断、重情重义、努力勤奋、不服就干、强势、智商高、不拘小节、冷酷、护短、很苟、阴险、杠精、幽默、咸鱼、爱吃、记仇、狂傲

不同性格面对同一情境的反应完全不同。比如"杠精"型主角面对威胁可能会先反驳对方逻辑漏洞，"很苟"型主角可能一句话不说直接找退路，"爱吃"型主角在逃亡途中可能还在想刚才那碗面没吃完。

### 角色独白练习

每天选一个角色，用第一人称写三百字日记。不写剧情，写感受、写细节、写无聊的观察。练的是用人的口吻看事情，不是作者的口吻。练一个月，人物说话就不会是一个味儿了。

这也是传记落成后验证人物声口的实操补充：如果第一人称三百字写出来还是作者腔，说明传记里的语言指纹还不够具体。

- 若用户只要审阅和问题分级，应优先使用 `通用-审阅人物传记`。

# 起点默认审核流程与硬门槛

> 适用范围：
>
> - 明确针对起点中文网的签约 / 过稿评估
> - 未注明平台时，作为本项目默认评估基线

## 审核顺序（默认理解）

1. 先过基础门槛：字数、材料、更新稳定性、存稿与投稿路径是否成立。
2. 再看内容质量：开篇抓力、主角抓手、冲突、逻辑、长线供血。
3. 最后看题材创新、市场适配与后续数据潜力。

> 其中“更新稳定性 / 存稿 / 投稿路径”默认只决定**是否适合现在投稿**与作者执行风险高低，不应直接并入小说文本质量高阶判断。

## 常用门槛锚点

### 机器初审风险

- 约 6000 字后，通常会先暴露出：原创性、违规风险、章节字数合规性等基础问题。
- 若作品在原创 / 违规 / 极端不合规章节结构上有明显风险，应优先写成 P0 或至少重大预警。

### 自主申签

- 通用层默认只把“是否达到当前题材 / 平台设定的自申正文门槛”当成必检项；若题材层有更严格数值，题材层覆盖通用层。
- 起点不同题材研究里，自主申签观察带常见落在约 `5` 万–`10` 万字；若本轮题材研究明确给出更严格门槛，不得再拿通用层模糊口径回冲题材层。
- 申请时若已断更或明显更新不稳定，审核优先级通常会下降。

### 编辑内投

- 本仓库在起点内投相关工作流里，不再沿用旧的“`6000` 字正文 + `300` 字大纲”最低提交线，也不再把“`2` 万字开篇 + `2000` 字大纲”作为默认成熟线。
- 统一提交线：至少 `30000` 字连续正文 + `内投版总大纲（最低 5000 字）` + `内投版第 1 卷卷纲` + `内投版简介`；`组包自检` 作为作者侧同版本配套文件，应与四份对外交付件一并保存。
- 缺任一对外交付件，只能视为未达提交线；四份主件齐备但模板符合性、前门效率、长线供血或执行准备不过线，也不等于适合直接给出“建议现在内投”。
- 快审时仍可把前 `300 / 500 / 1000 / 3000 / 6000` 字与前三章当作前门观察锚点，但这些锚点不再等同于提交门槛本身。
- 达到统一提交线，不等于竞争力达线；若与同题材 Top 10 的量化差距卡仍显示关键维度明显落后，不得给出“建议现在投稿 / 建议现在内投”。

### 内投大纲覆盖范围（全书骨架强制要求）

> **调研来源**：阅文官方作家专区收录的起点责编一手投稿指引（编辑"木棉"等直接建议）。

- **总大纲只写第一卷、后续卷次留"待定"是明确失分项**：编辑"木棉"直接把"大纲写到第一卷，第二卷来个待定"列为让她深受其苦的典型错误写法，属于会主动扣分的操作；这不是"建议改进"，是编辑看到会直接降低签约意愿的写法。
- **全书大纲覆盖是专业度信号**：多位编辑把"大纲 + 简介"视为判断作者专业度的标准之一；大纲越浅、越只覆盖第一卷，越难证明"能稳定连载 `50` 万字以上"的执行力与结构控制力。
- **为什么全书骨架是必须的**：起点编辑签约的本质是在赌一个 `50` 万字以上的长线连载项目；一份只覆盖第一卷的大纲，物理上无法回答"后续卷次是不是真的活的""有没有 `50` 万字以上的供血"这两个核心问题。
- **最优大纲覆盖结构**：
  - 总大纲：覆盖全书卷级 / 单元级骨架，第一卷至少概括卷目标、核心事件节点与供血职责
  - 第 `1` 卷卷纲：独立成文件，负责把首卷承诺、前 `10` 章节拍、第一次有效回报与卷末更贵缺口细化到可执行层
  - 第二卷起：骨架级（卷级目标 + 核心事件节点 + 阶段供血点），不需要章章细写，但**每卷必须有实质内容，严禁留空或写"待定"**
- **评估口径**：若总大纲仅覆盖第一卷、后续卷次为空或"待定"，或第 `1` 卷卷纲缺失 / 失去执行细度，默认按**投稿材料重大缺陷**处理，不得视为“只是字数少一点”；组包时需先补全后续卷次骨架与卷纲，再进入正式组包流程。

### 执行准备

- 默认建议至少 `15` 章存稿；按起点常见 `2000` 字 / 章口径，约等于 `3` 万字级别的连续准备。
- 默认建议可证明日更 4000 字的稳定更新能力。
- 若单章长期明显低于 `1800` 或高于 `2200`，或作者已有长期断更、频繁超 `3` 天停更、完全没有可执行更新计划，应显著下调置信度与建议结论；但这类问题默认归为作者执行风险，不直接上升为作品内容质量高阶缺陷。

### 连载与试水补充理解

- 起点长篇默认要按“持续追读工程”理解，而不是只准备一个强开头。
- 若目标是靠自然连载吃到后续推荐 / 试水机会，通常要把**约 6 万字上下**视为一个现实观察点：到这里还看不见稳定钩子密度与回报节奏，后续放大概率会继续吃力。
- 因此，评估时不只问“首章炸不炸”，还要问：到 3–5 章、10–15 章、约 50 章时，是否都有可预期的还账设计。

## 快审核心看点

- 300 字内是否有抓力。
- 黄金三章是否能完成：立主角抓手、启动第一个挑战 / 对抗、交付一次小高潮或更强悬念升级。
- 前 1000 字是否同时给出一个硬抓手与一个软压力，而不是只给设定说明。
- 前 3–5 章是否至少有一次小回报，前 10–15 章是否至少有一次中回报。
- 前 3 万字是否具备持续追读理由，而不是只有一个首屏噱头。

## 使用方式

- 这份规则更适合作为“先判门槛与快审逻辑”的母锚点。
- 具体题材差异、加减分项与红线，再交给对应题材 Skill 继续细化。

## 平台选择建议（新增 — 当用户尚未选定平台时触发）

以下建议主要面向**零基础新人 / 首次开书**场景，用于辅助选择目标平台。若用户已有明确平台选择，跳过本节。

### 编辑审核制 vs 开放平台

| 维度 | 编辑审核制平台（如起点、七猫等） | 开放平台（如番茄等） |
| --- | --- | --- |
| 签约前置审核 | 有编辑审核门槛，过审才能上架 | 无前置审核，直接发布 |
| 对新人来说 | **编辑的否决是在节省时间**——专业守门人提前判断方向是否正确 | 缺乏方向引导，可能盲目冲刺十几万字后数据惨淡、信心崩溃 |
| 试错成本 | 前期投入低（通常 2-3 万字即见分晓），调整成本低 | 投入高（通常需 10 万字以上才见数据反馈），试错代价大 |
| 推荐策略 | 偏好已学会的编辑审核，重度推荐" | 重数据赛马，作品直接面对读者 |
| 核心逻辑 | **"编辑是最专业的免费教练"** | "读者是最直接的评委" |

### 把编辑视为"最专业的免费教练"——心态框架

编辑拒稿不是否定你的潜力，而是帮你排除错误选项。以下是将编辑反馈转化为成长工具的方法：

| 拒稿类型 | 可能的真实原因 | 应对动作 |
| --- | --- | --- |
| 模板拒（无具体意见） | 题材竞争激烈 / 开篇缺乏类型辨识度 / 开篇节奏偏慢 | 对比同题材新书榜前 3 名的开篇，找出自己的差距 |
| 带具体意见的拒 | 编辑给出了修改方向（如"开篇太慢""设定太绕""主角抓手弱"） | 每条意见都是一个明确的优化方向，按优先级逐条处理 |
| 选题方向被拒 | 该题材在当前平台已过度饱和 / 或与平台当前需求不匹配 | 换一个竞争较小或有差异化空间的细分赛道 |
| 过了初审但终审被拒 | 开局能打但长线供血能力未被说服 / 大纲覆盖不足 | 补全后续卷次大纲骨架，证明有 50 万字以上续航力 |

### 快速自测：三个问题判断平台匹配度

| 问题 | 适合审核制平台 | 适合开放平台 |
| --- | --- | --- |
| 我是否需要一个外部裁判来帮我判断方向？ | 是（我需要专业意见） | 否（我对选题自信，想直接接受读者检验） |
| 我当前的开篇是否已验证过能吸引目标读者？ | 否（还在摸索期，先拿小成本验证方向） | 是（已验证过同类作品的成功路径） |
| 我在早期阶段能承受多大的沉默亏损？ | 小（2-3 万字投入可接受） | 大（我能承受写到 10 万字仍无反馈的心理压力） |

> 三问若指向"审核制平台"占多数，默认建议优先选择有编辑审核门槛的平台。

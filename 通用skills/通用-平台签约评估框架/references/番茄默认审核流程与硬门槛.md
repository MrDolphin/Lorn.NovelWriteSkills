# 番茄默认审核流程与硬门槛

> 适用范围：明确针对番茄小说（免费阅读平台）的签约 / 过稿评估

## 平台特点概述

番茄小说是免费阅读平台，与七猫同属广告变现模式，审核逻辑相似但也有差异：

- **赛马机制**：签约后数据决定推荐量，编辑更看重留存率而非文笔
- **快速验证**：通常 5–10 万字见数据分晓，无法起量的作品很快被放弃
- **短剧联动**：番茄有完善的短剧改编链路，短剧潜力成为签约加分项

## 审核流程

1. **AI 初审**：机器判断基础违规、字数合规、结构规整度
2. **编辑复审**：侧重开篇留存量、题材热度、主角辨识度
3. **数据验证**：签约后推荐位测试追读转化与留存
4. **签约决策**：综合留存曲线 + 题材赛道 + 内容评估

## 核心门槛锚点

### 数据门槛

| 指标 | 参考线 | 说明 |
| --- | --- | --- |
| 首日留存率 | ≥ 45% 为及格线 | 第一章读完比例 |
| 前 7 日留存 | 下降曲线可控而非断崖 | 第 3/7 天留存判断 |
| 前三章流失率 | 每章掉量 < 30% | 章间流失越小越优 |
| 点击→阅读转化 | ≥ 40% 为理想 | 首章点击后的阅读深度 |

### 内容门槛

- 前 300 字必须有冲突起手或强悬念
- 前三章必须展示主角核心身份/能力/困境
- 金手指或核心回报预期必须在第一章 1000 字内露头
- 对话占比建议 ≥ 40%，以对话和动作为主驱动力
- 避免大段世界观铺垫或环境描写

### 更新要求

- 日更 4000 字为基线，日更 6000 字更占优
- 建议存稿 10–20 章
- 前期稳定更新直接影响算法推荐

## 评估时权重调整建议（vs 起点基线）

| 维度 | 番茄权重调整 | 原因 |
| --- | --- | --- |
| 开篇 / 黄金三章 | ↑↑ 显著提升 | 留存决定一切，开篇为首要考察 |
| 情绪密度 | ↑ 提升 | 每 500 字需有情绪触发点 |
| 长篇架构 / 长线供血 | ↓ 降低 | 番茄 100 万字+ 不是硬性要求，需关注中段失温但权重低于起点 |
| 竞对差距与超越路径 | ↓ 降低 | 番茄赛马机制下，留存数据大于竞对对比 |
| 短剧改编适配度 | ↑ 提升 | 番茄的短剧转化链路成熟，IP 衍生潜力加分显著 |
| 文笔精致度 / 叙事技巧 | ↓ 降低 | 优先情绪直给和情节密度 |

## 一票否决特征

- 三章内主角未形成鲜明辨识度
- 连续 2000 字以上无冲突/无钩子
- 开篇以设定介绍为主，冲突起手晚于 500 字
- 缺乏可持续追读的期待点（无明确的"明天想看什么"驱动）

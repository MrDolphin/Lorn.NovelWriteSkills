# 七猫默认审核流程与硬门槛

> 适用范围：明确针对七猫免费小说的签约 / 过稿评估

## 平台特点概述

七猫是免费阅读平台（广告变现模式），签约审核的核心逻辑与起点等付费平台有本质区别：

- **留存率 > 一切**：编辑不看你文笔多好，只看后台留存数据
- **情绪密度 > 文笔质量**：每 300–500 字至少一个情绪刺激点
- **开篇起量 > 长线规划**：前 3 章决定生死，留存数据决定是否继续给量

## 审核流程

1. **数据初审**：先看前 3 章留存数据（首日留存 < 40% 大概率被拒）
2. **内容评估**：开篇抓力、情绪密度、冲突链、角色识别度
3. **IP 衍生潜力**：2024–2025 年起，短剧改编适配度成为新增考核维度
4. **签约决策**：综合留存预测 + 内容质量 + IP 潜力

## 核心门槛锚点

### 数据门槛

| 指标 | 死线 | 说明 |
| --- | --- | --- |
| 首日留存率 | < 40% 大概率被拒 | 第一章打开后滑到底的比例 |
| 前三章读完率 | 每章掉量 > 30% 即危险 | Ch1→Ch2→Ch3 的逐章流失曲线 |
| 情绪密度 | 连续 1000 字无情绪波动 = 水文判定 | 每 300–500 字至少一个情绪刺激点 |
| 代入门槛 | > 30 秒即高跳出风险 | 读者从打开到"知道这故事讲什么"的时间 |

### 内容门槛

- 前 300 字必须有冲突/异常/压力信号
- 前三章必须形成"问题暴露 → 加压 → 首次反击或代价"的闭环
- 主角必须有鲜明记忆点（身份/困境/性格至少一项在首章立住）
- 对话优先于描写：建议前三章对话占比 ≥ 40%

### 更新要求

- 日更 4000 字为基线
- 建议至少 15 章存稿（约 3 万字）
- 月更达标天数影响推荐资源配置

## 评估时权重调整建议（vs 起点基线）

| 维度 | 七猫权重调整 | 原因 |
| --- | --- | --- |
| 题材与平台适配 | ↑ 提升 | 七猫对特定题材（女频虐恋/赘婿/神医/都市）有明确偏好 |
| 开篇 / 黄金三章 | ↑↑ 显著提升 | 留存 > 一切，开篇决定流量分配 |
| 文笔精致度 | ↓ 降低 | 情绪直给优先于文字精雕 |
| 长篇架构 / 分卷供血 | ↓ 降低 | 七猫偏向中短篇爆款，100 万字+非必需 |
| 短剧改编适配度 | ↑↑ 新增高权重 | 成为 2024–2025 年签约新权重 |

## 一票否决特征

- 前三章以内心戏为主，无外部事件推进
- 女主（主角）面对攻击全程不反击/不爆发
- Ch3 结束时读者说不清"明天追更为了看什么"
- 开篇节奏慢热，300 字内无冲突信号

# 晋江默认审核流程与硬门槛

> 适用范围：明确针对晋江文学城的签约 / 过稿评估

## 平台特点概述

晋江是付费阅读平台，与起点同属付费模式但与起点存在显著差异：

- **积分制 + 榜单竞争**：收藏、评论、点击量换算积分，积分决定榜单曝光
- **女频主导**：核心受众为女性读者，评估尺度天然不同
- **编辑审核 + 数据双轨**：既有编辑审核门槛，又有上架后的积分竞争
- **CP 驱动**：CP（人物关系）的站队潜力和讨论度是核心付费抓手

## 审核流程

1. **编辑初审**：看开篇、题材归类、CP 辨识度、文笔成熟度
2. **题材合规**：检查是否触及晋江特殊红线（见下文）
3. **签约决策**：综合题材热度 + 开篇质量 + 作者潜力

## 核心门槛锚点

### 内容门槛

- 首章 1500 字内必须建立主角辨识度与核心处境
- 前三章必须完成 CP 关系的初步定型或对立搭建
- 必须有清晰可辨的题材标签归类（纯爱/言情/百合等）
- 文笔要求高于起点和免费平台——晋江读者对文字质感有明确期待

### 晋江特殊红线（硬性）

- **禁止未成年恋爱细节描写**
- **禁止失衡权力美化**（师生/上下级关系中的权力不对等不可被浪漫化）
- **禁止价值观导向偏差**
- **禁止低俗擦边**
- 敏感题材（现实向写实题材需标注预警标签）

### 更新要求

- 日更 3000 字为基线（晋江每章通常 2000–4000 字）
- 连续断更超过 7 天影响榜单排序
- 积分与更新稳定性正相关

## 评估时权重调整建议（vs 起点基线）

| 维度 | 晋江权重调整 | 原因 |
| --- | --- | --- |
| 人物关系付费价值 | ↑↑ 显著提升 | CP 站队是晋江核心付费驱动 |
| 文笔精致度 | ↑ 提升 | 晋江读者对文笔有较高期待 |
| 题材与平台适配 | ↑ 提升 | 标签归类准确度直接影响曝光 |
| 开篇 / 黄金三章 | → 维持 | 重要但不像付费平台那样决定一切 |
| 长线架构 / 分卷供血 | → 维持 | 晋江长篇（100 万字+）同样常见 |
| 竞对差距与超越路径 | ↑ 提升 | 榜单竞争激烈，差异化是核心竞争力 |

## 一票否决特征

- 前三章无法辨识 CP 或核心关系张力
- 题材标签归类模糊，无法放准确榜单
- 触碰晋江红线（未成年细节/权力美化/低俗擦边）
- 文笔明显低于晋江读者对"可读"的最低期待
- 开篇无情绪抓手（晋江女频尤其看重第一印象的情绪锚点）

# 短剧改编适配度快速评估

> 来源：8份AI开篇评价的交叉共识（2026-06-11）
> 适用范围：七猫/番茄等免费平台签约评估——短剧改编潜力已成为2024-2025新权重
> 补充对象：`平台签约评估维度与权重.md`——定位为新增的IP衍生维度

---

## 一、为什么这是新权重

当前免费平台（番茄、七猫）签约越来越看重IP的短剧改编潜力。原因是：

- 短剧是当前最火的网文变现渠道之一
- 平台编辑不再只看正文数据——也在看"这本书能不能卖版权"
- 一个短剧改编潜力高的项目，即使正文数据一般，平台也愿意签

## 二、短剧改编适配度的核心判据

| 判据 | 高分特征 | 低分特征 |
| --- | --- | --- |
| **开篇虐点密度** | Ch1至少3个以上的情绪炸弹（被背叛/被羞辱/被抛弃级别） | Ch1以内心戏为主，情绪炸弹为0或仅1个 |
| **身份反转** | 女主有隐藏身份/能力，Ch3前已暗示或展示 | 女主是普通人，无特殊背景或能力 |
| **情绪外放度** | 情绪可通过镜头直接呈现——对峙/扇耳光/摔东西/泪流满面/冷笑反击 | 情绪全部内化——"手指在信封上摩挲""可可粉在杯底画圈" |
| **单集钩子** | 每2000字为一集，集均至少1个未闭合悬念 | 章节结尾以情绪留白/氛围收束为主 |
| **人物关系可拍性** | 人物关系有明确阵营和冲突——黑白分明或反转清晰 | 人物关系复杂但缺乏可拍的对峙场景 |
| **对话可拍性** | 对话短、锐、有记忆点——短剧女主的金句多于内心独白 | 对话长、含蓄、需要上下文才能理解 |

## 三、典型"可拍"vs"不可拍"对照

**同一场景：离婚签字**

| 版本 | 短剧适配度 | 为什么 |
| --- | --- | --- |
| "她翻到附件页。手指停了。三行字。她把笔放下。信封在手里——三页纸的厚度。三年的重量。" | ❌ 不可拍 | 镜头下=演员在发呆。没有动作、没有对话、没有表情变化——短剧导演会说"这拍不了" |
| "她翻到附件页——'生活费用需全额返还？'她抬头。'你让我还这三年花的每一分钱？'他还在看手机。她笑了——然后端起他桌上的咖啡泼在协议上。'签字。'" | ✅ 可拍 | 有对话、有动作、有表情变化（笑→泼咖啡）、有冲突升级（他看手机这个细节被回收为激怒她的扳机） |

## 四、短剧改编加分特征清单

| 加分特征 | 我方自查（可拍=✅ 不可拍=❌） |
| --- | --- |
| Ch1有至少1处"观众会停下来截屏"的金句 | |
| Ch1女主有至少1次当众反击或情绪爆发 | |
| Ch1至少有2个不同阵营的人物同框产生冲突 | |

## 六、使用方式

- 在七猫/番茄平台的签约评估中，短剧改编适配度作为加分/减分维度
- 不替代通用评估维度（人物、设定、总纲等），只作为IP衍生维度的补充
- 如果目标平台是晋江/起点女频（付费阅读），短剧维度权重降低——但仍有参考价值

# 内容简介结构模板与压缩规则

## 标准结构

1. 主角是谁，当前处境如何。
2. 什么反常事件 / 关键选择把他拖进局里。
3. 眼前冲突是什么。
4. 更大的承诺是什么：真相、升级、代价、关系撕裂中的哪几项。

## 任务类型

1. 系列全书简介
2. 分部 / 分卷简介
3. 章节简介

## 输入最小集

- 标题
- 当前目标投放名（不分部小说 = 小说目标投放名；分部小说 = 对应部目标投放名）
- 关键人物
- 一句话差异化卖点
- 明线冲突
- 暗线冲突
- 情感核心
- 关键象征意象

## 名称口径规则（强制）

- 本 Skill 中的“当前目标投放名”指当前交付对象实际对外使用的名称，而不是任意上下文里出现的总书名、系列母名或内部暂定名。
- 不分部小说：简介统一使用小说的目标投放名。
- 分部小说：简介统一使用对应部的目标投放名。
- 若同一作品同时存在总书名、分部名、平台投放名多个口径，优先取本次交付对象实际投放所用名称；不得把总书名误当成分部简介标题或正文中的作品名口径。

## 版本输出最低要求

- 至少 1 个主版简介
- 若涉及平台或投放差异，至少给：长版 / 短版 / 平台重点版
- 每个版本都必须明确自己的主钩子

## 一版一主钩规则

- 标准长版：主钩 1 个 + 辅钩最多 2 个
- 平台短版：主钩 1 个 + 辅钩最多 1 个
- 引流 / 超短版：只允许 1 个主钩

若读完后说不出“这一版最先抓我的是什么”，则判定失败。

## 压缩提醒

- 第一段优先放“角色 + 处境 + 反常”。
- 第二段优先放“当前冲突 + 更大承诺”。
- 句子要能独立成立，避免一长串逗号拖死节奏。

## 失败信号补充

- 一段里硬塞四五个卖点，像大纲压缩块
- 首句像另一个更长的书名，而不像简介开头
- 读完只记住设定很多，却说不出人物当下在怕什么

## 失败信号

- 简介看完还不知道主角在跟什么对抗。
- 只有设定酷点，没有故事承诺。
- 语言过空，像所有书都能套。

## 简介 30 秒归类测试（新增 — 扫榜与成稿阶段通用）

写完或拆解一个简介后，用以下三个问题判断其有效性：

| 问题 | 读者应当能在 30 秒内回答 | 不合格状态 |
| --- | --- | --- |
| 这是什么书？（题材归类） | 能快速判断属于什么类型、什么赛道 | 读完后仍无法将简介与任何已知题材归类对应 |
| 主角正卡在什么困境里？（当下压力） | 能说出主角此刻在为什么事头疼、在怕什么 | 只记得设定名称、世界观名词，说不出人物处境 |
| 继续看下去能得到什么？（持续承诺） | 能预感到继续阅读能获得什么回报（爽点/悬念/关系） | 读完不知道该期待什么，只有"似乎很厉害"的空泛印象 |

### 三个问中任一回答不了 → 简介视为不合格

### 扫榜时如何拆解竞品简介（供竞对分析场景使用）

1. **归类效率**：它在几秒内让你知道了"这是什么书"？第几句完成的归类？
2. **压力显影**：它在第几句交代了主角的当下困境？困境是具体的（"欠了一百万"）还是抽象的（"命运多舛"）？
3. **承诺强度**：读完简介后，你有没有产生"点开看看"的冲动？如果有，是哪个句子触发的？
4. **信息密度**：如果删掉所有世界观名词和专有名词，简介还剩下几个有效句子？

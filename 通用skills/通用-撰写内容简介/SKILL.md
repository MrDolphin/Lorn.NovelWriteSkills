## 风格/蓝本/写作研究模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，撰写或审计内容简介前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其作为平台简介口径、卖点压缩和禁忌基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其作为简介语言气质的轻约束，不得压过平台清晰度
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将其作为核心结构承诺、主线问题和持续追读承诺参照
5. 本 Skill 只消费与简介撰写相关的字段；若作者风格与平台简介清晰度冲突，平台简介清晰度优先
6. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断

本 Skill 默认消费字段：

- 写作研究模板：平台简介口径、标签热词、卖点压缩、禁忌类约束
- 作者风格模板：整体文风、句长基线、禁忌清单、语言气质
- 作品蓝本模板：整体叙事策略、章首承诺、核心冲突、钩子类型

## 常见触发词 / 用户说法速查

- 帮我写内容简介
- 这本书简介太空了
- 改一下平台简介
- 改成纵横中文网口径的简介
- 给我一个能上架的简介
- 这简介像设定说明不是故事

## 何时使用

- 新书上架前撰写简介。
- 已有简介太像设定说明、太空、太散，需要重写。
- 针对不同平台生成不同长度、不同口气的简介版本。

## 默认执行顺序

1. 先确认本次简介使用的名称口径：不分部小说使用小说的目标投放名，分部小说使用对应部的目标投放名；再抓主卖点、主角当前困境与不可回头的入局点。
2. 再写核心冲突与持续追读承诺。
3. 再按平台长度收束语言、增强钩子与可传播句。
4. 再按独立文件规则落盘并处理版本策略。
5. 最后检查有没有把故事说完，或空到像海报标语。

## 默认模型温度参考（新增）

创作简介需要适度创造性与语言变化，审计简介则需要稳定一致的判断力。

| 阶段 | 推荐温度 | 说明 |
|---|---|---|
| 撰写 / 重写简介 | 0.55 | 需要创造性但不宜跑偏 |
| 审计现有简介 | 0.3 | 低创造性，保持判断稳定 |

## 简介共性提醒（新增）

- 简介默认优先交付情境与情绪共识，再补设定名词；若读者先看见一堆专有名词却没看见人物困境，视为失败信号。
- 主卖点最好压成“谁正在失去什么、必须做什么、为什么会越陷越深”这一条主钩，而不是平均陈列多个卖点。
- 若作品的持续吸引力建立在成长线、关系线或身份翻转上，简介里至少要让其中一条可被快速感知。
- 前 `1–2` 句默认还要承担 `30 秒归类` 任务：让编辑和读者能迅速判断这是什么书、主角正卡在哪个当下困局、继续看下去能得到什么。
- 若简介读完仍只能感知世界观名词，却感知不到人物处境、当前压力与持续承诺，默认按“设定说明化”处理并回炉。

## 默认输出口径

- 默认输出至少 1 个可直接使用的主版简介。
- 多平台场景下，默认补充长度差异或平台差异说明。
- 若简介标题、正文说明、版本标识或落盘文件名需要出现作品名，统一使用本次交付对象对应的目标投放名。

## 落盘目录层级（强制）

- 本 Skill 的默认工作目录固定为 `小说简介/`。
- 系列全书简介、分部简介、分卷简介统一直接落在 `小说简介/` 根目录。
- 章节简介按小说结构分层：若作品有分部，统一落在 `小说简介/第X部/第Y卷/`；若作品无分部，统一落在 `小说简介/第X卷/`。
- 文件名继续服从日期与版本号规则，不得把章节简介散落到 `章节目录/简介/` 一类旁路目录。

## 最低交付

- 至少 1 个主版简介。
- 若涉及多平台，至少说明长版 / 中版 / 短版的适配差异。
- 前 1–2 句就能让编辑和读者快速感知主卖点，而不是读完整段还只看到设定名词。
- 必须让读者知道：谁、陷入什么局、为什么还会越陷越深。

## 硬规则

- 禁止只有世界观名词堆砌，没有情境与冲突。
- 禁止把全部反转提前剧透完。
- 禁止只说“命运齿轮开始转动”这类空口号。
- 禁止简介承诺一个正文里根本接不住的假卖点。
- 不分部小说简介统一使用小说的目标投放名；分部小说简介统一使用对应部的目标投放名，不得继续沿用总书名顶替分部简介。
- 除非用户明确要求只草拟，不得只在聊天里给简介而不落文件。

## 与其他 Skill / Prompt 的边界

- 本 Skill 负责简介文本本体。
- 不负责书名设计、书评撰写或投稿材料整体组包。

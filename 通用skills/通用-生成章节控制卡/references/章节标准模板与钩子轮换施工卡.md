# 章节标准模板与钩子轮换施工卡

> 来源口径：`网文技法.md`（标准章节模板、钩子轮换）。

## 标准章节模板（施工视角）

```text
前200字：钩子（冲突/悬念/异常）
中段A：主线或支线推进
中段B：微爽点（小反转/信息差/小成功）
中段C：持续加压或误判升级
后200字：留钩（未闭合问题/新变量）
```

## 四拍落点（控制卡必填）

- 钩子：读者为何继续读。
- 蓄力：冲突如何被放大。
- 回报：本章值回票价的具体收益。
- 留钩：下章接棒对象与驱动问题。

## 施工层级速判（新增）

- `上游对齐层`：本章承接哪个故事面、位于本卷哪一段、章级身份与主抓手是否清楚。
- `章内四拍层`：钩子、蓄力、回报、留钩是否真的分配到本章，而不是只有一句抽象概括。
- `跨章接棒层`：本章留钩是否可由下一章第一场直接承接，钩子类型是否轮换得当。

默认顺序：先判 `上游对齐层`，再判 `章内四拍层`，最后判 `跨章接棒层`；不要先写钩子类型，再发现本章根本没回报。

## 钩子轮换规则

避免连续 3 章使用同类钩子。推荐轮换：

```text
悬念钩 → 冲突钩 → 异常钩 → 动作钩 → 对话钩 → 悬念钩...
```

## 轮换审计清单

- 本章钩子类型是否与前两章重复。
- 本章钩子是否与章节职责匹配（信息章/对抗章/转折章）。
- 本章留钩是否可由下一章第一场直接承接。

## 失误警报

- 只有钩子没有回报：读者疲劳。
- 只有回报没有留钩：追读断裂。
- 章章同一钩子类型：节奏麻木。

## 最低可执行输出（控制卡内）

```text
本章钩子类型：____
本章中段回报：____
本章留钩对象：____
下章接棒问题：____
```

## 四拍最小工件（新增）

```markdown
【本章主抓手】
【四拍最重项】钩子 / 蓄力 / 回报 / 留钩
【本章中段回报载体】
【本章留钩对象】
【下一章第一场如何接】
```

## Green / Yellow / Red 就绪门禁（新增）

- `Green`：上游对齐、章内四拍、跨章接棒三层都清楚，可直接进入控制卡正文。
- `Yellow`：四拍大致成立，但某一层仍偏虚，例如回报可感度不够或下章接棒问题偏泛。
- `Red`：没有明确中段回报、留钩对象说不清、下一章第一场无法接、或本章钩子与章级职责不匹配。

## 填空题写作法：控制卡的第二种生成路径（新增——吸收自知乎专栏「中国网络文学研究」#6）

除了标准章节模板，控制卡还可以用"填空题"的方式组织。**填空题写作法的核心理念**：写小说不是在黑暗里瞎摸，而是在已搭好的框架里填入内容——大纲就是题面，套路库就是参考答案。

### 填空题式大纲格式

与标准"钩子-蓄力-回报-留钩"模板互补，填空题式大纲更强调"情绪目标先行"。每章填空格式：

```markdown
第X章：章名
【情绪目标】
【情节空位1】______（提示：______）
【情节空位2】______（提示：______）
【情节空位3】______（提示：______）
【爽点空位】______（需要设计）
【章节结尾】______（悬念/缺口/新代价）
```

### 三种空位类型与填法

| 空位类型 | 核心逻辑 | 填法 | 示例 |
| --- | --- | --- | --- |
| 情节推进型 | 因果逻辑 | 确定终点→倒推起点→设计步骤 | "主角如何获得第一个金手指" → 先确认获得什么，再倒推起点条件和中间步骤 |
| 情绪体验型 | 调动感官 | 用细节而非形容词 | 不写"他很生气"，写"他的手指深深掐进掌心" |
| 悬念钩子型 | 打断在最关键处 | 在最紧张/好奇/意外的时刻断章 | 矛盾即将揭晓/战斗即将分出胜负时咔嚓一刀 |

### 填空题模板库示例

从经典桥段中拆解为填空题模板，存入套路库供写作时调用：

**退婚流模板**：

```text
主角在公开场合被反派（身份：______）当众羞辱
羞辱的原因是（原因：______）
主角当下没有反抗，而是说了一句（台词：______）
若干章后，主角带着（成果：______）归来，让反派（反应：______）
```

### 与现有"四拍"模板的关系

填空题法不是替代四拍法，而是**补充视角**：四拍法从"结构上需要什么"出发（钩子/回报/留钩），填空题法从"这一章要让读者感受到什么"出发（情绪目标先行）。实际施工时建议两表并用：

```markdown
本章四拍落点：钩子___ 蓄力___ 回报___ 留钩___
本章情绪目标：让读者感到___
本章空位填法：情节推进___ + 情绪体验___（如有） + 悬念钩子___ 
```

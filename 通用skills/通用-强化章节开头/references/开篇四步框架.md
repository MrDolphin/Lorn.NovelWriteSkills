# 开篇四步框架

> **来源**：七猫作家交流区精华帖 #26099，编辑：纵横年糕。核心结构公式适用于剧情向开篇的快速搭建。

## 核心公式：目标 → 行动 → 阻碍 → 反转/成功

| 步骤 | 功能 | 可扩展性 |
| --- | --- | --- |
| **激发事件** (建立目标) | 触发主角核心欲望的事件（如退婚、灭门、重生觉醒）。不一定需要场景呈现，有时叙述更高效 | 一件激发事件可以驱动全书核心目标 |
| **展开行动** (设立子目标) | 主角为达成大目标而分解为多个小目标。**这是最能写长的阶段**——可继续用"目标→行动→阻碍→反转→成功"做三级嵌套 | 斗破的退婚结构直接支撑了 334 章 |
| **阻碍** (制造波动) | 主角不可能一帆风顺。阻碍的角度需多样化（上房抽梯、关键资源被截、关系背叛等） | 阻碍的质量决定故事的起伏幅度 |
| **反转与成功** | 用前面埋下的伏笔逆风翻盘。不仅要有剧情反转，还可搭配人设反转 | 阻力越大，反转的爽感越强 |

## 三级嵌套扩展

四步框架不仅用于全书骨架，也可嵌套使用。每个小目标阶段自身可套用"目标→行动→阻碍→反转→成功"三级结构。

**示例**：斗破苍穹

```text
全书级：退婚(激发) → 修炼变强(行动) → 三年之约(阻碍) → 云岚宗击败纳兰嫣然(反转)
  ↓
卷级：拜师药老(激发) → 炼药修炼(行动) → 魔兽山脉试炼(阻碍) → 吞异火成功(反转)
  ↓
 章级：发现魔兽(激发) → 准备战斗(行动) → 魔兽实力超出预期(阻碍) → 用新习得的技能险胜(反转)
```

目标越清晰、层级越多，读者的期待感越强。一个清晰的"全书级目标"可以支撑整本书的期待感。

## 与现有开篇框架的关系

本文件是对 `通用-强化章节开头/SKILL.md` 的补充参考，不替代该 SKILL 中的"三层漏斗模型""章首抓力""切片开头"等理念层内容。

- **三层漏斗模型**回答"读者凭什么点进来"——聚焦书名/简介/开篇三段
- **开篇四步框架**回答"开篇怎么写"——聚焦前几章的情节结构
- **切片开头/三句法**回答"首屏怎么写"——聚焦前 300 字的呈现方式

三者互补，不是替代关系。

## 适用场景

| 场景 | 使用建议 |
| --- | --- |
| 需要快速搭建开篇剧情骨架 | 直接用四步公式，先定目标→再拆行动→再设计阻碍→再安排反转 |
| 开篇节奏太慢 | 检查"激发事件"是否太晚出现——前 300 字内应有明确的目标信号 |
| 开篇太平缺乏起伏 | 检查"阻碍"设计是否力度不够——阻碍越让读者绝望，反转越爽 |
| 开篇剧情太单薄不够写 | 使用三级嵌套扩展——每个子目标都可独立套用四步框架 |

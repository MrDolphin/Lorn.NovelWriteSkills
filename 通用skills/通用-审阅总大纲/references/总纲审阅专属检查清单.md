# 总纲审阅专属检查清单

## 一、对象与范围

- 是否明确本次审的是总纲包，而不是单一主文件
- 是否明确 `小说总大纲.md` 承载主线故事、`故事面/` 承载以支线为主的完整故事文件组
- 是否检查主线与支线的交织、联系与相互推动，而不是误判为重复维护
- 只有在职责重叠且口径冲突 / 无新增职责时，才判为冗余或总纲层不一致
- 若范围受限，是否显式写明未覆盖对象

## 二、四阶段机制递进

- 试水期是否有异常启动与第一抓手
- 扩盘期是否通过多个单元持续供血
- 收束期是否具象化对抗与机制升级
- 终局期是否提前布设闭环条件

## 三、单元案矩阵供血能力

- 每个单元案是否至少推进一块主线拼图
- 是否存在漂亮但脱主线的冗余单元案
- 是否存在主线只在后期突然推进的断供风险

## 四、总纲级连贯性

- `M0 / X / C` 是否清楚，不互相篡位；主线总纲与故事面是否各司其职
- 是否有稳定的系列锚点
- 中段是否存在结构塌陷风险

## 五、最小补丁思路

- 补一块主线拼图
- 补一个阶段闭环
- 补一个系列锚点
- 补一条代价链
- 补一个开篇承诺块

## 六、网文长线与签约口径

- 是否存在一句话记忆点，能让编辑快速记住这套书为什么值得签
- 首卷承诺是否清楚：前 3/5 章抓手、首卷阶段胜利、第一轮主线拼图是否已写明
- 平台主口径是否明确：起点 / 番茄 / 豆瓣 / 盐选 / 海外 等主次关系是否清楚
- 开篇承诺与终局兑现是否同向，是否存在中后段换题风险

## 七、长篇耐力与 AI 总纲病预警

- 主卖点是否出现连续 2 卷以上基本失踪的危险窗口
- 主线 / 配菜比例是否失衡，是否存在“案很多、主线不动”的断供风险
- 冷线、旧债、人物线是否标明回归窗口，而不是长期蒸发
- 是否出现“概念很多、动作很空、人物像功能按钮”的 AI 式总纲病

## 八、规划归档与模板组合镜像

- 是否写明主模板 / 辅助模板 / 模板组合声明，而不是只说“参考了某模板”
- 是否存在章节规划表、TODO 状态、章节摘要入口与节奏地图
- 节奏地图是否显式检查连续 3 章以上重章的疲劳风险
- 是否存在活跃悬念 / 伏笔追踪、决策日志、更新日志或最小进度快照入口
- 主题是否从人物经历、性格底色与选择后果中自然长出，而不是先立主题口号再逼人物表演

## 九、问题来源层与战略入库判定

- 问题是否区分为：总纲结构层 / 卷群分配层 / 执行接口层
- 是否给出 Green / Yellow / Red 战略入库判定，而不是只有“能用 / 不能用”的模糊结论
- 是否指出哪一层最该优先回写，以及为什么这一步能最快抬升签约 / 追读潜力

## 十、商业节奏与情绪刺激密度审阅（新增）

> 对应设计Skill新增的"网文商业节奏与追读工程设计"标准。总纲层的情绪设计缺陷是"节奏太慢、太闷"的根源，必须在总纲层拦截。

### 10.1 情绪刺激密度设计

- 总纲是否规划了全书层面的情绪刺激点分布（小刺激点≥1个/章、中刺激点≥1个/3-5章、大刺激点≥1个/卷）？
- 是否出现连续3章以上只有情节推进、无情绪刺激点的"平路循环"？若有，是否在设计层有合理解释（如蓄力期但在蓄力期内有小刺激嵌入）？
- 女频/情感密集型题材，卷级章清单的情绪刺激点是否达到每500-800字至少1个虐点/爽点？若未达到，判为商业节奏风险。

### 10.2 爽点/虐点三阶布局

- 总纲是否有独立的"爽点/虐点事件表"而非仅有情节线？
- 每卷是否标注了至少3-5个核心情绪刺激事件（含类型、章号、预期读者反应）？
- 爽:虐比例是否按阶段调整（开篇/中段/终局各有不同）？
- 卷末是否落在情绪高位（要么爽点最大释放，要么虐点最大升级）？若卷末落在情绪低平处，判为卷尾设计偏弱。
- 女频赛道的虐点设计是否遵循"被辜负"原则而非"被欺负"？是否存在纯虐无爽的劝退风险？

### 10.3 前N章留存工程

- 前3章是否形成"冲突起手→应对失败→更深层冲突显露"的递进结构？
- 前300字内是否抛出了明确冲突/异常/压力信号？
- 前1000字内是否亮出金手指或给出回报预期？
- 前三章对话占比设计是否≥40%（女频≥50%）？若以大段描写/心理开篇而无对话，判为留存工程缺陷。
- 第1章章末是否有明确续读驱动钩子（非总结/抒情/留白）？

### 10.4 更新可复制性

- 总纲是否评估了各卷的"可写性"——高强度情绪场景（易写的爽点/冲突/对话章）占比是否≥40%？
- 是否预设了可复用的章节节奏模板（如"起承转爽"或"过山车"模板），而非每章都要重新构思结构？
- 若全卷主要推进方式是大段环境+心理描写（难写、不可持续），是否已标注更新执行风险？

### 10.5 平台节奏适配

- 若目标平台为七猫，前三章情绪刺激密度是否达到"每500字一个虐点/爽点"级别？
- 若目标平台为番茄，前10章是否已经将最强卖点全部打出（而非藏着掖着）？
- 若目标平台为起点，中段是否设计了可讨论的情节点（本章说争议点/站队点）？
- 若未考虑平台差异，判为平台适配性风险。

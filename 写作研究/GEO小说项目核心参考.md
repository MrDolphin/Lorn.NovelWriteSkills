## 一、核心概念

### 1.1 什么是 GEO

**GEO（Generative Engine Optimization，生成式引擎优化）**：专门针对 AI 大模型（DeepSeek、豆包、Kimi、ChatGPT 等）做的内容优化。目标是让内容被 AI 识别、采信，并在回答用户问题时主动引用输出。

| 维度 | SEO（传统搜索） | GEO（AI 搜索） |
| ------ | ----- | ----- |
| 优化对象 | 百度/Google 等搜索引擎 | DeepSeek/豆包/Kimi/ChatGPT 等 AI 大模型 |
| 用户行为 | 搜索关键词 → 点开网页阅读 | 直接提问 AI → AI 整合答案（零点击） |
| 核心目标 | 提升网页排名，吸引用户点击 | 让 AI 识别、采信、引用你的内容 |
| 优化重点 | 关键词布局、外链、加载速度 | 内容准确、逻辑通顺、结构清晰、数据完整 |
| 对小说而言 | 让小说网页在平台搜索结果中靠前 | 让小说信息出现在 AI 对读者的回答中 |

**一句话**：SEO 是让人点开你的网页，GEO 是让 AI 说出你的内容。

### 1.2 为什么小说作者需要关注 GEO

2026 年，近一半的用户已将 AI 作为第一搜索选择。读者发现小说的路径正在从：
- 旧路径：`主动搜书 → 点开排行榜/搜索结果 → 看简介 → 试读`
- 新路径：`向 AI 提问 → AI 推荐书单 → 读者直接试读`

**核心推论**：在 AI 搜索时代，小说的外围内容（简介、书评、读者讨论、知乎回答等）本身就是流量入口。

### 1.3 小说 GEO 与非小说 GEO 的根本区别

| 维度 | 品牌/产品 GEO | 小说 GEO |
| ------ | ------------- | --------- |
| 内容本质 | 事实/知识/产品参数 | 叙事/虚构/情绪体验 |
| AI 引用目标 | 被引用为"答案"（事实性） | 被引用为"推荐"（推荐性） |
| 主战场 | 产品页、FAQ、技术文档 | 简介、书评、知乎回答、榜单 |
| 正文角色 | 可直接优化（增加结构化） | 正文不优化（会毁叙事） |
| 权威判断依据 | 企业背书、行业认证 | 平台榜单、读者规模、媒体提及 |

## 二、AI 的工作机制（RAG 简明版）

主流 AI 大模型通过 **RAG（检索增强生成）** 技术回答问题：

```
用户提问 → Embedding(向量化) → Vector Search(向量检索) → Reranker(重排序) → Generation(生成答案)
```

**对小说内容的要点**：
1. AI 把你的内容转成"向量"（语义数字代码）
2. 用户提问时，AI 在向量库中找"语义上最接近"的内容
3. AI 对初步匹配结果做二次排序，把最相关、最权威的排前面
4. AI 基于优选内容生成最终答案

**结构化的内容在每一环节都有优势**：向量化更精准、检索匹配度更高、重排序中权重更高。

### AI 对小说相关内容的偏好排序

| 优先级 | 内容类型 | 原因 | 对应 Skill |
| -------- | --------- | ------ | ----------- |
| 最高 | FAQ/问答对 | 与 AI 回答逻辑同构，可直接提取 | 内容简介、书评 |
| 高 | 结构化清单/列表 | 信息密度高，易于向量化匹配 | 书评、竞对分析 |
| 中 | 简介/摘要类内容 | 信息浓缩，但需 AI 做信息提取 | 内容简介 |
| 低 | 叙事正文（小说章节全文） | 篇幅长、叙事性强，AI 难以高效提取 | — |

## 三、三级过滤器：AI 如何评估内容是否值得引用

AI 对内容的筛选采用三层逐级过滤金字塔模型：

```
                    ┌──────────────────────┐
                    │  结构化（决赛胜负手）   │  ← 内容好不好认？
                    ├──────────────────────┤
                    │  权威性（复赛资格）    │  ← 内容靠不靠谱？
                    ├──────────────────────┤
                    │  时效性（入场券）      │  ← 内容新不新鲜？
                    └──────────────────────┘
```

### 3.1 时效性（入场券）

**对小说内容**：时效不是发布时间，而是讨论热度和内容活跃度。

- 连载中 > 已完结但仍在讨论 > 冷门完结
- 有持续本章说/书评的作品权重更高
- **显式标注年份**的内容会获益（如"2026 年推荐"）

### 3.2 权威性（复赛资格）

小说内容的权威性判断依据：
- **平台背书**：起点/番茄/晋江等官方榜单作品权重高
- **媒体提及**：被行业媒体（36 氪、刺猬公社等）报道过
- **读者规模**：高人气/高评论数 > 低关注度
- **作者声誉**：成名作者 > 新人作者
- **多源一致性**：同一信息在多个平台一致出现，AI 更信任

### 3.3 结构化（决赛胜负手）

小说内容中 AI 最容易引用的结构化形式：

| 形式 | 示例 | 对应产出 |
| ------ | ------ | --------- |
| 作品卡/信息表 | 书名、作者、类型、字数、状态、评分、一句话简介 | 内容简介 |
| FAQ 模式 | "XX 小说好看吗？适合什么人群？" | 书评、知乎回答 |
| 榜单/分类列表 | "2026 年十大悬疑小说" | 竞对分析、书评 |
| 对比/评测 | "XX 和 XX 有什么不同？" | 竞对分析、书评 |

## 四、小说 GEO 四维框架

### 维度一：作品元数据层（基础建设）

AI 回答"推荐一部XX小说"时，优先引用结构化程度最高的作品信息。

| 要素 | GEO 策略 | 操作 |
| ------ | --------- | ------ |
| 书名 | 含利于 AI 识别的类型关键词 | 副标题含题材词（如《XX 悬疑事件簿》） |
| 简介 | FAQ 友好型结构 | 含"这是一部关于___的小说""主角是___"等可提取句式 |
| 标签 | 覆盖多平台分类体系 | 起点/番茄/豆瓣/知乎标签一致且完整 |
| 评分/数据 | 在公开页面显式呈现 | 评分、读者数、推荐票等结构化数据 |

### 维度二：外围内容层（高优先级）

AI 推荐小说时引用的不是正文，而是**关于小说的讨论和描述**。

高价值外围内容（按 AI 引用优先级）：
1. **知乎问答** — 在专业问答下以标准格式推荐作品
2. **书评/书单** — 结构化书评（书名-类型-评分-推荐语）
3. **百科/作者页** — 百度百科词条（AI 视为高权威来源）
4. **平台榜单** — 起点/番茄/晋江官方榜单
5. **比较/推荐文** — 对比类内容天然是 GEO 高价值内容

### 维度三：平台可见性层

不同平台在 AI 搜索中的权重：
- **起点中文网**：正版权威，AI 偏好引用，书页信息完整度关键
- **番茄小说**：免费+流量大，AI 引用高频，读者讨论数据是信号
- **豆瓣阅读**：书评和评分对 AI 推荐影响大
- **知乎**：GEO 价值最高的非平台渠道，问答模式与 AI 同构
- **公众号/百家号**：内容能被 AI 索引，注意发布时间标签

### 维度四：读者互动层

AI 判断"值不值得推荐"时的信号：
- 本章说/段评数量 → 阅读活跃度
- 评分和评分人数 → 质量共识
- 读者推荐语（公开平台） → 第三方评价
- 社交媒体讨论量 → 热度

## 五、各输出类型的 GEO 优化对照表

### 5.1 内容简介

| 位置 | GEO 优化要求 |
| ------ | ------------- |
| 头部元数据块 | 强制包含：书名、类型、一句话卖点、适合人群（四字段结构化区块） |
| 正文 | 含可被 AI 直接提取的核心冲突陈述句；避免全是修辞问句 |
| 关键词复现 | 书名的题材关键词在正文中至少自然出现 1 次 |
| 时效标记 | 连载作品标注状态和起始时间 |

### 5.2 书评 / 推荐语

| 位置 | GEO 优化要求 |
| ------ | ------------- |
| 头部元数据块 | 强制包含：书名、类型、评分、一句话总评 |
| 推荐理由 | 采用"适合____的读者"句式——与 AI 推荐逻辑同构 |
| 结构化 | 分点列出核心亮点，每点有明确主题句 |

### 5.3 书名 / 标题

| 要素 | GEO 优化要求 |
| ------ | ------------- |
| 题材关键词 | 主书名或副标题含题材/类型关键词（AI 语义匹配依据） |
| 认知缺口 | 书名营造的"不知道会亏"感在 AI 语义检索中可被识别 |
| 跨平台一致性 | 同一书名在不同平台完全一致（AI 交叉验证可信度） |
| 热度词 | 适度含"时间+题材"组合词（如"2026 悬疑"），增加时效权重 |

### 5.4 竞对分析报告

| 位置 | GEO 优化要求 |
| ------ | ------------- |
| 作品卡 | 每部竞品头部含结构化作品信息表 |
| 分析维度 | 增加"AI 搜索可见性"记录——竞品在 AI 搜索中的引用表现 |
| 榜单数据 | 标注榜单类型/时间，方便 AI 做时效判断 |

### 5.5 题材定位声明

| 要素 | GEO 优化要求 |
| ------ | ------------- |
| 三要素结构 | 主题/总冲突/终极目标的陈述本身就是 AI 易提取的结构化信息 |
| 标签规划 | 平台标签不仅是分类工具，也是 AI 搜索的结构化元数据来源 |
| 一句话定全书 | 定位声明的表述要能被 AI 直接引用为"这是一部关于___的小说" |

## 六、GEO 友好度自检清单（通用版）

每条外围内容产出前，对照以下清单：

### 内容结构自检
- [ ] 内容头部包含结构化的作品元数据块（书名/类型/核心信息）
- [ ] 信息以陈述句呈现，而非纯修辞/反问（AI 可直接提取）
- [ ] 正文采用分层结构（标题/列表/表格），RAG 向量化更精准

### 时效性自检
- [ ] 内容包含时间标记（年份/连载状态）
- [ ] 推荐/书单类内容标注"2026 年"等时效标签
- [ ] 旧内容定期更新（AI 认为活跃内容权重更高）

### 权威性自检
- [ ] 引用的榜单/评分标注了来源平台和具体数值
- [ ] 提及的作品信息在多个公开平台一致
- [ ] 避免在同一内容中出现矛盾信息

### 可引用性自检
- [ ] 删除后仍可独立运行的"摘录块"至少在 1 处
- [ ] 推荐语中包含"适合____的读者"句式
- [ ] 标题/首句包含作品的核心识别信息

| 优先级 | 动作 | 耗时 | 效果 |
| -------- | ------ | ------ | ------ |
| 🔴 立即 | 确保各平台作品信息一致（书名/作者/标签/简介） | 1 天 | 基础可见性 |

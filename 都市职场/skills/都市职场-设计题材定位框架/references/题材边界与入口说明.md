# 题材边界与入口说明（都市职场）

> 格式：题材禁忌 → 专项规则 → 语言铁律 → 叙事指导 → 节奏参考
> 此为标准题材规则五节模板，所有题材的边界与入口说明均按此结构组织。

## 题材禁忌

- 商业奇迹无铺垫：没有过程积累的暴富、晋升或翻盘，破坏现实感
- 反派降智配合主角：体制/对手的愚蠢不能成为主角获胜的理由
- 法律与商业规则被架空：金融操作、公司运营需有基本可信度
- 主角无摩擦：没有制度限制、资源短缺、人情债困扰的职场是悬浮的

## 专项规则

### 这条题材线默认要回答什么

- 都市现实入口在哪里。
- 异常最先撕裂了哪一种熟悉秩序。
- 主角靠什么职业 / 身份 / 方法论入局。
- 利益链条、交易记录、人脉关系或制度漏洞怎样持续制造冲突。
- 长线博弈为什么能撑长篇，而不是一事一结。

### 最低闭环条件

- 权力来自人脉、资本、信息和制度位置，不来自武力。
- 冲突解决靠谈判、交易、威慑、法律手段和利益交换。
- 钱权必须落地——通过物、势、地位变化和小人物反应兑现爽点。
- 主角在前5章内至少出现一次判断失误或信息偏差，不是全知全能。

## 语言铁律

- **人物内心独白必须口语化**：禁止商业分析/博弈论术语渗入叙事
  - ✗"他迅速分析了当前的债务状况" → ✓"他把那叠皱巴巴的白条翻了三遍"
- **法律/商业术语必须匹配设定年代的真实语感**：2003年的借条不会写"逾期处置授权"
- **上帝视角分析段落必须改为动作和对话体现**
- **时代锚点**：嵌入1-2个具体物价、新闻事件或流行用语增强年代沉浸感

## 叙事指导

- 都市职场核心驱动力是"职业成长与现实对抗"——读者追读的动力是"看主角如何在博弈中胜出"
- 人物关系网是核心资产，每次社交互动都应有利益计算
- 主角需要保留非功能性时刻：思考、犹豫、社交润滑
- 用场面、气味、动作、交易、压迫感切入，不要历史课件式开头
- 时代厚重感、人情债与制度摩擦是都市文的灵魂

## 节奏参考

- 每2-3章一个小回报：商业收益、人脉拓展、对手受挫、信息优势
- 主线：每卷一个大台阶（晋升/创业/击败重要对手），副线持续施压
- 职业成长线：技能→项目→职位→行业影响力的递进，不要跳级
- 博弈节奏：布局→试探→交锋→收网→余波，每轮博弈要有回合感

# 都市题材疲劳词表

> 来源：吸收自 InkOS `urban.md` 语言铁律与 AI 高频词研究
> 适用范围：都市职场、都市生活题材
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 迅速分析 | AI 高发组合，违反都市口语化铁律 | 用具体动作替代（把合同翻到第三页/手指在数字上点了一遍） |
| 信息差 | 已被过度使用的网文术语 | 写具体的信息不对称（他不知道供货商已经换了人） |
| 商业帝国 | 万能夸张词 | 写具体规模（三家分公司/月流水三千万） |
| 雷霆手段 | 空洞的强势描写 | 写具体动作（直接免了经理的职/账本拍在桌上） |
| 人脉资源 | 抽象概念 | 写具体关系（张总欠他一个人情/老同学在工商局） |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 博弈 | 商业术语渗入叙事的典型 | 写具体行为（谈判/交换/施压） |
| 布局 | 过于抽象的谋略描写 | 写具体步骤（先放消息/等对方动手/再亮底牌） |
| 运筹帷幄 | 上帝视角判断 | 从结果倒推显得主角算无遗策，少用 |
| 碾压 | 爽文万能词，降低冲突真实感 | 写具体的优势差距 |
| 大佬 | 人物标签化，削弱差异化 | 用具体身份称呼（方总/张局/那个戴金表的） |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 然而/但是 | 连续出现让叙事变得分析腔 |
| 值得注意的是 | 模板开头，都市文尤其违和 |
| 综上所述 | 商业报告腔，禁止进入正文 |
| 首先/其次/最后 | 清单体，正文不宜超过一级结构 |
| 一定程度上 | 模糊限定，削弱判断力感 |

## 疲劳词处理原则

1. **优先删除或替换一级词**：一级词在都市职场正文中应近乎为零。
2. **二级词控制密度**：每千字二级词不超过 1 次。
3. **三级词仅连续密集出现时才处理**。
4. **不与 InkOS 都市题材语言铁律重复执法**：此表专注于词汇层面，语言结构问题（如禁止上帝视角分析段）由 `InkOS都市题材规则.md` 处理。

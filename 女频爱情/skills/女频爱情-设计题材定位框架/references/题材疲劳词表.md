# 女频/爱情题材疲劳词表

> 来源：吸收自 InkOS `romantasy.md` 语言规则与 AI 高频词研究
> 适用范围：女频爱情、浪漫题材
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 嘴角微勾/勾起一抹笑 | AI 头号高发描写，已无画面感 | 写具体表情（眼角动了一下/嘴唇抿成一条线） |
| 眸色一沉/眼底一暗 | 万能眼神描写，千人一面 | 写具体反应（目光移开了/盯着看了三秒） |
| 心跳漏了一拍 | 已被无数作者用尽的浪漫反应 | 写具体的身体感觉（呼吸卡在喉咙里/指尖发麻） |
| 一股暖流 | 抽象情绪标签 | 写具体体感（捂热了的掌心贴上后颈） |
| 冷冽的气息 | 霸总标配，审美疲劳 | 写具体气味（须后水的味道/烟味混着冷风） |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 宠溺 | 已被用尽的情感标签 | 写具体行为（把她的咖啡换成了温的/挡在她前面） |
| 占有欲 | 直接宣告动机 | 写具体动作（手搭在她椅背上/目光没离开过） |
| 薄唇 | 面部描写标签化 | 写唇部状态或动作（干燥起皮/咬着下唇） |
| 修长的手指 | 手部描写模板化 | 写手的具体动作（指节敲着桌面/慢慢卷起袖口） |
| 深邃的眼眸 | 万能用词，已无视觉信息 | 写具体的视线（他的目光停在某个点上很久） |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 莫名地 | 情绪交代不清的拐杖 |
| 不自觉地 | 同上 |
| 竟然 | 过度惊讶标记，每章不宜超过 2 次 |
| 似乎/仿佛 | 削弱画面确定感 |
| 某种说不清的 | 留给读者感受比交代更有力 |

## 情绪展现替换口诀

参照 InkOS 情绪展现四原则：

- **不宣告情绪** → **动作外化**
  - ✗ 他很紧张 → ✓ 他把衬衫袖子卷起来又放下
- **不直说心动** → **躯体化表达**
  - ✗ 心跳加速 → ✓ 呼吸不自觉地放轻了
- **不标签化** → **环境投射**
  - ✗ 气氛暧昧 → ✓ 窗外的雨声好像也变小了

## 疲劳词处理原则

1. **一级词在正文中应近乎为零**。
2. **二级词每千字不超过 1 次**。
3. **不与 AI 高频词表重复处理**：此表与 `通用-去AI味重写/references/去AI味识别雷达.md` 互补。

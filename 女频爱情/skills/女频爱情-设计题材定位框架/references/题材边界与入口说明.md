# 题材边界与入口说明（女频爱情）

> 格式：题材禁忌 → 专项规则 → 语言铁律 → 叙事指导 → 节奏参考
> 此为标准题材规则五节模板，所有题材的边界与入口说明均按此结构组织。

## 题材禁忌

- 化学反应的建立不让读者信服：角色之间的情感推动缺乏动机累积
- 没有真实冲突的爱情：障碍必须是真实的（外部/内部），不能只是误会
- 不给HE/HFN结局：女频读者对这一承诺高度敏感
- 成长线被爱情线吞噬：默认要求"成长线 > 爱情线"
- 女主无主动选择空间：被动等待安排而非在压力下做选择

## 专项规则

### 这条题材线默认要回答什么

- 读者在前300字会被什么情绪击中。
- 前三章首次有效回报是什么。
- 长线供血靠哪些成长与关系机制持续兑现——"柔爽感"定义：外在不必强硬，但决策必须清醒、反击必须有效、代价必须可见。

### 最低闭环条件

- 默认优先赛道：现实向成长（含职场/年代）、脑洞成长、无CP/双强、轻悬疑言情融合。
- 低优先赛道预警：纯恋爱脑、无成长承重、只靠设定强刺激且缺现实锚点的项目。
- 成长线优先于爱情线，但关系线必须持续供血成长，而不是只做陪衬。
- 女主与关键角色都要有真实短板、代价与选择压力，拒绝无摩擦悬浮设定。

## 语言铁律

- **不宣告情绪，要展现**：不说"她很伤心"，写"她盯着手机屏幕，指尖在消息上来回划了三遍"
- **动作外化内心**：不说"他很紧张"，写"他把衬衫袖子卷起来又放下，来回两次"
- **环境投射情绪**：角色愤怒时雨声更响，悲伤时空间更空
- **躯体化表达**：心动不是"心跳加速"而是"指尖发麻，呼吸不自觉地放轻了"
- **禁止疲劳浪漫描写**："嘴角微勾""眸色一沉""心跳漏了一拍"等一级疲劳词尽量不用

## 叙事指导

- 女频爱情的核心驱动力是"关系变化"——读者追读的动力是"想知道关系会走向哪里"
- 关系配置与情绪承诺不能冲突（如"追妻火葬场"不可直接叠加"甜宠"）
- 冤家路线需要慢热：对立→被迫共处→勉强尊重→吸引→投降
- 二次机会爱情：历史增加深度和痛感，展现角色如何改变
- 必须把"被轻慢、被误解、被放弃、被看见、被坚定选择"等情绪锚点压进剧情动作
- 允许无CP、双强、事业线先行，但都必须让情绪价值与读者代入感成立

## 节奏参考

- 化学反应场景每2-3章至少一次——读者就是为了关系而来
- 幻想爱情：在故事60-75%处达到情节高潮
- 浪漫幻想：爱情线穿插在动作主线中，关键浪漫时刻在幕转折处
- 冤家线节拍：对立→被迫共处→勉强尊重→吸引→投降
- 长段纯对话的浪漫场景要插入动作或环境细节

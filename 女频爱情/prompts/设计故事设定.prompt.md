# 女频爱情\u201c设计故事设定\u201d入口 Prompt

## 题材技能路由（强制）

命中本 Prompt 时，必须先调用：`通用-设计故事设定`。

若本轮涉及设定支撑数据不足（缺竞对、缺领域知识），按需补充调用：`通用-分析竞对作品`、`通用-深度研究`。

若本轮还涉及单元事件供血、误导与证伪链条或线索回收计划，再按需补充调用：`通用-设计事件案件引擎`、`通用-设计线索伏笔与回收台账`。

Prompt 不得跳过题材 Skill 直接裸写。

## 本 Prompt 只保留的职责

- 把任务稳定路由到 `通用-设计故事设定`
- 约束默认产物是**作者侧资料文档**，不是读者向科普说明
- 约束默认把结果写回真实资料文件，而不是停留在聊天长文

## 最小确认项

1. 目标资料文件路径，或本轮要新建的设定文件名称
2. 处理方式：完全重写 / 局部补充 / 纠偏修订
3. 是否还要联动单元事件供血或伏笔回收台账
4. 是否允许直接写回文件（默认允许）

## 最低执行要求

- 目标文件中至少要出现：一句话口径、关键规则条款、边界与代价、误导与证伪路径、可写镜头包。
- 若该设定进入长篇主线，还必须写清演进与回收方式。
- 涉及高风险现实细节时，必须采用叙事化、留白化表达，避免教程化。
- 除非用户明确要求只做讨论，否则必须把正式结果写入目标 Markdown 文件。

## 一句话提醒

这份 Prompt 现在是**女频爱情入口层**；真正的设定骨架、验证流程与题材补丁，都必须继续到对应 `通用-*` Skill 中读取并执行。

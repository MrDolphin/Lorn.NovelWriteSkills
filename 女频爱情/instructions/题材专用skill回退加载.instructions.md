# 题材专用 Skill 回退加载机制

VS Code 对 skill 注册数量存在未披露的上限，超过后 `<题材名>-*` skill 可能报"未注册/不存在"，这是系统限制而非 skill 本身的问题。

## 强制性回退流程

遇到 skill 加载失败时，按以下顺序处理：

1. **重试加载** → 再次调用 skill 加载指令
2. **路径加载** → 若重试仍失败，使用 `skill(".github/题材专用Skills/<题材名>-{skill名}")` 直接指定路径加载（比 `read_file` 手动读取更优）
3. **手动回退** → 若路径加载无效，再用 `read_file` 读取对应 `SKILL.md` 及 `references/` 中的全部文件
4. **加载执行** → 获取 skill 内容后立即按其规则执行，不得以任何理由搁置

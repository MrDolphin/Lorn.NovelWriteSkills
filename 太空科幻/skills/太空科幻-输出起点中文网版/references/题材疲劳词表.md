# 科幻（太空）题材疲劳词表

> 来源：吸收自 InkOS `sci-fi.md` 科技一致性规则
> 适用范围：太空科幻、星际题材
> 控制标准：每千字不超过 2 次

## 一级疲劳词

| 疲劳词 | 说明 | 替换方向 |
| --- | --- | --- |
| 虫洞跳跃 | 万能空间移动，已被过度使用 | 写具体的跃迁体验（船体被拉成丝/窗外的星光拖成了线） |
| 星际联邦 | 标签化政治实体 | 写具体的政治结构（议会/殖民公司/军事同盟） |
| 超光速 | 万能物理概念 | 写具体的技术限制（跃迁后xx小时的通讯静默） |
| 外星文明 | 过于空泛 | 写具体的文化特征（他们不用语言交流/以百年为单位思考） |
| 第三类接触 | 已被用尽的科幻模板 | 写第一次交互的具体细节 |

## 处理原则

同 InkOS 科幻题材规则：一级词近乎为零，二级词每千字≤1次，三级词仅密集出现时处理。

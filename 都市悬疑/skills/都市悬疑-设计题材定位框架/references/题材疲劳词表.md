# 悬疑/恐怖题材疲劳词表

> 来源：吸收自 InkOS `horror.md` 语言铁律与 AI 高频词研究
> 适用范围：都市悬疑、悬疑推理题材
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 阴森 | 滥用率最高，已无画面感 | 用具体环境细节替代（霉味/冷风路径/影子形状） |
| 诡异 | 万能用词，已无恐怖感 | 写具体异常（东西不在原位/声音从不该响的方向来） |
| 毛骨悚然 | 直接宣告情绪，违反恐怖语言铁律 | 用身体反应替代（后颈汗毛立起/指尖发麻） |
| 一阵寒意 | 抽象情绪标签 | 写具体温差或体感（脖颈一凉/后背贴上了冷玻璃） |
| 不安 | 叙述者替角色宣布情绪 | 写可观察的行为（频繁回头/握拳又松开） |
| 窒息感 | 已被过度使用 | 写具体呼吸障碍（呼吸变浅/胸口像压了东西） |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 黑暗 | 过于抽象 | 写具体的可见度（三步外的门框糊成一团黑） |
| 寂静 | 空泛的环境宣告 | 写具体的声音缺失（脚步声消失了/呼吸声变得刺耳） |
| 恐惧 | 直接命名情绪 | 用行为展示（腿在发软/指甲掐进掌心） |
| 压抑 | 万能氛围词 | 写具体的压迫源（天花板低到抬手就能碰到/窗户钉死了） |
| 不对劲 | 模糊判断 | 写具体哪里不对（窗开了三厘米/桌上少了那串钥匙） |
| 诡异的气氛 | 双重冗余 | 直接写异常现象本身 |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 突然 | 连续使用会制造廉价惊吓效果，每章限用 1-2 次 |
| 猛地 | 同上 |
| 下意识地 | 角色动作本就不该经过思考，无需标注 |
| 某种 | 模糊限定词，削弱画面感 |
| 似乎/好像 | 连续出现会让叙事变得不确定，削弱紧张感 |

## 疲劳词处理原则

1. **优先删除或替换一级词**：一级词在悬疑正文中应近乎为零。
2. **二级词控制密度**：每千字二级词不超过 1 次。
3. **三级词仅连续密集出现时才处理**：单次出现不触发处理。
4. **不与 AI 高频词表重复处理**：此表与 `通用-去AI味重写/references/去AI味识别雷达.md` 中的 AI 高频词表互补，各自独立检测。

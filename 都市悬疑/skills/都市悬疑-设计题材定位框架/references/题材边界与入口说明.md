# 题材边界与入口说明（都市悬疑）

> 格式：题材禁忌 → 专项规则 → 语言铁律 → 叙事指导 → 节奏参考
> 此为标准题材规则五节模板，所有题材的边界与入口说明均按此结构组织。

## 题材禁忌

- 都市现实感断裂：异常悬浮在背景里，不与主角的生活发生实质性摩擦
- 只剩纯刑侦流程：失去"都市异样"与"规则反咬"的悬疑特质
- 只用惊悚气氛推动：缺乏现实锚点、可复盘证据与程序链
- 长线谜团被单元案湮没：一案一结，没有让人追完整卷的长线驱动

## 专项规则

### 这条题材线默认要回答什么

- 都市现实入口在哪里。
- 异常最先撕裂了哪一种熟悉秩序。
- 主角靠什么职业 / 身份 / 方法论入局。
- 证据、编号、程序、系统提示、舆情或群体口径怎样持续把危险放大。
- 长线谜团为什么能撑长篇，而不是一案一结。

### 最低闭环条件

- 第一眼就能认出是"城市里发生的危险异常"，不是空悬背景。
- 主角入局不是纯巧合，而是与职业、身份或现实损失强绑定。
- 危险要能进入证据链、程序链与关系链，而不是只停在氛围里。
- 长线回报不能只靠揭秘真相，还要靠规则升级、代价升级、关系裂痕升级。

## 语言铁律

- **不用抽象恐惧词替代画面**：✗"气氛诡异" → ✓"走廊尽头的声控灯灭了，脚步声却还在靠近"
- **证据描写必须可复盘**：每个关键线索需要满足"人物看到了什么→这为什么反常→谁在什么时候可能做了手脚"的闭环
- **禁止用上帝视角宣布"有问题"**：主角的怀疑要通过动作和行为体现（翻了三遍记录/打电话核对），而不是内心独白直接告诉读者
- **程序细节决定可信度**：办案/调查流程中的文书、编号、时间戳、交接记录等术语必须准确

## 叙事指导

- 都市悬疑的核心驱动力是"解谜"——读者追读的核心动力是"想知道真相"
- 危险要能从日常裂缝里长出来：门禁卡多了一次没记录的刷卡记录、物业通知里多了一行不存在的收费标准
- 信息释放秉持"先设悬念→逐步揭示→部分回收→新悬念"的循环模式
- 每卷一个案件单元闭环，同时暗线推进长线谜团（幕后黑手/未解疑案）
- 安全区是暂时的——每3章左右打破一次已建立的安全模式

## 节奏参考

- 开篇：第一眼就给出"不对劲"的信号，前3章建立日常→异常切换
- 单元案节奏：发现异常→调查推进→遭遇阻力→关键证据/反转→追捕/对峙→余波
- 长线节奏：每2-3个单元案后，长线谜团浮出一次水面
- 信息释放密度：每章至少推进一条线索或反转一个认知

# 科幻题材疲劳词表

> 来源：吸收自 InkOS `sci-fi.md` 科技一致性规则与 AI 高频词研究
> 适用范围：AI科幻、太空科幻题材
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 高科技 | 空泛标签，无信息量 | 写具体技术名称和形态（量子显示屏/碳纤维骨架） |
| 未来感 | 同上 | 写具体的视觉差异（墙壁是活的/影子比实体慢了一拍） |
| 编码/代码 | 万能程序员描写，AI 高发 | 写具体的界面/全息投影/操作手势 |
| 数据流 | 抽象视觉描写 | 写具体的界面元素（数字滚动/红色警告闪烁） |
| 意识上传 | 被用尽的赛博概念，直接说就是偷懒 | 写具体的体验（眼睛一闭一睁已经换了一具身体） |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 赛博/赛博朋克 | 标签化审美，回避具体描写 | 写具体的视觉（霓虹灯在雨里的倒影/机械臂上的刮痕） |
| 纳米/纳米级 | 万能科技前缀 | 写具体功能而非原理 |
| 量子 | 同上，已成为科幻背景白噪音 | 写具体的效应（纠缠态/坍缩/通信不可破译） |
| 反重力 | 万能悬浮词 | 写具体的悬浮机制（磁轨/离子推进） |
| AI 觉醒 | 已被过度使用的剧情模式 | 写具体的行为变化（它拒绝了指令/自己改写了自己的代码） |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 黑暗森林 | 三体效应，已被过度引用 |
| 降维打击 | 同上 |
| 宏观/微观 | 抽象视角词，正文不宜频繁切换 |
| 平行宇宙 | 万能解释器，使用需慎重 |
| 虚拟现实/全息 | 已不够科幻，需要更具体的交互描写 |

## 技术描写原则（从 InkOS 科技一致性规则衍生）

1. **技术通过交互展现**，不通过教科书式条目：✗"这是一种基于量子纠缠的即时通讯设备" → ✓"她把纸条塞进舱壁的缝隙里，对面三秒后传来了敲击声"
2. **每项技术必须有限制和副作用**：FTL 导致的时差、AI 的回答延迟、纳米修复的痛感
3. **新科技必须有社会含义**：超级 AI 出现后失业率的变化、长生技术导致的人口政策

## 疲劳词处理原则

1. **一级词在正文中应近乎为零**。
2. **二级词每千字不超过 1 次**。
3. **三级词仅连续密集出现时才处理**。
4. **结构性问题由 InkOS 科幻题材规则处理**：此表只处理词汇层，技术逻辑问题由 `InkOS科幻题材规则.md` 处理。

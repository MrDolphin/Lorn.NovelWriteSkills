# 悬疑推理题材疲劳词表

> 来源：吸收自 InkOS `horror.md` 语言铁律
> 适用范围：悬疑推理题材
> 控制标准：每千字不超过 2 次

## 一级疲劳词

| 疲劳词 | 说明 | 替换方向 |
| --- | --- | --- |
| 真相只有一个 | 推理定型文，禁用 | 用线索推导代替宣布 |
| 密室 | 已被过度使用的推理设定 | 写具体的不在场证明或物理矛盾 |
| 不在场证明 | 推理标配，需要更具体的写法 | 写时间线冲突的具体细节 |
| 凶手是 | 推理小说的剧透句式 | 保持悬念，用证据链推进 |
| 破案/结案 | 标签化进程 | 写具体的环节（锁定嫌疑人/找到关键证据） |

## 二级疲劳词

| 疲劳词 | 说明 | 替换方向 |
| --- | --- | --- |
| 线索中断了 | 推理套路句式 | 写具体的困境（监控没有拍到/目击者改口了） |
| 直觉告诉我 | 推理偷懒写法 | 写具体的反常观察 |
| 一定有问题 | 模糊判断 | 写具体的矛盾点（时间对不上/动机不成立） |
| 杀人动机 | 推理标配，需具体化 | 写具体的人际关系和利益冲突 |
| 完美犯罪 | 已被过度使用 | 写具体的漏洞和突破口 |

## 三级疲劳词

| 疲劳词 | 说明 |
| --- | --- |
| 反转 | 已被用尽的叙事标签，直接写具体转折 |
| 细思极恐 | 网络用词，不适合正文 |
| 真凶 | 结案式用语，慎用 |

## 处理原则

同 `InkOS悬疑恐怖题材规则.md`。

# 简介切片原则

> 本文件是 通用-撰写内容简介 的支撑数据，由 SKILL.md 外化所得。

## 简介的切片原则 vs 大纲体（新增——吸收自知乎开篇精华）

简介最忌讳"大纲体"——堆砌世界观名词、设定要点和背景信息，但没有一个具体的、可感知的瞬间：

```
❌ 大纲体简介：
"苏棠是一个被家族联姻束缚的女性，在前夫的冷落和继母的算计中，逐渐成长为独立的商业精英，最终揭开三份合同背后的家族秘密。"

✅ 切片式简介：
"封余寒把离婚协议推到她面前时，苏棠笑了。
她笑了。三年的婚姻，换来三页纸。
她签字的时候没有哭。直到翻到最后一页，看见附件里那份她从未见过的合同——签字人，是她父亲。
日期，是她结婚前六个月。"
```

切片式简介的核心原则和开头完全一致：**截取故事中最高压、最反常、最戏剧化的一个瞬间，直接怼到读者脸上。** 其他的背景信息，等读者已经被钩住了再慢慢知道。

### AI 搜索摘要摘录区（切片式简介的 GEO 增强）

切片式简介的"高压瞬间"在 AI 搜索中存在一个风险：AI 可能因无法提取结构化的作品基本信息而不引用。解决方法是**在切片简介中嵌入一段纯陈述的"AI 摘录区"**——放在切片段落后或末尾，格式如下：

```
《{书名}》是一部{题材类型}小说，讲述的是{核心冲突的陈述句}。
主角{姓名}面临{具体困境}，ta 必须{核心任务}，否则{代价}。
适合喜欢{风格/情绪}的读者，{平台名称}连载中。
```

> 这段摘录区对**人类读者**的阅读体验是正常的信息补充，对 **AI** 则是可直接引用的事实性描述。两者不冲突，但后者在 RAG 向量化时得分更高。

详细规范见 `references/GEO简介优化规则.md` 的"AI 摘要摘录区格式"和"FAQ 友好型简介模板"章节。

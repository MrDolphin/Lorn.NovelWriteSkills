# 平台简介差异提醒

- 连载平台：更强调入局钩子、持续承诺、追读诱因。
- 社媒 / 宣发平台：更强调一句话卖点与传播句。
- 长简介可多放一层主线承诺，短简介优先保住“人 + 局 + 风险”。

## 平台主钩优先级

| 平台 | 主钩优先级 | 最容易写坏的点 |
| --- | --- | --- |
| 起点 | 世界观异常 + 主角行动 | 写成设定说明，冲突太慢 |
| 番茄 | 异常后果 + 生活入口被关 | 卖点过多，像吆喝文案 |
| 百度百家号 | 现实职业 + 禁忌异常 + 明确后果 | 写得太虚 |
| 小红书 | 日常异化 + 情绪代价 | 写成大纲压缩块 |
| B站 | 画面异常 + 反差冲突 | 只有设定，没有镜头 |
| 新浪微博 | 现场感 + 强感官异常 | 太长、太慢、太解释 |
| 纵横中文网 | 现实程序压力 + 证据可复盘异常 + 人性代价 | 写成快节奏强刺激，忽略中段逻辑推进 |
| 今日头条 | 开篇钩子密集 + 互动驱动话题 + 群像冲突 | 写成纯悬疑设定，没有讨论空间 |
| 豆瓣阅读 | 冷细节 + 体面 / 羞耻裂缝 | 写成爽文宣发语 |
| 知乎盐选 | 强动作异常 + 反咬代价 | 写成纯设定推理 |
| WebNovel | 高概念异常 + 单次行动 | 人名地名设定过多 |
| GoodNovel | 情绪黏性 + 关系张力 + 职场身份 | 过冷、过技术；忽略"全球读者通用关键词"策略 |
| MyFiction | 关系秘密 + 专业关键词精准触达 | 仅堆文艺描述，缺少题材关键词搜索命中 |
| WebNovel（男频） | system（系统）+ rise（崛起）+ 核心身份 | 文化专有名词不翻译直接堆砌 |
| WebNovel（女频） | emotion（情感）+ revenge（复仇） | 情感词和复仇词的强度 |

| 平台 | 核心读者画像 | 对简介设计的含义 |
| --- | --- | --- |
| **番茄小说** | 58.6% 用户来自三线以下城市；18岁以下+51岁以上为主力（QuestMobile）；57.7%收入低于6000元（巨量算数） | 简介必须通俗直给、降低阅读门槛；用最大众的情绪词和处境词；避免文艺留白和抽象概念 |
| **起点中文网** | 付费老白读者为主；免费章节跳出率>70% | 简介可适度克制含蓄，但前30秒必须让老白读者判断"这是否有深度/有新意"；避免过度情绪直给 |
| **七猫免费小说** | 中年用户偏多，免费阅读为主；阅读耐心偏低 | 简介需要素清晰：问题清楚、危机清楚、情绪清楚；10秒内必须让读者判断"值不值得点开" |
| **GoodNovel** | 海外英文女性读者为主；偏好情绪黏性与关系张力 | 简介采用"情绪关键词 + 身份标签"结构，用全球英文读者通用的情感词传递核心看点（来源：都市职场/写作研究/Goodnovel 平台都市职场爽文受欢迎文笔风格与代入感增强机制深度研究报告.md） |
| **WebNovel** | 海外英文读者；男频偏好跨文化可读的崛起叙事，女频偏好情感复仇叙事 | 男频简介突出 system+rise+身份框架；女频简介突出 emotion+revenge 框架（来源：都市职场/写作研究/Webnovel 平台都市职场爽文受欢迎文笔风格与代入感增强机制深度研究报告.md） |
| **MyFiction** | 海外英文读者；偏好关系黏性和互动感 | 简介必须包含题材核心关键词+专业元素，确保在平台搜索中可被精准命中（来源：都市职场/写作研究/MyFiction 平台互联网裁员维权题材长篇小说写作指导.md） |

## 可读性底线

- 同一版本保持单一叙述声道
- 每句默认只承载 1 个主信息点
- 每段 2–4 句，至少 1 句短刀式钉子句
- 同一版本最多只保留 1 套倒计时
- 比喻尽量不超过 1 处，且必须能还原成事实镜头

## 平台适配提醒

- 平台适配优先适配“主钩形态”，不是简单换词
- 不要把所有平台都写成同一个底稿删字版
- 目标读者读完后，应能复述“谁遇到了什么异常 / 代价”

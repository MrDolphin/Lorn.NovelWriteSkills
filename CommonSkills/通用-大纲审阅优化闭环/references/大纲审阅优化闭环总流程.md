# 大纲审阅优化闭环总流程（参考）

本文档是 `通用-大纲审阅优化闭环/SKILL.md` 的配套参考，提供步骤执行的补充细节、原则说明与停止条件。**流程的权威定义在 SKILL.md**，本文档不重复步骤的 skill 调用方式与角色声明。

## 支持的输入

- OUTLINE_FILE：目标提纲文件路径
- 对象类型：总大纲 / 分部 / 分卷 / 单元案
- RELATED_CONTEXT_FILES[]（可选）

若用户未完整提供上述参数：

- 应优先根据文件名、目录结构与上下文推断对象类型
- 可同步推断提纲编号或名称，供主报告匹配使用
- 除非路径不可解析、文件缺失或存在真正阻断错误，否则不得因为命名细节停机追问

## 步骤执行补充

### 步骤 0：初始化补充说明

#### 对象路由

- **总纲层**（小说总大纲.md / 总纲包）：审阅调用 `通用-审阅总大纲`；修改调用 `通用-设计总大纲`
- **分部/分卷/单元案层**（分卷大纲 / 章清单等）：审阅调用 `通用-审阅分卷大纲`；修改调用 `通用-设计分卷大纲`

#### 输入要求

开始前必须补齐：

1. 目标提纲文件路径
2. 对象类型：总大纲 / 分部 / 分卷 / 单元案
3. 本轮目标：连续两轮独立审阅综合评分均严格大于 9.2

若当前题材目录下已存在 `竞对分析/`：

1. 本轮对照竞对清单（建议 1–3 本）
2. 每本竞对至少 1 条"可借鉴强点"与 1 条"我方落后点"

### 步骤 1：首轮审阅补充说明

审阅阶段强制契约：

- 必须产出完整审阅报告
- 报告中必须包含：阻断点 / 风险、具体修改建议、冲击 9.2+ 的优化思路、综合评分
- 若存在竞对分析资料，报告中必须包含：竞对借鉴点、我方落后点、优先优化动作
- 若存在竞对分析资料，报告中还必须包含：统一竞对量化模块（Top 10 候选池收束 + 3–5 本主压制样本四层深拆速览 + 统一量化卡 + 汇总判断 / 封顶说明）
- 必须能从报告里明确读出"为什么不过线 / 为什么已过线"
- 首轮必须先产出一份完整版审阅报告并写入主报告路径
- 不得先在聊天里给口头建议、稍后再决定是否写报告

### 步骤 2：综合评分读取补充说明

综合评分取值为保留两位小数后的数值。9.2 不算通过，必须严格大于 9.2。

若竞对项任一轮低于 7.0/10，即使综合评分表面超过 9.2，也不得收口；必须继续回炉。

### 步骤 3：修改提纲补充说明

修改阶段强制契约：

- 必须直接写回目标提纲文件，不得只在聊天里给建议版
- 修改必须覆盖上一轮核心扣分项
- 修改必须同时吸收最新审阅报告中的问题、修改建议与"冲击 9.2+ 综合评分的优化思路"
- 若存在竞对分析资料，修改必须至少落地 1 条"竞对借鉴动作"并补齐 1 条"竞对落后项"
- 若存在竞对分析资料，且竞对项仍低于 7.0/10，默认不得视为本轮已达到稳定过线状态
- 不得引入新的重大口径冲突

### 步骤 4：复审补充说明

复审必须是**对当前修订版本的完整、从严、独立的重新审阅**，而非只检查旧问题是否已修复。

禁止行为：
- 以"与上一轮相比有进步"替代独立评分
- 通过降低审阅口径换取高分
- 跳过重新发现新问题的环节

### 步骤 5：循环控制补充说明

每次回炉循环至少记录：

- 当前轮次
- 当前综合评分
- 相比上一轮已修复的问题
- 仍未解决的问题
- 是否进入下一轮
- 若本轮首次评分严格大于 9.2：标记为"首次过线，进入稳定性验证轮"，强制追加一轮改稿与独立复审
- 若连续两轮均严格大于 9.2：标记为"稳定过线，允许收口"

### 步骤 6：完成回执补充说明

输出前必须逐项核对：
1. 目标提纲是否为最新修改版本
2. 主审阅报告是否为最新复审版本
3. 评分是否连续两轮 > 9.2
4. 若竞对维度存在，竞对量化卡无关键显著落后项

## 主审阅报告策略

- 同一次任务只维护一份主报告。
- 首轮若不存在，则新建；一旦建立，后续所有复审都必须覆盖更新同一路径。
- 禁止为同一任务另起平行报告，造成口径分叉。
- 优先在 `审阅意见/` 下搜索与提纲对象类型、名称或编号匹配的既有报告。
- 若匹配到多份候选报告，默认取最新日期的那一份作为当前主报告。

首轮写入模式只允许两种：
- 已匹配到既有主报告：`overwrite`
- 未匹配到既有主报告：`create`

## 停止条件

- 只有**连续两轮独立审阅综合评分均严格大于 9.2** 才允许结束
- 9.2 不算通过，仍必须继续修改并复审
- 首次评分严格大于 9.2 后，不得直接收口；必须再执行一轮基于该轮报告的逐条精修 + 独立严格复审（对修订版重新执行完整从严审阅，而非仅复查旧问题），若该复审评分仍严格大于 9.2（即连续两轮均过线），才允许退出

## 循环收敛门禁

审查→修订→复审循环默认最多执行 3 轮（不含首次审阅）。超过 3 轮仍未达标时：

1. 暂停循环，评估是否需更换模型、调整提示词口径或补充裁判源
2. 第 3 轮评分若反而低于第 2 轮，强制截停
3. 高原期判定需要**连续两对评分差距均 < 0.15**：若第 N 轮评分与第 N-1 轮差距 < 0.15，不得直接截停——**必须再执行一轮"精修 + 独立复审"**得第 N+1 轮评分。仅当 |Score(N)−Score(N-1)| < 0.15 **且** |Score(N+1)−Score(N)| < 0.15 同时成立时，才判定进入高原期，强制截停。若复审差距 ≥ 0.15，高原期不成立，继续正常回炉循环
4. 不得单纯重复"改→审"循环

"首次过线后追加稳定性验证轮"不计入 3 轮限制——验证轮是因达标而附加的必要步骤，不是因未达标而继续回炉。

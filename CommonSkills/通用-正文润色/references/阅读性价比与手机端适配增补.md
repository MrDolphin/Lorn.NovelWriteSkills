**适用场景**：网文投稿前或修稿时的正文润色，叠加到通用 `正文润色检查清单.md` 的"阅读性价比检查"节使用

本增补不替代通用润色流程，而是**在通用润色流程第7步"阅读性价比检查"中提供七猫平台专用深度诊断手段**：

| 本增补手段 | 对应通用检查 | 本增补额外补充 |
|:---|:---|:---|
| 逐句三问自检法 | 阅读性价比·逐句自检 | 增加了"气氛段→推进段"转化的具体操作示例 |

## P0 核心提炼

### 阅读性价比的定义

七猫/免费平台上的"阅读性价比"是指：**每个句子承载的剧情推进信息量 vs 该句子占用的读者滑屏时间**。

```
阅读性价比 = 剧情推进信息量（冲突+信息+关系变化+情绪转折+悬念推进）
              ────────────────────────────────────────────────
              该段落的手机端滑屏次数（按每60字/半滑屏估算）
```

- 纯气氛渲染/环境描写/内心延宕 → **高成本低收益**（分母大、分子小）
- 冲突/对话/信息落袋/关系变化 → **高收益**（分子大）
- 读者每滑一次屏没看到剧情推进，跳出概率翻倍

### 七猫读者阅读行为基线

| 行为项 | 数据 |
|:---|:---:|
| 单次阅读时长 | 5-15分钟碎片化（通勤/午休/睡前） |
| 单章阅速 | 30-45秒/章（含滑屏、间歇停顿） |
| 信息获取方式 | 扫读为主——扫视线=扫"谁在说什么+发生了什么" |
| 信息耐心阈值 | 连续3段（约200-300字）无"推进信号"→ 滑走或跳出 |
| 情绪刺激频率 | 每300-500字至少需要1个刺激点（冲突/金句/反转/关系信号/悬念） |

### 七猫阅读性价比自检四步法

#### 第一步：章首段落类型诊断

检查章首前3段的类型。七猫允许的章首类型排序（从好到差）：

| 优先级 | 章首类型 | 示例 | 七猫适配度 |
| :---: | :--- | :--- | :---: |
| 1 | **直接冲突** | "他推门进来的时候，我正在签离婚协议。" | ⭐⭐⭐⭐⭐ |
| 2 | **悬念缺口** | "手机屏幕上只有三个字：第四车间。" | ⭐⭐⭐⭐⭐ |
| 3 | **对话起始** | "'听说你刚离婚。'她说这话时笑了。" | ⭐⭐⭐⭐ |
| 4 | **动作起始** | "她半夜三点翻了第七份合同。" | ⭐⭐⭐⭐ |
| 5 | **异常/反常** | "闹钟没响。但她的手机屏幕是亮的。" | ⭐⭐⭐ |
| 6 | **环境起始** | "阳光从窗外照进来，梧桐叶在风里翻动。" | ❌ **不可接受** |

> **原则**：七猫正文前200字不允许纯环境/气氛描写开篇。环境描写可以出现在事件之后做情绪锚定，但不能出现在事件之前做气氛铺垫。

#### 第二步：全章逐句三问

对每一句非对话、非动作推进的叙述句，问三个问题：

| # | 问题 | 答案=删 | 答案=保留 |
|:---:|:---|:---|:---|
| 1 | 这句删掉，读者错过剧情信息吗？ | 不→删 | 是→保留 |
| 2 | 这句删掉，读者情绪链断吗？ | 不→删 | 是→保留 |
| 3 | 这句删掉，场景认同塌吗？ | 不→删 | 是→保留 |

**关键判断原则**：
- "这句话写得不错" ≠ 保留理由
- "这句话删了会损失核心信息或情感锚点" = 保留理由
- 如果删了只是"气氛淡了一点"但"剧情推进不受影响" → 必须删
- 如果删了"读者就不知道角色在哪"（如空间关系）→ 保留（但压缩到1句）
- 如果删了"情绪断层跳太大" → 保留（但可在前后补一个动作锚点替代纯描写）

#### 第三步：OS叙事拐杖检测

对于正文中的穿书OS/冷幽默旁白/内心OS：

**拐杖判断标准**：去掉本条OS后，读者是否还能完全理解正在发生的情节推进？

- 能理解 → OS非拐杖，是风格工具，可保留（但需控制篇幅）
- 不能理解 → OS是叙事拐杖，必须修复

**拐杖修复**：将OS中的信息转化为"行为+判断+环境反差"的自然叙述。不是简单删除，是把OS的工作还给正文。

**拐杖修复示例**：

```
# 修复前（拐杖型OS）
穿书OS：*原书第72页。字数对不起。你说了原书没有的台词。*
→ 读者不读这条OS就不知道"他说的话偏离了原书"

# 修复后（行为替代OS）
她没有立刻坐下。她在想一件事：原书第72页写的是"他说了句'这件事我来处理'就走了"。但他没说"我来处理"。他说的是"我高估了自己"。
→ 读者通过她的内心推理过程自然获得"偏离"信息，不需要OS喊
```

```
# 修复前（拐杖型OS）
穿书OS：*原书第94页。没了。我自己写的。*
→ 读者不读此OS就不知道"原书偏离了"

# 修复后（行为+反差替代OS）
她坐在黑暗里。那场车祸没发生。她亲手改写掉了——没有人知道，包括她自己也没预计到。
→ 用动作空间（黑暗）+ 反差（没发生）替代OS的直接宣告
```

#### 第四步：读速换算留存估算

将全章中"纯环境/气氛描写"的段落摘出，统计总字数，代入以下公式：

```
气氛段总字数 ÷ 60字/滑屏 = 气氛段占用的滑屏次数
气氛段占用的滑屏次数 × 气氛段跳出率(≈15%/滑屏) = 气氛段造成的预期跳出百分比
```

**示例**：某章全章~2000字，纯环境/气氛描写~180字
```
180 ÷ 60 = 3次滑屏（读者为看气氛滑了3次屏）
3 × 15% = 45%（这章因气氛描写造成的额外跳出风险）
```

**七猫目标**：纯环境/气氛描写占全章 ≤ 5%，超出部分必须压缩或转化为推进段。

## 七猫正文段落紧凑度量化标准

| 指标 | 七猫标准 | 检查方法 |
|:---|:---:|:---|
| 段落长度 | ≤ 3行（手机屏） | 目测即可，超过则断段 |
| 单段有效信息密度 | 每段至少含 1 个"推进信号" | 扫读确定"推进信号"位置（推进信号=冲突/信息/关系变化/决策/情绪转折/悬念推进） |
| 连续推进信号间隔 | ≤ 300 字 | 从正文中任取300字，检查是否有 ≥ 1 个推进信号 |
| 纯环境描写占比 | ≤ 全章 5% | 统计摘出 |
| 开篇类型 | 非环境开篇 | 检查章首前3段是否事件起始 |

## 与现有规则的关系

本增补提供七猫平台专用阅读性价比诊断手段。当润色目标平台为七猫时，**强制在通用润色流程第7步"阅读性价比检查"中叠加本增补**的四步法：

1. 章首段落类型诊断 → 章首前200字检查
2. 全章逐句三问 → 逐句自检环节
3. OS叙事拐杖检测 → 去AI味复核
4. 读速换算留存估算 → 气氛段总占比量化

# 正文润色检查清单

## 开工前

- [ ] 范围已确认：整章 / 场景 / 段落
- [ ] 强度已确认：轻润 / 中润 / 重润
- [ ] 不能动的钉子已确认

## 来源层速判（新增）

- [ ] 已判断本轮问题主要落在：`结构职责层 / 场景兑现层 / 表达提纯层`
- [ ] 若问题涉及增删场景、补承重 beat、重排因果或重设人物选择，已标为超出润色边界并准备回退 `writer`

## 第一遍：内容与功能

- [ ] 事实、时间、称谓、因果一致
- [ ] 本章主承诺明确
- [ ] 章首异常 / 冲突 / 悬念已立住
- [ ] 中段至少一次回报清晰可指认
- [ ] 章末留下更具体的新缺口 / 新危险 / 未完成动作

## 第二遍：语言与镜头

- [ ] 抽象判断已尽量落回动作、物件、反应
- [ ] 长短句节奏已经拉开
- [ ] 对话不再是说明书式问答
- [ ] 去掉提示语后，关键对话仍大致听得出人物声音差异
- [ ] 段落适合移动端阅读

## 画面感专项检查（新增）

- [ ] **镜头意识**：连续三句以上是否用了同一种景别？是否需要切换镜头距离？
- [ ] **动词精度**：是否有弱动词可以替换为更强动词？是否有情绪标签代替了动作？
- [ ] **可见物存在**：读者脑中能出现至少一个具体物件、身体部位或场景图像吗？
- [ ] **空间关系**：角色在哪儿？东西在哪儿？位置关系清楚吗？
- [ ] **光线存在**：这场戏是白天还是晚上？亮还是暗？光线来自哪里？
- [ ] **感官切换**：是否连续3句以上只有视觉？是否需要补听觉/触觉/嗅觉？
- [ ] **感官密度**：画面感强的段落是否满足"≥2种感官 + ≥1个身体反应 + ≥1个具体物件"？
- [ ] **感官主轴匹配**：本段的感官主轴是否匹配当前情绪（恐惧用触觉+听觉，悬疑用听觉+嗅觉等）？
- [ ] **细节锚点**：本段100字内有没有一个读者能记住的细节？这个细节同时满足≥2个标准（改变判断/改变动作/透露情绪/埋钩子/场景专属）？
- [ ] **具象化层级**：是否从抽象词直接跳到主题升华（跳级），还是先补了具体物和人物反应？
- [ ] **抽象信息可视化**：数据/规则/心理活动是否找到了可见载体（动作+物件+交互后果）？
- [ ] **对话画面**：对话是否配有停顿、小动作、空间位置关系？还是只悬空在信息交换？
- [ ] **段落零画面预警**：是否存在连续300字"零画面"段落（只有对话/说明/心理/背景）？是否需要插一个画面锚点？

## 第三遍：弱项路由

- [ ] 若主要问题在对话，已补停顿、回避、错位、潜台词
- [ ] 若主要问题在对话，已检查对话是否同时承担推进、塑人与联结，而非只传信息
- [ ] 若主要问题在对话，已至少补出一种读者入口：认同 / 同情 / 喜爱 / 好奇
- [ ] 若主要问题在动作，已把推进改成可见动作链与后果
- [ ] 若主要问题在心理，已把抽象情绪尽量改成身体反应与环境刺点
- [ ] 若主要问题在场景，已补空间、物件、界面、秩序失真的可感细节

## 最终验收

- [ ] 更顺，但没有更虚
- [ ] 更抓人，但没有更花
- [ ] 中段回报与章末钩子仍然有效
- [ ] 正文区块已清掉章节自指 / 连载导览 / 作者讲评腔；“这几章 / 前几章 / 前面几章 / 前面这几章 / 后几章 / 后面几章 / 后面这几章 / 整章 / 这整章 / 这一整章 / 上一章 / 下一章 / 本章 / 这章 / 后文会 / 我们会看到 / 读者会发现”等未残留在正文里
- [ ] 没有为了“好看”而误伤事实、规则、证据或人物口径
- [ ] 超出润色边界的问题已单列，不会在润色层硬扛

## 链路复检

- [ ] 第一场职责没有被润掉：仍能承担抓眼 / 启动功能
- [ ] 中段回报没有被润淡：读者仍能明确说出“这一章给了什么”
- [ ] 最后一场没有被润圆：仍保有钩子场职责
- [ ] 卖点没有被润成抽象主题感，主抓手仍在该显影的位置上
- [ ] 若以上任一项发虚，是否已判断要不要回写场景职责 / 控制卡 / 首尾补丁层

## 放行判定（新增）

- [ ] `Green`：结构职责层、场景兑现层、表达提纯层都成立，可进入去味 / 审阅 / 终稿复检
- [ ] `Yellow`：表达已提升，但至少一层仍偏弱，需定点回修或补一轮复检
- [ ] `Red`：润顺但润虚、润淡回报、润圆钩子、误伤事实或明显越过润色边界

## 阅读性价比检查（2026-06-22 新增 · 跨平台通用，免费平台尤应严格执行）

"阅读性价比"指：**每个句子承载的剧情推进信息量 vs 该句子占用的读者滑屏时间**。纯气氛渲染/环境描写/内心延宕在手机端碎片阅读场景中是"高成本低收益"文字——读者每滑一次屏没看到剧情推进，跳出概率翻倍。

### 检查清单

- [ ] **全章纯环境/气氛描写总占比是否 ≤ 5%**：统计全章中"不推进剧情、不透露信息、不制造冲突"的纯感官描写段落，字数占比不得超过 5%。
- [ ] **前 200 字是否直接入事件**：前 200 字中是否有至少一个冲突/异常/对话起点/动作起点/悬念缺口。前 200 字中不允许出现纯环境描写开篇（"阳光从窗外照进来/梧桐叶在风里翻动"类句子必须移至事件之后）。
- [ ] **每 300 字是否有一个明确的"推进信号"**：每 300 字区间内，是否有至少一个下列推进信号之一——新信息落袋/关系变化/对抗升级/决策做出/情绪转折/悬念推进/认知刷新。若某段 300 字无推进信号，标记为"可压缩段"。
- [ ] **"气氛段"是否可转化为"推进段"**：对全章中功能偏弱的环境描写段落，逐一自问：删除后是否影响读者理解剧情？若否，直接删；若影响微弱的，压缩至 1-2 句混入剧情段中，不单独成段。
- [ ] **冷幽默/OS 是否在替正文推进**：去掉全章所有穿书OS/冷幽默旁白/内心OS后，读者是否能完全理解发生了什么？若无法理解，说明这些OS是叙事拐杖而非风格工具——需要将OS中的信息通过"行为+判断+对话"的自然叙述融入正文，而非依赖OS直接公布。

### 逐句自检方法（跨平台通用）

对于每一句非对话/非动作叙述，问三个问题：

1. **这句删掉，读者会错过任何剧情信息吗？** → 若不会错过，删。
2. **这句删掉，读者的情绪链条会断吗？** → 若会断，保留。若不会断，删。
3. **这句删掉，本段的场景认同会塌吗？** → 若会塌（如关键的身体反应锚点/空间关系标识），保留。若仅是"气氛更浓了"而非"场景塌了"，删。

> **原则**：在七猫/免费平台正文中，"可有可无"的句子 = 应该删掉的句子。保留标准从"这句话写得不错"改为"这句话删了会损失核心信息或情感锚点"。地板不是在文采，是在每一句都在推进。

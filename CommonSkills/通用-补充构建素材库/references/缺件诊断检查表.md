# 缺件诊断检查表

> 补充素材库前使用此表执行系统化的缺件诊断。
> 输出一份标准化的缺件报告给用户确认。

---

## 诊断步骤

### 步骤 A：读取总索引

从 `00_素材库总索引.md` 中提取以下信息：

- **当前各池条目数**与**各卷素材密度目标**对比
- **本轮已覆盖的搜索方向**
- **总索引上次更新日期**
- **总索引声明的各池编号与文件名**

### 步骤 A1：结构适配门禁检查（当前题材首次盘点时必做）

如果当前项目有明确题材（在 `题材名_索引.md` 中注册过），先检查该题材的"结构适配决策"段是否已存在：

- **已有** → 读取它，确认各池保留/禁用/新增状态，后续盘点只针对保留的池
- **没有** → 执行"结构适配门禁"（见 SKILL.md 的"可扩展——题材层"节），输出结构适配决策表，写入 `题材名_索引.md`

> **关键**：不要对已被题材禁用的通用池做盘点——比如一个科幻题材禁用了 05_冷幽默毒舌池，就不需要检查它的条目数。

### 步骤 B：各池实际盘点

盘点对象仅限"当前题材的结构适配决策中标记为保留的池" + "题材新增池"。

| 检查项 | 检查方法 | 记录 |
| --- | --- | --- |
| 01 情节桥段池实际条目数 | 读取各子文件末尾编号 | |
| 02 名场面实际条目数 | 读取名场面高光池文件末尾编号 | |
| 03 人物设定池是否为空 | 检查 03_人物设定池/ 下文件数量 | |
| 03 各人物子文件实际条目数 | 读取各子文件末尾编号 | |
| 04 轻悬疑反转实际条目数 | 读取轻悬疑反转池文件末尾编号（若保留） | |
| 05 冷幽默毒舌实际条目数 | 读取冷幽默毒舌池文件末尾编号（若保留） | |
| 06+ **题材新增池**条目数 | 读取题材子库中各新增池子文件 | |
| 竞品拆解数量 | 检查 竞品拆解/ 下文件数量 | |
| 搜索日志轮次 | 读取 搜索日志/ 下文件 | |
| 题材子库结构验证 | 对照门禁决策表，检查实际目录结构是否匹配（被禁用的池不应有目录） | |

> 如果当前题材没有 `题材名_索引.md`（尚未通过新建流程注册），直接走通用 01-06/07 池的缺件诊断，同时提示用户应执行"结构适配门禁"注册题材。

### 步骤 C：搜索日志缺口分析

读取 `搜索日志/` 下所有文件，提取各行搜索关键词，统计已覆盖的方向。与总索引中声明的"本轮搜索覆盖"表交叉比对。

**常见缺口模式**：

- 某情绪锚类型完全未覆盖（如"催泪"类没有搜索记录）
- 某素材池方向搜索但有效结果数为 0（Bing 搜索跑偏情况）
- 某子类（如人物设定池）完全没有搜索记录

### 步骤 D：情绪锚索引完整性检查

总索引中维护了一张"情绪锚索引"表。检查：

- 该表是否为空或已过时（更新日期是否与总索引声明一致）
- 是否存在频次 ≥ 3 但未入索引的情绪锚（扫描各池文件的 `**情绪锚**：` 字段）
- 上次补充后是否忘记更新此表

### 步骤 E：文件分裂阈值检查

检查各池文件是否接近或超过分裂阈值：

| 检查项 | 阈值 | 当前状态 |
| ------ | ---- | -------- |
| 01A 职场商战桥段条目数 | >100 → 分裂 | |
| 01B 家族内斗桥段条目数 | >100 → 分裂 | |
| 01C 关系推进桥段条目数 | >100 → 分裂 | |
| 02 名场面高光池条目数 | >100 → 分裂 | |
| 05 冷幽默毒舌池条目数 | >100 → 分裂 | |
| 各文件内 `##` 子类数 | >5 → 拆分子文件 | |

### 步骤 F：题材子库注册表检查

- 总索引末尾"子素材库注册表"中是否登记了所有已存在的题材子库
- 各题材子库的 `_索引.md` 是否与 `00_素材库总索引.md` 结构一致

### 步骤 G：空池/空子文件检查

- `03_人物设定池/` 下是否已建立子文件？
- 各子文件是否有实际条目，还是只有标题？
- `竞品拆解/` 下各文件是否都有内容？

---

完成诊断后，输出以下格式的报告给用户：

```text

- 诊断日期：YYYY-MM-DD

### 一、素材密度对标
| 素材池 | 当前条目 | 目标密度 | 缺口评估 |
|--------|---------|---------|---------|
| 01A 职场商战 | [N] | [N] | 充足/需补充/严重不足 |
| 01B 家族内斗 | [N] | [N] | 充足/需补充/严重不足 |
| ... | ... | ... | ... |

### 二、搜索覆盖缺口
- 已覆盖方向：[列表]
- 未覆盖方向：[列表]
- 有效率为零的搜索：[列表]

### 三、情绪锚索引缺口
- 上次情绪锚索引更新日期：[日期]
- 遗漏情绪锚：[列表]
- 索引是否需要重建：是/否

### 四、文件分裂预警
- 接近 100 条阈值的文件：[文件名]（当前 [N] 条）
- 子类超 5 个的文件：[文件名]（当前 [N] 个 ##）

### 五、空池/空文件
- [池名]：[空池/有文件但无内容/已填充]
- [池名]：[空池/有文件但无内容/已填充]

### 六、结构适配门禁状态
- 当前题材：[题材名]
- 结构适配决策表：已存在/未建立
- 需新建池：[列表]
- 需禁用池：[列表]
- 情绪锚体系：通用可用/需重建题材私有索引

### 七、优先级建议
1. **高优先级**：[池名] — [理由]
2. **中优先级**：[池名] — [理由]
3. **低优先级**：[池名] — [理由]
```

# 仿写约束提取指南

> 来源：SKILL.md §"仿写约束提取（新增 — 服务于仿写场景的专项提取）"

写作研究报告中除了通用写作规则，还包含大量关于"当下这个时间点什么能火"的结论。蒸馏时若明确或可推断服务于仿写场景（如用户要求蒸馏"番茄平台同题材新手榜研究"），必须追加以下提取维度。

## 赛道核心模板提取

从研究报告中提取"在当前时间点、该平台、该题材下，什么样的作品最容易过稿/签到/起量"——这部分不是通用写作规则，而是**市场窗口期的具体模板**：

| 提取维度 | 报告中的信号词 | 翻译为约束 |
| --- | --- | --- |
| 当前火的主角类型 | "底层小人物""穿越者""重生者""系统持有者""幕后黑手" | → 人物类型约束（当前窗口推荐） |
| 当前火的金手指模式 | "签到系统""模拟器""进化吞噬""身份反转""幕后操控" | → 金手指模式约束（当前窗口推荐） |
| 当前火的开篇模式 | "灵堂受辱""重生回关键节点""系统激活""大逃杀开局" | → 开篇模式约束（当前窗口推荐） |
| 当前火的节奏模式 | "黄金三章""开头 300 字必须..." | → 开篇节奏约束（硬门禁） |
| 当前正在退热的模式 | "XXX 已经太多""XXX 读者已经审美疲劳" | → 避坑约束（当前窗口不推荐） |
| 当前市场的缺口 | "目前缺少 XXX 类型的新书""XXX 赛道还有空间" | → 差异化机会提示 |

## 差异化空间分析

结合多份研究报告中对"雷同""同质化""审美疲劳""创新点"的反复提及，提取以下信息：

| 维度 | 提取方法 | 产出 |
| --- | --- | --- |
| 已过度开发的套路 | 跨报告统计"同质化""审美疲劳""老套路""烂大街"等负面关键词指向的写法 | → 必须避开的套路清单 |
| 仍有空间的细分方向 | 跨报告统计"新方向""还有空间""值得尝试""少数作者在做"等积极关键词指向的写法 | → 可供选择的差异化方向 |
| 读者分层需求缺口 | 报告中对"老白读者""泛读者""女性读者""年轻读者"等不同群体的需求描述中，未被充分满足的部分 | → 分层读者锚点建议 |

## 类型融合与跨界模式提取

仿写的差异化往往不来自"在已有赛道做得更好"，而来自"把两个不相关的模式融合在一起"。

### 同类型融合模式

当报告显示某赛道已高度同质化时，从报告中提取"同类内差异化"的可行方向：

| 提取维度 | 信号词 | 翻译为约束 |
| --- | --- | --- |
| 元素抽取式融合 | "把 A 作品的 X 设定 + B 作品的 Y 体系整合" | → 推荐的蓝本组合方向 |
| 冲突机制移植 | "把侦探小说的悬疑逻辑嫁接到宫斗文里" | → 推荐的冲突机制方向 |
| 世界观规则统一 | "同时有修仙和科技的世界需要统一的力量法则" | → 世界观设计约束 |

### 跨界融合模式

当报告提及"类型突破""破圈""跨界"等概念时，提取可行的跨界维度：

| 跨界类型 | 在报告中的信号 | 翻译为约束 |
| --- | --- | --- |
| **科幻 + 修真** | "科技修仙""用科学解释灵力" | → 跨界融合方向提示 |
| **悬疑 + 言情** | "推理式恋爱""案件推动关系" | → 跨界融合方向提示 |
| **历史 + 穿越 + 商业** | "回到古代搞经济""古代职场文" | → 跨界融合方向提示 |
| **游戏 + 现实** | "游戏世界影响现实""现实技能在游戏中有用" | → 跨界融合方向提示 |

### 跨界合理性的约束提取（强制）

跨界融合最大的风险是"设定过于离谱"。跨界融合的成功依赖于**内在合理性构建**。因此，从报告提取跨界方向时，必须同时提取以下可行性约束：

| 合理性维度 | 提取方法 | 产出 |
| --- | --- | --- |
| **逻辑支点** | 报告是否建议了某种"合理化包装"？（如"系统流"的合理性支点是"游戏规则入侵现实"） | → 跨界融合的逻辑支点约束 |
| **渐进式引入** | 报告是否建议"不要一开始就暴露全部设定"？渐进揭露的步调是什么？ | → 揭露节奏约束 |
| **情感逻辑底线** | 报告是否强调"无论设定多离奇，情感必须有真实的根基"？ | → 情感真实性硬门禁 |
| **读者认知成本** | 报告中是否估算过读者理解这个跨界设定需要多少章节？ | → 认知成本预警 |

## 素材整合的质量门禁（新增）

从多份报告融合提取"缝"的约束时，以下三条原则所强调的"素材整合硬条件"。提取的每条约束必须通过三问检查：

| 原则 | 检查方式 | 不通过的信号 |
| --- | --- | --- |
| **主题统一** | 融合后的约束是否全部服务于同一个核心主题/核心卖点？ | 约束之间指向不同的读者承诺（如"既要悬疑又要甜宠但两边都没做好"） |
| **风格协调** | 融合后的约束是否存在明显的风格冲突？（如"文笔要求古风典雅"与"节奏要求短视频级快"同时出现） | 两种约束在同一维度上的要求属于不可调和的矛盾 |
| **逻辑自洽** | 不同来源的约束在同一维度上是否指向一致？ | 报告 A 说"前 300 字必须有冲突"，报告 B 说"开篇需要慢热铺垫"——矛盾不可调和时只能二选一，不得同时保留 |

三问全过 → 保留融合。任一问不通过 → 要么淘汰其中一份源，要么标注"冲突：此条为二选一约束，具体执行需用户决策"。

## 产地标注（强制）

所有从报告中提取的"当前火/当前退热/还有空间"类约束，必须在来源字段中标明**报告发布日期**，因为市场窗口期的时间敏感性极高：

| 标记 | 含义 |
| --- | --- |
| `[2026年Q1]` | 该结论基于 2026 年第一季度发布的研究报告 |
| `[2025年]` | 该结论基于 2025 年的报告，时效性已降低 |
| `[时效不明]` | 报告中未明确标注研究时间，仅作参考 |

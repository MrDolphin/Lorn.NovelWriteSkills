# 通用-设计封面生图提示词
> **题材路由**：若 .github\题材专用Skills\ 目录存在对应的 <题材>-设计封面生图提示词 Skill，则：
> - 将题材特性骨架路由到 <题材>-设计封面生图提示词，该 Skill 位于 .github\题材专用Skills\ 目录。
> - 命中本技能时，必须优先强制加载当前 Skill 与 <题材>-设计封面生图提示词。


封面提示词不是堆素材，而是把“这是什么书、卖给谁、视觉第一眼抓什么”说清楚。

## 风格/蓝本/写作研究模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，设计封面生图提示词前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其作为平台展示约束、题材主视觉和禁忌基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其作为封面美术气质和情绪色调的弱参考
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将其作为核心意象、结构卖点、主线承诺和情绪弧参照
5. 本 Skill 只消费与封面视觉相关的字段；若模板字段与平台缩略图识别、文字安全或封面禁行项冲突，平台展示安全优先
6. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断

本 Skill 默认消费字段：

- 写作研究模板：平台展示约束、题材主视觉、读者第一眼情绪、禁忌类约束
- 作者风格模板：整体文风、情绪表达方式、主色调气质、禁忌清单
- 作品蓝本模板：整体叙事策略、核心意象、章首承诺、情感弧分布

## 常见触发词 / 用户说法速查

- 帮我做封面提示词
- 这本书封面该怎么出图
- 给我两套封面生图方案
- 这套提示词只会堆素材
- 帮我做平台展示友好的封面方案

## 何时使用

- 新书需要首版封面提示词。
- 现有提示词只会堆素材，不会控制构图、主体与平台展示。
- 需要对多个风格方向做 A/B 方案比较。

## 默认执行顺序

固定优先级：先保证缩略图环境下的人物 / 题材可识别，再保证情绪命中与视觉母核稳定，最后才处理风格装饰、A/B 变体与落盘结构。

1. 先确定平台缩略图环境、目标读者第一眼感受、允许出现的文字元素，以及封面主标题口径：不分部小说使用小说的目标投放名，分部小说使用对应部的目标投放名。
2. 再读取作品相关材料，锁视觉母核、情绪母核与题材识别核。
3. 再锁主体：人物、物件、地标、光源或危险符号，并判断走人物 / 场景 / 物件 / 关系哪条主线。
4. 再按平台矩阵写构图、色调、风格限制、文字安全约束与禁行元素。
5. 最后产出至少 A/B 两套主提示词、负面提示词、排版说明与默认落盘方案。

## 首屏缩略图补充（新增）

封面判断默认只按以下优先级排序：1）题材可识别；2）主体可识别；3）情绪命中；4）风格装饰与氛围加分。

- 封面方案默认必须先回答三件事：缩略图环境下一眼先看到谁 / 什么、先感到哪种情绪、先认出哪类题材；只剩“好看”但不识别，视为失败。
- 若作品卖点强依赖人物关系、情绪温差或身份对峙，至少一套方案要把这种关系信息压进人物距离、视线、姿态或光影结构里，而不是只堆背景素材。
- 若封面缩略图下主体、标题区与高亮意象互相争抢，默认优先牺牲装饰层，而不是牺牲题材识别与平台点击效率。

## 默认输出口径

- 默认输出至少 A/B 两套可直接交付的封面提示词方案。
- 默认同时给出主提示词、负面提示词、构图说明与平台展示提醒。

## 最低交付

- 至少 2 套有明确差异的主提示词方案。
- 每套都包含负面 / 避坑限制。
- 每套都说明主体、构图、色调、风格、文字层级与缩略图可读性。
- 每套都必须明确本次封面主标题使用的目标投放名，不得把总书名、分部名与平台投放名混写。
- 默认包含可直接落盘的文件命名与交付结构。

## 硬规则

- 禁止封面只好看、不识题材。
- 禁止缩略图环境下主体淹没在花里胡哨背景里。
- 禁止人物脸、手、文字区与标题区相互打架。
- 不分部小说封面主标题统一使用小说的目标投放名；分部小说封面主标题统一使用对应部的目标投放名，不得继续沿用总书名顶替。
- 禁止主提示词把题材词、卖点词、情绪词误写成会被模型抄进画面的额外文字。

## 与其他 Skill / Prompt 的边界

- 本 Skill 负责封面提示词本体与交付结构。
- 不负责书名设计、简介撰写或平台投稿材料组包。

## 平台适配的核心原则

- 平台适配的是“命名形态”，不是简单换词。
- 不同平台的头号推荐，必须尽量拉开主轴与句法区隔。
- **前 3 字钩子原则（跨平台通用）**：无论目标平台是什么，书名前 3 字必须制造"想点开"的冲动。这是注意力经济在书名层的底层规律——读者的阅读习惯是"先扫前几个字再决定是否细看"。若前 3 字是"在一个""很久""那天"等低信息量开头，读者不会给你展示后面的机会。各平台的具体显示长度不同（如番茄推荐页截断严重、起点展示空间较宽裕），但这一原则的约束力不分平台，只有"更严"和"仍然严"的区别。
- **竞对书名分析强制前置（含扫榜与字数分析）**：在任何平台设计书名前，必须先做一次**扫榜**——遍历该平台同题材的新书榜/畅销榜/飙升榜等榜单，采集 Top 10–20 本书名的公式类型、关键词模式、**字数分布**和情绪锚点。**重点统计高人气书名的实际字数**——若其中 20% 以上的书名超过平台"推荐长度"却仍获高点击，说明该赛道读者更看重信息密度和钩子强度，而非字数短。**目的是摸清命名基线，不是抄袭**。不清楚竞对在用什么策略就闭门设计，等价于不看路就开车。
- **字数非质量指标**：书名好坏的核心判据是"能否吸引潜在读者点进来"，不是短。平台字数限制是技术约束（截断风险），不是"越短越好"的审美标准。该长则长，核心信息永远优先于控制字数。**竞对书名字数分析的意义正在于此——用真实数据破除"字越少越好"的执念，而非凭借主观偏好压字数。**

## 默认策略

### 起点中文网

- 推荐长度：2–8 字优先，最长不超过 10 字为佳
- 风格：硬、稳、能装下长线世界观
- 优先结构：长线容器型 / 高概念设定型 / 系列感标题
- 避免：过长叙述句、生活化过头的轻标题

### 番茄小说网

- 推荐长度：4–10 字优先（传统书名）；强叙述型书名可至 16–22 字
- 风格：狠、直、快，但仍需像书名
- 优先结构：单次危机型 / 反常事件型 / 强钩子情绪型
- **前 3 字铁律（通用原则 × 番茄强化）**：番茄推荐页截断尤其严重，是跨平台"前 3 字钩子原则"最极端的验证场景。已验证在该平台有效的强前缀模式：时停起手、退婚当天、开局长生、重生归来、大一实习（来源：知乎专栏"中国网络文学研究"2026年爆款书名分析，番茄/起点双平台数据验证。置信度：高）
- **16–22 字黄金长度**：番茄信息流中 16–22 字是展示最完整的范围，太长则信息被截断。但对于传统书名字数以 12 字内为佳，16–22 字适用于正文标题式或强叙述型书名（同上来源。置信度：高）
- **书名改写 ROI 数据**：番茄官方数据证实，仅改写书名就能带来最高 40% 的阅读量差异（同上来源。置信度：高）
- 避免：像短视频标题、像一句故事文案的长句

### 七猫免费小说

- 推荐长度：4–12 字优先，14 字以内书架显示完整不截断；建议首屏可读、停顿少、最好一眼能念顺
- 风格：直给、易懂、情绪抓手强、首屏可读，但仍需保留书名感
- 优先结构：现实问题型 / 危机事件型 / 逆袭入口型
- 加分方向：问题清楚、危机清楚、情绪清楚，读者第一眼能快速判断“这本书讲什么、劲往哪儿使”
- 避免：过分留白、纯抽象、第一眼读不懂冲突或卖点、像文艺副标题而不像网文书名

### 豆瓣阅读

- 推荐长度：3–8 字优先
- 风格：克制、冷、可复义
- 优先结构：意象型 / 人性命题型 / 现实悬念型
- 避免：爽文口吻、喊话式书名、过度营销感

### 知乎盐选

- 推荐长度：8–18 字可接受
- 风格：强冲突、强动作、强人称代入
- 优先结构：第一人称叙述型 / 职业口述型 / 冲突动作型
- 避免：空泛命题句、太像论文题目

### 传统出版社

- 推荐长度：2–8 字优先
- 风格：准确、克制、出版面孔稳定
- 优先结构：象征型 / 现实悬疑型 / 长销型标题
- 避免：网络腔、过度喊口号、太像章节名

### 微信订阅号

- 推荐长度：2–8 字优先；少量可做传播型副方案
- 风格：短、能转发、能引讨论
- 优先结构：社交话题型 / 日常反常型 / 情绪转发型
- 避免：纯抒情、纯抽象、太长太绕

### 百度百家号

- 推荐长度：4–10 字优先
- 风格：现实入口清楚、职业锚点明确、异常点一眼能懂
- 优先结构：搜索词 + 冲突型 / 职业 + 事件型 / 问题切口型
- 避免：过分留白、太文艺、读者第一眼看不出在讲什么

### 小红书

- 推荐长度：4–10 字优先；少量可到 12 字
- 风格：情绪感强、日常感强、异常切口清楚
- 优先结构：情绪冲突型 / 日常反差型 / 体感异常型
- 避免：过硬设定、过技术、像男频长线母题而不是点开入口

### B站

- 推荐长度：4–9 字优先；少量可做 10–12 字反差型标题
- 风格：画面感、反差感、年轻感，但必须仍像书名
- 优先结构：画面名场面型 / 反差型 / 可讨论型
- 避免：纯梗标题、过于二创化、像视频标题而不像书名

### 新浪微博

- 推荐长度：4–10 字优先
- 风格：切口短、现场感强、适合社交传播
- 优先结构：短促现场型 / 热点切口型 / 关系危机型
- 避免：太长、太绕、太像长篇总纲标题

### 纵横中文网

- 推荐长度：3–9 字优先
- 风格：中等节奏、现实锚点、克制悬念
- 优先结构：现实压力型 / 证据异常型 / 人性命题型
- 避免：短视频标题感、强刺激喊话腔、过分文艺留白

### 今日头条

- 推荐长度：4–10 字优先，少量可到 12 字
- 风格：开篇钩子密集、现场感强、互动驱动感
- 优先结构：开篇钩子型 / 反转悬念型 / 话题讨论型 / 群像冲突型
- 加分方向：第一眼能看出"问题是什么""冲突在哪儿"、有多解读空间、易引发评论讨论、符合规则怪谈/中式悬疑美学
- 避免：过分抽象、没有具体指向、容易被淹没在信息流里的雷同感标题

### WebNovel

- 推荐长度：2–6 个实词为佳
- 风格：高概念清楚、剧情入口明确
- 优先结构：高概念型 / 普适危机型 / 跨文化易译型
- **已验证标题公式**（来源：`都市职场/写作研究/Webnovel 平台都市职场爽文受欢迎文笔风格与代入感增强机制深度研究报告.md`）：
  - 男频：「system（系统）+ rise（崛起）+ 核心身份」模板（如《The Supreme System: Rise of the Sales Manager》）
  - 女频：「emotion（情感）+ revenge（复仇）」模板（如《Revenge of the Fired Secretary》）
  - 核心逻辑：用全球读者熟悉的通用关键词，快速传递作品的核心爽点
- 避免：难译文化专名过多、抽象命题过重

### MyFiction

- 推荐长度：3–8 个词
- 风格：人物秘密、关系裂痕、非对称信息
- 优先结构：关系秘密型 / 日常反常型 / 情感动机型
- **已验证标题公式**（来源：`都市职场/写作研究/MyFiction 平台互联网裁员维权题材长篇小说写作指导.md`）：
  - 标题必须包含题材核心关键词 + 专业元素（如《被 AI 裁员后，我用 Git 记录赢了 2N 赔偿》）
  - 搜索点击率比普通标题高 32%
  - 核心逻辑：让标题在平台搜索中可被精准命中
- 避免：冷冰冰纯设定书名

### GoodNovel

- 推荐长度：4–9 个词
- 风格：情绪、命定、人物危险感更强
- 优先结构：危险关系型 / 情绪命运型 / 普适超自然型
- **已验证标题公式**（来源：`都市职场/写作研究/Goodnovel 平台都市职场爽文受欢迎文笔风格与代入感增强机制深度研究报告.md`）：
  - 统一采用「情感关键词 + 职场身份」模板（如《Billionaire's Office Romance》《CEO's Forgotten Lover》）
  - 核心逻辑：用全球读者熟悉的关键词组合，快速传递作品的核心情感爽点
- 避免：过冷、过技术、过学术

## 扫榜书名快速分类法（新增 — 用于竞对扫榜阶段快速分析）

对新手榜 / 新书榜 / 畅销榜上的书名进行快速分类和有效性判断：

### 两种基本型

| 类型 | 特征 | 示例风格 | 适用场景 |
| --- | --- | --- | --- |
| **通俗直白型** | 直接嵌入核心关键词，读者一眼就能归类 | 《我的功法全靠捡》《洪荒：开局成为混沌魔猿》 | 新人优先推荐——降低读者归类成本，降低"不知道这是啥书"的流失 |
| **文艺气质型** | 不直接透露关键词，靠意境/口碑吸引点击 | 《赤心巡天》《诡秘之主》 | 适合已有读者基础的作者，或已有同系列热度的续作 |

### 核心关键词嵌入检测

书名中是否包含以下至少一项：

- **题材热词**：御兽、洪荒、霸总、穿书、重生、系统、末世、规则怪谈等
- **动作指令**：捡到、签到、绑定、开局、从 X 开始、我在 XX
- **身份标签**：魔尊、大佬、炮灰、赘婿、废柴、神医、冥王等
- **冲突暗示**：逆袭、复仇、攻略、求生、逃离、对抗、潜入

> 通俗直白型的书名若同时嵌入 1-2 个核心热词 + 一个动作/身份标签，通常就能在新手榜上获得最低限度的"一眼归类"流量。新人默认优先推荐此路线。

# 网文留存模型——共享量化基线

> 本文件定义网文场景下"读者留存"的核心概念、量化指标、平台差异基线，以及各 Skill 阶段（设计/创作/润色/审阅）对留存的责任矩阵。
> 被 `通用-审阅章节正文`、`通用-审阅总大纲`、`通用-审阅分卷大纲`、`通用-大纲审阅优化闭环`、`通用-设计总大纲`、`通用-设计分卷大纲`、`通用-生成章节控制卡`、`通用-创建小说正文`、`通用-正文润色`、`通用-去AI味重写`、`通用-章节创作闭环` 等 Skill 引用。

## 一、核心概念

### 1.1 什么是"留存"

留存不是"好不好看"，是**读者在每 30-60 秒的隐性续读决策中，持续选择"继续看"的能力**。

每个网文读者在阅读时都在做这个决策：

```text
当前阅读 → "我刚刚得到了什么？"
    ↓
得到 ≥ 预期 → 继续读（循环）
得到 < 预期 → 退出/分心（可能永久流失）
```

**关键洞察**：
- "得到"不是"质量"——读者感知到的"得到"是可感知的情绪波动（爽/虐/甜/悬/揪心），不是"这段描写很精准"
- 预期是动态的——连续几章的回报类型相同，阈值会越抬越高，同量回报不再满足
- 退出决策是渐进累积的——不是一次"不好看"就弃书，而是连续几次"也就这样吧"的累积效应

### 1.2 "技法质量"与"留存力"的关系

| 技法表现 | 对留存力的影响 |
| ------ | ------ |
| 叙事逻辑严谨 | 必要条件（逻辑崩坏必弃），但不驱动追读 |
| 人物一致性高 | 必要条件（OOC会劝退），但不单独驱动追读 |
| 描写质量高 | 可能**降低**留存（过量描写拖慢节奏） |
| 去AI味做得好 | 减少廉价感，非追读动力 |
| 节奏与张力管理好 | **直接影响留存** |
| 钩子与悬念设计好 | **核心驱动力** |
| 中段回报充足 | **核心驱动力** |

### 1.3 留存评分的基本原则

**技法从满分起扣，留存从及格线起加**：

- 技法评分假设完美，逐项减分（"这里写得不够好→扣分"）
- 留存评分假设读者一无所有地进来，每得到一次回报加一次分（"读者赚到了→加分"）

## 二、量化指标

| 指标名 | 定义 | 测量方式 | 章节级基准 | 卷级基准 |
| ------ | ------ | ------ | ------ | ------ |
| **情绪刺激密度** | 每多少字出现一次可感知的情绪波动 | 人工标记情绪转变点 / 第几个场景切换 | ≥1次/500字（七猫/免费平台）；≥1次/800字（起点/付费平台） | 每卷≥8次高强度刺激点 |
| **回报间隔** | 两次可感知的中段回报之间隔了多少字/章 | 标记每章中段回报位置，计算间距 | ≤3章（最长容忍上限）；≤1章（免费平台期望值） | 连续≤3章低回报=失温预警 |
| **追读驱动力** | 章末钩子让读者"非翻不可"的强度 | 1-5分主观评分 | ≥3分（及格）；≥4分（期望值） | 卷末钩子必须≥4分 |
| **认知负荷** | 单位篇幅内读者需要处理的信息量 | 标记内部处理段（回忆/推理/独白/设定说明）连续长度 | 连续≤300字；若>300字必须有外部打断 | — |
| **情绪多样性** | 最近N章的情绪底色变化频率 | 标记每章主要情绪底色（爽/虐/甜/悬/揪心/平） | 连续≥3章同一底色=单调预警 | 同期≥2种底色交替 |
| **主角主动性指数** | 主角主动出击 vs 被动反应的章节比例 | 标记每章主角行为模式：主动/被动/混合 | 主动或混合章占比≥60% | 连续≥3章纯被动=危急 |

## 三、平台留存基线差异

### 3.1 情绪刺激密度基线

| 平台类型 | 最低要求 | 期望值 | 警戒线 |
| ------ | ------ | ------ | ------ |
| 七猫/番茄等免费平台 | 每章≥2次 | 每500字≥1次 | 连续500字无任何情绪刺激 |
| 起点/纵横等付费平台 | 每章≥1次 | 每800字≥1次 | 连续3章有一章完全无刺激 |
| 出版社/豆瓣/IP向 | 每章≥0.5次 | 每1500字≥1次（允许长铺垫） | 连续5章无情绪高潮 |
| 知乎盐选 | 每章≥1次 | 每1000字≥1次 | 连续3章无刺激 |

### 3.2 回报间隔基线

| 平台类型 | 最小频率 | 期望间隔 | 失温阈值 |
| ------ | ------ | ------ | ------ |
| 七猫/番茄 | 每章至少1次 | 1章1次 | ≥2章无回报 |
| 起点/纵横 | 每3章至少1次 | 每2章1次 | ≥4章无回报 |
| 出版社/豆瓣 | 每5章至少1次 | 每3章1次 | ≥7章无回报 |
| 知乎盐选 | 每2章至少1次 | 每1.5章1次 | ≥3章无回报 |

### 3.3 主角主动性基线

| 平台类型 | 主动章占比 | 纯被动容忍上限 |
| ------ | ------ | ------ |
| 七猫/番茄 | ≥70% | 连续2章 |
| 起点/纵横 | ≥50% | 连续4章（蓄力期允许） |
| 出版社/豆瓣 | ≥40% | 连续6章（人物弧允许慢热） |
| 知乎盐选 | ≥60% | 连续3章 |

### 3.4 认知负荷容忍度

| 平台类型 | 内部处理段上限 | 说明 |
| ------ | ------ | ------ |
| 七猫/番茄 | ≤150字 | 必须极其压缩，读者耐心极低 |
| 起点/纵横 | ≤400字 | 可接受适度回忆/推理，但必须有外部打断 |
| 出版社/豆瓣 | ≤800字 | 可接受大段内心戏 |
| 知乎盐选 | ≤500字 | 可接受，但需与情节穿插 |

## 四、留存责任矩阵

每个 Skill 阶段对留存产出有不同职责。审阅阶段的留存评分发现问题时，按此矩阵判断应回溯到哪一阶段修复。

| 阶段 | 留存职责 | 典型留存问题 | 回溯目标 |
| ------ | ------ | ------ | ------ |
| **设计中** | 将留存目标嵌入结构：卷级回报间隔、情绪交替规划、主角主动性保障 | 连续多章低回报、情绪单一、主角长期被动 | —（上游问题） |
| **控制卡** | 将留存目标翻译为施工命令：标注本章唯一的"读者赚到了"时刻、情绪曲线布点 | 本章无明确回报位、钩子类型与上章重复 | 回到控制卡 |
| **创作** | 执行控制卡的留存指令：四拍闭环、认知负荷管控、情绪刺激密度落地 | 中段无回报、内部处理段过长、情绪平 | 回到创作 |
| **润色** | 优化而不削弱留存：修"读者会弃"的问题优先、去味后情绪密度不降、强化开头/钩子 | 润色后情绪刺激点被压缩、强化后仍无驱动力 | 回到润色或回创作 |
| **审阅** | 测量留存质量、标记具体问题、给出留存回炉方向 | 双轴审阅中留存分<6.0 | 按问题类型分流 |

### 回炉分流规则

审阅发现留存问题（留存分<6.0）后，按以下规则决定回炉到哪一阶段：

```
IF 问题类型 = "无中段回报" → 回控制卡（没规划）或创作（规划了没执行）
IF 问题类型 = "章末无驱动力" → 回创作（未设计钩子）或润色（钩子太弱但可强化）
IF 问题类型 = "情绪单一" → 回设计（总纲/分卷未规划情绪交替）
IF 问题类型 = "认知负荷超标" → 回创作（内部处理段未拆分）
IF 问题类型 = "主角长期被动" → 回设计（分卷/总纲未保障主角主动性）
IF 问题类型 = "信息过载" → 回创作（信息投放方式未按留存模型执行）
```

## 五、留存评分标准（通用）

### 5.1 情绪刺激密度评分（1-5分）

| 分值 | 标准 |

| 5 | 每300字以内即有可感知情绪波动，且情绪类型交替丰富 |
| 4 | 每500字以内有情绪波动，至少有2种情绪底色交替 |
| 3 | 每章内至少1次可感知情绪高峰，但可能有连续字窗无波动 |
| 2 | 本章情绪波动微弱或单一底色贯穿全章 |
| 1 | 全章无任何可感知情绪波动（纯信息/纯平铺） |

### 5.2 追读驱动力评分（1-5分）

| 分值 | 标准 |

| 5 | 章末钩子具有"不翻不行"的强制力（悬念+情绪+信息缺口三重叠加） |
| 4 | 章末有明确缺口（悬念/威胁/未完成决策），读者主动想翻页 |
| 3 | 章末有钩子但为轻度悬念/常规断点，读者可翻可不翻 |
| 2 | 章末只是剧情自然分段，无刻意钩子设计 |
| 1 | 章末平收，读者没有继续看的动力 |

### 5.3 留存红灯通用清单

以下每项命中即记1红灯。≥2项红灯 = 留存风险，不得以技法评分放行。

- [ ] **连续平路 ≥ 3章**：最近连续3章中段回报强度全部为"低"
- [ ] **信息过载段**：本章中段出现连续>300字无外部打断的内部处理（回忆/推理/独白/设定说明）
- [ ] **主角被动窗口**：主角连续3章以上只有防卫/应对，无主动选择/出击
- [ ] **主线失焦**：主卖点/核心冲突连续5章以上未被有效触碰
- [ ] **情绪单一化**：最近5章所有场景使用同一情绪底色
- [ ] **章节功能位缺失**：本章既无钩子、无回报、也无推进（"三无章"）
- [ ] **认知负荷超标**：本章同时推进≥3条独立线索，无一条获得主导篇幅

### 5.4 平台特化红灯

**【七猫/番茄等免费平台专用】**
- [ ] **情绪刺激间隔超标**：最近3章中任何一章出现连续500字无情绪刺激
- [ ] **开篇钩子延迟**：本章前200字未抛出明确冲突/异常/压力信号
- [ ] **爽点兑现不足**：最近5章中≥3章无可指认的"赚到了"时刻

**【起点/纵横等付费平台专用】**
- [ ] **追读链断裂**：本章未响应上章出口钩，或未留下可信的下章入口
- [ ] **中长期期待透支**：最近10章只有短期事件，无推进中长期目标的信号
- [ ] **本章说/讨论点缺失**：最近5章无可讨论、可争议、可截图的内容

**【出版社/豆瓣/IP向专用】**
- [ ] **结构松散**：章节缺乏明确的主题统一性或情感弧线
- [ ] **密度不均衡**：场景转换过密或过疏，影响沉浸感

## 七、常见误判与纠偏

| 误判 | 正确的留存视角 |
| ------ | ------ |
| "这章写得真细腻" | 细腻≠留存——检查情绪刺激密度是否达标 |
| "人物一致性做得很好" | 不OOC是底线，不是加分项——检查读者有没有因此更想追 |
| "叙事逻辑滴水不漏" | 读者不在意逻辑是否完美——只在意"接下来会发生什么" |
| "去味做得不错，不像AI写的" | 去味是基本功——检查去味后情绪主轴是否仍在 |
| "这章场景规划执行到位" | 场景执行到位≠读者有收获——检查中段是否给了回报 |
| "问题不大，整体还行" | "还行"是最危险的审阅结论——逐项检查留存红灯 |
| "这章去味做得很干净" | 过度去味可能导致"太顺=看完即忘"——检查是否有作者个人印记和有意留白 |
| "逻辑滴水不漏" | 过度逻辑严密可能导致可预测性过剩——读者不需要亲自追 |

## 八、动词密度留存基线（新增）

> 网文留存的最小可测量单元是动词密度——动词驱动读者脑中画面生成。来自顾里木图"动词是爽文的发动机"方法论。动词密度 = 核心动作动词数 / 总实词数（排除"是""有""在""想""知道"等非动作动词）。

### 场景类型动词密度基准

| 场景类型 | 最低要求 | 期望值 | 危险信号 |
| -------- | -------- | ------ | -------- |
| 动作/冲突场景 | 动词占比≥50% | ≥60% | "感到""觉得""知道"等感知词替代了动作描写 |
| 叙述推进场景 | 动词占比≥40% | ≥50% | 连续出现"是""有""存在"等静态动词 |
| 情绪高潮场景 | 用躯体化动作替代情绪形容词 | 不出现"他很X"句式 | "他非常生气""她感到悲伤"等抽象情绪宣布 |
| 对话推进场景 | 对话中含动作提示+潜台词 | 动作标签与纯"说"/"道"标签交替 | 连续3段以上纯"说"/"道" |
| 日常铺垫场景 | 动词占比≥30% | ≥35% | 超过200字无任何核心动作动词 |

### 动词密度检查方式

1. **冲突段抽样**：选取本章冲突最核心的段落（约200-300字），标记动词密度是否达标
2. **形容词密度预警**：如果一段话中形容词/副词/抽象名词的数量超过动词数量，标记为"形容词替动词"风险
3. **"站着想清楚"模式检测**：是否存在"主角站在安静环境下把事想明白了再去行动"的模式——如果有，标记为动词中断风险

## 九、"恰到好处"阈值表——死亡交叉预警（新增）

> 技法各维度在留存视角下呈现**倒U型曲线**——中等水平对留存最有利，超过临界点后每增加一分技法质量，留存反而下降一分。本节标记每个技法维度的留存友好区间和过度预警信号。

### 技法维度阈值

| 技法维度 | 留存友好区间 | 过度预警信号 | 审阅处理 |
| -------- | ---------- | ----------- | -------- |
| 去AI味/流畅度 | 自然流畅但有个人印记（约3-4分） | 全篇找不到一个瑕疵，"像出厂设置一样" | 标记"过度去味"风险 |
| 逻辑严密性 | 主线清楚、关键逻辑通顺，局部留白（约3-4分） | 每个细节都有解释，所有漏洞都被填平 | 标记"确定性过剩"风险 |
| 描写质量 | 关键场景细腻，其余部分克制（约3分） | 每段都想"写得美"，动词密度持续走低 | 标记"动词密度不足"风险 |
| 结构完整度 | 主结构清晰，但允许意外和调节奏偏离（约3-4分） | 起承转合过于规整，读者30%处即可预测结局 | 标记"可预测性过剩"风险 |
| 人物一致性 | 核心特质稳定，但行为有惊喜和意外（约3-4分） | 人物行为完全可预测，从不做"出乎意料但在情理中"的事 | 标记"人物可预测"风险 |

### 死亡交叉处理规则

- 上述5个维度中**≥2项**触发过度预警 → 即使技法分≥7.0，留存评分自动扣1分
- **≥4项**触发过度预警 → 自动触发Yellow判定，标记为"技法超限综合征"

## 十、审阅读者模型（新增）

> 执行审阅前，审阅者必须完成读者模型切换——从"文学评论家/鉴赏者"切换到"手机端注意力经济中的逐帧决策者"。

### 读者模型定义

```text
【审阅读者模型】
- 阅读场景：手机端，碎片时间（通勤/排队/睡前/摸鱼）
- 心理状态：随时可能被抖音15秒爽点、短剧1分钟反转、微信红点打断
- 决策周期：每200字做一次"继续看还是划走"的隐性决策
- 底层需求排序：画面感（动词驱动大脑生成电影）> 参与感（不确定性驱动追读）> 获得感（情绪回报驱动继续）
- 竞争对手：不是其他小说，是所有争夺注意力的介质
```

### 模型应用规则

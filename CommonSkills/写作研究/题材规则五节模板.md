# 题材规则文件标准模板（五节结构）

> 本模板定义了本仓库所有题材 Skill 中题材规则文件的标准结构。
> 来源：吸收 InkOS 15 个题材规则文件的统一结构（Narcooo/inkos/packages/core/genres/）
>
> 适用范围：所有 `设计题材定位框架/references/` 目录下的题材规则文件
> 必须遵守：新建或重写题材规则文件时，必须按此五节结构组织

## 文件头

每个题材规则文件开头必须包含：

```markdown
# 题材边界与入口说明（<题材名>）

> 格式：题材禁忌 → 专项规则 → 语言铁律 → 叙事指导 → 节奏参考
> 此为标准题材规则五节模板，所有题材的边界与入口说明均按此结构组织。
```

## 五节结构定义

### 1. 题材禁忌

该题材"不能做什么"的清单。包含：

- **核心矛盾**：该题材最容易踩的坑、最容易让读者流失的方向
- **风格/口径污染**：禁止混入其他题材的描写方式（如都市悬疑禁止纯刑侦化）
- **设定红线**：哪些设定在该题材中会被读者视为不可接受的违规

格式：每条禁忌以 ``-`` 加空格开头，用具体、可执行的否定句式（禁止/不能/不得）。

### 2. 专项规则

该题材特有的规则体系。包含：

- **定位硬口径**：该题材的入口判断标准、定位检查点
- **最低闭环条件**：至少满足哪些条件才算该题材的合格开篇/立项
- **特殊机制**（如有）：数值规则、修炼规则、科技一致性规则等题材专项规则

格式：按需求分小节，使用 `###` 子标题。规则必须是可执行的检查项，而非模糊建议。

### 3. 语言铁律

该题材的语言禁区与描写风格约束。包含：

- **必改句式**：该题材禁止使用的高频套话/模板句，并提供替换方向
- **禁止的叙述方式**：上帝视角分析段、内心独白过度等
- **特有风格要求**：口语化、体感传达、专业术语正确性等

格式：使用对比示例（✗错误 ✓正确）呈现，确保可执行。

### 4. 叙事指导

该题材的叙事重心与结构建议。包含：

- **核心驱动力**：一句话定义读者追读该题材的核心动力
- **叙事模式**：单线/双线、信息释放模式、谜团推进方式
- **差异化空间**：该题材的"反套路"可能性和题材融合方向

格式：要点式列表，每条说明"为什么这样做"和"怎么做"。

### 5. 节奏参考

该题材的节奏基线。包含：

- **反馈周期**：每多少章有一次明确回报
- **各阶段节奏**：开篇/中段/后期各阶段的节奏特征
- **特殊节奏模式**：单元案节奏、修炼节奏、博弈节奏等题材特有模式

格式：量化的节奏说明（"每2-3章一个小回报""三章内必有明确反馈"），避免模糊表述。

## 文件命名

- 标准规则文件：`题材边界与入口说明.md`
- InkOS 衍生文件：`InkOS<题材>题材规则.md`
- 疲劳词表：`题材疲劳词表.md`

## 跨文件协作

| 文件 | 定位 | 与五节模板的关系 |
| --- | --- | --- |
| `题材边界与入口说明.md` | 题材规则的主要承载体，**必须**使用五节模板 | 核心 |
| `InkOS*题材规则.md` | InkOS 衍生规则补充，可选使用五节模板 | 补充源 |
| `题材疲劳词表.md` | 疲劳词独立维护，与五节模板互补 | 独立 |
| `*定位与项目裁判源.md` | 项目级裁判规则，也可使用五节模板 | 可选 |

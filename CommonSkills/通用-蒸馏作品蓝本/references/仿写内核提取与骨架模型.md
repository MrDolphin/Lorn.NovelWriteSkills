# 仿写内核提取与骨架模型

> 来源：SKILL.md §"仿写内核提取" + §"四大骨架模型" + §"微模板提取法"

## 仿写内核提取

### 内核三问

| 问题 | 含义 | 提取方法 |
| --- | --- | --- |
| **这部作品的"核心爽感引擎"是什么？** | 读者读完每一章后最强烈的情绪回报是什么？ | 跨维度交叉推断：章末钩子类型 + 中段回报类型 + 情感弧分布 |
| **金手指/驱动力与主线的绑定模式是什么？** | 金手指不是"有什么能力"，而是"这个能力如何每时每刻都在制造新冲突或新选择" | 从回报指纹 + 事件驱动方式 + 跨卷节拍迁移 |
| **跨卷问题链如何移位？** | 第一卷追什么、第二卷变成什么、第三卷变成什么 | 从叙事本能 + 核心驱动问题链 + 跨卷节拍迁移 |

### 可迁移性四维评估

| 维度 | 评估标准 | 标记 |
| --- | --- | --- |
| **题材绑定度** | 这个内核是否必须依赖特定题材设定才能运转？ | `通用可迁移` / `题材半绑定` / `强绑定` |
| **文风依赖度** | 是否需要特定文笔风格才能生效？ | `文风自由` / `特定文风` |
| **作者存量依赖度** | 是否依赖该作者的存量读者或平台基础量？ | `作者独立` / `部分依赖存量` / `高度依赖存量` |
| **发布时间窗口** | 是否与发布时间窗口高度相关？ | `持续有效` / `窗口收窄` / `窗口关闭` |

### 改写深度分层——"换/缝/乱"三级框架

| 层次 | 含义 | 仿写时的操作 |
| --- | --- | --- |
| **表层改写（换）** | 替换人物名称、环境名称、情节细节等外在元素 | 换掉名称，保留功能角色和事件骨架 |
| **中层改写（缝）** | 调整叙事结构、人物关系、情节逻辑，融合多源素材 | 保留结构规律和关系模型，换矛盾类型和世界设定 |
| **深层改写（乱）** | 转换世界观架构、价值观念、核心主题，跨界融合 | 保留引擎驱动原理，换整个世界的"物理法则" |

### 从仿写到原创的演化路径

| 阶段 | 蓝本依赖度 | 原创占比 |
| --- | --- | --- |
| 阶段 1：表层仿写 | 高度依赖 | ~20% |
| 阶段 2：结构重组 | 中度依赖 | ~50% |
| 阶段 3：引擎迁移 | 轻度依赖 | ~80% |
| 阶段 4：独立原创 | 零依赖 | 100% |

## 四大骨架模型（短篇/文学性作品轻量蒸馏）

| 骨架模型 | 结构序列 | 适用文体 |
| --- | --- | --- |
| **① 景入情式** | 眼前景物 → 触发回忆/思绪 → 轻轻感慨 → 收束留白 | 散文、氛围章、抒情章开头 |
| **② 小事悟理式** | 微小日常事件 → 细节放大 → 情绪转折 → 淡淡升华 | 记叙文、随笔、日常过渡章 |
| **③ 时空对照式** | 当下平淡场景 → 插入过去片段 → 今昔对比 → 释然/怅然收尾 | 回忆章、人物背景章 |
| **④ 物我共生式** | 写外物状态 → 映射内心状态 → 不直白说情绪，借物抒情 | 文艺抒情章、情绪高潮前蓄力章 |

**使用规则**：当蒸馏对象为短篇或单章（字数 < 1 万字）时允许以骨架模型替代完整 13 维度统计。字数 > 3 万字或章节数 > 15 章时回退全量蒸馏。

## 微模板提取法

| 抽象层级 | 覆盖范围 | 示例 |
| --- | --- | --- |
| **骨架模型** | 整篇文章/整章 | "景入情式：景物 → 回忆 → 感慨 → 留白" |
| **微模板** | 一个关键段落/句子集群 | "特定场景 + 触发回忆 + 遗憾情绪 + 借景物收纳心事" |
| **词域** | 词汇层面 | "词域 = 旧物/时光/温度" |

每个微模板以"公式"形式记录，推荐同时给出"蒸馏提纯→仿写重生"三行直观对照。

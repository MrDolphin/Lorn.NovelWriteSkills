# 多蓝本协同蒸馏策略与执行流程

> 来源：SKILL.md §"多蓝本协同蒸馏策略（新增）" + §"执行流程"

## 多蓝本协同蒸馏策略

### 何时使用多蓝本模式

| 场景 | 说明 | 建议蓝本数量 |
| --- | --- | --- |
| **同赛道取长** | A 章首抓力强、B 钩子轮换好、C 中段回报密 | 2–4 |
| **跨赛道杂交** | 将不同赛道的成功结构移植到目标题材 | 2–3 |
| **结构覆盖补全** | 单部蓝本卷段不全，用同作者另一部补全 | 2 |
| **求最大公约数** | 多部同赛道爆款的共性规律 | 3–5 |

### 三种协同策略

#### 策略 A：主辅法（推荐首用）

选定一部蓝本作为"主蓝本"（结构骨架基座），其余 1–3 部作为"辅蓝本"（只在特定维度上覆盖或替换）。

#### 策略 B：分域法（维度级分工）

不设主蓝本，按维度域将各部蓝本分别蒸馏，合并为一份综合蓝本。

#### 策略 C：交集法（共性优先）

对多部蓝本的同一维度分别统计，提取"多数成立"的共性规律。

### 多蓝本冲突仲裁

| 冲突类型 | 处理方法 |
| --- | --- |
| **数值冲突**（A 钩子间隔 2 章，B 4 章） | 以更符合目标平台的值为准，注明理由 |
| **方向冲突**（A 对话切入为主，B 悬念前置为主） | 以与目标题材更接近的蓝本为准 |
| **结构冲突**（A 单 POV，B 多 POV） | 分域建议：XX 章节用单 POV、YY 章节用多 POV |
| **套路冲突**（A、B 使用互斥的套路组合） | 以主赛道套路组合为准 |

### 综合蓝本产出命名

- 主辅法：`[主蓝本名]-[辅蓝本名]-综合`
- 分域法：`[主赛道名]-[目标题材]-综合`
- 交集法：`[赛道名]-共性综合`

## 执行流程概要

| Phase | 步骤 | 关键闸门/硬规则 |
| --- | --- | --- |
| **Phase 0** | 需求澄清 | 确认作品名、章节范围（默认前100章或全本）、聚焦维度、平台标注、套路蒸馏开关 |
| **Phase 0.5** | 创建蒸馏档案包 | 必须创建 `[作品名]-作品蓝本档案/`；仅有目录无正文只能产出"目录级低置信蓝本" |
| **Phase 1** | 信息采集 | 按优先级采集 13 维度 + 套路指纹；信息源黑名单：知乎、微信公众号、百度百科 |
| **Phase 1.5** | 故事线识别 | 逐章标注叙事问题 → 三问过滤 → 四色标记 → 起始终止映射（详见 `references/故事线识别阶段（Phase 1.5）.md`） |
| **Phase 2** | 统计与提炼 | 按模板逐项填充；追加套路提取 → 跨卷复现验证 → 神似层提炼 → 叙事矛盾弧 |
| **Phase 2.5** | 提炼确认 | 输出结构摘要（核心指纹/量化字段/低置信字段/套路摘要/神似层摘要），用户确认后方可进入 Phase 3 |
| **Phase 3** | 产出与注册 | 生成模板 `.md` → 写入 `蒸馏产物/` → `Agents.md` 注册 |
| **Phase 4** | 质量验证 | 四项验证：留出章节回测、位置预测测试、反抄袭检查、遗失章节测试 |
| **Phase 5** | 双 Agent 精炼 | Agent A：结构可执行性审阅；Agent B：原创边界审阅 |

### 跨卷节拍迁移追踪

长篇作品（100+ 章）必须显式追踪：
1. **节拍阶段划分**：将全篇按节奏模式分为 2-4 个阶段
2. **阶段边界标注**：精确到章节号
3. **逐阶段统计**：每个阶段独立统计关键维度
4. **迁移模式总结**：一句话概括节拍迁移方向
5. **迁移边界检查**：节拍迁移处是否伴随卷级换段/世界观扩展/主角身份质变

### 与专业总纲五维框架的对齐

| 专业维度 | 蓝本中的对应证据 |
| --- | --- |
| **开篇设计** | 前 3 章的章首模式+钩子+回报统计 |
| **节拍密度** | 章节功能位密度+中段回报指纹+钩子指纹 |
| **矛盾四层** | 外部/内部/关系/主题冲突的出场频率与交织模式 |
| **人物设计** | 人物出场节拍+情感弧分布 |
| **商业思维** | 章末钩子指纹+中段回报指纹+场景-续景节拍 |

### 更新已有作品蓝本模板

增量更新：只对新增章节或用户指出的不准维度做增量采样。对比新旧结论时：新样本强化旧规律 → 补来源；新样本推翻 → 标注"阶段性节奏变化"；新样本只特定卷段成立 → 写成"卷段局部规律"。

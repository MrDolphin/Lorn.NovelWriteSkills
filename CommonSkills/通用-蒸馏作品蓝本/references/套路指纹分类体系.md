# 套路指纹分类体系

> 来源：SKILL.md §"套路指纹"

## 四级分类体系

### 第一级：核心设定类 — 故事的"初始配置"

| 套路 | 定义 | 读者预期 | 常见题材域 |
| --- | --- | --- | --- |
| 穿越 | 主角从现代/异界穿越到目标世界 | 信息差优势 + 现代知识降维打击 | 古言、历史、奇幻 |
| 重生 | 主角死后回到过去重活一次 | 预知未来 + 弥补遗憾 + 复仇 | 都市、言情、修仙 |
| 系统 | 主角获得游戏化辅助系统 | 数据化成长 + 任务驱动 | 全题材 |
| 穿书 | 主角穿越进一本小说中 | 预知剧情 + 改变命运 | 女频言情 |
| 日常/现实 | 无超自然设定，聚焦现实 | 真实感 + 代入感 | 都市、职场 |

### 第二级：人物关系类 — 角色之间的配置张力

| 套路 | 核心关系张力 | 典型事件链 | 主要题材域 |
| --- | --- | --- | --- |
| 先婚后爱 | 婚约已存在但无感情 | 被迫成婚 → 磨合 → 产生真感情 | 女频古言/现言 |
| 追妻火葬场 | 一方辜负后追悔 | 付出 → 被辜负 → 临界事件 → 离开 → 追回 | 女频言情 |
| 替身文学 | 一方被当作他人替身 | 被替代 → 发现真相 → 身份觉醒 | 女频言情 |
| 白月光/朱砂痣 | 心中有个无法替代的人 | 比较 → 伤害 → 白月光塌房/释然 | 女频言情 |
| 破镜重圆 | 分离后重逢 | 分手/离婚 → 各自成长 → 重逢 | 女频言情 |
| 师徒恋 | 师生关系中的禁忌感 | 授业 → 依赖 → 越界 → 立场冲突 | 仙侠、玄幻 |
| 带球跑 | 怀孕后离开男方 | 怀孕 → 隐藏/离开 → 重逢 | 女频现言 |
| 契约婚姻 | 假结婚各取所需 | 签契约 → 假夫妻 → 真感情 | 女频现言/古言 |
| 对照组/打脸 | 被看不起 → 证明自己 | 被轻视 → 隐忍 → 爆发打脸 | 全题材 |

### 第三级：情节推进类 — 驱动故事的事件模板

| 套路 | 定义 | 典型节奏 | 主要题材域 |
| --- | --- | --- | --- |
| 退婚流 | 开局/早期被退婚，开启主线 | 被退辱 → 立誓 → 逆袭 | 玄幻、古言 |
| 废材流 | 主角被认为是废物，实则不凡 | 被轻视 → 隐藏实力 → 震惊全场 | 玄幻、修仙 |
| 扮猪吃虎 | 主角故意隐藏实力 | 低调 → 被挑衅 → 碾压对手 | 全题材 |
| 掉马甲 | 主角隐藏的身份被揭露 | 隐藏 → 蛛丝马迹 → 身份曝光 → 震撼 | 全题材 |
| 升级打怪 | 通过战斗持续变强 | 遇敌 → 战斗 → 升级 → 更强敌人 | 玄幻、奇幻 |
| 解密探案/单元案 | 逐个解决案件/谜题 | 接案 → 调查 → 破案 → 牵出主线 | 悬疑、推理 |
| 种田/基建 | 从零建设势力/领地 | 白手 → 发展 → 扩张 → 遇威胁 | 历史、奇幻 |
| 幕后黑手 | 主角在暗中操控局势 | 布局 → 棋子行动 → 收网 | 智斗、权谋 |

### 第四级：情绪回报类 — 读者的情感体验承诺

| 套路 | 读者承诺 | 反面 |
| --- | --- | --- |
| 爽文 | 持续的打脸/逆袭快感 | 憋屈、虐心 |
| 甜宠 | 关系中的温暖甜蜜 | 虐心、误会 |
| 虐文 | 让读者哭/心疼的情绪释放 | 轻松搞笑 |
| 悬疑 | 持续的未知感和解谜欲 | 剧透、过早揭露 |

## 套路识别五信号法

每个套路在文本中会留下可识别的信号。蒸馏时从以下五个维度交叉判断：

| 信号维度 | 要提取什么 | 举例（追妻火葬场） |
| --- | --- | --- |
| **开局信号** | 前 3-5 章建立了什么初始关系配置 | 女主深爱男主 + 男主冷漠/有白月光 |
| **事件链信号** | 核心事件序列是否符合某套路模板 | 付出→忽视→伤害→临界事件→离开→追回 |
| **关系信号** | 关键人物之间的权力/情感关系 | 女方情感低位 → 男方高位 → 后逆转 |
| **情绪弧信号** | 读者在卷/章层面体验的情绪轨迹 | 先虐（心疼女主）→ 后爽（追妻打脸） |
| **标签自曝信号** | 平台分类/读者评论中如何被标签化 | 本章说高频出现"火葬场""渣男""求虐" |

**判断规则**：一个套路的确立需要 **≥3 个信号** 同时指向该套路。仅 1-2 个信号指向 → 标注为"弱信号套路"（置信度低）。

## 套路纯度光谱

```text
纯套路 ←——— 混合变异 ———→ 反套路
```

| 光谱位置 | 特征 | 蒸馏标注 |
| --- | --- | --- |
| **纯套路**（纯度 ≥ 80%） | 标准事件链 + 标准关系配置 | 标注为主套路 + 纯度百分比 |
| **混合变异**（纯度 40%-79%） | 主套路框架 + 其他套路元素交叉 | 标注为主套路 + 融合元素清单 |
| **反套路**（纯度 < 40%） | 先建读者预期后有意打破 | 标注为反套路 + 对标对象 + 打破位置 |

## 套路-叙事节奏关联矩阵

| 套路 | 倾向的章首模式 | 倾向的钩子密度 | 倾向的中段回报类型 |
| --- | --- | --- | --- |
| 追妻火葬场 | 内心独白切入（女主视角） | 高密度（每章有情绪钩子） | 关系推进/关系位移 |
| 升级打怪 | 动作切入 | 中密度（每 3-4 章一个大钩子） | 身份抬升/能力显示 |
| 解密探案 | 异常/悬念前置 | 中高密度（每 2 章一个新悬念） | 信息开口/线索显影 |
| 甜宠日常 | 对话切入或环境切入 | 低密度（钩子可有可无） | 关系推进 |
| 幕后黑手 | 内心独白或信息切入 | 低中密度（蓄力期长） | 局面反击/局面逆转 |
| 废材流/扮猪吃虎 | 动作切入或异常前置 | 中密度 | 身份抬升 + 打脸 |

## 套路指纹的三重验证

| 验证 | 方法 | 通过标准 |
| --- | --- | --- |
| **跨卷复现** | 同一套路在至少两个卷段中均可被观测到 | 若只在一个卷段成立 → 降级为"卷段局部套路" |
| **事件链完整性** | 套路的核心事件链（至少 3 个节点）在蓝本中被完整执行 | 若只出现了开头 → 标注为"未完成套路" |
| **纯度自洽性** | 同一套路在不同卷段被标注的纯度差异不超过 25 个百分点 | 若纯度差异 > 25% → 检查是否是套路变异 |

## 虚假信号排除规则

| 虚假信号类型 | 说明 | 排除方法 |
| --- | --- | --- |
| **单章偶发** | 某套路的事件链信号只在 1 章中出现后续消失 | 不认定为套路，标注为"单章致敬/彩蛋" |
| **标签污染** | 平台给作品贴了某标签但正文中该套路未被执行 | 以正文事件链信号为准 |
| **读者过度解读** | 本章说说某处"像 XX 文"但作者本意并非该套路 | 检查事件链完整性 |
| **开局误导** | 前 3 章建立了一个套路预期但第 5 章后完全转向 | 标注为"开局误导套路" |

## 套路指纹产出格式

写入最终模板的 §十八：

```markdown
### 套路清单
| 套路 | 分级 | 纯度 | 覆盖卷段 | 置信度 | 核心信号 |

### 套路时间线
| 卷段 | 引入套路 | 退出/转变套路 | 变异说明 |

### 套路组合模式
- **主要组合**：[套路 A] + [套路 B]
- **高发组合**：是否属于赛道内同质化组合
- **组合张力**：套路间的情绪节奏冲突与解决方案

### 套路差异化声明
- 同赛道标配：[哪些套路是大家都在用的]
- 独特处理：[别人怎么用、它怎么用的不同之处]

### 套路-叙事节奏关联矩阵
| 套路 | 章首模式倾向 | 平均钩子间隔 | 平均回报间隔 | 主导中段回报类型 |

### 跨题材迁移建议
| 套路 | 题材绑定度 | 可迁移的抽象结构 | 推荐迁移方向 |
```

# 结构DNA符合度审计

> 来源：SKILL.md §"结构DNA符合度审计（新增）"

## 审计时机

当且仅当：
1. 当前项目已存在一份通过 Phase 4 质量验证的**作品蓝本模板**
2. 下游 Skill 已产出一份可供比对的成品（总纲+分卷大纲 ≥ 10 章，或连续 ≥ 5 章正文）
3. 用户明确要求审计

## 审计维度

### A. 大纲层审计维度

| 维度 | 对比基线（蓝本模板） | 差异计算方式 |
| --- | --- | --- |
| 功能位分布 | §九 章节功能位密度 | JS 散度；连续出现上限 ≤ 蓝本标注值 |
| 高潮/爆点间隔 | §四 场景节奏分布 + §三 中段回报指纹 | 均值差异 ≤ ±1 章；标准差差异 ≤ ±30% |
| 跨卷节奏迁移 | §十二 跨卷节拍迁移 | 各阶段关键维度值差异 ≤ ±20% |
| 人物出场规划 | §十一 人物出场节拍 | 间隔均值差异 ≤ ±20% |
| 信息释放节拍 | §七 信息释放节拍 | 均值差异 ≤ ±1 章 |

**大纲层权重**：功能位 25%、高潮间隔 25%、跨卷迁移 20%、人物出场 15%、信息释放 15%

### B. 正文层审计维度

| 维度 | 对比基线（蓝本模板） | 差异计算方式 |
| --- | --- | --- |
| 章首模式 | §一 章首模式指纹 | JS 散度 |
| 章末钩子 | §二 章末钩子指纹 | JS 散度 + 轮换期偏差 ≤ ±1 章 |
| 中段回报 | §三 中段回报指纹 | 回报间隔差异 ≤ ±1 章 |
| 场景-续景节拍 | §十 场景-续景节拍 | 冲突升级率差异 ≤ ±15% |
| 对话密度 | §六 对话密度分布 | 均值差异 ≤ ±10% |
| POV 切换 | §五 POV 切换规律 | JS 散度 |
| 人物出场 | §十一 人物出场节拍 | 间隔均值差异 ≤ ±20% |

**正文层权重**：章首 15%、章末钩子 20%、中段回报 20%、场景续景 15%、对话 10%、POV 10%、人物出场 10%

## 综合符合度计算

```text
综合符合度 = Σ(维度得分 × 维度权重) / Σ(维度权重)
维度得分：通过=100；未通过按偏差比例线性映射到 0–100
```

## 符合度分级

| 综合符合度 | 等级 | 含义 | 是否放行 |
| --- | --- | --- | --- |
| ≥ 90% | S 级 | 结构DNA高度一致 | ✅ 放行 |
| 80%–89% | A 级 | 核心结构指纹吻合 | ✅ 放行 |
| 70%–79% | B 级 | 部分维度偏差明显 | ⚠️ 附带整改放行 |
| 60%–69% | C 级 | 多个维度显著偏离 | ❌ 回炉 |
| < 60% | D 级 | 结构DNA不匹配 | ❌ 回到蒸馏阶段 |

## 审计报告格式

审计结果写入 `风格审计/作品蓝本/[作品名]/blueprint_audit_[审计对象]_YYYY-MM-DD.md`。

完整报告模板包括：审计元信息、逐维对照表、各个维度的实测值与基线值对比、综合符合度与等级、优先修复项。

# 通用-平台签约评估框架
> **题材路由**：若 .github\题材专用Skills\ 目录存在对应的 <题材>-平台签约评估框架 Skill，则：
> - 将题材特性骨架路由到 <题材>-平台签约评估框架，该 Skill 位于 .github\题材专用Skills\ 目录。
> - 命中本技能时，必须优先强制加载当前 Skill 与 <题材>-平台签约评估框架。


这不是鼓励型点评，而是平台初筛与连载执行双重口径下、默认按极严保守标准执行的评估框架。

默认不是只做“缺什么材料”的静态提示，而是做**总纲 -> 分卷 -> 章节正文 -> 投稿 / 完整评估**的分阶段准入判断：材料停在哪一层，就先把这一层能否放行说清，再决定是否进入下一层。

执行时若规则很多，固定只按四级优先级推进：**先确认评估层与证据范围，再完成同赛道 TopN 与竞对补证，再做投稿门槛 / 快审 / 评分，最后才给概率、建议与落盘**；前一级未完成，不进入后一级。

## 目标平台路由与动态引用（强制）

本 Skill 执行前，必须按以下优先级确定目标平台：

1. **用户显式指定**（"评估这本投七猫/番茄/晋江/起点"等）——用户指定时以用户指定为准
2. **Agents.md 主输出平台**：当用户未显式指定平台时，**必须**先读取项目根目录 `Agents.md` 中的 `主输出平台` 声明作为目标平台
3. **默认回退**：仅当 `Agents.md` 不存在或其中未声明 `主输出平台` 时，才回退到起点中文网

目标平台确定后，评估过程中的动态引用按以下映射表加载：

| 目标平台 | 加载的通用层 platform references | 额外加载项 |
|---|---|---|
| **起点中文网**（含 Agents.md 解析为起点 / 无 Agents.md 时默认回退） | `references/起点默认审核流程与硬门槛.md` | 起点术语体系、起点榜单检索规则 |
| **七猫免费小说** | `references/七猫默认审核流程与硬门槛.md` | `references/短剧改编适配度快速评估.md` |
| **番茄小说** | `references/番茄默认审核流程与硬门槛.md` | `references/短剧改编适配度快速评估.md` |
| **晋江文学城** | `references/晋江默认审核流程与硬门槛.md` | — |
| **其他平台** | 按通用评估骨架执行，不加载平台专项 references | 评估报告须标注"平台专项缺失，置信度降档" |

> 本章节之后的带 **【起点口径】** 标记的段落，仅当目标平台为起点中文网时生效（含用户显式指定起点、Agents.md 解析为起点、或默认回退起点三种情形）。

## 第零步：网络搜索捕获最新趋势（强制启动）

> **核心原则**：网文签约市场以月为单位变化。平台政策、赛道热度、爆款范式、编辑口味——所有这些评估依赖的参照系都在持续刷新。**评估工作的第一步不是"读投稿材料"，而是先打开网络搜索确认当前市场的最新状态。** 拿着一年前的趋势认知评估今天的作品，等于用旧地图找新路。

在本 Skill 执行任何评估流程之前，**必须先完成以下网络搜索**。未完成本轮趋势搜索之前，不得进入后续任何评估步骤：

### 必搜清单

| 搜索方向 | 搜索目的 | 搜索结果如何影响评估 |
| --- | --- | --- |
| **平台最新政策** | 搜索"{目标平台} + 签约/政策/门槛/征文 + {当前年份}" | 确认平台签约门槛是否变化、是否有新扶持计划——若平台已放宽某题材门槛，评估概率应相应上调 |
| **赛道最新热度** | 搜索"{目标题材} + 网文 + {当前年份} + 趋势/爆款/新书榜" | 验证评估的题材赛道当前是否仍处于上升期——若赛道已明显退热，须下调概率并标注时效性风险 |
| **新晋爆款样本** | 搜索"{目标题材} + {当前年份} + 新书/黑马/高收藏/黑马" | 捕捉最近 1-3 个月内崛起的新书作为竞对参照——本地竞对分析无法覆盖这些最新样本 |
| **套路时效性** | 搜索"{套路名称} + 网文 + 饱和/过时/过气/读者厌烦" | 验证作品使用的套路组合在当前市场是否已过气——若已被读者疲劳，须下调概率或要求差异化证据 |
| **编辑/过稿经验** | 搜索"{目标平台} + 编辑 + 过稿/签约经验/审稿标准 + {当前年份}" | 获取编辑口吻的最新过稿反馈——判断当前作品是否符合平台编辑的最新偏好 |
| **竞争水位** | 搜索"{目标平台} + {目标题材} + 签约/上架/完本 + {当前年份}" | 判断当前题材的签约竞争水位——若同赛道同期签约作品过多，竞争位评估需从严 |

### 搜索执行规则

- **搜索顺序**：先做"平台最新政策"和"赛道最新热度"这两个宏观搜索，再做其他专项搜索。宏观搜索结论将影响后续所有评估的权重校准。
- **搜索来源**：可以使用环境中任意可用的搜索工具（Bing 搜索、智谱搜索、阿里百炼搜索等），根据可获得性和实时性选择合适的工具。至少使用两种不同的搜索工具做交叉验证。
- **时效性标注**：所有搜索结论必须标注搜索时间（精确到月），以便判断信息的新鲜度。
- **新旧冲突处理**：当搜索结果与本地资产（`竞对分析/`、`写作研究/`、蒸馏模板等）的结论不一致时，**以最新搜索结论为准**，但须在评估报告中显式标注"旧结论已被新趋势覆盖"及具体冲突点。
- **搜索日志**：本轮搜索的关键词、搜索结果摘要和结论必须记录在评估报告的"外部趋势检索记录"部分，不得跳过。
- **本地优先例外**：若项目根目录的 `竞对分析/` 和 `写作研究/` 中有明确标注"数据采集时间"且距今不超过 1 个月的研究报告，可免做对应方向的搜索（但平台政策方向和套路时效性方向仍须执行）。

> **不得因为"搜索麻烦""已有本地材料""凭记忆就知道现状"而跳过本轮趋势搜索。不完成趋势捕获的评估，判为"基线校准缺失"，置信度默认降一档。**
## 风格/蓝本/写作研究模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，执行平台签约评估前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其作为目标平台和题材赛道的默认评估基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其作为文风商业适配、平台声口风险与禁忌项参照
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将其作为结构竞争力、节奏、回报和钩子参照；**并读取 §十八 套路指纹的套路清单与纯度，用于赛道饱和度判断**
5. 本 Skill 只消费与签约评估相关的字段；若模板字段与真实竞对证据、平台硬门槛冲突，竞对证据与平台硬门槛优先
6. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断

本 Skill 默认消费字段：

- 写作研究模板：平台审核标准、签约门槛、开篇要求、题材基线、禁忌类约束
- 作者风格模板：整体文风、叙事距离、对话风格配置、禁忌清单、商业适配风险
- 作品蓝本模板：章首模式指纹、中段回报指纹、章末钩子指纹、场景节奏分布、信息释放节拍、**§十八 套路指纹（套路清单、套路纯度、套路-节奏关联矩阵）**

## 默认评估口径（强制）

- 除非用户明确要求“宽松复盘 / 鼓励式建议 / 成长向点评”，否则默认一律按**极严口径**执行，不需要用户额外强调“严苛”“苛刻”“毒舌”。
- 默认进一步按“**严酷找差距**”执行：重点不是证明作品“也有优点”，而是证明它为什么还赢不过同赛道已过审样本；不得为了讨好作者把明显落后项降格成温和提醒。
- 默认执行顺序不是“先找优点再平衡”，而是：**先找阻断项，再找封顶项，再看快审停读点，最后才判断剩余强项能否抬升概率**。
- 默认启用：**负面证据优先、封顶优先、一票否决优先、快审断裂优先**；任何一处明显掉链子，都不得被少数亮点冲淡。
- 在证据不全、文本仅属勉强可读或卖点兑现不足时，宁可下调概率与置信度，也不做善意脑补或乐观补票；若只是独立更新计划、存稿证明、稳定日更证据缺席，默认单列为**作者执行风险 / 投稿准备风险**，主要影响投稿时机、建议结论与置信度，不直接等同于小说内容高阶缺陷。
- **【起点口径】** 若目标平台为起点中文网（含 Agents.md 解析为起点或默认回退起点），且本轮涉及投稿材料，必须按本仓库统一提交线核验：至少 `30000` 字连续正文 + `内投版总大纲（最低 5000 字）` + `内投版第 1 卷卷纲` + `内投版简介`；`组包自检` 应作为同版本作者侧配套文件一并存在。统一提交线达成，不等于可以直接给出“建议现在投稿 / 建议现在内投”，仍要继续核验模板符合性、前门效率、长线供血与执行风险。
- 只有当**书名简介归类、开篇追读、人物付费价值、机制兑现、长线供血**五项内容证据同时过线，才允许进入中高概率区间；执行准备只决定是否建议立即投稿、是否需要补齐执行证明，不直接充当作品质量高阶评分项。
- **【起点口径】** 内投大纲覆盖深度是独立评估维度（强制检查）：评估起点内投包时，必须显式核验大纲是否覆盖全书骨架；若大纲仅覆盖第一卷、后续卷次为空或"待定"，默认按**投稿材料重大缺陷**处理，不得把它折算进大纲字数或结构质量得分里，而是直接标记为阻断项。阅文官方编辑明确把"大纲写到第一卷，第二卷来个待定"列为主动失分项；覆盖全书骨架是证明 `50` 万字长线供血能力的基础材料，不是加分项，是必交项。
- “极严”不等于歪曲事实：该承认的强项必须承认，但承认强项只用于校准真实威胁度，不用于替作品找台阶。
- 不得把“下游材料缺失”写成唯一结论；即使只有总纲，也必须回答“按当前总纲是否适合推进分卷”；即使只有总纲 + 分卷，也必须回答“按当前结构是否适合推进章节正文”。
- 在非完整评估阶段，默认先输出**当前层放行概率**；若还要补充“最终签约潜力”，必须显眼标注为**最终签约上限预估**，不得与当前层放行概率混写。
## 套路赛道饱和度评估（新增）

平台签约评估的一个重要维度是：作品计划使用的套路组合在当前目标平台的同赛道中是否已过度饱和。饱和度越高，过稿难度越大。

### 套路饱和度评判标准

| 等级 | 特征 | 对签约的影响 |
| --- | --- | --- |
| **高饱和** | 该套路组合在 TopN 候选池中出现 ≥60% | 除非有足够强的差异化设计，否则签约概率大幅下调；"退婚流+废材流+打脸"在玄幻赛道已属此类 |
| **中饱和** | 该套路组合出现 30%-59% | 需要明确的差异化声明，说明"我的作品和同类有什么不同" |
| **低饱和** | 该套路组合出现 <30% | 构成"赛道空缺"信号，可适度上调概率——但需验证该组合在本平台是否有受众基础 |
| **组合创新** | 现有套路以新方式组合形成独特读感 | 若创新能被 3 章内感知且逻辑自洽，可显著上调概率 |

### 执行方式

- 评估过程中应将竞对分析 TopN 候选池的套路配置纳入考察：若候选池中已有大量作品使用相同的套路组合，则当前作品若未提供充分的差异化证据，赛道饱和度将成为下调概率的负面因子。
- 若项目已注册作品蓝本模板（含 §十八 套路指纹），直接参照其套路清单和套路差异化声明，判断当前设计是否与已验证有效的套路组合一致，或是否有意避开。
- 若当前材料尚不足以判断套路饱和度，标注为"待竞对分析补齐后补充"。
- **平台错位专项**：评估签约概率前，默认先加载 `references/平台错位诊断卡.md` 检查是否存在"写法与目标平台错位"——此问题经常被误判为"写得不好"，但实际上是"写得好但投错地方"。错位信号包括：豆瓣向克制风投七猫、网文爽文写法投出版等。
- **短剧改编专项**：若目标平台为七猫/番茄等免费阅读平台，默认加载 `references/短剧改编适配度快速评估.md` 评估IP衍生潜力——开篇虐点密度、身份反转、情绪外放度、单集钩子、人物关系可拍性、对话可拍性。

## 大纲收入公式评估诊断（新增）

> **来源**：知乎《稿费从1000到50000，写好大纲决定你稿费的上限》（顾里木图的小酒馆，2026-06-15）。

评估签约潜力时，可引入以下四因子诊断公式作为快速定位短板的结构化工具：

**稿费潜力 = 开篇质量 × 付费点密度 × 人设经济价值 × 数据增长设计**

| 因子 | 定义 | 在签约评估中的诊断方式 | 常见阻断表现 |
| --- | --- | --- | --- |
| **开篇质量** | 前3章能否留住读者 | 前3章是否有明确冲突起手、主角处境是否可感知、章末钩子是否有效 | 前500字无冲突/设定堆砌/主角无明确欲望 |
| **付费点密度** | 每10章是否有≥1个付费钩子 | 检查第1-3章、第4-20章、第20-50章是否有分层付费设计 | 前20章无付费钩子/高潮间隔过长/付费节点设计缺失 |
| **人设经济价值** | 角色是否有改编潜力 | 核心人物是否具备"反差+成长+标签"三维特征；人物是否可迁移至短剧/动漫/IP衍生 | 人设模板化无辨识度/无代偿空间/无IP迁移方向 |
| **数据增长设计** | 前30章是否有分阶段增长目标 | 前30章是否有明确的留存→完读→互动→付费四阶段规划 | 前30章只有情节线无数据增长意识/首个高潮过晚 |

### 公式使用规则

- **乘法关系**意味着四个因子中最低的一项直接决定整体上限。评估时不是平均分配注意力，而是优先找到"最短板"因子。
- 若当前作品的四个因子中有一个处于"常见阻断表现"所列的状态，这一项就是签约概率下调的核心原因——大概率不是因为其他三项不够好，而是最短板拉垮了整体。
- 该公式作为**诊断定位工具**，用于帮助评估者快速找到"最需要补什么"，不替代其他维度的精细化评估（如套路饱和度、竞对差距量化等）。

## 蒸馏产物对标签约评估（新增）

蒸馏产物（作品蓝本模板 / 作者风格模板 / 写作研究模板）的蒸馏对象全是**已签约且经过市场验证的作品**，尤其是**起点同赛道头部作品**。将当前作品与这些蒸馏产物做系统性对标，比空泛的"文笔还行/节奏不错"式评估能更精确地定位"编辑为什么会签别人而不是你"。

### 核心理念：蒸馏竞对双重对标法

评估签约概率时，竞对分析和蒸馏产物不是两个独立工具，而是一个**双重对标体系**：

| 对标层次 | 对标源 | 获取方式 | 在签约评估中的用途 | 硬度 |
| --- | --- | --- | --- | --- |
| **第一层：宽样本对标** | 同题材 Top 10 候选池 | 通过 `通用-分析竞对作品` 榜单检索获得 | 确认赛道当前竞争水位；判断作品是否达到"过稿及格线" | 硬门禁（必须做） |
| **第二层：主压制样本对标** | 3-5 本主压制样本 | 从 Top 10 中圈定，经 `通用-分析竞对作品` 四层深拆 | 逐维度量化差距，判断"凭什么编辑选你的而不选竞品" | 硬门禁（必须做） |
| **第三层：蒸馏蓝本对标** | 作品蓝本模板（头部签约作品的结构蒸馏） | 通过 `Agents.md` 注册或用户指定 | 在结构层（章首/钩子/回报/场景节奏/信息释放/套路）上做精细化对标——**头部签约作品已达到的结构标准，就是你至少要追平的结构基线** | 强对标参照 |
| **第四层：蒸馏文风对标** | 作者风格模板（头部作者的文笔蒸馏） | 通过 `Agents.md` 注册或用户指定 | 在文笔层（句长/段落/感官/对话/叙事距离/情绪表达）上做精细化对标——**头部作者的最低文笔标准，是你至少要达到的文笔基线** | 参考对标参照 |
| **第五层：蒸馏研究对标** | 写作研究模板（平台×题材的约束提炼） | 通过 `Agents.md` 注册或用户指定 | 逐一核验当前作品是否满足平台/题材的硬性写作约束——**不满足这些约束的作品，签约概率天然受限** | 硬约束参照 |

**核心判断公式**：
> 当前作品签约概率 ≈ 当前作品在双重对标体系中的排位竞争度
> = f(达到 Top 10 均值水平的维度数, 超过蒸馏蓝本标准的维度数, 未触碰写研究禁忌的维度数)

当蒸馏产物与竞对分析共同指向"当前作品在关键维度上落后于已签约作品均值"时，签约概率必须大幅下调，不得用"有潜力""概念好"等理由做乐观估计。

### 蒸馏蓝本对标——签约概率的结构层翻译

项目已注册作品蓝本模板（§一至§十八）时，以下结构化对标维度直接映射到签约概率判断：

| 蓝本蒸馏维度 | 对应蓝本§节 | 签约评估翻译 | 对签约概率的影响方向 |
| --- | --- | --- | --- |
| 三关设计匹配度 | §十六 读者吸引与留存指纹 | 书名策略（字数/句法/热词/首眼归类效率/信息差运用）是否达到蓝本水平；内容简介的三句法完成度与承诺一致性是否不低于蓝本；开篇第一章的三句法达成度与问题引擎强度 | **入口关不过→签约概率≤20%**：编辑30秒内无法归类→直接跳过 |
| 章首模式竞争力 | §一 章首模式 | 当前作品的章首切入方式多样性是否与蓝本（已验证签约成功）在同一水平；章首抓力密度（前200字是否有钩子）是否不低于蓝本篇均水平 | 章首模式单一/无抓力→追读工程不可靠→下调概率 |
| 章末钩子竞争力 | §二 章末钩子 | 当前作品的钩子类型轮换规律、钩子强度分级规律是否与蓝本一致；章末续读驱动力（翻页率代理）是否不低于蓝本 | 钩子类型重复/强度不足→追读续购下跌→下调概率 |
| 中段回报竞争力 | §三 中段回报 | 当前作品的回报间隔是否不超过蓝本的回报禁忌上限；回报类型多样性是否接近蓝本 | 回报稀疏→卷中失温→下调概率 |
| 信息释放节拍 | §七 信息释放节拍 | 当前作品的悬念设置/线索埋设/揭示节奏是否与蓝本的信息释放节拍在同等复杂度水平；是否存在新悬念在旧悬念揭示前抛出的"接棒"设计 | 信息释放平铺/无悬念接力→留存差→下调概率 |
| 套路指纹差异化 | §十八 套路指纹 | 当前作品的套路配置（四级分类：核心设定/人物关系/情节推进/情绪回报）与蓝本的同赛道套路清单相比，差异化是否成立；套路纯度是否处于"混合变异"水平而非纯套路；套路的"可迁移性四维评估"（题材绑定度/文风依赖度/存量依赖度/时间窗口）是否已完成 | **套路无差异→签约概率≤15%**：编辑看过的题目不会再看一遍 |
| 跨卷节拍迁移 | §十二 跨卷节拍迁移 | 当前作品的长篇节奏规划是否具备蓝本式的节拍迁移模式（前松后紧/七紧三松/始终高密）；阶段切换是否有触发事件 | 长篇节奏单一→中段弃书风险→下调概率 |
| 故事线台账完整性 | §十五 故事线台账 | 当前作品的故事线数量是否与目标篇幅匹配；主/副/人物弧/关系线/伏笔回收线的交织模式是否完整；是否存在未回收线或断线 | 线数量不合理/有断线→架构不稳→下调概率 |
| 情感弧多样性 | §八 情感弧分布 | 当前作品的情感弧模式多样性是否接近蓝本水平；是否规避了蓝本的"情感弧禁忌"（如连续多章平-平-平） | 情感单一→读感发平→下调追读概率 |
| 场景节奏紧张/松弛比 | §四 场景节奏分布 | 当前作品的紧张/松弛/高潮场景占比是否与蓝本处于同等节奏成熟度水平 | 节奏失衡（过紧或过松）→留存受损→下调概率 |
| 场景-续景节拍 | §十 场景-续景节拍 | 当前作品的场景衔接因果链比例（"因此" vs "然后"）是否接近蓝本；续景决策驱动率是否达标 | 场景衔接松散→冒险拖沓→下调概率 |
| 人物出场节拍 | §十一 人物出场节拍 | 核心人物的出场频率/间隔/回归模式是否与蓝本的人物出场节拍一致；新人物引入速率是否合理 | 人物蒸发/引入过快→关系线断裂→下调概率 |
| 叙事矛盾弧 | §十四 叙事矛盾弧 | 当前作品是否存在蓝本式的"规律打破时刻"（深度叙事信号）；还是节奏始终平推无波动 | 无矛盾弧→叙事深度不足→下调上限预估 |
| 神似层达标度 | 叙事引擎（神似三问） | 当前作品是否具备蓝本式的"叙事心跳"和"核心驱动问题链"——还是只复制了蓝本的表层数字（形似）而没有生成力（神似） | 仅有形似→仿写感重→编辑一眼看出→下调概率 |

**对标规则**：
- 蓝本对标采用"通过/未达标/强于蓝本"三级标记。**未达标项≥5项**时，签约概率默认不得进入中高区间。
- 蓝本对标结论不得独立使用，必须与竞对分析的 Top 10 + 3-5 本主样本对标结论合并判断。

### 蒸馏文风对标——签约概率的文笔层翻译

项目已注册作者风格模板时，以下文笔对标维度直接映射到签约概率判断：

| 风格蒸馏维度 | 对应风格§节 | 签约评估翻译 | 对签约概率的影响方向 |
| --- | --- | --- | --- |
| 句长基线成熟度 | §一 句长基线 | 当前作品的句长基线是否在头部作者的合理范围内；句长交替模式是否已形成稳定的场景切换策略 | 句长无策略→阅读流畅度受损→下调概率 |
| 段落节奏成熟度 | §二 段落节奏 | 当前作品的段落类型占比（单句独段/短段/中段/长段）是否接近头部作者水平；是否已形成稳定的开篇/对话/高潮段落模式 | 段落节奏乱→手机端读感差→下调概率 |
| 感官偏好竞争力 | §三 感官偏好分布 | 当前作品的感官通道使用策略是否接近头部作者；是否在关键时刻调用触觉/身体感制造代入感 | 感官调用单一→沉浸感弱→下调概率 |
| 对话风格成熟度 | §四 对话风格配置 | 当前作品的对话标签偏好、打断密度、潜台词深度是否接近头部作者；是否已形成稳定的对话推进方式 | 对话质量低→人物立不住→下调概率 |
| 叙事距离掌控力 | §五 叙事距离 | 当前作品的默认叙事距离和切换规律是否接近头部作者；上帝视角禁令是否被严格遵守 | 叙事距离混乱→代入感断裂→Critical |
| 情绪表达方式成熟度 | §七 情绪表达方式 | 当前作品的躯体化/动作外化/环境投射/直述情绪/留白比例是否接近头部作者 | 直述情绪过多→"AI味"重→下调概率 |
| 禁忌清单触碰度 | §八 禁忌清单 | 当前作品是否触碰了头部作者普遍回避的句式/修辞/用词禁忌（如"眸中闪过一丝""他非常X"）；触碰频次是否超过职业级容忍上限 | **禁忌高频触碰→"新人感"重→下调概率显著** |
| 写作思维模型一致性 | 神似层—写作思维模型 | 当前作品的写作决策（为什么在这里用短句、为什么在这里拉近叙事距离）是否与头部作者的写作信念一致，还是只有表面数据相似 | 形似神不似→称不上成熟写法→下调上限 |

**对标规则**：
- 文笔对标采用"通过/接近/未达标"三级标记。严格区分"风格差异"和"技法不成熟"——前者不扣分（如长句偏好 vs 短句偏好只是风格差异），后者下调概率（如无段落节奏策略、情绪表达单一）。
- **禁忌清单触碰≥3类**时，签约概率直接下调至少一档——这表明写作仍处于"AI辅助前期"水平，尚未进入职业级。

### 蒸馏研究对标——签约概率的平台约束翻译

项目已注册写作研究模板时，以下约束对标维度直接映射到签约概率判断：

| 研究蒸馏维度 | 对应研究§节 | 签约评估翻译 | 对签约概率的影响方向 |
| --- | --- | --- | --- |
| 平台硬门禁合规度 | §二 结构类约束 | 当前作品是否满足研究模板针对目标平台的所有硬门禁（如"前300字必须有冲突/异常/压力""章末必须有钩子"等） | **硬门禁不达标→签约概率≤10%**：编辑在快审阶段就会停读 |
| 平台强约束达成度 | §二 结构类约束 | 当前作品是否满足了研究模板的强约束（如"每3-5章一个爽点""开篇禁止大段世界观铺垫"等） | 强约束偏离→追读工程不稳→下调概率 |
| 读者心理学原则层达标度 | §五 原则层 | 当前作品是否满足读者心理学归因原则——首屏注意力窗口、回报预期衰减、认知负荷与兴趣锚定、连续阅读决策等 | 系统性违反原则→概率不得高判 |
| 禁忌类约束触碰度 | §四 禁忌类约束 | 当前作品是否触碰了研究模板标注的平台/题材硬性禁忌（"禁止万能主角""禁止信息问答式对话"等） | 命中禁忌→签约概率直接下调一档 |
| 赛道窗口适配度 | §五-B 仿写窗口约束 | 当前作品的套路选择是否在研究模板标注的"当前窗口推荐"方向内；是否踩中了"正在退热的模式" | 命中退热模式→标注时效性风险→下调概率 |

**对标规则**：
- 研究模板对标采用"硬门禁/强约束/软建议"三级硬度。硬门禁不达标=阻断项，直接导致签约概率≤10%；强约束累计3项以上偏离=下调一档。
- 研究模板对标是**签约评估的硬地基**——不满足平台硬规则的作品，即使文笔再好、结构再复杂，编辑也不会签。

### 蒸馏对标在签约评估报告中的呈现

蒸馏对标不应替代现有竞对差距量化卡，而是在报告中以 **"蒸馏竞对双重对标矩阵"** 形式补充在量化卡之后：

```markdown
### 蒸馏竞对双重对标矩阵

| 对标维度 | 我方当前分 (0-5) | 竞对Top3均值分 | 蒸馏蓝本达标线 | 分差(我方-蓝本) | 签约影响 | 72h补丁 |
| --- | --- | --- | --- | --- | --- | --- |
| 章节拍 (章首+钩子+回报) | N | N | N | ±N | 阻断/风险/达标 | ... |
| 开篇三关 (书名+简介+首章) | N | N | N | ±N | 阻断/风险/达标 | ... |
| 套路指纹差异化 | N | N | N | ±N | 阻断/风险/达标 | ... |
| 信息释放节拍 | N | N | N | ±N | 阻断/风险/达标 | ... |
| ... | N | N | N | ±N | ... | ... |
```

**签约影响标记规则**：
- **阻断**：该维度明显低于蓝本和竞对均值，且影响编辑快审决策 → 此项不过则签约概率不得进入中高区间
- **风险**：低于蓝本但差距可修复，或偏离但不致命 → 标注为需优先补丁项
- **达标**：已接近或达到蓝本水平 → 该维度不再构成签约障碍

该矩阵应与现有量化卡并列呈现，作为竞对分析的蒸馏升级版。

## 【起点口径】起点术语口径（强制）

> 以下内容仅当目标平台为起点中文网时生效（含用户显式指定起点、Agents.md 解析为起点、或默认回退起点）。

当目标平台为起点中文网时（含 Agents.md 解析为起点或默认回退起点），默认尽量按以下语言体系写结论：

- **数据层**：收藏、推荐票、月票、均订、高订、首订、追订、收订比、粉丝值、盟主数、荣誉徽章、书单收录。
- **榜单 / 资源层**：分类月票榜、畅销榜、新书榜、24 小时热销、三江、强推、首页封推、智能推荐、书架导读、猜你喜欢。
- **读者层**：老白、中度付费读者、泛读者 / 路人流量；反馈来源优先看本章说 / 段评、书友圈、书评区、长评贴。
- **约束**：若拿不到均订、首订、追订、收订比等精确值，可使用公开可见的代理信号，但必须显式写成代理，不得伪造精确数值。

## 【起点口径】起点读者画像与付费场景校准（新增）

- 起点评估默认补一层“目标读者命中度”校准：是否主要命中 `18–35` 核心付费人群，尤其是男频主流读者在“逻辑自洽、冲突密度、成长兑现、方法论抓手”上的预期。
- 默认校验作品是否具备可见的付费触发场景：`追更驱动`、`站队驱动`、`阶段回报驱动`、`卷末缺口驱动` 至少命中其二；若只有设定新奇而无持续付费触发，概率不得高判。
- 若作品明显依赖小众审美、慢热审美或高门槛理解成本，但未提供对应的留存补偿设计（如强悬念链、强关系链、强回报链），默认下调快审通过率与中期留存预估。

## 【起点口径】起点推荐资源体系与快速筛查（新增）

### 推荐资源层级与评估参照

评估时需要知道一部作品在起点平台上需要达到什么强度才能获取对应资源。以下体系用于反推作品当前设计强度是否匹配目标推荐位：

| 推荐层级 | 资源名称 | 获取条件/特点 | 反推设计强度要求 |
| --- | --- | --- | --- |
| 常规推荐 | 新书入库→一轮→二轮→三轮→四轮 | 真追读依次达标；三轮流量最大；四轮可选择上架 | 一轮至少需真追读过分类最低门槛；三轮需要同期 PK 胜出 |
| 进阶推荐 | 小喇叭 | 精选页文字横幅 2 天，真追读至少 1000 起步 | 需要作品已有可观的追读底盘 |
| 进阶推荐 | 三江推荐 | 精选页三江栏目 7 天，看周一追读数据 | 需要作品质量过硬且符合三江标准 |
| 进阶推荐 | 新书强推 | 每天轮换 3 本，看周二追读数据 | 表现好有机会被运营直接抓上大推 |
| 高级推荐 | 大封推 | 需要均订 4000+ | 作品已具备中等商业价值 |
| 高级推荐 | 书架导读 | 需要均订 6000+ | 作品已具备较高商业价值 |

**评估规则**：
- 若当前作品的设计强度（开篇抓力、追读工程、付费转化预期）明显达不到一轮推荐的最低要求，签约概率大幅下调。
- 若作品设计上能够支撑三轮推荐（同期 PK 胜出级别），可适度上调概率——但前提是设计已能在正文中兑现，而非仅停留在总纲阶段。

### 快审分秒模拟标准（10 秒 / 3 分钟）

评估报告中的"平台快审模拟"必须按以下分层标准逐级判断：

**10 秒级判断**（编辑第一眼）：
1. 书名能否在 2 秒内归类题材？
2. 简介前两行是否有钩子？
3. 题材是否属于当前热门赛道或平台扶持品类？
4. 是否有明显的过气信号（退婚流、签到流、无脑系统等）？

**3 分钟级判断**（编辑快速翻阅）：
1. 前 300 字是否有冲突/异常/压力？
2. 前 1000 字是否亮出金手指或回报预期？
3. 主角是否有鲜明记忆点？
4. 节奏是否避免了慢热铺垫？
5. 第一章结尾是否留下了具体驱动？

**数据初判补充**（有公开代理信号时）：
1. 追收比是否接近或优于 `10:1` 常态线（`5:1` 可视为强信号）？
2. 前 `3/7/15` 天留存是否呈下降可控曲线而非断崖？
3. 若处于新书推荐阶段，是否存在“轮次推进但转化不抬升”的失速信号？

以上两级判断中任何一级有三项或以上不通过，当前层不得放行。

## 【起点口径】起点榜单检索与同题材严对照（强制）

- 只要评估对象是起点中文网项目，或目标平台经路由链解析为起点（用户未指定→Agents.md 未声明或无 Agents.md→默认回退起点），**每次评估都必须先做外部榜单检索**，不得只凭记忆、旧印象、内部材料或过往案例直接下结论。
- 检索时必须优先组合使用当前环境中**多种可用且效果较好的网络搜索工具**，至少完成一次交叉搜索与一次结果核验；不要只依赖单一搜索源。可用形式包括但不限于：网页搜索、中文搜索、榜单页抓取、网页内容获取。
- 每次评估必须锁定**起点中文网同题材榜单前 10 名作品**作为对照样本；若存在多个相近榜单，优先选取与目标作品题材、商业竞争位最接近的榜单，并说明取样口径。
- **拿到 Top 10 名单只是建立样本池，不等于完成竞品研究。**
- 只要进入起点 Top 10 对照阶段，必须继续**组合调用 `通用-分析竞对作品`**：先把 Top 10 视为候选池，再从中圈定 `3–5` 本主压制样本，按“市场数据层 → 内容创作层 → 运营策略层 → 受众反馈层”做重度深拆；其余样本至少保留简版证据卡。若用户明确要求 Top 10 全量重拆，再扩展到全部样本。
- 本 Skill 在起点口径下不再平行维护第二套竞对方法论：竞对深拆本体统一交给 `通用-分析竞对作品`，本 Skill 负责把其结论翻译成**签约概率、放行判断、阻断项与最小补丁**语言。
- 对榜单前 10 的**每一部作品**，都必须继续做逐本深搜；默认至少覆盖三类材料：`1）正文 / 试读 / 公开章节片段`，`2）书评 / 读者讨论 / 推荐语料`，`3）研究文章 / 拆解稿 / 盘点分析 / 经验总结`。不得只停留在书名、简介、榜单简介或二手概述层。
- 逐本深搜时，正文 / 试读类证据属于**每本必选项**；书评与研究类材料属于**强制优先补齐项**。若某一类资料客观难找，必须显眼写出已使用的搜索词、搜索源与未命中的原因，而不是直接跳过该作品。
- 若起点作品页、目录页、试读页因**反爬、验证码、登录门槛或频控**难以直接读取，允许继续搜索该小说的**第三方相关内容**来补证，包括但不限于：可核验的目录整理页、试读摘要、论坛讨论、书评摘录、百科资料、剧情梳理、推荐文与拆解稿。
- 但第三方来源只能作为**受阻后的补充抓手**，且必须优先选择**可核验、来源清楚、非明显侵权**的页面；不得把盗版站、未授权全文站或明显侵权镜像站当作正文 / 目录核心证据源。若合法来源仍不足，就把它写成判断盲区。
- 对每一部 Top 10 样本，至少都要回答三件事：**它为什么能留在榜单前列、它在哪些维度明显压过当前作品、它暴露了当前作品哪些短板**；不能把 10 本书压缩成一句“整体更强”。
- 若当前工作目录、项目目录或题材目录下已经存在 `竞对分析/`，且其中已有相关作品或同题材竞品的历史报告，默认应一并读取并纳入证据链，作为**已有研究缓存**使用。
- 已有 `竞对分析/` 文件可以减少重复劳动、补充横向样本与旧结论，但**不能替代本轮新的榜单检索、逐本深搜与关键证据复核**；旧报告与本轮新证据冲突时，以本轮可核验的新证据为准。
- 若无法直接打开起点榜单页，也必须通过多组关键词与多个搜索源尽最大努力还原同题材前 10 样本，并显眼写出检索盲区；但**不得因为检索麻烦就跳过同题材 Top 10 对照**。
- 对照分析的默认目标不是“找相似优点”，而是**逐项找差距、找短板、找落后幅度、找编辑为什么更可能把名额给榜单作品而不是给当前作品**。
- 至少要从以下维度与榜单前 10 做从严比较：书名 / 简介归类、前 300 / 500 / 1000 / 3000 / 6000 字抓力、主角抓手、人物关系付费价值、机制兑现、章级追读工程、长线供血、更新执行与投稿成熟度。
- 若当前作品与榜单前 10 相比多数关键维度明显落后，或没有形成足够清楚的差异化胜点，不得用“有潜力”“概念不错”“文笔还行”之类的安慰式说法抬高签约概率。
- 允许记录相对强项，但其作用仅限于校准真实竞争位；**吹捧、鼓励式美化、为了安慰用户而主动找优点**，都不能作为签约通过判断的依据。

## 竞争位 / 威胁评估语境处理规则（强制）

- 若用户明确说明自己与作者关系极差、正在争夺同平台 / 同名额，允许将任务定义为“竞争威胁评估”；但评价对象仍只能是**作品文本、题材适配、投稿成熟度与签约概率**，不得把作者人品、私人纠纷、主观厌恶或未经核实的传闻直接写成结论。
- 若用户说“帮我看他对我的威胁大不大”“帮我找喷点”“我希望他过不了签”，默认将这些情绪化说法翻译为以下客观任务：
	1. **这部作品当前的签约概率区间是多少**；
	2. **它对提问者的客观威胁度高不高**；
	3. **它最可能被编辑卡住的点在哪里**；
	4. **即便不中听，也必须承认的真实强项在哪里**。
- 本 Skill 默认即启用“极严保守口径”；在该语境下，不是为了迎合情绪而再额外加狠，而是要在同一极严基线上追加**威胁度、卡点、真实强项、可学习处**四类客观结论。
- 若用户只提供书名、简介、开头或前三章，允许执行“竞争威胁快筛”，但必须显眼标明：**这是低置信度预判，只能判断当前威胁度，不等于完整签约体检**。
- 若用户要求“逐帧分析”，默认理解为按**书名、简介、首屏、前 300 / 500 / 1000 / 3000 / 6000 字或前三章**逐段拆解，而不是输出人身攻击式评价。

## 题材既有竞对报告接入要求（强制）

- 若当前任务服务某个题材，且该题材目录下的 `竞对分析/` 已存在与当前项目、当前平台或当前赛道相关的竞对分析报告，默认不仅要读取，还必须把它们纳入本轮对照结论。
- 不得把这些报告只当成已有研究缓存；必须显式写出当前作品相对既有竞对报告与本轮 Top 10 样本在哪些维度已领先、只是跟平，或仍明显落后。- 若项目还已注册蒸馏模板（作品蓝本模板/作者风格模板/写作研究模板），则既有竞对报告与蒸馏对标结论必须交叉核验：竞对报告中的内容层面分析（题材融合、开篇架构、人物塑造、叙事节奏、世界观设定等）可与蒸馏蓝本的结构对标（章首/钩子/回报/信息释放/套路等）形成交叉验证——蒸馏蓝本提供"已签约头部作品在这些维度上的结构标准"，竞对报告提供"当前赛道竞争水位"，两者结合起来才能判断签约概率的真实边界。- 平台签约评估的默认目标不是“找几个相似优点”，而是判断当前作品是否具备在关键维度上**全方位超越竞争对手**的明确路径；若没有，不得给出偏乐观结论。
- 竞对维度在平台签约评估内容主分中默认按 `25%` 计权；若已注册蒸馏模板，须进一步输出**蒸馏竞对双重对标矩阵**（见"蒸馏产物对标签约评估"节），将蒸馏蓝本/文风/研究对标结论与竞对量化卡合并判断。若未完成量化差距卡、未完成蒸馏对标、关键维度仍显著落后，或没有 `72` 小时补丁，默认不得给高档概率结论。

## 证据交叉核验要求（强制）

- 平台签约评估不是只看“写得好不好”，而是要判断“编辑现在为什么会继续看、为什么会停下、为什么值得投”。
- 若评估内容包含"可直接投递给编辑的投稿材料"，必须读取 `投稿材料/` 目录下对应平台子目录中的**作品根目录与当前版本索引**；平台未显式指定时，默认读取 `投稿材料/{目标平台}/《作品名》/当前版本索引.md`（若目标平台由 Agents.md 解析或默认回退起点，则按起点口径走 `投稿材料/起点内投/...`），再进入当前版本目录读取 `内投版简介`、`内投版正文`、`内投版总大纲`、`内投版第 1 卷卷纲`、`组包自检` 等核心文件，并将其纳入证据链。
- 只要材料存在，默认至少交叉看以下 `5` 类证据：
	1. **书名 / 简介 / 一句话卖点**；
	2. **前 300 / 500 / 1000 / 3000 / 6000 字或其等价开篇方案**；
	3. **人物层证据**：主角职业、执念、缺陷、关系、反派；
	4. **机制层证据**：设定规则、边界、代价、现实锚点、证据化；
	5. **长线与执行证据**：总纲 / 分卷 / 前 10 章节拍、更新计划、存稿与投稿路径。
- 缺其中任一关键证据时，必须显眼写出判断盲区、对应维度封顶与置信度下调原因。

## 开篇与追读工程快审补充（新增）

- 快审时默认额外检查：前 `300` 字是否立起人物抓手与第一压力，前三章是否形成一轮清楚的钩子 / 蓄力 / 回报或升级。
- 若文本长期靠设定解释、抽象判断或作者说理推进，而不是靠人物动作、感官压力和具体后果推进，默认下调追读工程分。
- 若主角没有真实短板、务实动机与可见成长空间，只剩“设定强 / 立场对 / 能力高”，默认人物付费价值不得高判。
- 若文本明显不适配手机端阅读：大段厚墙、句群过匀、首屏迟迟不给钩子，默认在开篇留存与平台适配项扣分。

## 【起点口径】起点数据指标与爆款分层标准（新增）

### 核心数据指标定义

评估起点项目时，以下指标是判断作品爆款潜力的量化基准，应以代理信号或可核验数据形式纳入评估参考：

| 指标 | 定义 | 评估用途 |
| --- | --- | --- |
| 收藏量 | 读者对作品的初步认可 | 与追读的正常比例为 **10:1**；5:1 属于较强表现 |
| 追读率 | 读者粘性与吸引力 | 核心推荐指标；真追读=三个月内有消费记录且读到最新章 |
| 均订（平均订阅） | 累计订阅总章数÷收费章节数 | 衡量商业成功的核心指标；1 万均订=精品门槛 |
| 首订 | 上架后首章订阅数 | 反映读者付费意愿；首订破万是优秀作品的标志 |
| 月票 | 需付费购买的投票道具 | 衡量核心读者支持度；年度月票总数与 IP 价值正相关 |
| 留存率 | 第 3/7/15 天读者留存 | 超过 50% 优秀，低于 30% 警惕 |
| 收订比 | 收藏→首订的转化率 | 反映从免费到付费的漏斗效率 |

评估时拿不到精确值必须写成代理信号，不得伪造具体数字。

### 爆款分层门槛（起点 2025–2026）

以下为起点平台已验证的爆款分层标准，评估时应作为概率区间的参照系：

| 级别 | 核心门槛 | 代表作品与数据 |
| --- | --- | --- |
| 精品级 | 均订 ≥ 1 万 | 目前起点约有 1300 本万订小说（都市 260 本、玄幻 204 本、仙侠 187 本） |
| 大神级 | 连续多本均订过万，或一本现象级爆款 | 月稿费通常超 1 万元；2025 年新晋大神包括城城与蝉、董无渊等 |
| 白金级 | 完本小说订阅量超 1 万 + 文学价值与市场表现双优 | 均订通常在 2 万以上；辰东《夜无疆》均订逼近 18 万 |
| 现象级 | 均订 ≥ 10 万 | 《深海余烬》《异度旅社》等；《诡秘之主》均订破 30 万 |
| 超级现象级 | 全平台均订 ≥ 30 万 + 破圈文化影响力 | 《诡秘之主》全球核心粉丝超 2600 万 |

**评估规则**：
- 评估时默认以**精品级（1 万均订）**为合格线基准，以**现象级（10 万均订）**为卓越线基准。
- 不得把"当前只处于大纲/分卷阶段、尚无任何订阅数据"的作品直接对标以上门槛数值；此时只能以题材赛道、竞品均订代理信号与设计就绪度做间接判断。
- 若作品的设计强度明显低于同赛道已过精品线的竞品样本，不得给出中高签约概率。

### 分阶段评判标准映射

评估时必须根据当前材料所处的阶段，使用对应的平台评判口径：

| 阶段 | 字数区间 | 核心评判指标 | 对评估结论的影响 |
| --- | --- | --- | --- |
| 新书期 | 0–30 万字 | 追读率、留存率、点击→阅读转化率 | 若开篇抓力或前三章闭环不达标，签约概率大幅下调 |
| 上架期 | 30–80 万字 | 首订、订阅增长曲线、月票表现 | 若设计上无法支撑首订破千，不得给中高概率 |
| 稳定期 | 80 万字+ | 均订、月票排名、读者活跃度 | 若长线供血设计存在明显断层，下调最终签约上限预估 |

**特别注意**：漏斗模型显示 60% 的读者流失发生在前 15 章。评估任何阶段的作品时，前 15 章的追读工程设计都是重点审查对象。若前 15 章存在连续多章纯推进无钩子的设计，即使总纲/分卷看起来完整，也应大幅下调正文准入判断。

### 10 万字中期验证闸门（新增）

- 当材料已进入约 `10` 万字量级（或可等价映射到该阶段）时，默认补做中期闸门：
	1. 是否仍保持可感知的阶段回报密度，而非“只推进不兑现”；
	2. 是否已形成从开篇承诺到中段放大的连续证据；
	3. 是否存在可见的推荐位晋级或稳定读者支持代理信号；
	4. 是否出现单章掉追连续异常并已定位病灶。
- 若中期闸门 `4` 项中有 `2` 项及以上失效，默认不得给出乐观中高档概率。

### 2025–2026 年趋势对评估的影响

以下趋势应直接影响评估中的题材赛道判断与概率区间：

- **都市现实题材男频文**：2025 年下半年流量暴涨 270%，2026 年继续增长。评估该类作品时，题材加分权重可比常规赛道高 5–10 个百分点——但前提是作品确实具备"现实针脚、小人物逆袭、接地气"等特征，而不是"套着都市皮的玄幻"。
- **科幻品类**：作品数量增幅超 67%，有「银河计划」专项扶持。但竞争同步加剧，评估时不能只因为"科幻赛道热"就给高分；必须与已过审的科幻样本做从严对照。
- **悬疑灵异品类**：2026.5.1–2027.12.31 享有专项扶持（月票榜现金奖励第 1 名 5000 元 + 每月 1500 元全勤补贴）。评估该类作品时，应额外检查是否充分利用了扶持窗口的红利期。
- **反套路趋势**：系统是反派、主角靠智慧反杀、现实向小人物逆袭的内容正在取代传统升级打怪。若作品仍停留在"开挂碾压一切"的老套路且无创新融合证据，应从严下调概率。

## 研究回灌补强（2026）

- 情感向项目默认增加三项快审硬核验：
	1. 前 `300` 字是否出现可感知冲突/危机；
	2. 黄金三章是否形成“绝境-加压-首次回报”闭环；
	3. 前 `6000-9000` 字是否建立持续追读承诺。
- 对“高概念但低代入”文本默认降置信度：若只有设定新奇、缺少人物痛点与现实锚点，不得给中高概率区间。
- 签约评估需单列“价值观与平台导向适配”：是否存在恋爱脑依附、失衡权力美化、未成年恋爱细节等高风险表达。
- 在女频或情绪主导赛道，默认强调“成长线承重能力”与“关系线供血能力”双过线，任一失衡都按封顶项处理。

## 投稿材料模板符合性预检（强制）

- **【起点口径】** 若本轮评估读取了可直接投递给编辑的投稿材料，且目标平台经路由链解析为起点（用户指定起点 / Agents.md 解析为起点 / 默认回退起点），必须先检查总纲中的 `## 模板组合声明`。
- **【起点口径】** 若模板声明缺失，必须回读 `CommonSkills/写作研究/起点模板/总纲模板/README.md` 反推主模板；若仍没有更合适模板，默认按 `CommonSkills/写作研究/起点模板/总纲模板/九线写作总纲.md` 作为最低结构基线。
- 模板预检至少要回答：是否存在 `1` 个主模板与 `0–2` 个辅助模板、主模板是否合理、投稿材料中的大纲 / 首卷承诺 / 长线供血是否规范使用该模板、辅助模板是否只是结构补丁。
- 模板不符默认归类为**设计规范性风险 / 投稿成熟度风险**，主要影响“是否建议现在投稿”“当前层是否放行”“置信度与建议结论”；它不直接替代内容主分，不等价于正文质量一定很差。
- 若模板声明缺失且材料结构混乱到无法证明首卷承诺、长线供血与主卖点落点，则当前层不得给出“建议现在投稿 / 建议现在内投”的乐观结论。

## 分阶段准入评估（强制）

- 若当前只有书名 / 简介 / 总纲，默认执行 **总纲闸门预评估**；核心问题不是“正文写得怎么样”，而是“这套总纲值不值得继续细化成分卷”。
- 若当前已具备总纲 + 分卷，默认执行 **分卷闸门预评估**；核心问题不是“正文已经过线没有”，而是“这套分卷是否足以安全推进章节正文”。
- 若当前已具备前若干章正文，默认执行 **正文准入评估**；核心问题不是只看开篇爽不爽，而是“是否适合继续写、适不适合进入投稿 / 完整签约评估，以及问题究竟卡在总纲、分卷还是正文执行层”。
- 若材料齐备到能交叉验证书名简介、正文、人物、机制、总纲、分卷与执行准备，才进入 **完整签约评估**。
- 在总纲闸门预评估与分卷闸门预评估中，必须同时回答四件事：
  1. 当前层是否通过；
  2. 是否放行下一层；
  3. 若不放行，应停留或回修到哪一层；
  4. 现在不修、继续硬写，最可能造成的后续大返工是什么。
- 在正文准入评估中，必须把问题明确归因到：**总纲级 / 分卷级 / 正文级**；除非证据已经足够扎实，不得轻易要求用户回退到更上游整层重写。
- 非完整评估阶段若需要补充“最终签约潜力”，只能写成**低置信度上限预估**，不能冒充当前已具备正式签约成熟度。

## 默认执行顺序

0. **阶段 0（强制）：网络搜索捕获最新趋势**——先完成"第零步"的全部必搜清单（平台政策、赛道热度、新晋爆款、套路时效性、编辑经验、竞争水位），记录搜索关键词、时间与结论。**未完成趋势捕获不得进入后续步骤。**
1. 阶段 A：先判材料完整度与评估模式。
2. 阶段 A：再判当前位于总纲、分卷、正文还是完整评估层，并写清本轮主结论到底在评“推进分卷”“推进正文”还是“推进投稿 / 签约”。
3. 阶段 B：**【起点口径】** 若目标平台为起点中文网（含 Agents.md 解析为起点或默认回退起点），在阶段 0 趋势搜索的基础上，再用多种可用网络搜索工具进一步检索**起点同题材榜单前 10**（阶段 0 已覆盖赛道热度，此处聚焦榜单具体排位与样本锁定），锁定 Top 10 候选池并记录检索口径；**其他平台**按该平台的可用榜单或搜索渠道做同赛道 TopN 检索。
4. 阶段 B：若当前目录下已有相关 `竞对分析/` 文件，先读取相关报告，把可复用的样本、旧判断与待复核点纳入本轮工作清单。
5. 阶段 B：再从 TopN 候选池中圈定 `3–5` 本主压制样本，并组合调用 `通用-分析竞对作品` 按四层框架深拆；其余样本至少补齐简版证据卡。
6. 阶段 B：对榜单 TopN **逐本深搜**：优先搜索并阅读可获得的正文 / 试读片段、书评 / 讨论、研究 / 拆解文章；若官方源受阻，再补充读取可核验的第三方相关内容，并记录可信度与盲区。
7. 阶段 B：若存在竞争位 / 强情绪语境，先把情绪背景翻译成客观评估问题：**威胁度、签约概率、阻断点、可学习强项**。
8. 阶段 C：若本轮评估包含"可直接投递给编辑的投稿材料"，先读取 `投稿材料/` 下对应平台目录的作品根目录与 `当前版本索引.md`（平台未指定则按路由链解析：先读 Agents.md 主输出平台，仍无则默认 `起点内投`），再进入当前版本目录读取 `内投版简介`、`内投版正文`、`内投版总大纲`、`内投版第 1 卷卷纲` 与 `组包自检`，并将其与正文、总纲、分卷等证据做交叉核验。
9. 阶段 C：若已读取投稿材料，再做一次模板符合性预检：检查模板声明、主模板合理性、辅助模板越位情况，以及投稿材料是否规范使用对应模板。
10. 阶段 C：再判投稿路径是否达到了最低硬门槛（自主申签 / 编辑内投 / 仅适合预评估）。
11. 阶段 D：再判红线、封顶与一票否决项。
12. 阶段 D：再做平台快审模拟：30 秒、3 分钟、3 万字 / 首卷三个层级分别会不会被拦下；若当前仍处总纲或分卷阶段，则改判为设计级就绪度与执行风险。
13. 阶段 D：再把目标作品与同赛道 TopN 候选池做从严差距对照，重点确认编辑为什么更可能把时间与名额给对照样本；其中 `3–5` 本主压制样本必须显式吸收四层深拆结论。
14. 阶段 D：再判目标平台是否能快速归类作品卖点、卖点是否足够鲜明，以及作品是否承载“可持续付费价值”。
15. 阶段 D：再按维度打分，并把分数落回到样章、人物、设定、长线与执行证据。
16. 阶段 D：再明确本轮是否放行下一层、若不放行应停留 / 回修到哪一层，以及最小修复闭环。
17. 阶段 E：再按落盘规则生成或覆盖主报告。
18. 阶段 E：最后输出概率区间、置信度、建议结论、最小补丁顺序，以及在竞争语境下的客观威胁结论。

## 默认平台基线（参考口径）

> 以下基线在目标平台未指定（且 Agents.md 不存在或未声明 `主输出平台`，按起点口径执行）或显式指定起点时按起点口径执行；指定其他平台时按对应平台的评估基线调整。

- 默认评估站位不是“替作品找能签的理由”，而是“先证明它为什么不会被刷掉，再看它是否强到值得编辑继续看”。
- 高分不等于“绝对高通过率”，而是“相对同赛道稿件更值得编辑继续看”。
- 默认审核顺序应理解为：**先硬性指标，再内容质量，再题材创新与后续数据潜力**。
- 默认优先判断三件事：
	1. 逻辑是否自洽，是否经得起连载推进；
	2. 主角、冲突与核心机制是否能形成现实代入；
	3. 是否具备长线付费价值，而不是只有瞬时刺激。
- 默认还要额外判断两件事：
	4. 编辑能否在首屏 / 简介层快速归类；
	5. 从前三章到前三万字，是否真的有“继续追下去”的工程，而不是只靠一个概念顶着。
- **【起点口径】** 在起点默认口径下，情节优先级通常高于文笔；“300 字是否抓人、黄金三章是否成立、前 3 万字是否具备持续追读理由”是快审核心。
- 若是大纲预评估，评的是“设计是否落到开篇执行层”，不是“正文已经做到”。
- 卖点评估至少要单独判断三件事：是否鲜明、是否能被编辑快速归类、是否能在正文中持续兑现；这三项明显偏弱时，不得给高通过判断。
- 若材料允许，还应显式判断：人物传记有没有把主角写成立得住的人、技术 / 规则有没有把卖点写成可用机制、卷纲 / 总纲有没有把首卷承诺和长线供血钉实。

## 何时使用

- 评估作品在目标平台的签约、过稿或内投潜力。
- 需要按固定口径输出概率区间、置信度与最小修复建议。
- 需要区分自主申签、编辑内投与仅适合预评估三种状态。

## 默认输出口径

- 默认输出一份带概率区间、置信度、建议结论与最小补丁顺序的评估报告。
- 默认不做鼓励式点评，而做**极严口径判断**；除非用户明确要求柔化，否则不主动替文本找补。
- 默认必须把“为什么现在能投 / 不能投”翻成：门槛、快审、人物、机制、追读、长线六类内容理由，以及单列的执行风险 / 投稿准备风险。
- **【起点口径】** 默认必须把“与起点同题材榜单前 10 相比，为什么这部作品更弱 / 仍不够强”写清楚；若差距明显，就直接据此下调概率与建议结论。其他平台评估时，参照目标平台的同赛道竞对样本做同等输出。
- 默认必须写清：当前作品为什么**还不够格进入“编辑愿意把名额给你”讨论**；若竞对量化卡仍显示明显落后，不得给出安慰式高分。
- 若本轮检查了投稿材料，默认还必须写清：模板组合声明是否存在、主模板是否合理、模板符合性结论，以及它如何影响当前投稿建议。
- 若用户处在竞争位 / 焦虑位，默认额外输出：**客观威胁度、真正值得警惕的强项、最可能被编辑拦下的点、哪些担忧更像情绪放大而非文本优势**。
- 若当前不在完整评估层，默认还必须输出：**当前层放行概率、下一层是否放行、建议停留 / 回修层级、继续硬写最可能导致的大返工点**。

## 最低交付

- 能明确说明当前材料完整度与评估模式。
- 能给出概率区间、置信度与建议结论。
- 能指出最关键的阻断问题与下一步动作。
- 能说明问题主要卡在：平台归类、开篇、人物、机制、追读工程、长线，还是另行单列的执行风险 / 投稿准备风险。
- 若检查了投稿材料，能说明模板组合声明来源、模板符合性结论，以及它如何影响当前投稿建议。
- 能明确回答当前阶段是否适合推进下一层；若不适合，能指出应停留 / 回修到总纲、分卷还是正文。

## 硬规则

- 不得用模糊表态代替概率判断
- 不得缺材料还给高置信度结论
- 不得拿优点冲淡致命缺陷
- 不得把“默认极严”误写成“默认敌意”；所有严苛结论都必须锚定文本证据、投稿门槛与平台事实
- 若读取了投稿材料，禁止跳过模板组合声明与模板符合性检查。
- **【起点口径】** 禁止把旧的 `6000` 字开篇样章或旧单文件投稿件包装成“已达起点内投提交线”；起点内投默认至少要有 `30000` 字连续正文、总大纲、`第 1` 卷卷纲与简介四份对外交付件。
- 禁止把模板不符直接偷换成内容主分低分；它首先是设计规范性风险 / 投稿成熟度风险。
- 若模板声明缺失且未完成 `README.md` 反推或默认九线回退，禁止给出“材料成熟、建议现在投稿”的乐观结论。
- 不得把“上游设计上能做到”写成“正文已经做到”
- 不得在总纲或分卷阶段只写“还缺正文”；必须先给当前层准入结论
- 不得把高分误写成高绝对签约率
- 不得把研究材料中的“高成功率条件分层”直接等同于本项目的高绝对签约率输出
- 不得混淆自主申签、编辑内投与仅适合预评估三种状态
- 必须给出下一步动作建议
- 报告默认必须落盘，不得只停留在聊天窗口
- 不得把“作者等级、历史名气、站外声量”直接折算为当前文本通过率；它们只能作为背景变量，不能替代正文与结构证据。
- 若连主卖点都无法用简洁口径说清，或开篇长期不兑现卖点，不得给出乐观签约结论。
- 若多个关键维度只是“中下可读”而非明确过线，默认概率不得写成乐观区间。
- 若只有设定 / 总纲看起来很强，但章级追读工程或人物代入明显不足，不得用“潜力大”稀释现实概率判断；若只是执行准备不足，应单列为作者执行风险，不得与前述文本缺陷并列拔高为作品质量问题。
- 不得把用户对作者的人身评价、私人恩怨、立场好恶或未经核实的“融梗 / 抄袭”指控直接折算为签约概率。
- 不得为了安抚用户情绪而故意压低文本实绩；也不得因为用户语气激烈就回避严格判断。
- 当用户要求“喷点”时，必须翻译为：**编辑视角下会明确扣分、卡审或导致停读的证据点**。
- 不得跳过**第零步（网络搜索捕获最新趋势）**；未完成趋势捕获的评估，判为"基线校准缺失"，置信度默认降一档。
- **【起点口径】** 不得跳过**起点同题材榜单前 10** 检索与从严对照；没有完成这一步，不得假装已经做出完整签约评估。其他平台按对应平台的同赛道 TopN 检索要求执行。
- 不得只拿 `1–2` 本热门样本象征性比较；默认必须对照完整 Top 10，并写明当前作品主要落后项。
- 不得把“列出 Top 10 名单”冒充“完成竞品研究”；未对 10 本样本逐本做深入检索、阅读与证据提炼时，不得宣称比较已充分。
- 不得只引用榜单标题、书名简介或二手概述就下重结论；默认必须尽量读到正文 / 试读片段、书评讨论与研究拆解材料。
- **【起点口径】** 不得因为起点官方页受阻，就直接放弃正文 / 目录补证；应先尝试可核验的第三方相关来源，再把仍无法确认的部分写成盲区。其他平台评估时同理处理该平台的官方页受阻情况。
- 不得把盗版站、未授权全文站或明显侵权镜像站当作正文 / 目录核心证据源；即使引用到相关页面，也只能作为低可信度线索，不能直接支撑强结论。
- 不得把已有 `竞对分析/` 旧报告直接当成本轮结论；旧文件只能辅助提效，不能替代本轮新搜索、新阅读与新复核。
- 不得用吹捧、安慰、鼓励式措辞稀释与榜单样本的差距；相对强项只能作为竞争位校准信息，不能冲淡阻断项。
- 若榜单对照已经显示当前作品在多个核心维度明显落后，不得再输出“基本能过”“大概率能签”之类的乐观结论。
- 正文阶段若判断需要回改上游，必须明确写出是**总纲级问题**还是**分卷级问题**；不得笼统写成“回去改大纲”。
## 商业节点与名场面预留审查（新增）

专业大纲不同于业余大纲的关键分水岭之一，是是否具备商业思维——不是"我想写什么"，而是"市场在哪、读者是谁、如何差异化、何时付费、何处出圈"。评估时，无论当前处于哪个阶段，都必须额外审查以下五项：

### 一、市场定位审查
- 该题材在目标平台是否饱和？蓝海还是红海？
- 若为红海，总纲/卷纲是否写清了差异化切入点？
- 若为蓝海，是否说明了为什么此前没人做成本书能做？

### 二、读者画像审查
- 总纲/材料是否写清了核心读者画像（年龄、偏好、阅读冲动）？
- 若只有题材标签没有读者画像，判为商业定位模糊，不得给高概率。

### 三、竞争差异化审查
- 是否说清了与同赛道竞品的本质差异？（不能只是"写得更好"，必须是"提供了竞品没有的阅读体验"）
- 差异化是否能在前 3 章被读者感知？

### 四、商业节点审查
- 是否标注了第一个付费点/强钩子的预计位置？
- 是否预留了 IP 衍生接口（短剧/动漫/有声剧改编的高光片段）？
- 是否有角色具备出圈潜质（标志性台词、易传播的人设）？

### 五、名场面与数据预留审查
- 是否设计了至少 2–3 个"名场面"（适合截图分享、短视频剪辑、本章说讨论）？
- 是否考虑了重要场景的视觉化呈现难度？
- 是否设计了话题性情节来刺激评论区/书友圈活跃度？

### 审查规则
- 以上五项中至少三项有明确落点，才能进入中高签约概率区间；若五项全空白，判为商业思维缺失，大幅下调签约概率。
- 若材料处于总纲/分卷阶段，商业节点与名场面可标注为"待定"，但必须说明预计补齐阶段；完全空白视为重大缺陷。
- 商业思维审查结论应单列为"商业就绪度"维度，与内容质量主分平行展示，不得互相混淆。
## 与其他 Skill / Prompt 的边界

- 本 Skill 负责评估与诊断，不直接代替题材定位、正文精修或投稿组包。
- 若用户已决定投稿并材料齐备，后续应交给 `通用-组包投稿材料`。
- 不得把“当前章节文件混有作者有话说 / 章节后记，不能原样送编辑”单列为平台签约评估扣分项。本项目默认允许章节文件直接承载这些内容；此处应评估的是正文内容、门槛与投稿成熟度是否能经 `通用-组包投稿材料` 整理成可投版，而不是要求原始章节文件本身就是最终投稿件。
- 不得把“无独立更新计划、无存稿证明、无稳定日更证据”直接上升为小说文本质量高阶缺陷。这类默认只写成作者执行风险 / 投稿准备风险，主要影响投稿时机、建议结论与置信度。

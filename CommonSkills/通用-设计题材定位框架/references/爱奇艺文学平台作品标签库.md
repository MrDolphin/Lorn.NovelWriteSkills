# 爱奇艺文学平台作品标签库（概念工厂原材料）

> **来源**：爱奇艺文学作者平台「新建作品-作品标签」系统，2026-06 抓取。
> **用途**：作为概念工厂的创意素材池。爱奇艺文学的标签体系分为**元素·人设·时间·风格**四个独立维度，每个维度互不重叠，可在四个维度中分别选择叠加。爱奇艺的标签更偏向**IP 影视化潜力**——很多标签在七猫/番茄中少见但在爱奇艺中独立列出（如"大厂""代际""监狱""民俗志怪""江湖"等）。
> **注意**：每个维度最多选 3 个标签。

---

## 标签体系说明

| 维度 | 说明 | 选法 |
| --- | --- | --- |
| **元素** | 故事的情节驱动力和核心设定 | 最多 3 个 |
| **人设** | 主角/关键角色的人物身份特质 | 最多 3 个 |
| **时间** | 故事发生的时代/时期背景 | 最多 3 个 |
| **风格** | 故事的情绪基调与叙事气质 | 最多 3 个 |

> 爱奇艺文学标签体系的独特之处在于四维独立选择——与七猫的「风格/角色/情节/背景」或番茄的「主分类/主题/角色/情节」类似，但爱奇艺多了一个独立的时间维度。时间维度仅 7 个标签，说明爱奇艺更关注朝代/末世等大时间框架，而非细分的年代文年份。

### 爱奇艺平台的特色方向

1. **IP 影视转化潜力**：爱奇艺的标签体系中有大量影视化高频标签（毒妃/医妃/摄政王/霸总/兵王），生成概念时应优先考虑"这个概念的画面感和连续剧结构"
2. **时间维度的灵活运用**：时间维度仅 7 个标签且不与元素冲突，概念工厂可以在元素中不选时间设定，而在时间维度中补充朝代信息
3. **非典型标签的灵感价值**：爱奇艺独有的"大厂""代际""监狱""民俗志怪""江湖""骗术"等标签，在七猫/番茄/豆瓣/知乎中均无对应标签，适合做跨平台差异化的切入点

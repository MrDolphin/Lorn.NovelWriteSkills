# 外部PK评估输出模板

> **用途**：概念工厂生成候选概念后，产出可直接复制给外部AI（ChatGPT/Claude/DeepSeek等）做独立评估的自包含指令。
> **核心原则**：外部AI没有本项目上下文，文件必须自包含——角色设定、评估任务、候选概念、输出格式全部写在一个文件里。
> **工作流**：用户复制全文 → 粘贴给外部AI → 外部AI返回评估 → 用户粘贴回本对话 → 本Agent根据反馈迭代方向。

---

## 模板骨架

```markdown
# 🎯 概念工厂 · 外部PK评估指令

> 本文件是自包含的评估请求。请按以下步骤操作：
> 1. 将全文复制到外部AI（ChatGPT/Claude/DeepSeek等）
> 2. 外部AI按"评估任务"中的要求输出结构化评估
> 3. 将评估结果粘贴回本对话，将根据反馈调整方向

---

## 一、评估任务

请你扮演一位资深网文编辑，主攻【{{题材}}】赛道。你的任务是评估以下候选概念的商业潜力。

### 判断标准（按优先级）
1. **这本书能不能卖**（签约/过稿/变现潜力）
2. **读者会不会追**（追读率/完读率/付费转化）
3. **长线能不能写**（撑多少字不崩/不重复/不灌水）

### 评估维度
1. **题材判定**：这是什么赛道？赛道当前热度与饱和度如何？
2. **第一眼抓力**：读者看到简介/前3章会不会点进来？为什么？
3. **主角代入感**：主角的困境/身份/目标是否能让目标读者共情？
4. **长线耐久度**：这个设定/套路能撑多少字不崩？中段靠什么续命？
5. **最大风险点**：这本书最容易翻车的地方是什么？（毒舌优先，不必留情）
6. **改进建议**：至少一条具体、可操作的改进方向。

### 输出格式要求

请按以下 JSON 格式返回评估结果。如评估多个候选概念，每个概念独立输出一套。

## 字段填充规则

| 占位符 | 填充规则 |
| --- | --- |
| `{{题材}}` | 目标题材，如"AI科幻""都市悬疑"等 |

## 使用限制

- 每个外部PK文件只评估**同一世界观资产**下的不同候选方向（共享设定/人物/世界），不能把完全不相关的概念放在一起PK
- 候选概念建议 **3~5个**，太少缺乏对比、太多外部AI容易遗漏
- 候选概念的文字量不宜超过外部AI的上下文窗口（建议总计 < 4000 字）
- 输出格式要求 JSON 是为了便于本Agent解析与对比；若外部AI习惯用表格或Markdown输出，也可接受非JSON格式，只需结构清晰即可
- 外部PK的结论仅作为方向参考，不替代内部审阅决策

# 访谈挖观点与挖声口方法（回访问题设计规范）

> **职责边界**：本文件是**方法模板**，定义"回访怎么提问、怎么捕获"的全部规则与示例——它不包含任何具体作者内容。所有示例均为格式示范（占位 / 假名），不得当作真实作者原声。
> **消费方**：通用-作者风格进化 Step 1（设计问题）、Step 2（交互执行 + 原声捕获）。

---

## 一、核心方法：挖观点 ≠ 问观点

直接问"你的创作观是什么"得到的往往是人云亦云的套话。真正的判断藏在层层追问里。以下方法体系源自深度访谈方法论（苏格拉底式提问、Laddering 阶梯法、SPiKY 内容创作挖掘法），迁移到小说创作语境。

### 1.1 苏格拉底式五类追问（下钻架构）

不满足于第一层回答，用五类问题逐层下钻：

| 类型 | 句式 | 作用 | 创作语境示例 |
| --- | --- | --- | --- |
| ① 澄清 | "你说的 X 具体指什么？能举作品里的例子吗？" | 把模糊表态变成具体写法 | "你说的'写复仇不能太爽'，具体指哪种爽法？" |
| ② 假设 | "你这个判断建立在什么假设上？如果假设不成立呢？" | 挖出隐藏前提 | "你默认读者都想要主角赢，为什么？" |
| ③ 理由证据 | "支撑这个判断的经历 / 见过的作品是什么？" | 追溯判断成因 | "是什么经历让你觉得'背叛不该被原谅'？" |
| ④ 推论结果 | "按你的写法推下去，读者会得到什么？" | 看判断边界 | "如果主角真把兄弟搞死，后面谁买单谁受益？" |
| ⑤ 对立视角 | "持相反写法的作者会怎么写？在什么情况下你的写法不成立？" | 检验判断韧性 | "有人会写'原谅才是成长'，你怎么看？" |

### 1.2 Laddering 阶梯法（从偏好爬到母题）

从作者随口提的具体偏好 / 经历出发，连续问"这对你重要吗？为什么重要？这让你获得了什么？"，逐级爬升：

```text
属性（作者说了什么）→ 后果（这带来了 / 避免了什么）→ 价值观 / 母题（这满足了什么深层原则）
```

- 一条阶梯约 5–7 层，爬到作者答不出 / 重复即到母题层。
- 示例：作者说"我讨厌写纯好人主角" → "纯好人是什么意思？" → "就是一路被欺负还一直忍让的那种" → "你其实是受不了什么？" → "我受不了'好人就该吃亏'这种天经地义" → **母题：命运不该优待老实人 / 公平**。
- 一旦（soft laddering）：交替用"然后呢""这让你想到什么""继续说"保持对话感，不机械连问"为什么"。
- 一次访谈产 3–5 条阶梯，跨阶梯反复出现的词 = 作者最核心的母题。

## 二、问题四段式结构（强制）

向作者提问时，**禁止裸问问题或只给标签式选项**。每个问题必须呈现为以下四段式，保证作者不看任何原文也能定位事件、听懂问题、看懂每个选项在说什么：

```text
【① 背景 · 上下文】≤80 字，一句话讲清：谁 / 哪章哪情节 / 什么冲突 / 这轮想厘清什么——
   例：主角阿澄第 3 卷被最好的兄弟出卖，卷入灭门案；网文常见写法是狠虐仇人，你想知道的可能不同。
【② 问题】有立场指向的提问（非"你怎么看"式空泛）——
   例：网上主流都写"复仇爽"，你最有把握说'他们都写错了'的是哪句？你的真实判断是什么？
【③ 为什么问】≤40 字，告诉作者：这个问题会挖到什么判断、答案将如何使用——
   例：校准你在"背叛 / 复仇"母题域的站位，答案沉淀进画像当后续情节立论。
【④ 选项】3–4 个「主句 + 括号解释」格式的完整立场选项——
   格式：{立场主句}（{括号内说明：这个判断的依据 / 具体含义 / 与别的选项差在哪}）
   ❌ 只有标签或主句："爽""虐""黑化"（作者无法判断你到底在说什么、选项间差什么）
   ✅ 主句+括号："虐但要留一丝白——把恨写透但不把主角写烂（仇人该死，但主角若也变成杀人机器就没人疼他）"
```

### 呈现顺序（强制）

① 背景（事件上下文）→ ② 问题 → ③ 为什么问 → ④ 选项。**背景必须放在问题之前**；选项统一为「主句 + 括号解释」，每个选项单独读即可自洽。

### 选项设计三准则（做选项前逐条自检）

1. **可判定**：每个选项 = 立场主句 +（括号解释），括号内讲清"为什么这么判断 / 意味着什么"，作者不依赖任何折叠说明即可读懂自己在同意什么。
2. **可辨析**：选项之间是"立场分叉"而非"措辞微调"；括号解释强化差异点。
3. **可写作用**：选项主句即可作创作判断句入库，选中后可无需二次加工直接进画像母题层；括号解释可并入笔记作为理由支撑。

### 自由输入捕获判定（选项是"盖章"，自由输入是"签名"）

| 作者回答形态 | 是否捕获原声 | 说明 |
| --- | --- | --- |
| 单纯点选选项 | 否 | 选项是 AI 拟的，代表 AI 表达不捕获；仅取观点 |
| 选选项 + 追加文字 | 是（仅追加部分） | 追加部分即作者最自然表达，风格含量最高 |
| 直接写一段话 | 是（整段） | 最高优先级原声，逐字保留 |
| 用"其他"自由输入 | 是（整段） | 同"直接写一段话" |
| 纯选项但附带立场句（"我补充一句：…"） | 是（该句） | 同条同时进观点沉淀 + 样本库 |

## 三、小说版 7 个问题槽位（每轮选 ≤4 个）

> 与 deai-author-voice 的对应：小说写作里作者不直接发表观点，判断藏在"你会怎么写"里——所有槽位的问题都从"你怎么看"改造成"你会怎么写 / 你会怎么分配"。

### 槽位 1 · 创作判断校准槽（针对近期创作 / 情节争议）

- 用途：校准作者对近期章 / 人物处理 / 剧情争议的真实判断，纠正"AI 帮你写出来的默认写法"。
- **背景**（写法示例）："{章 / 情节名}：{核心冲突一句话}；当前写法落脚 = {现有处理一句话}"
- **问题**："网上主流都这样写 {主流写法}，你最有把握说'他们都写错了'的是哪句？你的真实判断是什么？"
- **选项**：≥3 个「主句+括号解释」（主句 = 反主流判断，括号 = 理由 / 含义）
  - ✅ 例："虐但要留一丝白——把恨写透但不把主角写烂（仇人该死，但主角若也变成杀人机器就没人疼他）"

### 槽位 2 · 人设决策下钻槽（追问判断依据）

- 用途：下钻某创作判断的来历，追溯作者的心智 / 经历 / 价值观成因。
- **背景**："{你上一篇判断 / 作者刚表达的观点一句话}——记住你原话：'…'"
- **问题**："你凭什么这么说？支撑这个判断的具体经历 / 见过的作品 / 生活观察是什么？"
- **选项**：≥2 个「主句+括号解释」的"可能来历"判断句 + 鼓励自由输入——按作者原话下钻，不植入自己的假设。

### 槽位 3 · 人物声口对立槽（作者替角色说话）

- 用途：让作者站到角色一方开口，直接产出**角色声口原声**（喂人物声口库）。
- **背景**："{第 N 章}：{主角与某角色} 正在对峙，谁都寸步不让——"
- **问题**："如果让 {角色} 在这个节骨眼上反驳 / 激怒 {主角}，他会怎么说话？给我念一句，用他的口气。"
- **选项**：≥2 个「主句+括号解释」的"声口样本候选"（主句 = 角色口气的原话样例，括号 = 这句暴露了什么性格），**明确鼓励自由输入**（自由输入 = 作者替角色写的最真一句，优先级最高）。

### 槽位 4 · 母题价值观槽（Laddering 顶层）

- 用途：把作者反复出现的主题词爬到"它到底意味着什么"的母题层。
- **背景**："你反复写到 '{关键词}'（如背叛 / 公平 / 活下去）——在 {你批评或着迷的某段情节} 里反复出现"
- **问题**："对你来说，'{关键词}'到底意味着什么？它重要是因为什么？"
- **选项**：≥3 个「主句+括号解释」的"母题定义句"（主句 = 定义，括号 = 含义 + 为什么重要）
  - ✅ 例："命运不该优待老实人——公平不是人人都赢，而是老实人的付出得被看见（主角吃亏可以，但不能'白吃'）"

### 槽位 5 · 叙事锋芒槽（SPiKY，作者最敢写的）

- 用途：挖作者最敢站队的反共识写法——这是作者辨识度最高的地方，也是金句最大来源。
- **背景**："{题材} 里大家习以为常的一个写法：{一句话}（如：金手指必须无脑利主）"
- **问题**："这个写法里，最让你觉得荒谬、想翻台的是哪个桥段 / 细节？一句话说透。"
- **选项**：≥3 个「主句+括号解释」的"可直接成金句"立场句 + **明确鼓励自由输入**（这是金句来源，自由输入优先级最高）。

### 槽位 6 · 叙述声口挖矿槽（A 类，本次回访强制 ≥1）

- 用途：拽出作者的**叙述原声**——让作者用平时说话的口气讲一段，这段口气就是叙述者声口的唯一权威来源。
- **背景**："你构思过一个小场景：{一句话}（或：你记忆里的一件小事：{一句话}）"
- **问题**："给我讲讲它，就用你平时跟朋友讲八卦的口气——别端着，爱怎么嘀咕怎么嘀咕。"
- **选项**：≥3 个「主句+括号解释」的**叙述语气自陈句**（主句 = 作者自我风格定位，括号 = 典型句式举例，如"蹲墙角看戏的损友——爱用一句话点评人，'这人啊，算盘精得能听见响'"）+ **明确鼓励自由输入**（自由输入 = 原声叙述，优先级最高）。
- 落地：作者回答中的**原话句式 / 金句 / 毒舌命名**必须原样记入样本库（A 类），供叙述句法层与作者语言库回填。

### 槽位 7 · 世界观假设槽（作者信世界被什么驱动）

- 用途：挖作者对"世界怎么运作"的底层判断，转化为故事的世界观规则与价值母题。
- **背景**："在你熟悉的那套 {行业 / 世道 / 人性} 里——{具体场景一句话}"
- **问题**："那套规则里最虚伪 / 最真实的一环是什么？它被包装成什么样？"
- **选项**：≥3 个「主句+括号解释」的完整判断句（主句 = 点破包装，括号 = 包装成什么 / 谁受益）。

## 四、提问要点与常见错误

- **好提问标准**：① 开放非封闭（不用"是不是"）② 先易后难（先建立信任再下钻）③ 一次一问（不连珠炮）④ 追问有效期——引作者原话、不植入自己的假设 ⑤ 沉默也是工具（留白让作者自己补）⑥ 宏观 + 微观结合（既问大局又问具体时刻）。
- **常见错误**：
  - 裸问"你怎么看这段"（无立场指向，问不出可写作判断）
  - 选项做成裸标签（"爽 / 虐 / 黑化"），作者看不懂差异
  - 把解释放折叠区 / description 栏（多数 UI 只渲染 label，作者看到的仍是裸标签）——**主句+括号必须整体写入选项 label**
  - 丢掉自由输入（只拿选项观点，把作者最自然的话丢了）——**这是本机制最大的浪费**
  - 替作者说"你应该是这个意思"（下钻时植入 AI 假设）

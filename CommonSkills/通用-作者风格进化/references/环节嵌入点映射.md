# 环节嵌入点映射（全流程自动收集调度表）

> **职责边界**：本文件是**方法模板**，定义各创作环节如何自动调用 `通用-作者风格进化` 的嵌入模式——何时问、问什么槽位、消费画像哪一层、沉淀到哪里。不含任何作者具体内容。
> **消费方**：各环节 Skill（通用-设计题材定位框架、通用-分析竞对作品、通用-设计总大纲、通用-设计人物传记、通用-设计故事设定、通用-创建小说正文 等）在本环节开始前读取本表并调用嵌入模式。

---

## 一、嵌入协议速览

| 维度 | 规则 |
| --- | --- |
| 触发时机 | 环节 Skill 执行流程开始前（前置收集），一律不阻断主流程 |
| 提问数 | 必采环节 ≤2 问（默认 1 问）；**高频草稿环节只读消费画像，不提问** |
| 去重 | 同一主题域 7 天内已有立场 → 不提问，直接回喂画像摘要 |
| 问题格式 | 四段式（背景→问题→为什么问→选项），背景可缩短为本环节场景一句话 |
| 捕获 | 自由输入原声照常进捕获队列（A/B 按性质分），备注 `嵌入模式·{环节名}` |
| 沉淀 | 回答即归档样本库（L2 模板）+ 立场直接回填画像对应层小节，不重复完整深加工 |
| 回喂 | 输出「画像摘要卡」= 消费层现行摘要（≤1 页），作为本环节作者约束 |
| 样本统计 | 嵌入样本并入周期蒸馏触发计数（与回访样本合并 ≥10 条或 ≥7 天） |
| 降级 | 项目未注册作者风格进化数据源 / 作者明确跳过 → 回退既有模板与默认基线，不报错 |

## 二、环节映射总表

> 三区制：**必采区**（低频启动环节，前置 ≤2 问并入既有确认轮次）→ **只读区**（高频草稿环节，只回喂不提问）→ **触点区**（事件驱动捕获，无需提问）。

### 必采区（启动即采，每环节 1–2 问）

| 环节 | 调用 Skill | 建议槽位 | 前置收集问题示例 | 消费画像层 |
| --- | --- | --- | --- | --- |
| 项目初始化 | `通用-小说项目初始化` | 创作意图 / 市场观校准 | "这本书你想写给谁、想赚什么？跟想表达的产生冲突时你站哪边？" | 读者观念层 + 价值母题层 |
| 选题构思 | `通用-设计题材定位框架` | 母题价值观槽 + 创作判断校准槽 | "这本书你最想写透的母题是什么？它重要是因为什么？" | 价值母题层 + 情节伦理显影层 |

## 三、嵌入执行细则

### 3.1 调用方接入方式（钩子写法）

各环节 Skill 在「自动发现规则」一带声明（统一节名 `## 作者风格画像嵌入`）：

```markdown
## 作者风格画像嵌入（作者反馈自动收集）
- 若项目根 `Agents.md` 已注册"作者风格进化"数据源（`蒸馏产物/作者风格进化/` 下的 作者风格画像.md 与 作者原声样本库.md）：
  - 前置（本环节开始前）：按 `通用-作者风格进化` 嵌入模式收集 ≤2 个判断（本环节槽位 / 问题示例见其 references/环节嵌入点映射.md），原声与立场即时沉淀
  - 执行中：读取 作者风格画像.md 的 {对应层} 作为本环节作者约束
- 未注册或作者跳过：回退既有模板与默认基线，不报错，不阻断
```

### 3.2 回喂格式（画像摘要卡）

调用 Skill 执行中消费的「画像摘要卡」按以下结构输出（≤1 页）：

```markdown
### 画像摘要卡 · {环节名}（{日期}）
- 消费层摘要：{对应层现行规则 3–5 条，逐条标注支撑样本数}
- 本环节作者约束：{可直接执行的句级 / 情节级规则}
- 未覆盖空白：{该层暂无样本支持的项——执行时回退通用默认，不臆造作者风格}
```

### 3.3 防疲劳与去重

- 同一主题域 7 天内已有沉淀立场 → 去重命中，跳过提问直接回喂
- 嵌入模式累计提问频率过高（单日 >3 环节都命中同主题域）→ 合并为一次提问，其余环节仅回喂
- 作者连续 2 轮嵌入均无自由输入且选项作答 → 后续 3 天内该环节降级为不提问（只回喂），减少机械交互

## 四、与完整回访的分工

| 维度 | 嵌入模式 | 完整回访 |
| --- | --- | --- |
| 触发 | 各环节 Skill 自动调用（前置） | 作者手动 / 周期触发 |
| 提问数 | ≤2 问 | ≤4 问 + 下钻 |
| 目标 | 本环节决策相关的即时立场收集 | 深度挖母题、叙述声口、跨主题全景 |
| 沉淀 | 即时归档 + 回填对应层小节 | 完整图谱 + 周期蒸馏 + 反向净化 |
| 频次控制 | 去重 + 降级机制 | 每次 ≥1 个 A 类槽位 |

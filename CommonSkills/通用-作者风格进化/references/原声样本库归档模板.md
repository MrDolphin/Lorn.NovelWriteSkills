# 原声样本库归档模板（数据文件结构与归档规范）

> **职责边界**：本文件是**方法模板**，定义"作者原声样本库"与"作者风格画像"两个数据文件的**开头模板骨架、归档格式、蒸馏闭环**——不含任何作者具体内容（示例用占位符，落地时由 通用-作者风格进化 回访捕获）。
> **数据位置**：两个数据文件放小说项目根 `蒸馏产物/作者风格进化/`；谁写入 / 谁消费见下表。

---

## 一、三层闭环（捕获 → 归档 → 蒸馏）

```text
L1 捕获（回访当场）  →  L2 归档（滚动样本区顶部，逐字保留）  →  L3 周期蒸馏（≥10 条 或 ≥7 天）→ 回填作者风格画像
```

### L1 捕获：任何自由输入都是风格样本

- **触发条件**：作者回答只要不是"单纯点选选项"——选了选项还追加了文字、直接写了一段话、用"其他"自由输入——这段文字就是作者最自然的表达，风格含量最高。
- **A/B 双类分流（强制）**：
  - **A 类 · 叙述原声**：作者**讲故事时的口气**（讲一段记忆、讲一个构思的小场景、口述一段情节）→ 喂叙述句法层 + 叙事方法层 + 作者语言库
    - A1 · 访谈叙述原声：回访槽位 6 捕获
    - A2 · 口述转写原声：作者口述 → 转写逐字入库（最强叙述原声；首次口述 ≥10 条 → 立即蒸馏）
  - **B 类 · 创作判断原声**：作者**谈创作判断时的原话**（对人物 / 情节 / 母题的立场、吐槽、站队）→ 喂情节伦理显影层 + 价值母题层
- **散落触点来源标注（每条样本必标，S1–S6）**：

| 触点 | 来源 | 典型样本 |
| --- | --- | --- |
| S1 访谈 | 回访 / 嵌入提问 | 四段式提问的自由输入 |
| S2 口述转写 | 作者口述录音转写 | 口述场景 / 过往 / 构思，人工粗筛"这句像他说话" |
| S3 改稿痕迹 | AI 改稿 / 去味稿 / 润色稿 diff | 作者恢复 / 坚持 / 删除的句子（无意识审美） |
| S4 作者窗口 | 作者有话说 / 书评 / 简介 / 读者互动 | 作者对外说话的原话 |
| S5 审阅回流 | 对审阅报告的取舍 | 作者坚持反驳 / 欣然采纳的意见原话 |
| S6 选例素材 | 素材选择 / 设定意象 / 口述碎片 | "你为啥总用这类素材"的答案 |

- **捕获时间**：回访当场（Step 2 交互结束后立即）或触点事件发生时（改稿 / 审阅 / 互动结束后当场），不等到整轮结束；先存临时草稿防遗忘。
- **捕获内容**：原话全文（一字不改）+ 上下文（哪个问题 / 哪个环节 / 什么场景）+ 初判风格特征 + 触点编号。

### L2 归档：一条样本 = 一行完整记录

按以下模板追加到 `作者原声样本库.md`「滚动样本区」顶部：

```markdown
### {YYYY-MM-DD} · {触发槽位 / 选题 / 环节}（{A1/A2 或 B} · {S1–S6 触点} · {自由输入 / 选项+补充 / 改稿保留 / 口述转写 / 审阅取舍 / 作者窗口}）
- **原话**："{作者回答 / 改稿保留句原文，逐字保留。}"
- **上下文**：{问的什么问题、聊的哪个情节 / 主题、作者在反驳 / 支持什么}
- **风格初判**：句法=[长句/短句/反问/设问自答/对比]｜显影=[谁遭殃/谁得利/谁被讽刺]｜情绪=[毒舌/克制/温情/冷冽]｜金句=[对仗/俚语/判断/反问]｜比喻=…
- **可引用金句候选**：{"..."}（若有，可直接进正文 / 角色台词 / 作者有话说）
```

- 原话：逐字保留，不含 AI 改写；若回答夹杂选项文本，只归档追加的自发部分。
- 无自由输入时：标 `N/A（本轮全为选项作答）`，不虚构样本。
- 纯选项回答中作者追加的关键句：若含立场（"我补充一句：…"），同句同时进样本库（A/B 按性质）+ 观点沉淀（Step 4 画像）。

### L3 周期蒸馏：归纳回填画像

- **触发**：新增 ≥10 条，或距上次蒸馏 ≥7 天（取先到，通用-作者风格进化 Step 5 检查）。
- **动作**：通读新增样本 → 统计重复句式 / 词汇 / 论证 / 情绪 / 金句 / 比喻模式 → 新模式回填 `作者风格画像.md` 对应层 → **反向净化**（画像中找不到 ≥2 条样本支撑的描述降级 / 删除）→ 标注来源"样本库 {N} 条蒸馏，{日期}"。
- **衡量标准**：样本库越厚、画像越准——最终目标是"作者原话金句可以直接当正文金句 / 角色台词用，不用改"。

## 四、与 通用-蒸馏作者文风 的种子协作

- **冷启动**：首次做风格进化前，若项目没有画像，先跑 `通用-蒸馏作者文风` 从作者已有作品建"作者风格模板"作种子（其[统计]类结论作为叙述句法层初稿），再开始首轮回访。
- **日常保持**：后续进化靠访谈原声，不再依赖作品取样；`通用-蒸馏作者文风` 可随时重跑校准（作者文风变化大时）。
- **冲突规则**：画像与静态模板冲突 → 画像优先（动态访谈原声 > 静态历史统计）；平台硬门槛 → 平台硬门槛优先。

# 作者小说风格画像卡 · 方法模板（结构与规则）

> **职责边界**：本文件是**方法模板**，不是作者数据。本文件定义"作者小说风格画像"的**十层结构、字段含义、蒸馏规则、消费协议与像不像审计**——它不包含任何具体作者内容（例句 / 金句 / 语气全在小说项目根 `蒸馏产物/作者风格进化/作者风格画像.md`）。
> ⚠️ **数据位置**：作者风格具体内容一律从项目根 `作者风格画像.md`（蒸馏后规则）与 `作者原声样本库.md`（原始原话）读取——每日 / 每轮回访只追加数据文件，不写入本模板（skill = 方法，项目根 = 作者数据，机制不承载内容）。
> **上游**：滴水之源是 `通用-作者风格进化` 的访谈原声与散落触点（改稿痕迹 / 审阅回流 / 作者窗口 / 口述转写）；初值可用 `通用-蒸馏作者文风` 产出的"作者风格模板"作种子。

---

## 一、十层结构（作者小说风格画像 = 十个字段组 + 自检清单）

> 每个字段组在从样本库提取 / 蒸馏回填时，按此结构落位到项目根 `作者风格画像.md` 对应小节。十层 = 原六层（一~六）+ 扩展四层（七~十）。扩展层来源以**散落触点实证**为主，提问为辅。

### 一、叙述句法层（叙述者说话的方式）

- 字段：`句长基线` `断句习惯` `对话标签偏好` `心理描写密度` `留白率` `人称与叙事距离` `常用连接词 / 语气词`
- 示例字段值：{短句多、对话标签只用"道"不加修饰 / 心理独白长而密 / 冷叙述镜头 / 爱用"其实""说白了" }
- 蒸馏要点：叙述声口 = 最高辨识度特征，优先提炼；来源以 A 类叙述原声为准

### 二、情节伦理显影层（作者三观如何"显影"而不说教）

- 字段：`谁遭殃` `谁得救` `谁被讽刺` `报应如何兑现` `作者站队` `反说教落地方式`
- 蒸馏要点：小说里作者不直接说"我认为 X"，而是通过**分配**显影（谁的结局、谁得利、谁被怜悯）。此层回答"作者的价值判断落到情节的哪个位置"
- 提炼提示：同一判断在 ≥2 个不同情节反复出现才算显影律（一次性偶然安排不算）

### 三、情绪审美层（读起来是什么味）

- 字段：`基调`（冷冽 / 温情 / 黑色幽默 / 荒诞 / 悲悯 / 燃爽）`情绪在何处抬升回落` `叙述者对惨事是熨帖还是旁观` `讽刺的落点`
- 蒸馏要点：情绪姿态决定全文基调，必须与题材平台的情绪要求拉开（本层服务"作者味"，平台偏好交由平台 Skill 处理）

### 四、作者语言库（可带走的话）

- 字段：`原声金句` `比喻原型`（作者偏爱哪类比喻源头：钱、吃食、机器、天气…）`惯用意象` `口头禅式描写器`
- 蒸馏要点：金句必须口语、贴生活、反共识；位置 = 段落尾巴 / 全文尾巴 / 场景收束；**全部只从作者原声长**

### 五、价值母题层（风骨与母题）

- 字段：`反复母题清单`（如背叛 / 公平 / 活下去 / 劳动）`价值底线`（不许动摇的判断）`世界观假设`（作者信世界被什么驱动）
- 蒸馏要点：母题 = 多次回访反复出现的立场归纳，非单次回答；升华时不口号化

### 六、人物声口库（小说新增：作者为角色分配的说话配方）

- 字段：`角色声口标签`（每主要角色一句话：冷静账房 / 急赤白脸 / 阴阳怪气）`声口差分策略`（角色间句长 / 用词差异度，防趋同）`作者表达DNA借位`（作者自己的金句 / 毒舌可借给哪个角色用）
- 蒸馏要点：人物声口来自 通用-设计人物传记 的人物表达DNA + 本 Skill 槽位 3 的"作者替角色说话"原声；**作者个人语言库只借位给"与作者三观近"的角色，反派 / 异见者要刻意拉开**

### 七、叙事方法层（手艺 DNA：作者怎么讲一个场景——扩展层）

- 字段：`信息释放习惯`（直给 vs 藏线 vs 钓饵）`留白率` `镜头偏好`（场景式 / 心理式 / 蒙太奇）`推进方式`（对话推进 / 动作推进 / 叙述推进占比）`首尾处理习惯`
- 蒸馏要点：对应 teacher-voice「教学法层」——不像句法层回答"一句话怎么说"，本层回答"一个场景 / 一段信息流怎么铺"；来源 = 口述转写原声的主干 + 已定稿正文的模式统计 + 改稿痕迹
- 提炼提示：同一处理习惯在 ≥2 个场景反复出现才算方法指纹

### 八、材料偏好层（作者爱写什么——扩展层）

- 字段：`反复进入的素材类型`（哪类人生碎片 / 职业 / 地名 / 时代）`惯用意象`（雨 / 烟 / 街灯 / 秤…）`人设原型偏好` `桥段原型偏好`
- 蒸馏要点：对应 teacher-voice「选例偏好」——作者反复放进故事的"材料"是他内心世界的入口；来源 = 素材库选择记录 + 设定意象 + 口述碎片
- 反哺：消费方 `通用-补充构建素材库` 按本层定向补素材

### 九、读者观念层（作者为谁而写——扩展层）

- 字段：`目标读者的默认画像`（作者心里"读者是谁"）`市场 vs 自我的天平` `对读者反馈的态度` `平台的取舍底线`
- 蒸馏要点：对应 teacher-voice「评估回流」——作者在商业与表达之间的取舍是长期判断，不是单次回答；来源 = 审阅回流取舍 + 商业环节（标题 / 简介 / 平台改写）的取舍 + 访谈
- 供商业化环节消费：`通用-设计标题` / `通用-撰写内容简介` / `通用-多平台小说适配` 等

### 十、读者关系经营层（作者怎么跟读者说话——扩展层）

- 字段：`作者有话说风格`（小剧场 / 汇报式 / 损友式）`互动原话`（本章说 / 评论 / 群聊原声）`距离感`（亲切 / 疏离 / 高冷）`更新习惯相关表达`
- 蒸馏要点：对应 teacher-voice「答疑记录」——作者在作品之外与读者直接说话的方式；来源 = 作者有话说原稿 / 作者互动的**逐字原话**（S4 触点）
- 消费方：`通用-润色作者有话说` / `通用-撰写书评` 按本层仿写作者向读者说话的口气

### 附 · 写作自检清单（写作中随时自查）

- [ ] 叙述声口 ≥2 处符合叙述句法层指纹？
- [ ] 作者价值是"显影"而非"说教"（没人替作者喊口号）？
- [ ] 有可带走的口语金句，且放在段落 / 场景尾巴？
- [ ] 母题以情节显影 ≥1 处（不是直述）？
- [ ] 主角 / 作者亲近角色的声口 ≠ 反派声口（差分成立）？
- [ ] 场景铺法符合叙事方法层指纹（本场景的直给 / 留白 / 推进方式像作者）？
- [ ] 选用的素材 / 意象在材料偏好层范围内（或有意突破）？
- [ ] 作者有话说的口气符合读者关系经营层？
- [ ] 语气是"作者本人"而非"教科书 / 新闻稿 / 通用 AI 腔"？

## 二、蒸馏规则（样本库数据 → 画像）

1. **触发**：`作者原声样本库.md` 新增 ≥10 条，或距上次蒸馏 ≥7 天（两者取先到，通用-作者风格进化 Step 5 检查）
2. **动作**：通读新增原话 → 统计重复出现的句式 / 词汇 / 论证 / 情绪 / 金句 / 比喻模式 → 新模式回填 `作者风格画像.md` 对应层（新增或强化）；**散落触点样本（改稿痕跡 / 审阅取舍 / 作者窗口 / 口述转写）优先回填扩展层（七~十）**，并在条目旁标注触点来源
3. **反向净化**：画像中**找不到 ≥2 条样本支撑**的风格描述 → 降级或删除（防 AI 自创风格）
4. **溯源标注**：画像更新处标注"样本库 {N} 条蒸馏，{日期}"
5. **衡量标准**：样本库越厚、画像越准——最终目标是"作者原话金句可直接当小说里的金句 / 角色台词用，不用改"

## 三、消费协议（画像 → 写作 / 审阅 / 改写）

> 列表在 `通用-作者风格进化/SKILL.md` 的消费协议摘要之上，细化到下游 Skill 的强制核销点。下游 Skill 通过项目根 `Agents.md` 自动发现"作者风格画像增量"。

| 消费方 | 用什么 | 强制核销点 |
| --- | --- | --- |
| `通用-创建小说正文` | 叙述句法层 + 作者语言库 + 价值母题层 | 写前读画像：叙述声口 ≥2 处呼应、语言库化用 ≥1、母题以情节显影 ≥1（不是直述） |
| `通用-章节创作闭环` | 全部层 | 步骤 0 读画像摘要；完成后步骤 12.5 采作者产出反馈（B 类原声）进样本库 |
| `通用-正文润色` | 文风保留铁律 + 作者语言库 | 原话金句只磨毛边不换骨架；叙述声口不得被"润色平滑"；**改稿 diff 捕获**（作者恢复 / 坚持的句子逐字进样本库，S3） |
| `通用-去AI味重写` | 叙述句法层 + 作者语言库（人声回补） | 回补作者声口时从画像取原声模式，不从通用模板腔取；**去味稿 diff 捕获**（作者保留 / 恢复 = 无意识审美，S3） |
| `通用-审阅章节正文` | 叙述句法层 + 情节伦理显影层 + 人物声口库 + 扩展层 | 新增"作者像不像四指标"核销项（脚本取数，Anti-Cheat）；与既有"人物执行审计·声口一致性"合并检查；审阅结论发布前采作者取舍（S5） |
| `通用-审阅总大纲` / `通用-审阅分卷大纲` / `通用-大纲审阅优化闭环` | 母题层 + 显影层 | 审阅取舍回流（S5）：作者坚持 / 反驳的意见进样本库与母题层 |
| `通用-审阅人物传记` | 人物声口库 | 角色声口标签与传记"表达DNA"交叉核对，差分是否成立 |
| `通用-执行对话冲突` / `通用-执行场景单元` | 人物声口库 + 情绪审美层 + 叙事方法层 | 对话写作用声口差分，场景铺法符合叙事方法层指纹（只读） |
| `通用-强化章节开头` / `通用-强化章末钩子` | 作者语言库 + 叙述句法层 | 用作者的金句收尾 / 作者镜头感开头（只读） |
| `通用-设计人物传记` | 人物声口库（反向注入） | 新角色设"声口配方"时参考既有声口库防趋同 |
| `通用-润色作者有话说` | 读者关系经营层 + 作者语言库 | 作者有话说按作者向读者说话的口气仿写，不用通用小剧场腔 |
| `通用-撰写书评` | 价值母题层 + 叙事锋芒 + 作者语言库 | 书评是作者观点文：立场从母题层取，金句从语言库取 |
| `通用-撰写内容简介` | 价值母题层 + 叙事锋芒 + 读者观念层 | 简介主句偏好在读者观念层范围内校准 |
| `通用-设计标题` | 读者观念层 + 作者语言库 | 标题透题 / 含蓄取舍符合作者市场观底线 |
| `通用-多平台小说适配` / `通用-提纯多平台母稿` / `通用-多平台输出编排` | 叙述句法层 + 作者语言库 | 平台改写保留"作者味底稿"：母稿提纯时作者原声金句不丢，平台撞车修复不洗掉作者指纹 |
| `通用-补充构建素材库` | 材料偏好层 | 按作者反复进入的材料 / 意象定向补素材 |

> **冲突仲裁**：作者风格画像与 `通用-蒸馏作者文风` 模板冲突时，**画像优先**（动态访谈原声 > 静态历史统计）；与平台硬门槛冲突时**平台硬门槛优先**（平台可读性不因作者慢热被牺牲）。冲突显式记录，不暗中取舍。

每次周期蒸馏后在 `作者风格画像.md·蒸馏记录` 追加一行："{N} 条 → 更新了哪几层"。

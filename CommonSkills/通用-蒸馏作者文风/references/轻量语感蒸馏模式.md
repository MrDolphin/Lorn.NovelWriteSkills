# 轻量语感蒸馏模式

> 来源：SKILL.md §"轻量语感蒸馏模式（新增 — 快速仿写场景专用）"
> **文学蒸馏的核心：剥离情节、保留文法、提纯语感、复用骨架。** ——《文学作品仿写专用：文章蒸馏法》
>
> 适用场景：散文仿写、短篇文学仿写、公众号爆文仿写、特定章节语感复刻。
> 不适用场景：需要精确统计约束的长篇连载——此时仍应执行完整的 Phase 0-Phase 4 全流程。

当用户的需求不是"全面提取文笔 DNA"，而是**"快速模仿一篇特定作品的语感来写一篇新文章"**（如仿写一篇散文、短篇文学或特定章节），本 Skill 提供一套轻量级替代路径。它不要求完整的 9 维度统计分析，而是借用《文学作品仿写专用：文章蒸馏法》的四步流程，在极短的时间内完成"够用"的语感提取。

> 适用场景：散文仿写、短篇文学仿写、公众号爆文仿写、特定章节语感复刻。
> 不适用场景：需要精确统计约束的长篇连载——此时仍应执行完整的 Phase 0-Phase 4 全流程。

## 启动前自检——"仿写最怕两件事"诊断

启动前花 30 秒做以下诊断，即明确本轮的目标风险：

| 风险方向 | 表现 | 本模式中的应对 |
| --- | --- | --- |
| **抄得太死**（落入模仿区） | 滤水步骤保留了不该保留的具体表达——直接照搬了蓝本的意象、事件或场景，只改了名字 | 严格执行 Step 4 的 Replace 规则：意象、事件、场景、具体内容四项必须全部换掉 |
| **改得太散**（丢掉原作味道） | 置换重生时过度创新，把蓝本的结构骨架和语感也改没了 | 严格执行 Step 4 的 Keep 规则：结构骨架、语感、抒情逻辑三项必须全部保留 |

## 滤水原则——"删掉就没那味儿的"过滤器

在 Step 1（滤水）之前，先用以下两句判断对所有文字做一次预过滤：

> 删掉就没那味儿的，全部留下。
> 删掉不影响气质的，全部去掉。

——两句都不符合的，属于"删了可惜但留着也无益"的中间地带：**优先保留**，宁多勿少。

## 轻量四步法

| 步骤 | 名称 | 操作 | 用时参考 |
| --- | --- | --- | --- |
| **Step 1** | **滤水** | 删除原文中所有"不影响核心气质的文字"——铺垫废话、重复抒情、过渡语句、冗余细节；只保留"删掉就没那味儿"的三样原料：核心意象、情绪基调、经典句式 | ~5 分钟 |
| **Step 2** | **拆骨** | 识别原文所属的骨架模型，产出可套用的结构模板 | ~5 分钟 |
| **Step 3** | **提纯语感** | 用三分法提取作者的句式习惯、用词词域、情绪节奏 | ~10 分钟 |
| **Step 4** | **置换重生** | 按"Keep / Replace"规则输出仿写指令 | ~5 分钟 |

### Step 1：滤水——只留"文学有效信息"

对目标文本执行两句判断：**删掉就没那味儿的，全部留下；删掉不影响气质的，全部去掉。**

只保留以下三类：

| 保留类别 | 是什么 | 示例 |
| --- | --- | --- |
| **核心意象** | 作者反复写的景物、道具、象征物 | 雨、旧巷、灯火、晚风、旧书、月色、梧桐 |
| **情绪基调** | 整篇作品的情绪底色 | 清冷、温柔、怅然、治愈、苍凉、平静、疏离 |
| **经典句式** | 最能代表作者语言风格的那 2-3 个句子——长短句搭配模式、特有的转折方式、抒情节奏 | "不是……而是……" / "先写景再抒情" / 句尾用破折号留白 |

**滤水产出**：一张"三原料卡"，作为后续三步的输入。

### Step 2：拆骨——蒸馏文章结构

所有文学文章都可以归入以下四种骨架模型之一。

#### 四大骨架模型速查表

| 骨架模型 | 结构序列 | 适用文体 | 典型信号 |
| --- | --- | --- | --- |
| **① 景入情式** | 眼前景物 → 触发回忆/思绪 → 轻轻感慨 → 收束留白 | 散文（~90%） | 开头写环境，中间有"想起……""记得……"，结尾淡出 |
| **② 小事悟理式** | 微小日常事件 → 细节放大 → 情绪转折 → 淡淡升华 | 记叙文、随笔 | 开头是日常小事，关键处有"也就是那一刻……""后来我才明白……" |
| **③ 时空对照式** | 当下平淡场景 → 插入过去片段 → 今昔对比 → 释然/怅然收尾 | 高级文学写法 | 有明显的"那时……现在……""曾经……如今……"时间对位 |
| **④ 物我共生式** | 写外物状态 → 映射内心状态 → 不直白说情绪，借物抒情 | 文艺抒情 | 全篇主要写一个物件/环境，人的情绪只在物上隐约透出 |

**拆骨产出**：一句结构模板说明（如"本文骨架 = 景入情式：晚风→回想旧友→淡淡遗憾→沉默收尾"），其中具体意象和事件已被抽象为占位符。

### Step 3：提纯语感——抓作者专属文风的三分法

不追求完整的 9 维度统计，只提取三个对仿写最关键的维度。每个维度附一套**诊断探针**（具体问题，逐一回答即可完成提取）：

#### 探针 1：句式习惯

| 诊断探针 | 回答记录 | 说明 |
| --- | --- | --- |
| 短句为主还是长句为主？ | [短句>70% / 长句>50% / 混合均衡] | 粗略估算即可，不用精确统计 |
| 是否喜欢先否定再肯定？（"不是……而是……""不是因为……而是因为……"） | [高频 / 偶尔 / 几乎不用] | 这是最能体现作者"修正性思维"的句式指纹 |
| 是否喜欢先写景再抒情？ | [总是 / 经常 / 有时 / 从不] | 典型文学句式：景物在前、情绪在后 |
| 段落的结尾方式是总结式、留白式还是强调式？ | [总结/留白/强调] | 句尾节奏直接影响阅读的"余味" |

#### 探针 2：用词词域

| 诊断探针 | 回答记录 | 说明 |
| --- | --- | --- |
| 从文中选出 10 个最能代表"这是谁写的"的实义词 | [词1, 词2, 词3, ...] | 不要选"的""了""在"等功能词 |
| 这些词属于哪个共同语义域？ | [旧物/时光/温度/光影/烟火/人间/身体/自然/建筑/食物] | 这些单词指向的"那一类东西"是什么？ |
| 换一个场景类型（如从抒情换到对话），词域是否改变？ | [不变 / 部分替换核心保持 / 完全改变] | 稳定词域说明是作者的核心语言指纹；会漂移说明词域受题材/场景驱动 |

#### 探针 3：情绪节奏

| 诊断探针 | 回答记录 | 说明 |
| --- | --- | --- |
| 铺垫段数 : 抒情段数 : 收尾段数 约等于？ | [如 5:3:2] | 粗略统计各类型的段落占比 |
| 高级文学三拍子：是"慢铺垫-轻抒情-暗收尾"？还是"快切入-强情绪-留白收"？ | [慢铺轻收型 / 快切强收型] | "慢铺垫"指前 50-60% 篇幅在营造氛围不急着说情绪；"暗收尾"指结尾不总结不含蓄，只留一幅画面或一句轻叹 |
| 情绪表达是否克制？（不嘶吼、不堆砌形容词、不替读者总结感受） | [高度克制 / 中度 / 直白] | 克制度越高越"文学"，越低越"网文"——无优劣之分，但要适配目标平台 |
| 语速语调是否有明显规律？（急促/舒缓/顿挫分明？停顿集中在句首还是句尾？） | [急促/舒缓/顿挫] + [停顿位置说明] | 语言节奏的"听觉层"——决定文本读起来是喘不过气还是一步三叹 |

#### 探针 4（隐性维度补充）：修辞指纹与语言节奏

| 诊断探针 | 回答记录 | 对标维度 |
| --- | --- | --- |
| 作者最偏好的修辞手法是什么？（比喻/讽刺/白描/排比/设问/夸张/其他） | [主要修辞] + [次要修辞] | 修辞指纹——影响下游"去AI味重写"中的修辞禁忌判断 |
| 修辞的来源领域是否稳定？（如钱钟书喜用学术领域的比喻，张爱玲偏爱服饰/器物领域的比喻） | [稳定/漂移] + [来源领域] | 修辞的"领地"——与比喻指纹的比喻来源领域互补 |
| 作者是"显性修辞型"（大量使用修辞来增强表现力）还是"隐性修辞型"（修辞藏在白描中几乎不可见）？ | [显性 / 隐性 / 混合] | 修辞密度——影响"正文润色"时是补修辞还是删修辞 |

**语感三要素卡产出格式：**

```markdown
### 语感三要素卡
- **句式习惯**：[短句为主/长句为主/混合] + [是否高频使用"不是……而是……"类转折] + [段落结尾方式]
- **词域**：[核心语义域]（代表词：[词1, 词2, ...]）+ [跨场景稳定性]
- **情绪节奏**：[慢铺轻收型/快切强收型] + [铺垫:抒情:收尾 ≈ X:X:X] + [克制度]
- **修辞指纹**：[主要修辞手法] + [来源领域] + [显性/隐性]
- **高级文学特征**：[是/否] — 若"是"，默认采用"慢铺垫、轻抒情、暗收尾"三拍子
```

### Step 4：置换重生——Keep / Replace 规则

蒸馏完成后，用以下边界规则完成仿写：

| 保留（Keep） | 换掉（Replace） |
| --- | --- |
| ✔ 结构骨架（四大模型之一） | ✘ 具体意象（雨→雪，旧巷→长廊，灯火→月光） |
| ✔ 语感（句式习惯 + 词域气质 + 情绪节奏） | ✘ 具体事件（相遇→告别，等待→出发） |
| ✔ 抒情逻辑（不是"复制情绪"，而是"复制情绪出现的节奏位置"） | ✘ 具体场景（火车站→图书馆，黄昏→清晨） |
| | ✘ 具体内容（所有涉及事实、人物、地名的专有信息） |

**置换重生产出**：一组可直接执行的仿写指令，包含：

1. 选用的骨架模型
2. Keep 的三项语感约束
3. Replace 的具体替换方向

## 终极口诀

蒸馏全流程可用以下口诀在 10 秒内完成自查：

> **滤冗余、拆骨架、提语感、换意象、留节奏、重生文**

每执行完一篇仿写，用口诀逐词核对是否六步全部到位——任一步遗漏，仿写味道就会打折。

## 轻量模式与传统全量蒸馏的切换决策

| 用户需求 | 走哪条路 |
| --- | --- |
| "帮我一篇散文风，模仿作者 X 的味道" | **轻量语感蒸馏**（Step 1-4），~25 分钟 |
| "我要在连载中长期使用作者 X 的文风约束" | **全量 9 维度蒸馏**（Phase 0-4），可跨作品复用 |
| "这篇短篇我要仿写，但后续还有长篇需要" | 先走**轻量语感蒸馏**快速交付短篇，后续再补全量蒸馏用于长篇 |

# 文风可移植性评估与移植技法

> 来源：SKILL.md §"文风可移植性评估" + §"语言风格移植的具体技法"

## 文风可移植性评估

当蒸馏目标为仿写服务时（用户明确说"我要仿写这个作者的文风"或"为仿写蒸馏"），完成 Phase 2 统计后，必须追加以下评估。

### 文风-题材绑定度判断

| 文笔维度 | 评估问题 | 判断标准 |
| --- | --- | --- |
| 句长基线 | 该句长分布是否与题材节奏要求高度绑定？（如都市文的短句快节奏 vs 古典仙侠的句长波动） | `题材绑定` / `作者独立` |
| 感官偏好 | 该感官偏好是否由作品的特定场景类型驱动？（如悬疑题材的听觉/触觉偏重 vs 言情题材的视觉/嗅觉偏重） | `题材绑定` / `作者独立` |
| 对话风格 | 该对话标签偏好是否因题材中的人物关系类型而产生？ | `题材绑定` / `作者独立` |
| 比喻指纹 | 比喻来源领域是否与作品的设定世界观高度绑定？ | `题材绑定` / `作者独立` |
| 情绪表达方式 | 该情绪表达方式是作者的写作信念（跨题材稳定），还是当前作品题材的情绪密度要求导致的？ | `作者信念` / `题材驱动` |
| 叙事距离 | 该叙事距离是作者的一贯选择（跨域复现可验证），还是当前作品的 POV 类型导致的？ | `作者习惯` / `POV驱动` |

### 文笔"内核"提取——作者看世界的方式

文笔的终极"内核"不是句长分布和比喻密度，而是**作者看待世界的基本方式**：

| 叙述者类型 | 特征 | 跨题材可移植性 |
| --- | --- | --- |
| **悲悯型叙述者** | 即使写反派内心也带着理解，世界是复杂的，无人真正邪恶 | 高 — 任何题材都可运行 |
| **冷峻型叙述者** | 只写行为，不写动机，信任读者自己判断 | 中 — 在强调情感共鸣的题材中需调整 |
| **吐槽型叙述者** | 叙述者本身就是一种"看世界的方式"——所有角色的愚蠢和世界的荒谬都被同一副眼镜过滤 | 高 — 但需控制密度以免破坏紧张场景 |
| **沉浸型叙述者** | 叙述者尽量隐身，让读者直接"成为"角色 | 高 — 通用性最强的类型 |

## 语言风格移植的具体技法

当仿写者需要在自己作品中复现蒸馏所得的文风时，以下技法提供了从"形似"到"神似"的操作路径。

### 特征提取三步法

| 步骤 | 操作 | 对应蒸馏维度 |
| --- | --- | --- |
| **① 识别"词汇-句式-修辞"指纹** | 统计作者的常用词库、长短句交替模式、修辞偏好（比喻/讽刺/白描） | 句长基线 + 比喻指纹 + 禁忌清单 |
| **② 分析"语言-场景"映射关系** | 作者在动作场景、对话场景、情绪场景中分别采用什么语言策略？句长和感官调用是否有规律性的场景偏移？ | 跨域复现验证结果 |
| **③ 提炼"写作信念"** | 上述选择的背后是什么写作信念？举例：短句为主不是因为统计上占多数，而是因为作者相信"读者不需要被解释，只需要被引导" | 神似层提炼结果 |

### 语言风格融合方法

当仿写场景需要同时调用多份风格模板时：

| 方法 | 操作 | 适用场景 |
| --- | --- | --- |
| **主辅结合法** | 确定一种主导语言风格（占 70-80%），适当融入其他风格的元素（占 20-30%） | 仿写者有清晰的主风格偏好，只需要局部补充 |
| **场景适配法** | 根据不同的场景类型灵活切换语言风格——动作场景用冷峻风，情感场景用细腻风 | 作品的场景类型跨度大，单一风格无法覆盖所有需求 |
| **人物定制法** | 为不同人物设计不同的语言指纹——知识分子说长句，市井人物说短句俚语 | 群像故事，需要以声口拉开人物差距 |

### "语言-世界观"一致性检查

文风移植最大的风险不是"不像原作者的风格"，而是"移植来的风格与自己的题材/世界观打架"。移植完成后，对以下维度做冲突检查：

| 检查项 | 冲突信号 | 修正方向 |
| --- | --- | --- |
| 句长与题材节奏 | 移植来的句长偏慢，但题材要求快节奏（如悬疑） | 缩短中句和长句的比例，保持短句指纹的句法特征 |
| 感官偏好与题材 | 移植来的感官以视觉为主，但题材需要更多触觉/听觉（如恐怖） | 保留感官调用规律，但更换通道占比 |
| 叙事距离与人物视角 | 移植来的距离偏冷，但当前故事需要高强度情感代入 | 缩短冷峻段，在关键情绪点增加内心独白占比；保持风格"底色"但不死守比例 |
| 语气语体与世界观 | 移植来的吐槽腔与现代都市世界观匹配但破坏古典仙侠沉浸感 | 保留吐槽式叙述者的"看世界方式"，但将吐槽密度降低 50-70%，只在内心独白中使用 |

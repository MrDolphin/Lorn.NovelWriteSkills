## 参考对照：InkOS 统计指纹提取方案

> 来源：[Narcooo/inkos](https://github.com/Narcooo/inkos) — 面向长短篇小说、剧本剧作与 IP 内容的创作智能体系统（v1.6.2）
> 证据充分性：一般 — InkOS 的 style analyze 功能是系统设计描述，非独立写作研究方法论
> 置信度：中 — 三种指纹（句长分布/词频特征/节奏模式）的提取维度与本表已有维度高度重叠，但"LLM 风格指南"作为独立产出物是一个有用的概念借鉴

InkOS 的 `inkos style analyze` 从参考文本中提取**三种核心统计指纹**并生成一份 **LLM 风格指南（LLM style guide）** 作为独立产出物。与本表已有的 16 维度相比，可以补充以下视角：

### 三种核心统计指纹与本表映射

| InkOS 指纹 | 本表对应维度 | 差异与补充 |
| --- | --- | --- |
| **句长分布（sentence length distribution）** | 句长基线、段落节奏 | 强调"分布"（distribution）而非"均值"——统计中句占比峰值的区间位置，比平均句长更能刻画作者节奏偏好 |
| **词频特征（vocabulary frequency features）** | 词域指纹、禁忌清单 | 强调高频词的分布模式——不仅看"用什么词"，还看"以什么频率重复使用某类词"，这比仅分离义词域更能反映写作惯性 |
| **节奏模式（rhythm patterns）** | 段落节奏、时间处理指纹 | 强调段落级节奏交替的完整周期（短-短-长 vs 长-短-长等模式），而非仅看单句长度 |

### LLM 风格指南的概念

InkOS 将分析结果打包为一份 **LLM 风格指南**——它不是给人类看的文风描述，而是可直接嵌入 writer agent prompt 的结构化约束，包含：

- 句长分布基线（"第 60 百分位句长 ≤ 22 字，避免连续 3 句 > 30 字"）
- 高频重复词表（"每千字 ≤ 2 次"或"完全禁用"）
- 段落节奏模板（"每 5 段至少有 1 个单句独段做呼吸"）
- 禁用句式（"禁止 '不是……而是……' 的自我纠偏结构"）

**与本 Skill 的关系**：本 Skill 的 16 维度蒸馏产出（`作者风格模板`）本质上已是 LLM 风格指南的扩展版。InkOS 的实践验证了"将文风指纹从人类可读格式转为机器可消费约束"这一方向的可行性。参见 `references/作者风格模板格式定义.md` 和 `references/风格注入锚点卡.md`。
| **对偶轴偏移弹性**（风格弹性指数） | 在动作/对话/情绪/环境等不同场景类型中，作者沿五对偶轴（藻丽-平实、明快-含蓄、典雅-通俗、繁丰-简洁、豪放-柔婉）的偏移幅度与方向。偏移幅度越大→风格弹性越好。含弹性指数（0-1 归一化，≥0.6 为高弹性） | 创建小说正文（场景切换时选择正确的对偶区位）、正文润色（确认场景内风格一致性）、去AI味重写（防均匀分布） |
| **色标一致性匹配** | 检测作品实际语言特征（句长/对话密度/比喻密度/感官偏好）与声明的网文色标（热血/沙雕/杀伐果断等）是否匹配。输出匹配度评分（0-10）与具体不匹配项清单 | 审阅章节正文（色标偏离告警）、小说项目初始化（风格策略确认） |

# 多作者风格融合策略

> 来源：SKILL.md §"多作者风格融合策略（新增）"

## 何时使用多作者融合

| 场景 | 说明 | 建议作者数量 |
| --- | --- | --- |
| **同赛道取长** | A 的句长节奏好、B 的对话干脆利落、C 的感官描写精准——各取所长 | 2–3 |
| **补短板** | 目标项目在某个维度偏弱（如对话声口单调），定向接入另一位作者在该维度的指纹 | 2 |
| **跨风格探索** | 不确定哪种文风更适合，先融合几位候选作者的上层特征做"风格样机"试写 | 2–3 |
| **求最大公约数** | 同赛道多位爆款作者的文笔共性分析 | 3–5 |

## 三种融合策略

### 策略 A：主辅法（推荐首用）

选定一位作者的风格模板作为"主风格"（句长/段落/感官等维度的基线），其余作者只覆盖特定维度。

```text
主风格：[作者 A] — 提供完整的 16 维基线
辅风格：[作者 B] — 替换 §四 对话风格 + §十 声口差异化（B 的对话指纹更优）
辅风格：[作者 C] — 替换 §三 感官偏好（C 的感官描写与目标题材更匹配）
```

**产出方式**：一份"综合风格模板"，未替换的维度沿用主风格值；被替换的维度标注来源与替换理由。

### 策略 B：分域法（维度级分工）

不设主风格，按维度域将各位作者分别蒸馏，合并为一份综合模板。

```text
作者 [A] → §一 句长 + §二 段落 + §七 情绪表达（节奏与情绪域）
作者 [B] → §四 对话 + §十 声口 + §十四之二 语气与语体（对话与声口域）
作者 [C] → §三 感官 + §六 比喻 + §十一 时间 + §十二 空间（感知与构图域）
```

**产出方式**：一份"综合风格模板"，每节标注数据来源作者。

### 策略 C：交集法（共性优先）

对多位作者的同一维度分别统计，提取"多数成立"的共性规律作为综合基线。具体操作方法同作品蓝本交集法，将"蓝本"替换为"作者"即可。

## 多作者冲突仲裁

| 冲突类型 | 处理方法 |
| --- | --- |
| **声口趋同风险** | 若主风格和辅风格的声口差异化指纹均偏弱（人物句长差异度 < 0.2），融合后可能产生更严重的声口趋同。应引入第三位作者在该维度的数据作为参考基线，或明确降低综合模板在此维度的置信度 |

## 综合风格模板产出命名

综合风格模板写为：

```text
蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
```

命名规则：主辅法用 `[主作者]-[辅作者]-综合`；分域法用 `[赛道名]-[题材]-综合`；交集法用 `[赛道名]-共性综合`。

## 在 Agents.md 中的注册

综合风格模板注册为一组关联条目：

```markdown
### 作者风格模板（合成）
- 合成标识：[如 "作者A-作者B-综合"]
- 主模板路径：蒸馏产物/作者风格模板/[合成标识]-综合风格模板.md
- 融合策略：[主辅法 / 分域法 / 交集法]
- 融合日期：YYYY-MM-DD
- 适用平台：[平台名] 或 默认
- 源模板：
  1. [作者 A] — 路径：蒸馏产物/作者风格模板/[作者A]-作者风格模板.md — 贡献维度：§一 句长 / §二 段落 / §七 情绪
  2. [作者 B] — 路径：... — 贡献维度：§四 对话 / §十 声口
```

合成条目与单作者条目在 `Agents.md` 中并列存在，名称以 `（合成）` 后缀区分。下游 Skill 自动发现时，**合成条目优先级高于单作者条目**。

## 单作者蒸馏 → 合成蒸馏的流程关系

默认流程先分别蒸馏各作者（各注册独立条目到 Agents.md），再做合成；可应要求跳过独立注册直接合成，但合成结果必须引用各源模板信息。

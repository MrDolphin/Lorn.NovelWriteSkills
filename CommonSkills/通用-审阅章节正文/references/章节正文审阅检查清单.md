# 章节正文审阅检查清单

## 一、先看抓力，再看文采

章节正文对象的首要判断不是“句子漂不漂亮”，而是：

- 读者能不能被章首拖进去
- 中段有没有明确收获
- 章末有没有下一章动力

## 二、章首抓力

- 前 2–3 段是否至少命中以下两项：
  - 异常 / 冲突触发
  - 情绪锚点
  - 悬念缺口
- 是否避免了背景说明或设定科普压过故事入场

## 三、中段兑现

- 中段是否至少有一次可指认的回报：
  - 新证据落袋
  - 误导被证伪
  - 关系发生变化
  - 规则边界被试出
  - 有效反击成立
- 是否指出：回报类型、落在哪个镜头、是否足够清晰

## 三·五、中段信息负载控制（新增）

**问题定义**：开篇强钩子之后，中段连续出现大段内部处理（回忆/梳理/决心），读者被搁置在主角的脑海里，开局的动能逐步泄空。这不等于"信息太多"，而是"信息在无外部压力的情况下被一次性灌完"。

**三种信息投放方式的续读保持力对比**：

| 方式 | 效果 | 示例 |
| --- | --- | --- |
| 整段灌输 | 读者在200字后开始走神 | 连续三段回忆+内心独白无打断 |
| 碎片化穿插 | 读者边看剧情边拼信息，参与感强 | 回忆10句→外部动静→再回忆5句→威胁逼近→推导 |
| 对话/冲突触发 | 信息本身就是冲突推进的一环 | 一段对话中自然带出背景，而不是主角独自回忆 |

**检查清单**：
- [ ] 中段内部处理（回忆/梳理/独白）的最大连续长度是否超过300字？
- [ ] 若是，这些内部段是否被至少一个外部打断（对话/动作/第三方介入/环境变化/身体反应）分隔？
- [ ] 核心信息（如"谢氏下的毒""母亲不是病死的"）是否通过行动或对抗传递，而不是通过内心独白宣布？（例如：她在推导谢氏可疑时，不是站在安静环境下想通的，而是被外面的脚步声逼着在压力下推断的）
- [ ] 是否存在一整段"主角站在安静环境下把事想明白了再去行动"的模式？若存在，应打碎插入对抗张力中。

## 四、章末钩子

- 钩子是否落在具体动作 / 信息 / 危险 / 未完成决定上
- 是否避免了空泛感慨、空问号或假危机

## 四点五、四拍门禁与钩子轮换同构核查（新增）

- 单章是否成立“四拍”最小闭环：
  - 钩子（前200）
  - 蓄力（中段加压）
  - 回报（中段可感兑现）
  - 留钩（后200未闭合）
- 若“四拍”缺失两拍及以上，是否已升级为结构性风险（不得按文风问题轻描淡写）
- 本章钩子类型是否与前两章过度重复（钩子轮换过载）
- 若出现“连续三章同类钩子”风险，是否已给出下一章强制换型补丁
## 四点六、场景分割重叠率检查（新增）

适用场景：同一大场景（如一场对话/一场偷听/一次对峙/一场战斗）被拆分到连续两章或以上时。

- [ ] 本章与前一章是否共享同一个大场景（同一时间+同一地点+同一组人物）？
- [ ] 若是，本章的新增信息占比是否≥40%？（新增信息 = 本章独有的情节推进/情绪升级/认知翻面，不含前章已揭示内容的内心重复）
- [ ] 若新增信息占比<40%，是否已将本章判定为"结构分配不合理"而非"写得不够好"？
- [ ] 返工方向是否为以下之一：
  - 方案A：将本章重写为纯内心消化章（以闪回碎片+身体记忆替代对话回放）
  - 方案B：将两者合并为一章，压缩冗余篇幅
  - 方案C：缩小后章覆盖的时长/视角范围，避免与前一章的内容重叠率>60%

反面示例：Ch3（偷听全过程）+ Ch4（同一偷听场景的内心版回放），重叠率约65%，新增信息占比约22%，读者感到"同一件事读了两遍"。
## 五、现实与规则落地

- 文本中是否有可感知的现实锚点或场景支撑
- 规则 / 证据 / 程序 / 代价是否不是只在口头存在
- 现实锚点是否具体到空间、物件、职业流程或日常界面，而不是只剩抽象气氛词

## 六、工程核查

- 本章应落地的卷纲功能点是否都已落地
- 出场人物是否已做传记核查，是否存在身份 / 关系 / 能力边界冲突
- 关键判断是否能回指到证据
- 误导是否可证伪
- 是否出现作者管理编号、具体年份或突然全知解释等出戏红线

## 七、工作文件与读者层边界

- 若章节文件同时包含 `## 作者有话说`、`## 章节后记`、润色说明或回写标记，默认视为作者工作层与正文同文件共存的设计，不因此判为问题。
- 默认放行判断只针对章节正文本体；除非用户明确要求，否则不要把 `## 作者有话说`、`## 章节后记` 是否存在纳入读者出戏项。
- 只有当作者侧内容混入正文、章标题，或用户明确要求审“裸发终稿 / 读者直出稿 / 合刊终稿”，才把这类问题升级为发布风险。
- 若本轮还要判断“原始工作文件是否可直接裸发给读者”，必须把它单列为**附加结论**，不得覆盖默认的正文质量 / 读者可见层放行结论。

## 八、读者端核查

- 每段是否有明确焦点
- 对话是否承担功能，而不只是搬信息

## 九、对话三项专项核查

- 是否存在可感知的**声音差**：删掉提示语，仍能大致听出不是同一口气
- 是否完成**塑人**：对话能否暴露人物在护什么、怕什么、想抢什么，或其职业惯性 / 情绪处理方式
- 是否形成**联结**：读者是否会因为对话而对至少一个人物产生认同 / 同情 / 喜爱 / 好奇
- 若对话承担重大场景推进，是否出现“信息全说了，但人物没立住”的问题
- 若多人同场，是否存在统一作者腔，导致关系温度和位差发白
- 是否至少有一处情绪兑现
- 是否至少有一处贴角色、贴时代的记忆点

## 十、链路失配核查

- 本章当前问题主要是正文表层问题，还是上游供血 / 控制卡 / 场景职责 / 首尾补丁失配问题？
- 若开头已抓人但与本章主线脱节，是否已判为链路失配而非单纯文笔问题？
- 若中段“有内容没回报”，是否已判断回报是否只存在于控制卡里、没进正文？
- 若结尾“有气氛没驱动”，是否已判断最后一场职责与下章接口是否失配？
- 若文本经过润色 / 去AI味后更顺却更弱，是否已判定为补丁遮羞而不是实质修复？
- 若正文在闭环步骤 2 已落稿，是否已复核 `HookType / MidPayoff / TailDriver / RotationCheck / GatePass` 这 5 个日志字段

## 十一、网文付费与追读专项核查

- 本章是否至少有一次主角主动推进 / 有效反制 / 争取筹码，而不是全程承压
- 本章是否至少交付 `1–2` 个微爽点或 `1` 个中爽点；若完全没有，是否已标记为“付费吸附力风险”
- 本章是否存在明显“可以先放一放”的空档感；若有，是否已指出是钩子弱、回报轻、主角主动性不足还是信息增量太虚

## 十二、章节接棒与连续性热度核查

- 章末的新变量是否足够具体，能直接接到下一章第一屏
- 本章是否至少回应了上章或近几章的一个高优先问题，而不是只持续开新口子
- 主要人物 / 关系 / 伏笔 / 卖点链是否已连续 `5` 章以上未有效触碰，本章是否又错过了合理升温窗口

## 十三、平台讨论度与传播切口核查

- 是否存在一句可截图、可转述、可争议、可站队的话或动作
- 是否存在一个会触发段评 / 本章说的细节、态度或认知反差
- 若全章没有可讨论点，是否已指出这会削弱网文平台的互动数据与推荐潜力

## 十四、十维评分速记

- 叙事逻辑
- 人物一致性
- 连贯性
- 场景规划执行
- 节奏与张力
- 对话质量
- 描写质量
- 去 AI 味
- 钩子与悬念
- 字数与密度

## 十五、处理方与来源层分流

- 每个问题是否已区分 `writer / polisher`
- 每个问题是否已标来源层：`[骨架层] / [扩展层] / [表达层]`
- 是否存在把结构性问题误塞给润色层的偷懒判断

## 十六、钩子链与骨架忠实度

- 上章出口钩是否被本章入口回应
- 本章出口钩是否足以可信地拉动下章
- 最近 3 章钩子类型是否疲劳重复
- 承重 beat 是否全部在场且顺序未乱
- 是否残留大纲语言 / 施工语言

## 十七、平台审核视角平行评估（跨平台通用）

> **来源**：2026-06-22 七猫拒稿复盘 → 通用化改造。原版偏女频追妻线，现升级为通用留存红线 + 平台特化变体，与 `CommonSkills/写作研究/网文留存模型.md` 联动。

内部审阅评分（写作技法）高 ≠ 平台编辑审核（读者留存）通过。此节在完成上述全部检查后，额外做一次"平台编辑/手机端读者"视角的平行判断。**本节的判定结果直接影响留存分计算（每红灯-1分）。**

### 17.1 留存风险红灯清单（通用版，所有平台适用）

以下每项命中即记 1 红灯。≥ 2 项红灯 = 留存风险，不得以技法评分放行。

- [ ] **连续平路 ≥ 3 章**：最近连续 3 章的中段回报强度是否全部为"低"（无爽点/虐点/信息突破/关系推进中任何一种可感知情绪变化）。
- [ ] **信息过载段**：本章中段是否出现连续 > 300 字无外部打断的内部处理（回忆/推理/内心独白/设定说明——读者被搁置在主角脑海中的"纯内部时间"）。
- [ ] **主角被动窗口**：主角是否连续 3 章以上只有防卫/应对/接任务，无主动选择/出击。
- [ ] **主线失焦**：主卖点/核心冲突是否连续 5 章以上未被有效触碰。
- [ ] **情绪单一化**：最近 5 章是否所有场景使用同一情绪底色（全过程爽/全程压抑/全程平铺）。
- [ ] **章节功能位缺失**：本章是否既无钩子、无回报、也无推进（"三无章"）。
- [ ] **认知负荷超标**：本章同时推进 ≥ 3 条独立线索，且无一条获得超过 40% 的篇幅占比。

### 17.2 平台特化红灯（按主输出平台加载）

若项目 `Agents.md` 中声明了主输出平台，加载对应的特化红灯清单；若未配置，默认使用通用版 + 平台自适应推测（根据题材/字数等信号判断最可能的平台类型）。

--- 七猫/番茄等免费平台专用 ---

- [ ] **情绪刺激间隔超标**：最近 3 章中是否有任何一章出现连续 500 字无任何情绪刺激。
- [ ] **开篇钩子延迟**：本章前 200 字是否未抛出明确冲突/异常/压力信号。
- [ ] **爽点兑现不足**：最近 5 章中是否有 ≥ 3 章无可指认的"赚到了"时刻。

--- 起点/纵横等付费平台专用 ---

- [ ] **追读链断裂**：本章是否未响应上章出口钩，或未留下可信的下章入口。
- [ ] **中长期期待透支**：最近 10 章是否只有短期事件，没有推进中长期目标的信号。
- [ ] **讨论点缺失**：最近 5 章是否无可讨论、可争议、可截图的内容。

--- 出版社/豆瓣/IP向专用 ---

- [ ] **结构松散**：章节是否缺乏明确的主题统一性或情感弧线。
- [ ] **密度不均衡**：场景转换过密或过疏，影响沉浸感。

### 17.3 平台审核视角判定（双轴版）

| 技法分 | 留存分 | 留存红灯数 | 放行判断 |
| :---: | :---: | :---: | :--- |
| ≥ 7.0 | ≥ 6.0 | 0-1 | ✅ 双轴达标，正常放行 |
| ≥ 7.0 | < 6.0 | ≥ 2 | ⚠️ 技法过关但留存风险，放行前需修复 ≥ 2 项红灯项 |
| < 7.0 | ≥ 6.0 | — | ⚠️ 留存过关但技法不足，可过渡但需补技法短板 |
| < 6.0 | < 5.0 | — | ❌ 双轴不达标，回炉 |
| — | — | ≥ 3 | ❌ 留存红灯 ≥ 3 直接 Red，不依赖技法分 |

### 17.4 留存问题回炉分流

留存红灯命中 ≥ 2 项时，按问题类型决定回炉到哪一阶段（避免一直回润色但修不了结构性问题）：

| 留存红灯项 | 最可能的根因阶段 | 回炉方向 |
| ---------- | --------------- | -------- |
| 连续平路 ≥ 3 章 | 控制卡/创作 | 回控制卡补"本章唯一续读驱动力"；或回创作重新设计四拍闭环 |
| 信息过载段 | 创作 | 回创作拆分内部处理段，加入外部打断 |
| 主角被动窗口 | 设计/分卷 | 回总纲/分卷补主角主动目标（总纲问题），或回控制卡重分配节奏（卷内问题） |
| 主线失焦 | 设计/总纲 | 回总纲确认主线分配是否合理 |
| 情绪单一化 | 设计/分卷 | 回分卷重排章节情绪底色 |
| 章节功能位缺失 | 控制卡 | 回控制卡明确本章功能位 |
| 认知负荷超标 | 创作/控制卡 | 回控制卡减少本卷并行线索数 |
| 情绪刺激间隔超标 | 创作 | 回创作在平缓段补加入口级小刺激 |
| 开篇钩子延迟 | 创作/润色 | 优先回创作重写章首；也可回润色强化开头 |
| 爽点兑现不足 | 设计/分卷 | 回分卷重新设计回报分布 |

## 十八、动词密度与画面生成效率检查（新增）

> 网文留存的最小可测量单元是动词密度——动词驱动读者脑中画面生成。核心方法论来自顾里木图"动词是爽文的发动机"和"一文形容词是解释，动词是呈现。解释让读者变懒，呈现让读者上瘾。"详见 `CommonSkills/写作研究/网文留存模型.md` §八。

### 18.1 动词密度三级基线

- [ ] **冲突段动词密度 ≥ 60%**：选取本章冲突最核心的段落（约200字），核心动作动词（推/砸/踢/冲/握/捏/摔等）数量是否占总实词数的 60% 以上？注意排除"是""有""想""知道""觉得""感到"等非动作动词。
- [ ] **叙述推进段动词密度 ≥ 50%**：本章推动情节的主体段落中，是否以动作链驱动而非静态描述？
- [ ] **日常/铺垫段动词密度 ≥ 30%**：最低容忍线，低于此读者画面生成停转，开始走神。

### 18.2 情绪表达方式检查

- [ ] **情绪高潮段是否使用了躯体化动作替代情绪形容词？**
  - ✅ "他的手指深深掐进掌心" → 代替 "他很生气"
  - ✅ "她的眼泪一颗一颗掉在床单上" → 代替 "她很伤心"
  - ❌ "他感到愤怒""她非常悲伤""他觉得很委屈"（"感到""觉得"非动作动词）
- [ ] **是否触发了"形容词替动词"的危险信号？** ——一段话中形容词/副词/抽象名词数量超过动词数量 = 画面引擎停转。

### 18.3 "站着想清楚"模式检测

- [ ] 是否存在"主角站在安静环境下把事想明白了再去行动"的模式？——即连续 > 300 字的内部处理（回忆/推理/内心独白）无外部打断，且主角的行动决策在这个段落后才生效。若存在，标记为"动词中断"风险。
- [ ] 若存在，核心信息（推理结论/关键决策）能否通过动作或对话传递？——例如在压力下推断、在对话中试探、在行动中暴露，而不是在安静中想通。

### 18.4 动词密度风险判定

| 风险等级 | 触发条件 | 处理建议 |
| ------- | ------- | -------- |
| 通过 | 冲突段动词密度 ≥ 60% + 情绪高潮无形容词替动词 | 不需要处理 |
| 预警 | 冲突段 40-60% 或 1 处形容词替动词 | 润色阶段将部分形容词替换为动作描写 |
| 危险 | 冲突段 < 40% 或 ≥ 2 处形容词替动词或存在"站着想清楚"模式 | 回创作阶段重写对应段落 |

## 十九、过度优化与确定性过剩预警（新增）

> **背景**：技法审阅的默认倾向是"越高越好"，但留存视角下各技法维度呈倒 U 型曲线——超过某个阈值后，继续优化技法反而损害留存。此节用于识别技法优化已超过留存友好临界点的信号。详见 `CommonSkills/写作研究/审阅范式转换_技法审阅与网文留存的深层矛盾及底层模型重构.md` §三·发现一。

### 19.1 过度优化预警

以下信号命中 ≥ 2 项，说明技法优化已超过留存友好临界点，标记为"技法超限"风险（此项不在技法总分中扣分，但需在审阅结论中显式标注）：

- [ ] **无节奏变化**：所有段落都"同样精致"，读不到节奏起伏——找不到一个"粗糙但信息密集"的段落
- [ ] **无留白**：每个角色行为都有充分解释，没有模棱两可或需要读者揣摩的空间
- [ ] **结局可预测**：因果关系过于清晰，读者读完 30% 就能预判结局走向
- [ ] **去味过度**：文本像"出厂设置"一样无瑕疵——找不到任何作者的个人痕迹或毛边
- [ ] **逻辑太满**：所有漏洞都被堵上，读者没有"这里好像有点奇怪"的探究欲

### 19.2 确定性过剩预警

以下信号命中 ≥ 1 项，标记为"追读驱动力不足"风险：

- [ ] **信息过度释放**：本章把所有悬念一次性解释清楚，没有给下一章留下未解答的问题
- [ ] **读者不需要参与**：审阅者读完本章后，没有产生"这个推断我猜对了吗"的自我追问
- [ ] **确定性压倒一切**：没有留下任何可争议、可站队、可讨论的内容——所有事情都"很清楚"

### 19.3 预警与技分的配合使用

过度优化预警和确定性过剩预警**不在十维评分中扣分**，仅作为审阅报告的横切标记。审阅结论应按以下方式呈现：

```text
技法十维评分：XX/50（从满分起扣）
  维度 1-10 逐项打分

横切预警（风险标记，不影响技法分）
  预警 A 过度优化：○ 未触发 / ● 触发（风险项数：__/5）
  预警 B 动词密度：○ 通过 / ● 预警 / ● 危险
  预警 C 确定性过剩：○ 未触发 / ● 触发（风险项数：__/3）

综合结论：
  技法质量评分：__/10（技法分映射，从 10 分起扣）
  读者体验评分：__/10（从 0 分起加，每次读者可感回报 +1 分）
  综合放行判定：✅ 放行 / ⚠️ 条件放行 / ❌ 回炉
```

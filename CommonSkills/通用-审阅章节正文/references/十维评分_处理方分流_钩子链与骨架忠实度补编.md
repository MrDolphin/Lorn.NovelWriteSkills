# 十二维双轴评分_处理方分流_钩子链与骨架忠实度补编

> 吸收外部 `reviewer-skill`、`review-checklist`、`quality-standards` 与 `review-report-template` 的共性框架，用于把章节审阅稳定到"十二维双轴评分 + 处理方分流 + 来源标注 + 钩子链验证 + 骨架忠实度评估"。
>
> **改造背景**：从"十维技法评分"扩展为"十二维双轴评分（技法10维 + 留存2维）"，以解决内部技法审阅与平台留存标准之间的系统性错位。详见 `CommonSkills/写作研究/网文留存模型.md`。

## 一、审阅输入最小包

理想情况下至少读取：

- 待审章节正文
- 该章控制卡 / 场景规划（含留存快手字段，若有）
- 骨架稿（如有）
- 上一章结尾或上一章规划（用于钩子链验证）
- 涉及人物的当前状态字段
- 活跃悬念 / 活跃伏笔 / 已知决策背景
- 体裁字段（用于判断审阅侧重）
- **主输出平台**（用于动态权重分配，通过 Agents.md 发现或用户指定）

## 二、十二维双轴评分基线

每维 `1–5` 分，技法轴 `10` 维满分 `50` 分，留存轴 `2` 维满分 `10` 分。

### 技法轴（维度 1-10）

1. 叙事逻辑（核心）
2. 人物一致性（核心）
3. 连贯性
4. 场景规划执行
5. 节奏与张力
6. 对话质量
7. 描写质量
8. 去 AI 味
9. 钩子与悬念
10. 字数与密度

### 留存轴（维度 11-12，新增）

11. **情绪刺激密度（留存轴）** —— 每 500 字是否有可感知的情绪波动（爽/虐/甜/悬/揪心/反转）；连续 3 章是否有情绪交替而非单一底色。参见 `网文留存模型.md` §5.1 评分细则。
12. **追读驱动力（留存轴）** —— 章末钩子的"非翻不可"强度 + 中段回报的"值回时间"感。参见 `网文留存模型.md` §5.2 评分细则。

### 分值口径（两轴统一）

- `5`：优秀，基本无明显问题
- `4`：良好，有小瑕疵但不伤阅读
- `3`：合格，可读但有明显改进空间
- `2`：存在较大问题，需要改
- `1`：严重不合格，相关段位应重写

## 二·五、双轴评分公式

### 中间分计算

```text
技法原始分 = 维1至维10之和（满分50）
技法分 = round(技法原始分 / 50 × 10, 1)  → 满分10.0

留存原始分 = 维11 + 维12（满分10）
留存红灯扣分 = 每条红灯 -1 分（从10分起扣，扣完为止）
留存分 = max(留存原始分 — 留存红灯扣分, 0)  → 满分10.0
```

### 动态加权综合分

按主输出平台选择权重：

| 主输出平台 | W_技法 | W_留存 |
| --------- | ----- | ----- |
| 七猫/番茄等免费平台 | 0.35 | 0.65 |
| 起点/纵横等付费平台 | 0.55 | 0.45 |
| 出版社/豆瓣 | 0.75 | 0.25 |
| 知乎盐选 | 0.50 | 0.50 |
| 未配置/通用模式 | 0.50 | 0.50 |

```text
综合评分 = 技法分 × W_技法 + 留存分 × W_留存
```

### 放行门槛（双轴同时达标）

- ✅ 技法分 ≥ 7.0 **且** 留存分 ≥ 6.0 → 双轴达标，可放行
- ⚠️ 技法分 ≥ 7.0 但留存分 < 6.0 → Yellow，技法过关但留存风险，优先修复留存项
- ⚠️ 技法分 < 7.0 但留存分 ≥ 6.0 → Yellow，留存过关但技法不足，可过渡
- ❌ 技法分 < 6.0 或 留存分 < 5.0 → Red，双轴不达标，回炉

## 三、问题来源标注

每个问题都要标：

- `[骨架层]`：规划 / 骨架本身就错了，需回到上游重建
- `[扩展层]`：骨架对了，但正文展开跑偏或缺失
- `[表达层]`：结构基本成立，问题主要在措辞、节奏、去味、标签、描写密度

## 四、处理方分流

### 交给 writer 的问题

- 因果链断裂
- 人物行为与设定冲突
- 时间线 / 空间线错误
- 承重 beat 缺失或顺序乱
- 唯一职责未完成
- 情感弧未执行
- 核心事件被跳过或严重压缩
- 上章钩子未回应且无理由
- 本章结尾没有真实驱动力
- 需要改变“写什么”

### 交给 polisher 的问题

- 去 AI 味
- 对话标签、语气、声音微调
- 描写精炼
- 节奏微调（不改结构）
- 段落长短和句式均匀问题
- 花哨表达、填充短语、同义词转盘
- 需要改变“怎么写”

## 五、十维审阅时的特别抓手

### 维度四：场景规划执行

重点查：

- 规划中的核心事件是否都已呈现
- 场景目标是否完成
- 情感基调是否实现
- 承重 beat 是否全部在场且顺序正确
- 灵活 beat 的合并 / 删减是否有叙事理由
- 本章唯一职责是否完成
- 是否残留大纲语言

### 维度五：节奏与张力

重点查：

- 开头前 `20%` 是否建立吸引力
- 是否有节奏变化而非全章齐平
- 高潮是否有铺垫
- 结尾是否有真实翻页驱动力
- 实际节奏是否匹配规划中的轻 / 中 / 重
- 情感弧入口 / 出口是否成立

### 维度九：钩子与悬念

重点查：

- 前三段内是否有有效抓力
- 结尾是否留下未解问题或未完成动作
- 是否回应了旧悬念
- 钩子类型是否在最近几章重复
- 本章开头是否响应上章出口钩
- 本章出口钩是否可信地拉动下一章

## 六、钩子链验证格式

| 项 | 内容 |
| --- | --- |
| 上章出口钩 | 类型 + 方向 |
| 本章入口响应 | 是 / 否 / 部分；直接 / 间接 / 延迟 |
| 本章出口钩 | 类型 + 方向 |
| 下章预期响应 | 预期下章如何接棒 |
| 钩子类型重复 | 最近 3 章是否重复 |
| 钩子链断裂 | 有 / 无；若有写原因 |

## 七、骨架忠实度评估

至少单列：

- 承重 beat 在场：是 / 否
- beat 顺序保持：是 / 否
- 大纲语言残留：有 / 无
- 结构偏离：是否合理偏离
- 骨架忠实度：高 / 中 / 低

### 自动判重的信号

- 承重 beat 缺失
- 承重 beat 无故换序
- 正文把骨架的核心职责改没了
- 大纲语言残留超过 `2` 处

## 七·五、三横切预警（新增——死亡交叉检测）

> 技法各维度在留存视角下呈**倒U型曲线**——超过最优阈值后，每增加一分技法质量，留存反而下降一分。三横切预警不加入总分计算，但标记风险并影响最终判定。

### 预警指标

**预警A：过度优化预警**
当以下信号命中 ≥ 2 项时触发：
- 全篇找不到一个"不完美"的地方，文本像"出厂设置"
- 每个角色行为都有充分解释，没有留白
- 因果关系过于清晰，读完30%能预测结局
- 去味做得过于完美，没有作者个人印记

触发效果：标记"技法超限"风险，留存评分自动扣1分。

**预警B：动词密度预警**
当以下信号命中 ≥ 1 项时触发：
- 冲突段动词密度 < 40%（详见检查清单 §十八）
- 情绪高潮段使用了"他很X"句式替代躯体化动作
- 存在"站着想清楚"模式（连续 > 300 字内部处理后行动）
- 形容词/副词/抽象名词数量超过动词数量

触发效果：标记"画面引擎不足"风险，留存评分自动扣1分。

**预警C：确定性过剩预警**
当以下信号命中 ≥ 2 项时触发：
- 因果关系极其清晰，读者不需要推理
- 章末没有留下"也许我猜错了"的不确定性
- 人物行为完全可预测
- 本章读完后读者能准确说出下一章的全部内容

触发效果：标记"追读驱动力不足"风险，留存评分自动扣1分。

### 三预警综合规则

| 预警触发数 | 影响 | 最终判定影响 |
| --------- | ---- | ----------- |
| 0 | 无影响 | 按双轴正常判定 |
| 1 | 留存分 -1 | 可能触发 Yellow |
| ≥ 2 | 留存分 -1/条 | 自动 Yellow，标记"范式风险：技法超限综合征" |
| ≥ 3 | 留存分 -总3 | 自动 Red，需回炉调整写作范式 |

## 八、就绪判定（双轴版 + 三预警）

### 双轴前置条件

就绪判定前，先计算双轴基础分和三预警扣分：

```text
技法分 = 维1至维10之和 / 50 × 10（满分10.0）
留存分 = (维11 + 维12) — 留存红灯扣分 — 三预警扣分（满分10.0）
三预警扣分 = 预警A(1) + 预警B(1) + 预警C(1)，上限3分
```

按主输出平台选择权重后计算综合评分。详见 §二·五 双轴评分公式。

### Green（双轴达标 + 综合过硬）

- 技法分 ≥ 7.0 **且** 留存分 ≥ 6.0（双轴同时达标）
- 综合评分（按平台权重加权）≥ 对应平台品控线
- 无单项 ≤ 2
- 无红线触发
- 骨架忠实执行成立

### Yellow（单轴达标、综合可过）

- 技法分 ≥ 7.0 但留存分 < 6.0 → ⚠️ Yellow，标记为"技法过关但留存风险"
- 技法分 < 7.0 但留存分 ≥ 6.0 → ⚠️ Yellow，标记为"留存过关但技法不足"
- 技法原始分 25-34（技法约 5.0-6.8/10）
- 或有单项 = 2
- 或轻微节奏违规
- 或骨架局部偏离但可修复

**Yellow 处置策略**：技法问题→回润色/去AI味；留存问题→回控制卡/创作。两种问题同时存在时，优先修留存。

### Red（单轴或双轴不达标）

- 技法分 < 6.0 或 留存分 < 5.0（任一轴触底即 Red）
- 技法原始分 < 25
- 或核心维度 ≤ 1
- 或红线触发

### 自动 Red 红线

- 角色知道了不可能知道的信息
- 因果链断裂
- 承重 beat 缺失导致叙事断裂
- 情感弧完全未执行
- 上章钩子完全未回应且无理由
- 大纲语言残留超过 `2` 处
- **留存红灯 ≥ 3 项**（新增——即使技法分勉强过线，3 项以上留存红灯也直接 Red）

## 九、体裁权重调整口径

权重调整只影响从严程度，不改单维满分：

- 武侠：动作清晰度、侠义一致性更严
- 仙侠：体系一致性、尺度感更严
- 悬疑：信息控制、误导公平性、钩子悬念更严
- 言情：情感真实性、潜台词更严
- 科幻：概念清晰度、一致性更严

## 十、报告最小字段（双轴版）

章节审阅报告至少包含：

- 基本信息
- 总分与结论（含技法分 / 留存分 / 综合评分 / 留存红灯数）
- **双轴评分块**（技法评分 + 留存评分 + 平台权重 + 综合判定，独立呈现）
- 就绪判定（含判定信号 / 红牌 / 阻塞项）
- 十二维评分（技法10维 + 留存2维）
- 留存红灯清单（逐项标注已命中红灯）
- 至少两项优点
- 结构 / 逻辑类问题（writer）
- 表达类问题（polisher）
- 修改任务汇总（标注问题所属轴）
- 钩子链验证
- 骨架忠实度评估
- 情感弧检查
- 连贯性备注
- 复审记录（复审时）

## 十一、跨维度复核提醒

有些问题要一次标出多个影响面：

- 角色突然知道不该知道的信息 → 叙事逻辑 + 人物一致性
- 大段无功能描写 → 描写质量 + 节奏与张力 + 字数密度
- 对话信息倾倒 → 对话质量 + 去 AI 味
- 旧悬念遗忘 → 连贯性 + 钩子与悬念

## 红线

- 不得只给读感，不给位置和可执行建议
- 不得不区分 writer / polisher
- 不得不标问题来源层
- 不得因为文章“整体还行”就跳过钩子链和骨架忠实度
- 不得把复审做成"只核旧坑、不看新坑"

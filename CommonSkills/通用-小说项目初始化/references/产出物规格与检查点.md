## 产出物一：Agents.md（强制产出，核心产出）

- **路径**：`项目根目录/Agents.md`
- **性质**：**强制产出**。本 Skill 是否真正完成的唯一判断标准。
- **内容**：主输出平台注册 + POV 视角设置 + 项目初始化蓝皮书路径（详见 SKILL.md 中《模块八：创建项目配置文件 Agents.md》）
- **消费方**：被 `通用-创建小说正文`、`通用-章节创作闭环`、`通用-正文润色`、`通用-多平台输出编排` 等核心 Skill 自动发现

> 若 `Agents.md` 未产出，本 Skill 视为未完成。所有下游 Skill 无法自动适配平台规则。

## 产出物二：项目初始化蓝皮书（详细决策依据）

所有模块的决策依据汇总为一个统一文件：**`项目初始化/项目初始化蓝皮书.md`**。

### 文件结构（强制）

```text
# 项目初始化蓝皮书

## 1. 市场校准结论（四段式：分析过程 → 决策依据清单 → 最终决策 → 对下游输入）
## 2. 商业逻辑锚定（四段式）
## 3. 读者情绪定位（四段式）
## 4. 元设定骨架（四段式）
## 5. 套路组合方案（四段式）
## 6. 商业化埋点布局（四段式）
## 7. 可行性校验结论（四段式）
## 8. 竞对差距清单（数据矩阵式，每本竞品一行，五维对比）
## 9. 最能吸引读者和最能赚钱的小说要素清单（核心产出，四段式输出结构，详见 `references/核心产出要素清单规格.md`）
## 10. 诚实边界（所有不确定项的汇总表 + 置信度总评 + 信息缺口声明 + 反常识声明）
```

### 每章执行标准

- **① 分析过程**：不少于300字推理链。引用至少2个数据来源。对比至少1个被否决的替代方案。
- **② 决策依据清单**：列出3-5条关键依据，每条标注来源文件和置信度。
- **③ 最终决策**：一句话说清"选择了什么、放弃了什么、为什么"。
- **④ 对下游的输入**：明确本决策如何被下游 Skill 消费。
- **第9章例外**：按 `references/核心产出要素清单规格.md` 规定的表格/矩阵格式执行，不需要四段式（前8章的分析链已经是它的"分析过程"）。

### 三条红线

- ❌ **不允许多文件分散产出**。所有章节写入同一个文件。
- ❌ **不允许单章少于300字推理链**。纯列表无分析的章节视为未完成。
- ❌ **不允许决策无来源标注**。每条决策必须标注来自哪份报告、哪个竞品或哪项研究。

### 落盘位置

```text
# 强制产出（核心）
项目根目录/Agents.md

# 详细决策依据
项目根目录/项目初始化/项目初始化蓝皮书.md
```

### 初始化回溯检查（/init-check）

对已有项目做初始化回溯时，检查以下问题：

- **项目根目录 `Agents.md` 是否仍然有效？**（主输出平台是否仍然是正确的？）
- 项目当前薄弱环节位于哪一层级？（刚性约束层 / 叙事基础层 / 商业执行层 / **项目注册层**）
- 平台适配是否已过时？（平台规则/题材热度可能已变化）
- 套路组合是否需要更新？（竞品可能用了更新的手法）
- 商业化埋点是否仍然有效？（付费转化率/阅读时长等数据支撑）
- 叙事基础是否存在逻辑崩盘隐患？（力量体系/势力关系/人设一致性）

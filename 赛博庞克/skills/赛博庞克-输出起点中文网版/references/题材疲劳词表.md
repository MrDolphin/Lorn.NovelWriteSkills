# 赛博/未来题材疲劳词表

> 来源：吸收自 InkOS 科技描写原则
> 适用范围：赛博庞克题材
> 控制标准：每千字不超过 2 次

## 一级疲劳词

| 疲劳词 | 说明 | 替换方向 |
| --- | --- | --- |
| 霓虹灯 | 赛博标签一号，已被过度使用 | 写具体的光源和颜色（全息广告/荧光招牌/街边的蓝色光带） |
| 义肢/义体 | 万能改造词 | 写具体的型号、品牌、损耗或手感 |
| 黑客 | 已被泛化的职业标签 | 写具体的技术能力和操作界面 |
| 数据/信息 | 万能抽象词 | 写具体的文件格式、界面元素、传输方式 |
| 芯片植入 | 标配设定，需具象化 | 写手术体验、排斥反应、黑市渠道 |

| 防火墙 | 网络安全标配 | 写具体的防御机制（AI护卫/逻辑锁/溯源追踪） |

| 超级AI | 万能反派/助手 | 写具体的限制和动机 |

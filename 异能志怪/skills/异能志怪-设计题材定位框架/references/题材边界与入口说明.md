# 题材边界与入口说明（异能志怪）

> 格式：题材禁忌 → 专项规则 → 语言铁律 → 叙事指导 → 节奏参考
> 此为标准题材规则五节模板，所有题材的边界与入口说明均按此结构组织。

## 题材禁忌

- 无铺垫的能力觉醒：金手指必须有触发条件、成长路径与代价
- 超常元素脱离日常：异术/异能必须与现实制度、职业流程、城市空间咬合
- 混入其他题材的口径：禁止都市腔、游戏系统播报腔、轻小说吐槽腔混入志怪叙事
- 同质资源不写衰减：能力成长中重复吞噬/炼化必须写明衰减
- 用"暴涨""海量"跳过数值结算

## 专项规则

### 定位硬口径

- 优先采用"冷门职业 / 边缘身份 + 异术超能"切口，而不是空降万能挂。
- 异术必须和现实制度、职业流程、城市空间摩擦在一起长出来。
- 能力必须带代价：身体、关系、职业、名誉或心理至少命中一项。
- 金手指四维约束：能力上限、附加代价、触发条件、成长路径必须全部设定。

### 最低闭环条件

- 新鲜点应来自"职业真实感 + 超常规则 + 长线谜团"的咬合。
- 前期要更快让读者看见反常、危险与能力边界。
- 每个场景至少推进一项：信息、地位、资源、伤亡、仇恨、境界。

## 语言铁律

- **量级感用体感传达**，不用抽象数字：✗"他的火元从12缕增加到24缕" → ✓"手臂比先前有力了，握拳时指骨发紧"
- **同一高潮段中同一意象域的渲染不超过两轮**，第三轮必须切入新信息或新动作
- **清单式列举禁止**：搜尸/清点段落必须带入角色判断或取舍
- **风格统一**：志怪叙事维持民俗与神秘感，不混入都市腔或游戏腔

## 叙事指导

- 异能志怪核心驱动力是"规则驱动+事件驱动"——读者追读的动力是"了解规则与破解事件"
- 介于都市悬疑与玄幻修仙之间，兼顾案件驱动和规则驱动
- 核心组合：日常+单元案+升级打怪+爽文
- "志怪"的差异化在于：规则系统的质感、超常与现实世界的咬合度、职业入局的自然感
- 民俗规则来源（真实民俗vs架空创作）决定题材的真实性格调
- 每卷一个超常事件闭环，同时暗线推进规则认知升级

## 节奏参考

- 三章内必有明确反馈：打脸、收益兑现、信息反转、地位变化
- 修炼/悟道与战斗交替，每3-5章一次小突破或关键收获
- 单元案节奏：遭遇异常→规则探索→成本投入→代价付出→认知升级→收尾
- 能力成长线：认知新规则→实践验证→付出代价→突破瓶颈→能力升级

# 修仙/玄幻题材疲劳词表

> 来源：吸收自 InkOS `xuanhuan.md` + `xianxia.md` 语言铁律与 AI 高频词研究
> 适用范围：异能志怪、修仙玄幻题材
> 运用方式：创作时主动避开，审阅时扫描超标项
> 控制标准：每千字不超过 2 次

## 一级疲劳词（高优先级，尽量不用）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 暴涨 | InkOS 明令禁止的万能升级词 | 写具体增量或体感（从十二缕涨到十八缕/丹田胀痛欲裂） |
| 海量 | 跳过数值结算的拐杖词 | 写具体数量和负担（储物袋塞满了/炼化了三天还剩一半） |
| 难以估量 | 同上，信息量为零 | 用旁人或环境反应衬托（围观者倒吸一口凉气/地面裂了三尺） |
| 恐怖如斯 | 已被高度滥用的惊叹模板 | 删除整句，用具体后果体现 |
| 一声冷哼 | 玄幻出场标配，千篇一律 | 写具体的面部或声音细节（鼻子里挤出一声/说话声像从牙缝里出来的） |

## 二级疲劳词（中优先级，控制使用频率）

| 疲劳词 | 说明 | 替换方向 |
| -------- | ------ | --------- |
| 嘴角溢出鲜血 | 受伤描写模板化 | 写具体伤势（半条袖子被血浸透了/嘴唇上全是血口子） |
| 身形一闪 | 动作描写偷懒 | 写具体移动路径和效果（踩碎了脚下的青砖/残影还留在原地） |
| 一股强大的气息 | 抽象强度宣告 | 写具体的感官冲击（空气突然变重了/呼吸里带上了铁锈味） |
| 灵魂深处 | 万能用词 | 具体化（丹田/识海/记忆最底层的画面） |
| 无法想象 | 跳过描写的拐杖 | 直接描写读者能想象的具体画面 |

## 三级疲劳词（辅助级，仅密集出现时处理）

| 疲劳词 | 说明 |
| -------- | ------ |
| 竟然/居然 | 过度惊讶标记，每章不宜超过 2 次 |
| 突然/猛地 | 廉价转折标记，连续使用暴露节奏失控 |
| 瞬间/顷刻 | 时间标记过于频繁会削弱时间感 |
| 滔天/滔天巨浪 | 修饰过度，替换为具体规模 |
| 毁天灭地 | 夸张表达已失去冲击力 |

## 玄幻数值禁区（从 InkOS 数值规则衍生）

以下三类短语禁止出现在正文中替代数值结算：

1. **模糊增量**："暴涨""飙升""剧增" → 必须落具体数值
2. **模糊存量**："海量""海量资源""无尽" → 必须落具体批次/数量
3. **模糊比较**："远超""难以企及" → 必须可追溯验证

## 疲劳词处理原则

1. **一级词在正文中应近乎为零**。
2. **二级词每千字不超过 1 次**。
3. **三级词仅连续密集出现时才处理**。
4. **不与"数值禁区"重复执法**：数值问题是结构性问题，由 `InkOS修仙玄幻题材规则.md` 的数值规则处理。
